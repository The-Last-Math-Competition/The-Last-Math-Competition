# TLMC 00000007811: the natural inclusion has zero kernel

The Chow tautological ring R*(M_g) is a subring of A*(M_g), generated by tautological classes. The natural map to A*(M_g) is inclusion. A subring inclusion has zero kernel in every genus, contradicting the printed nontrivial-kernel clause at g=8.

This does not concern the kernel of a polynomial/strata presentation or the cycle-class map to cohomology. It does not refute Faber's Gorenstein conjecture.
