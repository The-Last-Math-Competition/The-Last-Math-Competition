\section{The conjecture}

\begin{quote}
\textit{Conjecture:} there exists an explicit matrix family whose
rigidity $R_M(r)$ (minimum number of entries to change to lower the
rank to $r$) is \emph{always} superlogarithmic in $n$; the candidates
for realization are Vandermonde and Chebyshev-type matrices.
\end{quote}

\section{The refutation}

``Always'' quantifies over every rank level --- but at $r = n - 1$
the rigidity of \emph{any} invertible matrix is exactly $1$: the
matrix determinant lemma gives
$\det(M + t\,e_i e_j^{\mathsf T}) = \det(M)\,(1 + t\,(M^{-1})_{ji})$,
so the single change $t = -1/(M^{-1})_{ji}$ annihilates the
determinant, while zero changes preserve rank $n$. Constant $1$ is
not superlogarithmic in $n$. This applies to \emph{every} invertible
matrix --- the conjecture's own candidates included (any
Vandermonde or Chebyshev-type matrix with distinct nodes is
invertible).

Certified instance, the $3\times 3$ Vandermonde at nodes $1,2,3$,
scaled by $5$:
\[
V_5 = \begin{pmatrix}5&5&5\\5&10&20\\5&15&45\end{pmatrix},\quad
\det V_5 = 875 - 625 + 125 = 250 = 125\cdot 2 \ne 0,
\]
and since $(V^{-1})_{21} = -\tfrac52$, the change $t = \tfrac25$ at
entry $(1,2)$ gives
$\det\begin{pmatrix}5&7&5\\5&10&20\\5&15&45\end{pmatrix} =
750 - 875 + 125 = 0$: \; $R_{V_3}(2) = 1$, while any
superlogarithmic bound at $n = 3$ already demands $\ge 2$. The
script verifies the same rank drop with exact rational arithmetic for
Vandermonde and Chebyshev-type matrices at $n = 3..7$.

\section{Verification}

\texttt{reproduce.py} runs exact-rational elimination: for $n =
3..7$, both candidate families are invertible and a single entry
change with $t = -1/(M^{-1})_{ji}$ lowers the rank to exactly $n-1$.
The Lean package (core Lean~4, v4.33.1) certifies the exact
cofactor expansions (with Nat-safe ordered subtractions):
\texttt{detV} ($250$), \texttt{detVmod} ($0$),
\texttt{rigidity\_is\_one}, \texttt{superlog\_exceeds} ($1 < 2$),
and \texttt{conjecture\_refuted}. All five audited theorems report
\texttt{does not depend on any axioms}.

\section{Boundary}

The kernel certifies the instance arithmetic (invertibility, the
single-change singularity, rigidity value $1$, the superlog violation
at $n = 3$); the matrix determinant lemma is classical, cited in
prose and instantiated by the script for both families at $n = 3..7$.
The universal ``for all $r$'' superlogarithmic claim is refuted; no
claim is made about rigidity at low rank levels (Valiant territory).
