## Objects and Quantifiers

We use the standard rational S-unit group: products of -1 and primes in a
finite prime set S, with arbitrary integer exponents. The source does not
explicitly restrict to a non-rational number field. Rational solutions suffice
for the standard rational interpretation and for an assertion covering all
number fields. We do not claim to cover an unstated nonstandard definition.

RatBridge.lean defines IsSUnit using nonzero rational values and the actual
reduced numerator/denominator prime supports. GeneratedUnits.lean defines
unitGroup as the subgroup of rational units generated by -1 and the primes
in S, and proves that the constructed fractions belong to that subgroup.
Thus the counterexample also uses literal generated S-units, independently
of a support-predicate naming convention.

Solutions and GeneratedSolutions contain ordered pairs of these actual
rational numbers satisfying x+y=1. Every witness has positive coordinates,
so is nonzero and nondegenerate. Supports need only be subsets of S.

## Complete Counterexample Chain

CoprimePairs.lean counts every ordered coprime pair in [1,N] squared and
proves N^2 <= 4 times that count for every natural N, not only tested values.
RatBridge.lean proves that (a/(a+b), b/(a+b)) is a genuine supported solution
and that reduced-fraction uniqueness makes the map injective on these pairs.
Final.lean transfers the exact cardinality to witnessSolutions.

PrimeBound.lean sets N(m)=2^(2m) and primeSet(m) to all primes up to 2N(m).
The primorial bound proves m times the support cardinality <= 6N(m).
Combining the two bounds gives a solution/support-square ratio at least
m^2/144, which is unbounded. every_constant_is_exceeded quantifies over
every real C and selects a positive natural m; the conclusion is a strict
inequality for a finite set of actual solutions.

UniformQuadraticBound and GeneratedUniformBound assert that every finite
subset of the respective true solution set obeys the same absolute bound.
If the full solution count obeyed the source claim, every finite subset
would obey it. no_uniform_quadratic_bound and
no_generated_unit_quadratic_bound negate these statements without assuming
that the full solution set has already been enumerated or proved finite.
All counterexample supports are finite sets of actual primes.
