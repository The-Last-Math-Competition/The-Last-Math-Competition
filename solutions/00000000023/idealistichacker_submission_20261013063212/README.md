# A counterexample to conjecture 00000000023

The conjecture claims an absolute quadratic bound in the size of the finite
prime support for solutions of `x + y = 1` in S-units. This submission gives a
fully explicit rational family whose number of distinct solutions divided by
the square of the support size is unbounded.

For `N >= 1`, take every coprime pair `1 <= a,b <= N` and map it to
`(a/(a+b), b/(a+b))`. The fractions are nonzero rational S-units for the finite
support `S_N = {p prime | p <= 2N}`, and the map is injective. A finite divisor
union bound gives at least `N^2/4` coprime pairs. For `N = 2^(2m)`, an
elementary primorial estimate gives `m * |S_N| <= 6N`; hence the ratio of this
finite solution set to `|S_N|^2` is at least `m^2/144` and is unbounded.

The Lean project formalizes the actual rational numerators/denominators and
the subgroup generated by `-1` and the primes in S. It proves the finite
coprime-pair bound, prime-support estimate, injective solution construction,
and the negation of every absolute quadratic bound. It does not use PNT,
floating point estimates, a hard-coded Boolean, or an assumed conclusion.
