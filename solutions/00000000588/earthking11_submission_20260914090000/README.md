# Disproof of conjecture `00000000588`

**Verdict: FALSE.**

This submission disproves conjecture `00000000588` as stated. The refutation is
unconditional, completely elementary, and consists of one explicit
counterexample together with the correct closed form:

```
t(<n, n+1, ..., 2n-1>) = n - 1      (n >= 2),
```

which equals the conjectured `ceil(n/2)` only at `n = 2` and `n = 3`. The
smallest counterexample is `n = 4`:

```
S = <4,5,6,7>,   Ap(S,4) = {0,5,6,7},   t(S) = 3  !=  2 = ceil(4/2).
```

The value `t = 3` is not merely computed: it is formalised in Lean 4 with a
self-contained, **import-free**, **axiom-free** proof (`lean4/Main.lean`).

## Definitions and conventions

We pin every notion appearing in the statement.

- **Numerical semigroup.** A submonoid `S ⊆ ℕ` under addition with finite
  complement `ℕ \ S`. For `A ⊆ ℕ`, `<A>` is the submonoid generated by `A` (all
  finite sums, including the empty sum `0`).
- **Interval semigroup.** `S_n = <n, n+1, …, 2n-1>` for `n ≥ 1`.
- **Multiplicity.** `m(S) = min(S \ {0})`, the smallest positive element. For
  `S_n` this is `n`.
- **Apéry set.** For a numerical semigroup `S` and `m ∈ S \ {0}`,
  ```
  Ap(S, m) = { s ∈ S : s - m ∉ S },
  ```
  with `s - m` computed in `ℤ` (so `0 ∈ Ap(S,m)`, as `-m ∉ S`). This
  submission uses the standard convention `m = m(S)` (the multiplicity); the
  robustness section records that the verdict does not depend on this choice.
- **Apéry order.** `x ≤_S y  ⟺  y - x ∈ S`; strict part
  `x <_S y  ⟺  x < y and y - x ∈ S`. A **maximal Apéry element** is an element
  of `Ap(S,m)` maximal for `≤_S` restricted to it.
- **Type.** `t(S)` = the number of maximal Apéry elements.

**Cross-check.** The maximal Apéry elements are in bijection with the
pseudo-Frobenius numbers `PF(S) = { x ∉ S : x + s ∈ S for all s ∈ S \ {0} }`,
via `x ↦ x - m`; equivalently `t(S) = |PF(S)|`.

## The counterexample `n = 4`

Let `S = <4,5,6,7>`, with multiplicity `4`.

**Step 1 — the semigroup is a tail.** `S = {0} ∪ [4, ∞)`. Indeed every
generator is `≥ 4` and `0` is the empty sum, giving `⊆`; conversely, strong
induction on `m ≥ 4`: if `4 ≤ m ≤ 7` then `m` is a generator, and if `m ≥ 8`
then `m - 4 ≥ 4` is in `S` by induction, so `m = 4 + (m-4) ∈ S`.

**Step 2 — the Apéry set is `{0,5,6,7}`.** Testing each `s ∈ S`:
`s = 0` gives `0 - 4 = -4 ∉ S`, so `0 ∈ Ap(S,4)`; `s = 4` gives `4 - 4 = 0 ∈ S`,
so `4 ∉ Ap(S,4)`; `s ∈ {5,6,7}` gives `s - 4 ∈ {1,2,3}`, and `1,2,3 ∉ S`, so
`5,6,7 ∈ Ap(S,4)`; `s ≥ 8` gives `s - 4 ≥ 4 ∈ S`, so `s ∉ Ap(S,4)`. Therefore

```
Ap(S,4) = {0, 5, 6, 7}.
```

**Step 3 — incomparability.** The nonzero Apéry elements are `5, 6, 7`; their
pairwise differences are

```
6 - 5 = 1,   7 - 6 = 1,   7 - 5 = 2,
```

and `1, 2 ∉ S`. Hence for any two distinct `x, y ∈ {5,6,7}` with `x < y` we
have `y - x ∈ {1,2} ∉ S`, so `¬(x <_S y)`: the three are **pairwise
incomparable** and each is maximal. Meanwhile `0` is not maximal, because
`0 <_S 5` (`5 - 0 = 5 ∈ S`).

**Conclusion.** The maximal Apéry elements are exactly `{5,6,7}`, so

```
t(S) = 3,    whereas    ceil(4/2) = 2.
```

The conjecture fails at `n = 4`.

## The true closed form

**Theorem.** For every `n ≥ 2`, with `S_n = <n, n+1, …, 2n-1>`,

```
S_n = {0} ∪ [n, ∞),     Ap(S_n, n) = {0} ∪ {n+1, n+2, …, 2n-1},
```

the `n-1` elements `n+1, …, 2n-1` are pairwise incomparable (hence maximal),
`0` is not maximal, and therefore

```
t(S_n) = n - 1.
```

**Proof.** *Semigroup:* every generator lies in `[n, 2n-1] ⊆ [n,∞)` and `0` is
the empty sum; conversely any `m ≥ n` is a generator when `m ≤ 2n-1`, and for
`m ≥ 2n` the number `m - n ≥ n` is in `S_n` by strong induction, so
`m = n + (m-n) ∈ S_n`. *Apéry set:* test `s ∈ S_n = {0} ∪ [n,∞)`: `s = 0` has
`-n ∉ S_n`; `s = n` has `s - n = 0 ∈ S_n`; `n+1 ≤ s ≤ 2n-1` has
`s - n ∈ [1, n-1]`, which contains no element of `S_n`; `s ≥ 2n` has
`s - n ≥ n ∈ S_n`. *Maximality:* for distinct `x, y ∈ {n+1,…,2n-1}` with `x < y`,
`1 ≤ y - x ≤ n - 2 < n`, and `S_n` has no elements in `[1, n-1]`, so
`¬(x <_S y)`; `0 <_S n+1` since `n+1 ∈ S_n`. *Count:*
`t(S_n) = (2n-1) - (n+1) + 1 = n - 1`. ∎

**Agreement.** `n - 1 = ceil(n/2)` iff `n ∈ {2,3}`: for `n ≥ 4`,
`n - 1 - ceil(n/2) = floor((n-2)/2) ≥ 1`.

## Robustness

We tried to save the conjecture by varying each convention; none succeeds.

**Choice of Apéry modulus.** The type is independent of the nonzero modulus.
For `n = 4` and each `m ∈ {4,5,6,7,9,13}` we computed
`Ap(S,m) = {s ∈ S : s - m ∉ S}` and its maximal elements:

| modulus `m` | `Ap(S,m)` | maximal elements | count |
|:-----------:|:----------|:-----------------|:-----:|
| 4  | `{0,5,6,7}`              | `{5,6,7}`     | 3 |
| 5  | `{0,4,6,7,8}`            | `{6,7,8}`     | 3 |
| 6  | `{0,4,5,7,8,9}`          | `{7,8,9}`     | 3 |
| 7  | `{0,4,5,6,8,9,10}`       | `{8,9,10}`    | 3 |
| 9  | `{0,4,5,6,7,8,10,11,12}` | `{10,11,12}`  | 3 |
| 13 | `{0,4,…,12,14,15,16}`    | `{14,15,16}`  | 3 |

Every modulus gives **3** maximal elements, and the maximal set is always the
translate by `m` of `PF(S) = {1,2,3}` (e.g. `{5,6,7} - 4 = {6,7,8} - 5 =
{1,2,3}`). The pseudo-Frobenius numbers are `PF(4) = {1,2,3}`, of size `3`,
matching `t`.

**Rounding conventions.** All natural readings of `n/2` give `2` at `n = 4`:
`ceil(4/2) = 2`, `floor(4/2) = 2`, `round(4/2) = 2`. Since `t = 3`, none of
them saves the claim. (At `n = 5` likewise `t = 4` while every rounding of
`5/2` is `2` or `3`.)

**Other readings.** The conjecture is a universally quantified closed-form
identity, not an asymptotic or an inequality, so there is no free constant or
error term to adjust. Either `t(S_n) = ceil(n/2)` for all `n` (it does not:
`n = 4`) or the conjecture is false.

## Reproducing

Python (dependency-free, runs in well under a second):

```sh
python3 reproduce.py
```

For each `n`, membership in `S_n` is computed by exact dynamic programming
(unbounded coin change), `Ap(S_n, n)` is formed, maximal elements are found
under the Apéry order, and `t` is compared with `ceil(n/2)`. It prints `PASS`
and exits `0` exactly when every check holds (including `t(4) = 3 ≠ 2` and
`t = n - 1` for all `n ≥ 2`).

LaTeX document:

```sh
tectonic --outdir build main.tex
```

Lean 4 project:

```sh
cd lean4
lake build
lake env lean Check.lean
```

`lake build` exits `0`; `Check.lean` prints `#print axioms` for every theorem
and reports no `sorryAx`. The main theorems `counterexample_n4`,
`counterexample_n5`, `t_eq_3`, `t_ne_two`, `conjecture_holds_n3` depend on
**no axioms**; the structural lemmas only on the core axioms `propext` and
`Quot.sound`.
