# Disproof of TLMC conjecture 00000000591 (v2: the limit statement, formalized)

**Verdict: FALSE.**

## The conjecture, quoted verbatim

From `conjectures/00000000591.md` (first paragraph, definition sentence quoted
word for word):

> Definition: Wilf's conjecture. Conjecture: e·n(S) ≥ g(S) + e (n(S) the number
> of nongaps, g the Frobenius number). New-direction conjecture: on
> embedding-dimension-3 semigroups the ratio of the surplus e·n(S) − g(S) − e
> to g tends to 0, with an explicit convergence rate.

(中文原文：「定义：Wilf。猜想：e·n(S) ≥ g(S) + e(n(S) 为非隙数,g 为 Frobenius
数)。新方向猜想:嵌入维 3 半群上盈余 e·n(S) − g(S) − e 与 g 的比值趋于 0,且
收敛速率显式。」)

**Correspondence declaration.** Throughout, S ranges over numerical semigroups;
e = e(S) is the embedding dimension; g = g(S) is the Frobenius number (the
conjecture's own notation — here `g` is **not** the genus); n = n(S) is the
number of nongaps **in `[0, g]`**, i.e. `n(S) = #{s ∈ S : 0 ≤ s ≤ g(S)}` (this
is the standard reading of Wilf's inequality and the reading of the v1 review:
"n(S) = nongaps in [0, g(S)]"); surplus = e·n(S) − g(S) − e. Every object of
this submission is an embedding-dimension-3 numerical semigroup of exactly this
kind — v1's four isolated instances are replaced by an explicit **infinite**
family whose members are certified as genuine semigroups by exhaustive search
(see "Anchoring" below and `reproduce.py`).

## The explicit infinite family

For every `k = 0, 1, 2, …` put `r_k = 6k + 5` (coprime to 6, so `6, 2r_k, 3r_k`
are pairwise coprime) and

    S_k = ⟨6, 2·r_k, 3·r_k⟩  =  ⟨p·q, p·r_k, q·r_k⟩  with (p, q, r) = (2, 3, 6k+5).

Each `S_k` is a complete-intersection numerical semigroup (gluing of ⟨2⟩, ⟨3⟩,
⟨r_k⟩), hence symmetric, with embedding dimension exactly 3 (no generator is
generated by the other two). For complete intersections of this shape the
Frobenius number has the closed form

    g_k = 2pqr − pq − pr − qr = 42k + 29,

and symmetry gives `n_k = (g_k+1)/2 = 21k + 15` nongaps on `[0, g_k]`, so the
Wilf surplus at e = 3 is

    surplus_k = 3·n_k − g_k − 3 = 21k + 13,        ratio_k = surplus_k / g_k.

Since `ratio_k = (g_k − 3)/(2g_k) = 1/2 − 3/(2g_k)` and `g_k ≥ 29 > 9`:

* `ratio_k ≥ 1/3` for **every** k, and
* `ratio_k → 1/2` (monotone from above).

The new-direction claim "surplus/g → 0 on embedding-dimension-3 semigroups" is
therefore false, and maximally so: the ratio stays near its universal ceiling
1/2. `reproduce.py` verifies all four closed formulas **by exhaustive
enumeration** of `S_k` for every k ≤ 300 and spot checks up to k = 100 000
(e.g. g = 4 200 029, n = 2 100 015, ratio = 0.49999996), verifies
`gcd(surplus_k, g_k) = 1` along the family, and verifies the same formulas on
the prime triples (2,3,5), (2,3,7), (2,5,7), (3,5,7):
ratios 13/29 ≈ 0.448, 20/43 ≈ 0.465, 39/81 ≈ 0.481, 68/139 ≈ 0.489 — all ≥ 1/3
and → 1/2.

## What the Lean project formalizes (`lean4/`, core Lean 4.33.1, no Mathlib)

The main theorem `main` is the discretized negation of the vanishing claim:

    ∃ ε : Rat, qzero < ε ∧ ∀ N : Nat, ∃ k : Nat, N ≤ k ∧
      ε.den * ratioNum k ≥ ε.num.natAbs * ratioDen k

* `ε = third = 1/3` (exact ℚ); `qzero` is the rational 0; `ε.num.natAbs = ε.num`
  because ε's numerator is positive (`third.num = 1`).
* `ratioNum k = surplus_k = 21k+13`, `ratioDen k = g_k = 42k+29`.
* The member inequality `ε.den·surplus_k ≥ ε.num·g_k` is the **exact
  cross-multiplied form** of `ε ≤ surplus_k/g_k` — both denominators are
  positive (`third.den = 3`, `g_k ≥ 29`, and `gcd(surplus_k, g_k) = 1` along the
  family, verified in `reproduce.py`: a common divisor divides `2·surplus_k −
  g_k = 3`, and `surplus_k ≡ 1 (mod 3)`). The witness is `k = N`: members far
  out in the family keep violating any decay-to-0 rate.

Supporting formalized facts (all with zero axioms, zero `sorry`):

* `wilf_relation` — `3*n_k = g_k + surplus_k + 3` (the defining Wilf relation).
* `exact_identity` — `2*surplus_k*g_k = (g_k − 3)*g_k`, i.e.
  `surplus_k/g_k = (g_k − 3)/(2g_k)`; `frob_ge_nine` — `g_k ≥ 9`.
* `third_le_ratio_zero`, `third_le_ratio_one` — on the concrete members `S_0`,
  `S_1` the ℚ-order statement **`1/3 ≤ ratio_k` itself** (as ℚ values, by
  definitional reduction of the rational order on the ground values 13/29,
  34/71).
* Anchoring certificates (no object substitution): for `S_0 = ⟨6,10,15⟩` the
  exhaustive search certifies `29` is a gap and `30…35` are nongaps (so `29` is
  exactly the Frobenius number) with exactly `15` nongaps on `[0,29]`; likewise
  `S_1 = ⟨6,22,33⟩` with Frobenius number `71` and `36` nongaps on `[0,71]`.
  These match the closed formulas at `k = 0, 1`.

**Note on the shape of the symbolic inequality.** In core Lean 4.33.1 (no
Mathlib) the order on ℚ is decided by a boolean cross-multiplication on the
`num/den` fields, and core `Rat` literals (`0`, `OfNat` instances) carry
`propext`/`Quot.sound` through their `by decide` coprimality fields. The main
theorem therefore (a) uses a ground-constructed ε = 1/3 and rational 0, and
(b) states the symbolic member inequality in the equivalent exact cross-multiplied
ℕ form; the ℚ-order form itself is formally proved on ground members
(`third_le_ratio_zero/one`). The fraction `(surplus_k, g_k)` is reduced for
every k, so cross-multiplication is order-exact.

## What remains true

* Wilf's inequality itself (`e·n(S) ≥ g(S) + e`) holds on every member here:
  e.g. `3·15 = 45 ≥ 29 + 3`. The disproof targets only the new vanishing-rate
  direction attached to it.
* The pairing bound `n ≤ (g+1)/2` shows `surplus/g ≤ (g−3)/(2g) < 1/2` for every
  numerical semigroup of embedding dimension 3; the symmetric family above
  attains the ceiling, so 1/2 is the exact asymptotic supremum of the ratio and
  the conjectured limit 0 fails in the strongest possible way.
