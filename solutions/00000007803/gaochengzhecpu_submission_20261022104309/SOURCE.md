# 00000007803

**English.** Definition: A zero-one type extreme value law: the ratio of the maximal norm M_n = max_{i<=n}|X_i| of an isotropic log-concave sequence X_i to sqrt n. Conjecture: The distribution of M_n/sqrt n minus c_n converges to a Gumbel-type extreme value law, with normalization c_n = sqrt(2 log n)/sqrt n and correction term (log log n)/sqrt(2 log n) times n^{-1/2}; the Gumbel scale parameter is an explicit function of L_K, and the product of the extreme exponent with the thin-shell constant is the universal constant 1/sqrt 3. (Gumbel law for maximal log-concave norms)

**中文。** 定义：0-1 型极端值律：迷向 log-concave 列 X_i 的最大范数 M_n=max_{i≤n}|X_i| 与 √n 之比。猜想：M_n/√n - c_n 的分布收敛到 Gumbel 型极值律，规范化常数 c_n=√(2 log n)/√n 的修正项为 log log n/√(2 log n)·√n^{-1}；且 Gumbel 尺度参数为 L_K 的显式函数，极值指数与薄壳常数之积恒为普适常数 1/√3。
