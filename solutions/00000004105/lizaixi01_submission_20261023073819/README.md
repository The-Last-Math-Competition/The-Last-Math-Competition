# 00000004105: incompatible necessary growth clauses at an actual star

The original source simultaneously says that motion-group growth is polynomial iff the graph is a tree and that the star-graph motion group grows strictly super-polynomially. For any consistent candidate assignment of growth functions these clauses are incompatible, since the actual four-vertex star is a tree.

The Lean proof uses Mathlib's actual starGraph, IsTree and edgeFinset (three genuine edges in the four-vertex witness), actual IsBigO polynomial growth, and an explicit quantified numerical super-polynomial condition: for every natural degree d, positive real C and cutoff N, there exists n >= N with C*n^d < f(n). The latter is not defined by logical negation; for nonnegative functions its equivalence to absence of polynomial big-O upper bounds is proved. A true IsBigO-to-eventual-envelope equivalence and simultaneous numerical cutoff yield the contradiction. A generic theorem covers every finite vertex type and star center, independently of the unspecified star order. Final statements also quantify every candidate assignment to actual four-vertex graphs and to all finite labelled graphs, including natural count functions. No growth value is assigned from the desired contradiction.

Scope: this is a universal necessary-clause obstruction, not a computation of any configuration-space fundamental group or growth function. The source leaves the particle number and configuration conventions unspecified; any consistent actual growth assignment satisfying both source clauses is nevertheless among the universally quantified candidates. No claim that tree motion groups are trivial is used. No separate sub-exponential classification, minimality theorem or corrected conjecture omitting either incompatible clause is claimed.
