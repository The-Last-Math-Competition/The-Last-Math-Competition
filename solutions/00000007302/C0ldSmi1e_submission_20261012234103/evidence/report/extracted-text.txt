3 The obstruction to density
For a convex set B in a real vector space, an extreme point x ∈ B is a point such that if x lies in
the open segment between a,b ∈ B, then a = b = x. We use Mathlib’s actual Set.extremePoints
predicate.
Lemma 2. In any nontrivial real normed space, every extreme point of the closed unit ball belongs
to the unit sphere.

The point x is the midpoint of the two distinct ball points x+y and x−y, so it is not extreme.
Every extreme point already has norm at most one, and therefore has norm exactly one.
Theorem 1. For the nuclear ball B = {x ∈ T : ν(x) ≤ 1},
0 ∈ B, 0 ∈/ ext(B), B 6⊆ ext(B).
In particular, the extreme points are not dense relative to B.
Proof. Lemma 2 puts all extreme points on the unit sphere of the nuclear norm. That sphere is
closed, so it contains the closure of those extreme points. The zero tensor belongs to the ball and
has norm zero, so it is outside that closure.
For any S ⊆ B, density in the relative topology on B means B ⊆ S, where the closure on the
right is in T. Thus the displayed negation addresses relative density in the ball, not just density in
the whole tensor space. It does not require classifying the extreme points or proving uniqueness of
rank-one decompositions.
