\section{The conjecture}

\begin{quote}
\textit{Conjecture:} the capacity of $M_m(M_n)$ (maximal dimension of a
linear subspace on which the determinant vanishes identically) is
$(m-1)n^2 + n$.
\end{quote}

\section{The refutations}

\textbf{Case $m = n = 1$.} $M_1$ is the scalars and $\det(\lambda) =
\lambda$, so the only linear subspace with identically vanishing
determinant is $\{0\}$: capacity $0$, while the formula gives
$(1-1)\cdot 1 + 1 = 1 \ne 0$.

\textbf{Case $m = n = 2$.} $M_2(M_2) = M_4$; the $12$-dimensional subspace
of matrices with last row zero consists of matrices of rank $\le 3 < 4$,
so the determinant vanishes identically on it. Capacity $\ge 12$, formula
$(2-1)\cdot 4 + 2 = 6$; $12 > 6$.

\section{Verification}

\texttt{reproduce.py} checks both cases (the second with the zero-row
structure). The Lean package (core Lean~4, v4.33.1) certifies the five
arithmetic statements, all \texttt{does not depend on any axioms}; the
structural facts are classical and cited.

\section{Boundary}

Only the capacity formula is refuted; the orbit-classification clause is
not addressed.
