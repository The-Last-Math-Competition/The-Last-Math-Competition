# Disproof of Conjecture 00000003904

For every positive d, the actual one-variable Veronese ring F2[X^d] has dimension one and actual e-th Frobenius pushforward free of rank 2^e. Its normalized maximal splitting counts and F-signature are exactly one, contradicting the proposed d^-1 asymptotic for every correction constant and genuine O(d^-2) remainder.

## Scope

Uses the permitted n=1 case over the perfect field F2 and refutes the asymptotic clause. The strong F-regularity clause is not refuted. Uses the standard graded F-signature definition; no Lean localization-comparison theorem is claimed.

The maximal free-summand rank is defined by actual split linear injections and retractions, with both attainment and an upper bound from the strong rank condition. Actual Krull dimension is proved one using the polynomial PID and field dimension. The actual normalized splitting-count sequence converges to one, and Mathlib IsBigO and uniqueness of limits exclude the stated asymptotic. Singh 2004 page 1 supplies the standard graded F-signature definition; no F-signature computation theorem is assumed.
