# 00000008412

**English.** Definition: A difference set (v,k,lambda) is a k-element subset D of a group G of order v such that every nonidentity element has exactly lambda representations in D - D. Conjecture: The multiplier group of a difference set always contains the prime part of the numerical multiplier group; non-numerical multipliers exist if and only if the difference set coexists with a (16,6,2) type exception or its index-2 extension; and the attainable spectrum of multiplier group orders is the set of products of prime powers. (complete spectrum of difference set multipliers)

**中文。** 定义：差集 (v,k,λ) 指 v 阶群 G 中使每个非单位元恰有 λ 种方式表为 D−D 的 k 元子集 D。猜想：差集的乘子群恒含数值乘子群的素数部分；非数值乘子的存在当且仅当差集与某个 (16,6,2) 型例外或其指数 2 扩张共存；乘子群的阶的可达谱为素数幂的乘积集。（差集乘子完全谱）
