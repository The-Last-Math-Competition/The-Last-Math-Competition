Main result
-----------
Sequence214.not_eventually_negative_third takes:
  f : Nat -> Real
  hzero : forall n, 0 <= f n
  hunbounded : forall C : Real, exists n, C < f n
  hno_affine_lower : forall a : Real, 0 < a -> forall b : Real,
    exists n : Nat, f n < b + a * (n : Real)
and proves the impossibility of a tail with
  f(n+3) - 3*f(n+2) + 3*f(n+1) - f(n) < 0.

Sequence214.not_eventually_nonpos_third proves the stronger conclusion where
the tail condition uses <= 0. A full-sublinear corollary is also included.

Proof idea
----------
On a tail with nonpositive third differences, second differences decrease.
If a second difference were negative, first differences on that tail would
decrease. A nonnegative sequence with decreasing first differences must have
nonnegative first differences: any negative first difference gives a negative
affine upper bound far enough out. The same negative second difference would
then force those nonnegative first differences eventually negative. Thus all
second differences on the original tail are nonnegative. First differences
therefore increase. A positive first difference would give a positive affine
lower bound on the tail; nonnegativity absorbs the finite initial prefix to
give a global affine lower bound. Thus first differences are nonpositive and
the tail decreases. The finite prefix and decreasing tail give a global upper
bound, contradicting unboundedness.
