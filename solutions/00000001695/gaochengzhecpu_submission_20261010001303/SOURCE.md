# 00000001695

**English.** Definition: The prime-time average A_N = (1/N)Σ_{p≤N}f(T^p x). Conjecture: For badly approximable polynomial phases T, |A_N − ∫f dμ| ≤ C·(log log N)/(√N·log N); the convergence exponent 1/2 is optimal.

**中文。** 定义：素数时刻平均 A_N=(1/N)Σ_{p≤N}f(T^p x)。猜想：对 badly-approximable 多项式相位 T,|A_N−∫f dμ| ≤ C·(log log N)/(√N·log N);收敛指数 1/2 为最优。
