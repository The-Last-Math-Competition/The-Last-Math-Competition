## Mathematical argument and statement alignment

Define s(1) = 3, s(3) = 1, and s(n) = n otherwise. Case analysis gives
s(s(n)) = n for every natural n. This implies injectivity (apply s to an equality
s(a) = s(b)) and surjectivity (s(b) is a preimage of b). The displacements are
2 at 1 and 3, and 0 elsewhere. The positive divisors of 2 are 1 and 2, so 2 is
prime. Also s(1) != 1, so this solution is not the identity.

Definitions are explicit in Lean:

- `Prime p` means `2 ≤ p` and every positive divisor of p is 1 or p.
- `absDiff a b = (a - b) + (b - a)` uses **both** directions of truncated
  natural subtraction. `absDiff_piecewise` proves it equals b-a when a ≤ b
  and a-b otherwise, so it is the ordinary absolute difference.
- `IsBijection f` contains both injectivity and surjectivity on the entire
  domain. `AllowedDisplacements f` quantifies over **every** natural input.
- Lean's Nat includes 0, but s(0) = 0 and s preserves positive inputs. The file
  also proves the original property, with a nonidentity witness, on the subtype
  `PositiveNat = {n : Nat // 0 < n}`. Either convention for N is covered.

## Reproduce

From this submission directory, with the pinned toolchain installed and lake
on PATH:

```text
python reproduce.py
```
Or supply the Lake executable explicitly. In PowerShell, for the coordinator's
tool installation (replace the example path):

```powershell
python reproduce.py --lake 'C:/path/to/lean-4.33.1-windows/bin/lake.exe'
```
The script works from other working directories too, because it resolves its
own location. It prepends the selected binary directory to the **child process**
PATH only; it does not modify system PATH or require global installation.

The full run performs:

1. Source/configuration preflight, including toolchain pin and forbidden-token scan.
2. Finite regression on n = 0..10000 inclusive, the 65 x 65 absolute-difference
   grid, small primality examples, and three large-integer samples.
3. Actual Lean version verification, then `lake build`.
4. `lake env lean -DwarningAsError=true Main.lean`: direct source replay,
   not only reliance on an existing incremental build.
5. `lake env lean -DwarningAsError=true Check.lean`: all 17 dependency audits
   must say `does not depend on any axioms`. Missing/nonempty audits fail.
6. Verification that the generated Lake manifest has no external packages.

A command failure, missing toolchain, version mismatch, or failed check causes
a nonzero exit status. There is no silent fallback to finite testing. To
intentionally run only the finite regression and preflight:

```text
python reproduce.py --regression-only
```
That mode prints **PARTIAL** and explicitly says Lean was not run. **Finite
enumeration is regression testing, not a proof about all natural numbers.**
The infinite results are established by the Lean theorems.

Manual proof checks, from `lean4/`:

```text
lake build
lake env lean Main.lean
lake env lean Check.lean
```
