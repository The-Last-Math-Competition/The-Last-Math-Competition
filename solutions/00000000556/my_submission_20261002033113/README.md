# Disproof of TLMC conjecture 00000000556

**Verdict: FALSE.**

## The conjecture

> HH¹(Λ) = 0 if and only if Λ is representation-finite and rigid
> (a rigidity characterization by trivial first Hochschild cohomology,
> claimed to be verified for string algebras).

## The attack

Take the **dual numbers** Λ = k[x]/(x²) over any field k (basis 1, x; x² = 0).

1. **Λ is representation-finite.** A Λ-module is a vector space V with a
   nilpotent endomorphism T satisfying T² = 0. Over an algebraically closed
   field such pairs decompose into Jordan blocks of size ≤ 2, so the only
   indecomposable modules are k and Λ — two of them.

2. **Λ is rigid (self-injective).** The linear form λ(a + b·x) = b has
   bilinear form B(u, v) = λ(u·v) with matrix [[0, 1], [1, 0]], determinant
   −1 (resp. 1 in characteristic 2) — never 0. So Λ is Frobenius, hence
   self-injective. (Also Ext¹_Λ(Λ, Λ) = 0 trivially, Λ being projective over
   itself.)

3. **HH¹(Λ) ≠ 0.** A k-derivation d satisfies d(1) = 0 and, from
   d(x²) = 0 = 2x·d(x), the value d(x) may be any v with 2xv = 0. For
   char k ≠ 2 this forces d(x) ∈ (x), so Der_k(Λ) ≅ k, generated by
   d = x·∂ (d(1) = 0, d(x) = x); for char k = 2 the constraint is vacuous and
   Der_k(Λ) ≅ k². In both cases the inner derivations vanish because Λ is
   commutative, so

   HH¹(Λ) = Der/Inn ≅ k (char ≠ 2), resp. k² (char 2) — **nonzero**.

## Conclusion

Λ is representation-finite and rigid, yet HH¹(Λ) ≠ 0. The "if" direction
(representation-finite + rigid ⟹ HH¹ = 0) fails; the conjecture's
iff is **false**.

## Boundary conditions

* **Characteristic.** The attack works over every field: HH¹ ≅ k for
  char ≠ 2 and HH¹ ≅ k² for char = 2 — nonzero either way — and even over ℤ.
* **Meaning of "rigid".** The verdict adopts the self-injectivity reading,
  which Λ satisfies (Frobenius). Two alternative readings under which Λ would
  *not* be rigid, and this particular attack would not apply:
  - deformation-rigidity (HH² = 0): the 2-periodic bimodule resolution of
    k[x]/(x²) (differentials x⊗1 − 1⊗x and x⊗1 + 1⊗x) gives HH² ≅ Λ/(x) ≅ k ≠ 0;
  - "every indecomposable module is rigid": Ext¹(k, k) ≅ k ≠ 0 via the
    nonsplit extension 0 → (x) → Λ → k → 0.
* **Failure direction.** Only the ⟸ direction is refuted; no claim is made
  about the ⟹ direction.
