# 00000008872

**English.** Definition: The atomic weight of all-small combinatorial games: the integer-level invariant of equivalence classes all of whose options are number games. Conjecture: Atomic weight together with the number part forms a complete invariant of all-small equivalence — two all-small games are equivalent if and only if both weight and number part agree; the value spectrum of weights is all integers, each realized by infinitely many non-isomorphic all-small games; weight addition under disjunctive sums adds by elementary terms with leading term exactly the maximum of the component weights; and the value of a sum of weight-balanced games is dominated by the number part with temperature never exceeding the highest subgame temperature. (atomic weight complete invariant disjunctive maximum)

**中文。** 定义：微小组合游戏的 atomic weight：一切选择余局均为数字游戏的等价类的整数层不变量。猜想：atomic weight 连同数字部分构成微小等价的完全不变量——两个微小游戏等价当且仅当其权与数字部均相同；权的取值谱为全部整数且每个整数值由无穷多个非同构微小游戏实现；权的加法在析取和下按初等项相加且主导项恰为各分量权的最大者；权平局之和的值由数字部主导且温度恒不超过子局最高温度。
