# TLMC 00000001520: the unrestricted hyperbolic Whitehead vanishing clause is false

For the actual finite cyclic group C5, the signed Whitehead class of the genuine integral group-ring unit `u = 1 - t - t^-1` is nonidentity. The group has a finite symmetric generating set and its true Cayley-walk metric satisfies the four-point hyperbolicity inequality. This refutes the printed vanishing assertion for Gromov-hyperbolic groups with no torsion-free premise on the group.

The source's parenthesis follows `Wh(Gamma)=0` in both languages. Our group has torsion. This submission does not refute the torsion-free-Gamma revision, and makes no claim about the later 2-torsion, boundary-action or Farrell–Jones clauses. The full original bilingual source is preserved in `SOURCE.md`.
