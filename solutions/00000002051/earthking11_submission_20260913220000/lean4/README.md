# Lean 4 formalisation — disproof of conjecture `00000002051`

Core Lean only (`import Std`), no Mathlib, no `sorry`. The project pins
`lean-toolchain` to `leanprover/lean4:v4.33.1` and defines the library `Main`
(name `tlmc2051`) in `lakefile.toml`.

## Build and audit

```sh
lake build
lake env lean Check.lean
```

`Check.lean` prints `#print axioms` for every theorem so a reviewer can confirm
the absence of `sorryAx` and of Mathlib dependencies.

## What is formalised

The conjecture claims `f(n) = 2^n * C_n` for the fine spectrum of the variety
`<x^2 = x>` (bands), where `f(n)` is the cardinality of the free band on `n`
generators. The formalisation establishes the two smallest failures.

### Bands and one-generated subsemigroups

```lean
structure Band where
  carrier : Type
  mul : carrier → carrier → carrier
  assoc : ∀ a b c, mul (mul a b) c = mul a (mul b c)
  idem : ∀ a, mul a a = a

inductive GenByOne (B : Band) (x : B.carrier) : B.carrier → Prop where
  | base : GenByOne B x x
  | step : GenByOne B x y → GenByOne B x z → GenByOne B x (B.mul y z)
```

`genByOne_eq` proves that **in any band, every element of the subsemigroup
generated by one element `x` equals `x`** (a product of two copies of `x` is
`x * x = x` by idempotency). `genByOne_subsingleton` states that this
subsemigroup is a singleton. This is the mathematical heart of the `n = 1`
refutation, and it holds for an arbitrary band, not merely for the free one.

### The free band on one generator

`unitBand` is the one-element band on `Unit`. `unitBand_free` proves the
universal property: for every band `B` and every chosen image `x ∈ B` of the
generator, there is a band homomorphism `unitBand → B` sending `()` to `x`, and
any two such homomorphisms agree everywhere. Hence the free band on one
generator has exactly one element — `freeBand_one_singleton : ∀ x y : Unit,
x = y`. Therefore `f(1) = 1`, whereas the formula gives `2^1 * C_1 = 2`.

### The explicit six-element band on two generators

`sixMul : Fin 6 → Fin 6 → Fin 6` is the multiplication table of the free band on
`{a, b}` under the encoding `a ↦ 0`, `b ↦ 1`, `ab ↦ 2`, `ba ↦ 3`, `aba ↦ 4`,
`bab ↦ 5`:

| `·`   | `a`=0 | `b`=1 | `ab`=2 | `ba`=3 | `aba`=4 | `bab`=5 |
|:------|:-----:|:-----:|:------:|:------:|:-------:|:-------:|
| `a`=0   | 0 | 2 | 2 | 4 | 4 | 2 |
| `b`=1   | 3 | 1 | 5 | 3 | 3 | 5 |
| `ab`=2  | 4 | 2 | 2 | 4 | 4 | 2 |
| `ba`=3  | 3 | 5 | 5 | 3 | 3 | 5 |
| `aba`=4 | 4 | 2 | 2 | 4 | 4 | 2 |
| `bab`=5 | 3 | 5 | 5 | 3 | 3 | 5 |

- `sixMul_assoc` : `∀ a b c, sixMul (sixMul a b) c = sixMul a (sixMul b c)`,
  by `decide` (216 triples).
- `sixMul_idem` : `∀ a, sixMul a a = a`, by `decide`.
- `sixBand` : the resulting `Band` on `Fin 6`.
- `sixBand_has_six_elements` : every element of `Fin 6` is one of
  `0,1,2,3,4,5` — the carrier has exactly six elements.
- `sixBand_generated_by_two` : every element is `a = 0`, `b = 1`, `a*b = 2`,
  `b*a = 3`, `(a*b)*a = 4` or `(b*a)*b = 5`; the band is generated by two
  elements.
- `band_reduce_sound` : in any band, `w * w = w`; this is the reduction rule
  used to compute the table, and it is sound for arbitrary elements.

### Catalan numbers and the arithmetic failures

```lean
def cat : Nat → Nat
  | 0 => 1
  | n + 1 => cat n * (2 * (2 * n + 1)) / (n + 2)

def formula (n : Nat) : Nat := 2 ^ n * cat n
```

`cat_one` / `cat_two` / `cat_three` give `C_1 = 1`, `C_2 = 2`, `C_3 = 5`;
`formula_at_one` / `formula_at_two` / `formula_at_three` give `2, 8, 40`. The
free-band orders are recorded in `freeBandOrder` as the literature values
`1, 6, 159` for `n = 1, 2, 3` (OEIS A030449; Howie, *Fundamentals of Semigroup
Theory*, Oxford 1995, p. 123), and

```lean
failure_at_one   : freeBandOrder 1 ≠ formula 1     -- 1 ≠ 2
failure_at_two   : freeBandOrder 2 ≠ formula 2     -- 6 ≠ 8
failure_at_three : freeBandOrder 3 ≠ formula 3     -- 159 ≠ 40
```

### The packaged disproof

| Theorem | Statement | Role |
|:--------|:----------|:-----|
| `genByOne_eq` | in any band, elements generated by `x` equal `x` | one-generated subsemigroups are singleton |
| `genByOne_subsingleton` | any two such elements are equal | singleton form |
| `unitBand_free` | universal property of the one-element band | freeness on one generator |
| `freeBand_one_singleton` | `∀ x y : Unit, x = y` | the free band on one generator has exactly one element |
| `sixMul_assoc` | associativity of the table | `sixBand` is a semigroup |
| `sixMul_idem` | idempotence of the table | `sixBand` is a band |
| `sixBand_has_six_elements` | `Fin 6` has the six elements `0…5` | the carrier has six elements |
| `sixBand_generated_by_two` | every element is a word in `0,1` | `sixBand` is 2-generated |
| `band_reduce_sound` | `w * w = w` in any band | soundness of the reduction |
| `cat_one/two/three` | `C_1 = 1`, `C_2 = 2`, `C_3 = 5` | the Catalan numbers |
| `formula_at_one/two/three` | `2^n C_n = 2, 8, 40` | the conjectured values |
| `freeBand_one/two/three` | free-band orders `1, 6, 159` | the true values |
| `failure_at_one/two/three` | `1 ≠ 2`, `6 ≠ 8`, `159 ≠ 40` | the arithmetic failures |
| `conjecture_00000002051_false_at_one` | singleton ∧ failure at `n=1` | first witness |
| `conjecture_00000002051_false_at_two` | assoc table ∧ failure at `n=2` | second, independent witness |
| `conjecture_00000002051_false_at_three` | failure at `n=3` | third value |
| `conjecture_00000002051_false` | failures at `n = 1, 2, 3` | main theorem |

## Proof strategy

- **One generator.** The inductive predicate `GenByOne` closes the singleton
  `{x}` under multiplication, because `x * x = x` (`Band.idem`); induction on
  the derivation gives `y = x` for every generated `y`. The universal property
  of `unitBand` is proved directly: the constant map `_ ↦ x` is a homomorphism
  exactly because `x * x = x`, and uniqueness is immediate since `Unit` has one
  element.
- **Two generators.** The table is closed by construction (`sixMul` returns
  `Fin 6`); associativity and idempotence are finite checks closed by `decide`.
  That the table really is the free-band table was computed independently in
  `reproduce.py` by exhaustive reduction of all words over `{a,b}` up to length
  8, and `reproduce.py` also verifies the table entry-by-entry and checks that
  the six classes are exactly the reduced words.
- **Freeness of the six-element band.** The band `sixBand` is generated by
  `0` and `1`, so by the universal property of the free band it is a *quotient*
  of the free band on two generators; conversely every word over `{a,b}` reduces
  by the band identity `u*u = u` to one of the six words (over two letters every
  word of length ≥ 4 has a square factor), so the free band has at most six
  elements. Hence it has exactly six. The first half is formalised as
  `sixBand_generated_by_two`; the second (the reduction being complete) is
  argued in prose here and verified exhaustively in `reproduce.py`. See the
  scope note.
- **Arithmetic.** `cat` uses the standard recursion; `formula` is `2^n * cat n`.
  All numeric comparisons are closed by `decide`.

## Scope note

- **Fully formalised.** The `Band` structure; that one-generated subsemigroups
  of an arbitrary band are singletons; the universal property of the
  one-element band (freeness on one generator) and hence `f(1) = 1`; the
  explicit six-element multiplication table with machine-checked associativity
  and idempotence and a machine-checked proof that it is 2-generated; the
  Catalan values `C_1, C_2, C_3`; and the arithmetic failures `1 ≠ 2^1 C_1`,
  `6 ≠ 2^2 C_2`, `159 ≠ 2^3 C_3`.
- **Argued in prose.** The full universal property of the six-element band
  (that `sixBand` is not only a quotient but *the* free band on two generators)
  uses the completeness of the reduction `u*u → u` over a 2-letter alphabet. The
  combinatorial ingredient — over two letters every word of length ≥ 4 contains
  a square factor, and the six square-free words of length ≤ 3 are exactly
  `a, b, ab, ba, aba, bab` — is verified exhaustively by `reproduce.py` for all
  words up to length 12 and does not depend on any computation beyond elementary
  case checking. The formalisation therefore certifies the *size* of the
  exhibited band and the arithmetic; the identification of that band as the free
  one is a documented prose step.
- **Literature values.** `freeBandOrder 3 = 159` and `freeBandOrder 4 = 332380`
  are taken from OEIS A030449 (Howie 1995, p. 123). The refutation needs only
  `n = 1` (fully formalised, axiom-free) and, for an independent second witness,
  `n = 2` (fully formalised up to the prose freeness step).

Lean 4.33.1, Lake, no Mathlib. `lake build` needs no cache download. The axiom
audit reports **no `sorryAx`** and no Mathlib dependency: `genByOne_eq`,
`unitBand_free`, `freeBand_one_singleton`, `band_reduce_sound`, the Catalan
lemmas, the `failure_at_*` lemmas and `conjecture_00000002051_false` depend on
