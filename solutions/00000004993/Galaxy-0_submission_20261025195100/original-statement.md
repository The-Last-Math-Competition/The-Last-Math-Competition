# 00000004993

**English.** Definition: A Spin(7) manifold is an eight-dimensional manifold with holonomy contained in Spin(7), and one asks for the attainable third Betti numbers of compact examples with vanishing first and second Betti numbers. Conjecture: The attainable values of b_3 of compact Spin(7) manifolds with b_1 = b_2 = 0 form an explicit set of odd values realized by matching twist-sum data; the minimal attainable value is the 1186 of the known example; and the parity constraint is always that b_3 + b_4 is odd. (attainable set of Spin(7) third Betti numbers)

**中文。** 定义：Spin(7) 流形：和乐含于 Spin(7) 的八维流形；一二维贝蒂数为零的紧例的三阶贝蒂数可达值。猜想：b₁=b₂=0 紧 Spin(7) 的 b₃ 可达值为显式奇数集且由解拧和的匹配数据实现；最小可达值为已知例的 1186；奇偶约束恒为 b₃+b₄ 为奇。（Spin7 三贝蒂数可达集）
