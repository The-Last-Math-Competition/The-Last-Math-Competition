# 00000002187

**English.** Definition: The size-Ramsey number R̂(P_n) of the path P_n is the minimal number of edges of a graph containing P_n. Conjecture: R̂(P_n) = (3+o(1))·n; the exactness of the constant 3 follows from the limit of Bhamidi–Hoagy–Hoarau universal networks.

**中文。** 定义：路 P_n 的 size-Ramsey 数 R̂(P_n) 指容纳 P_n 的图的最小边数。猜想：R̂(P_n) = (3+o(1))· n;常数 3 的精确性由 Bhamidi–Hoagy–Hoarau 通用网络的极限。
