# 00000001404

**English.** Definition: The smooth 4-dimensional Poincaré conjecture asks whether every smooth homology 4-sphere is diffeomorphic to S⁴. Conjecture: There exists an invariant θ of smooth homology 4-spheres, valued in a countable abelian group, additive under connected sum (θ(M#N) = θ(M) + θ(N)), with θ(S⁴) = 0; if some M has θ(M) ≠ 0, the smooth Poincaré conjecture fails.

**中文。** 定义：光滑 4 维 Poincaré 猜想问每个光滑同调 4-球是否微分同胚于 S⁴。猜想：存在光滑同调 4-球的不变量 θ,取值于可数交换群,在连通和下可加(θ(M#N)=θ(M)+θ(N)),且 θ(S⁴)=0;若存在 M 使 θ(M)≠0 则光滑 Poincaré 猜想否定。
