# Conjecture 00000008532 — Disproof and Formalization

## Problem Statement

From `SOURCE.md`:

> **English.** Definition: The Sperner number of a lattice is the size of its largest antichain. Conjecture: The Sperner number of the free distributive lattice is an explicit central correction of $\binom{n}{\lfloor n/2 \rfloor}$; the correction is of logarithmic order with always positive sign. (free distributive lattice Sperner)
>
> **中文。** 定义：格的 Sperner 数指其最大反链的尺寸。猜想：自由分配格的 Sperner 数为 $\binom{n}{\lfloor n/2 \rfloor}$ 的显式中心修正；修正项为对数级且符号恒正。（自由分配格 Sperner）

## Outcome: Disproved

**Both assertions of Conjecture 00000008532 are false** under both standard conventions for the free distributive lattice on $n$ generators:

1. **Bounded free distributive lattice $\mathrm{FD}(n)$** (allowing empty join $\bot$ and empty meet $\top$, isomorphic to the lattice of all monotone Boolean functions $f : \{0,1\}^n \to \{0,1\}$, with $|\mathrm{FD}(n)| = M(n) = 2, 3, 6, 20, 168, 7581, \dots$ for $n = 0, 1, 2, 3, 4, 5$).
2. **Unbounded free distributive lattice $\mathrm{FD}_0(n)$** (generated by $x_1, \dots, x_n$ via non-empty finite joins and meets, isomorphic to monotone Boolean functions satisfying $f(\mathbf{0}) = 0$ and $f(\mathbf{1}) = 1$, with $|\mathrm{FD}_0(0)| = 0$ and $|\mathrm{FD}_0(n)| = M(n) - 2$ for $n \ge 1$).

### Summary of Main Results

Let $w(L)$ denote the Sperner number (maximum antichain size) of a lattice $L$, let $N_n = \binom{n}{\lfloor n/2 \rfloor}$, and define the signed central corrections

$$\Delta(n) = w(\mathrm{FD}(n)) - \binom{n}{\lfloor n/2 \rfloor}, \qquad \Delta_0(n) = w(\mathrm{FD}_0(n)) - \binom{n}{\lfloor n/2 \rfloor}.$$

- **Width Invariance ($n \ge 1$):** Because $\mathrm{FD}(n) = \{\bot\} \sqcup \mathrm{FD}_0(n) \sqcup \{\top\}$ and $\mathrm{FD}_0(n)$ is non-empty for all $n \ge 1$, maximum antichain sizes coincide: $w(\mathrm{FD}(n)) = w(\mathrm{FD}_0(n))$ and $\Delta(n) = \Delta_0(n)$ for every $n \ge 1$.
- **Obstruction 1 — Failure of Always-Positive Sign at $n = 1, 2$ (and $n = 0$):**
  - At $n = 0$: $w(\mathrm{FD}(0)) = 1 = \binom{0}{0}$ so $\Delta(0) = 0$, while $w(\mathrm{FD}_0(0)) = 0$ so $\Delta_0(0) = -1 \lt 0$.
  - At $n = 1$: $\mathrm{FD}(1) \cong C_3$ and $\mathrm{FD}_0(1) \cong C_1$ are chains, so $w(\mathrm{FD}(1)) = w(\mathrm{FD}_0(1)) = 1 = \binom{1}{0}$ and $\Delta(1) = \Delta_0(1) = 0$.
  - At $n = 2$: $\mathrm{FD}(2)$ ($6$ elements) and $\mathrm{FD}_0(2) \cong B_2$ ($4$ elements) have $w(\mathrm{FD}(2)) = w(\mathrm{FD}_0(2)) = 2 = \binom{2}{1}$, so $\Delta(2) = \Delta_0(2) = 0$.
  - Complete sign classification: $\Delta(n) \ge 0$ for all $n \ge 0$, and $\Delta(n) \gt 0 \iff n \ge 3$ (likewise $\Delta_0(n) \gt 0 \iff n \ge 3$ for all $n \ge 1$).
- **Obstruction 2 — Doubly-Exponential Growth Refuting Logarithmic Order:**
  - For every subset $S \subseteq \mathcal{M}_n = \{x \in \{0,1\}^n : |x| = \lfloor n/2 \rfloor\}$, setting $f_S(x) = 1$ for $|x| \gt \lfloor n/2 \rfloor$, $f_S(x) = \mathbf{1}_{x \in S}$ for $|x| = \lfloor n/2 \rfloor$, and $f_S(x) = 0$ for $|x| \lt \lfloor n/2 \rfloor$ defines a monotone Boolean function $f_S \in \mathrm{FD}(n)$ (and $f_S \in \mathrm{FD}_0(n)$ for $n \ge 2$) satisfying $f_S \le f_T \iff S \subseteq T$.
  - Taking all subsets $S \subseteq \mathcal{M}_n$ of fixed size $\lfloor N_n / 2 \rfloor$ yields an explicit antichain of cardinality

    $$w(\mathrm{FD}(n)) \ge \binom{N_n}{\lfloor N_n / 2 \rfloor} \ge \frac{2^{N_n}}{N_n + 1} \ge 2^{2^{\lfloor n/2 \rfloor - 1}} \qquad (n \ge 2).$$

  - Consequently, for every threshold $n_0 \in \mathbb{N}$, base $B \in \mathbb{N}$, and constants $C, D \in \mathbb{N}$, there exists $n \ge n_0$ such that $\Delta(n) = \Delta_0(n) \gt C B^n + D$. In particular, $\Delta(n)$ is not $O(\log n)$ (nor polynomial, nor singly exponential). Combined with Kleitman's upper bound on Dedekind numbers, it is $\log_2 w(\mathrm{FD}(n)) = \bigl(1 + o(1)\bigr)\binom{n}{\lfloor n/2 \rfloor}$, rather than $w(\mathrm{FD}(n))$ itself, that scales like $\binom{n}{\lfloor n/2 \rfloor}$.

## Package Structure

- `SOURCE.md` — Original conjecture statement (unmodified).
- `main.tex` / `main.pdf` — Self-contained mathematical paper proving all structural results, exact small-$n$ evaluations, and doubly-exponential lower bounds.
- `verify.py` — Standalone Python 3.12 verification script (standard library only) computing certified exact widths for $0 \le n \le 5$ via Hopcroft–Karp matching and König–Dilworth dual chain partitions, checking the Lean bitmask certificates, and verifying middle-slice antichains and doubly-exponential bounds up to $n = 10$.
- `lean/` — Core Lean 4.19.0 formalization (`leanprover/lean4:v4.19.0`, `-DwarningAsError=true`, zero external dependencies, zero `sorry`/`admit`/`native_decide`, zero custom axioms):
  - `SpernerFD/Basic.lean` — Duplicate-free lists, Boolean cube `Cube n`, weight layers, fixed-size sublists, and binomial growth bounds.
  - `SpernerFD/Lattice.lean` — Bounded and unbounded free distributive lattices `FD n` and `FD0 n`, distributivity, Shannon decomposition, categorical universal property of `FD n`, and Dedekind enumerations.
  - `SpernerFD/Antichain.lean` — Constructive Sperner number `spernerFD` and `spernerFD0`, maximum-antichain characterization, Dilworth chain-cover certificate, width invariance `spernerFD0_eq_spernerFD`, and elementary conjunction embedding `centralBinom_le_spernerFD`.
  - `SpernerFD/SmallN.lean` — Certified exact Sperner numbers for $n = 0, 1, 2, 3$ and rank-$8$ lower bound $w(\mathrm{FD}(4)) \ge 24$.
  - `SpernerFD/Main.lean` — Middle-slice antichain construction, doubly-exponential lower bounds, exact sign classification $\Delta(n) \gt 0 \iff n \ge 3$, refutations of always-positive sign (`not_always_positive_FD_pos_n`), refutations of logarithmic/polynomial/exponential order (`not_logarithmic_order_FD`, `not_logarithmic_order_FD0`), and master refutations (`conjecture_00000008532_false_FD`, `conjecture_00000008532_false_FD0`).
- `verification/` — Build and audit logs (`lake-build.log`, `lean-axioms.log`, `lean-version.log`, `pdf-build.log`, `python-verify.log`) and `SELF_REVIEW.md`.
