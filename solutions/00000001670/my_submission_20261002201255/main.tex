\section{The conjecture}

\begin{quote}
\textit{Conjecture:} $M_d = 1/2 + P_d/\sqrt d + O(1/d)$ where $P_d$ is a
Dembo--Montanari--Sen type constant with the analytic characterization
$P_3 = 0.918$: the closed form $P_3 = \frac{2}{\pi}\arctan(\sqrt 2)$.
\end{quote}

\section{The refutation}

The conjecture's own closed form satisfies
\[
  \tfrac{2}{\pi}\arctan(\sqrt2)
  \;<\; \tfrac{2}{\pi}\arctan(\sqrt3)
  \;=\; \tfrac{2}{\pi}\cdot\tfrac{\pi}{3}
  \;=\; \tfrac23
  \;<\; \tfrac{459}{500} = 0.918,
\]
using that $\arctan$ is strictly increasing, $\sqrt2 < \sqrt3$, and
$\arctan(\sqrt3) = \pi/3$; the final comparison is the integer
certified $2\cdot500 = 1000 < 1377 = 3\cdot459$. Hence the closed form
evaluates strictly below the $0.918$ the conjecture simultaneously
asserts: the two descriptions of $P_3$ contradict each other. (The actual
value is $\approx 0.608$; the true DMS constant for $d = 3$ is
$P^* \approx 0.763$.)

\section{Verification}

\texttt{reproduce.py} evaluates the closed form and checks the chain. The
Lean package (core Lean~4, v4.33.1) certifies the integer statements
($2 < 3$, $1000 < 1377$, the two products), all \texttt{does not depend on
any axioms}; the analytic facts used are standard and cited.

\section{Boundary}

Only the $P_3$ characterization clauses are refuted.
