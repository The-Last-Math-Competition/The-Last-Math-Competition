# Disproof of TLMC Conjecture 00000001031

**Verdict: FALSE.**

## The conjecture

The multiplier group of a Singer difference set `D ⊂ F_{q^3}` (the set of
multiplicative translations `τ` with `τD = D`) is conjectured to be exactly
the norm subgroup `N(F_{q^3}/F_q)` of `F_{q^3}^*`, i.e. the image of the norm
map, a subgroup of order `q − 1` and index `q² + q + 1`; and this structure is
claimed to completely characterize the automorphisms ("no other multipliers").

## Counterexample (q = 2)

Take `F_8 = F_2[α]`, `α³ = α + 1`, so `F_8^* ≅ Z_7` is cyclic; identify
`α^k ↔ k ∈ Z_7`. The classical Singer difference set is the set of nonzero
trace-zero elements, `Tr(x) = x + x² + x⁴ = 0`, which as exponents is

    D = {1, 2, 4} ⊂ Z_7.

This is indeed a `(7, 3, 1)` difference set: the six ordered differences of
distinct elements of `D` cover every nonzero residue of `Z_7` exactly once
(`λ = q − 1 = 1`).

**Multiplier group.** Checking `τD = D` for all units `τ ∈ Z_7^* = {1,…,6}`:

    τ = 1: {1,2,4} ✓    τ = 2: {2,4,1} ✓    τ = 3: {3,6,5} ✗
    τ = 4: {4,1,2} ✓    τ = 5: {5,3,6} ✗    τ = 6: {6,5,3} ✗

so the multiplier group is `{1, 2, 4}`, of order **3**. (It is `⟨q mod q²+q+1⟩
= ⟨2 mod 7⟩`, the subgroup generated by the Frobenius `x ↦ x²`.)

**Norm subgroup.** The norm map `N : F_8^* → F_2^*`, `N(x) = x^{1+2+4} = x⁷`,
has image `F_2^* = {1}`: a subgroup of order `q − 1 = 1`, index
`7 = q² + q + 1` in `F_8^*`.

Since `{1, 2, 4} ≠ {1}` (order 3 vs. order 1), the conjectured equality fails.
The companion clause "no other multipliers" fails as well: `2` and `4` are
multipliers of `D` that do not lie in the norm subgroup.

## Boundary of this disproof

Only the case `q = 2` is computed here. That is enough because the conjecture
is a universal "exactly" statement; a single counterexample refutes it. We make
no claim about which subgroup is the correct description of the multiplier
group for general `q` (for `q = 2` the actual group `{1,2,4}` equals `⟨q⟩`
inside `Z_7`, of order 3, not `F_q^*`).
