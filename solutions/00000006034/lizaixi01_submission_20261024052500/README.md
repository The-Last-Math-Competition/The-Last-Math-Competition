# Counterexample to 00000006034

The compact Lie group C₂ acts on the connected real symplectic plane by the identity and negation. The standard area form is smooth, alternating, nondegenerate and closed; the action is jointly smooth and preserves it. Its actual tangent Lie algebra is zero, so the genuine zero moment map satisfies both the Hamiltonian differential identity and coadjoint equivariance.

The zero level is the whole plane. In its actual orbit quotient, the origin has stabilizer C₂ and every nonzero point has trivial stabilizer. These subgroups are not conjugate. The image of the true stabilizer-conjugacy-class function therefore has cardinality two. The actual coadjoint dual has one element, and its orbit quotient has cardinality one.

This disproves only the source's last clause equating the number of isotropy types with the number of coadjoint orbits. The source does not require the group to be connected or the moment map to be proper. Those additional versions, the classical orbit-type decomposition theorem, and the other unspecified constants or quantization data are outside the claim.

The formalization uses native smooth manifolds, `GroupLieAlgebra`, actual manifold derivatives of the conjugation and orbit maps, continuous linear maps for the area form, actual Fréchet derivatives for its coordinate exterior derivative and the moment identity, native stabilizers, and the native orbit quotient. The continuous dual is explicitly equivalent to the algebraic dual. Both cardinalities follow from the defined mathematical sets; neither is assigned as a constant.
