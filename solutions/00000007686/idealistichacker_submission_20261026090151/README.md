# Disproof of Conjecture 00000007686

## Result

Both source languages define `p_q(n)` as the coefficient sum of the Gaussian
polynomial `[2n choose n]_q`. This actual coefficient sum is

    c(n) = binom(2n,n).

It is not the ordinary partition function. The sequence is strictly increasing,
and, more strongly, `c(n) mod 3` is not eventually periodic. For every proposed
positive period T and onset N, a proved zero interval immediately before a
power of three gives an n>=N with different values at n and n+T.

This refutes the common necessary eventual-periodicity clause at k=1. We cover
both the printed natural-coefficient interpretation and the plausible implicit
coefficient modulus p=3, a=1. No value of the unspecified minimal-period formula
is invented or separately refuted. In particular we do not claim nonperiodicity
for every modulus: modulo 2 the sequence is eventually zero. Neither the
ordinary partition function nor a different recursive notion of periodicity is
substituted for the printed object or quantifiers.
