# 评分方法论与校准报告

> 对象：`The-Last-Math-Competition/The-Last-Math-Competition` @ `main`（2026-09-12）
> 覆盖：全部 10,000 条猜想 × 5 个维度 = 50,000 个评分单元格
> 复现：`extract_features.py` → `score_conjectures.py`

---

## 1. 为什么是"结构性启发式评分"

规则 2 要求"人类与 AI 共同为全部猜想打分"。但这条规则在当前状态下**不可执行**：

- `metadata.csv` 的 5 个评分列**全空**（5 × 10,000 = 50,000 个单元格中 0 个被填）
- 没有任何 rubric、没有标度定义、没有多人合并规则
- 10,000 条 × 5 维的纯人工评分不可行；纯 LLM 逐条评分成本高且不可复现

因此本方案采用**两阶段可复现管线**：

```
conjectures/*.md  ──(extract_features.py)──▶  结构化特征 JSONL
                                              │
                                              ▼
                            (score_conjectures.py)  ──▶  metadata.scored.csv
                                                     └─▶  review_queue.csv
```

- **特征层**确定性、可审计：正则与词典，任何人可复算
- **评分层**是显式加权的加法模型，权重全部写在代码里
- **不依赖 LLM 调用**，因此结果完全可复现，且可随 rubric 演进而低成本重跑

**这个方法能做什么**：给出一个可复现的**基线评分**，把 10,000 条猜想按结构性质量分层，让后续的人工/LLM 精评只需要聚焦在少数条目上。
**这个方法不能做什么**：它读的是**信号**，不是**数学**。它无法判断一条猜想是否真的为真、是否真的新。这一点在第 5 节明确列出。

## 2. 五个维度的标度定义

### 2.1 `well_definedness_level`（0–5，连续加法）

一条猜想"良定义"需要同时满足：术语有定义、量词范围明确、上下文充分、无含糊措辞、记号规范。每缺一项扣固定分。

```
wd = 2.0
   + 0.5   若有 Definition/定义 块；否则 -0.5
   + 1.5   若有显式量词（for every / there exist / For p ≥ 5 / 存在…）
   + 0.5   若长度 ≥ 300 字符（上下文充分）
   - 0.5   若长度 < 250 字符
   - 1.0   若含未定义常数（some constant / sufficiently large / 某常数）
   - 0.2×min(n_vague_phrase, 3)   含糊措辞（explicit / optimal / 显式 / 最优）
   - 1.0   若正文含状态元信息（(known) / partially known / 已知 / 完全开放）
   - 1.0   若含裸 LaTeX 命令（未用 $ 包裹）
截断到 [0, 5]，半值向上取整
```

**0 分的含义**：退化到无法解析（不是数学命题）。当前 7 条。

### 2.2 `importance`（1–5）

```
imp = 2.0
    + 3.0  若命中"重大猜想"锚点（Riemann / P vs NP / Langlands / Goldbach / Yang–Mills …）
    + 1.5  否则若有 ≥2 个"深水机械"术语
    + 1.0  否则若有 1 个
    + 0.5  若同时含全称量词与渐近陈述（一般性断言，而非特例）
    + 0.5  若引用具名定理/不等式
    + 0.5  若自称是已有结果的加强/最优形式
    + 0.5  若断言涉及无限族
    - 0.5  若主题归类为 general / other
    - 0.5  若长度 < 250 字符
    - 0.5  若 wd ≤ 1（不良定义的东西不可能重要）
```

### 2.3 `novelty`（1–5）—— **刻意保守、单侧**

```
nov = 1  若正文自述已知（(known) / partially known / 已知 / 完全开放）
    = 2  若复述重大猜想，或自称是已有结果的加强/最优形式/推广
    = 3  其余全部
```

> **3 的语义是"未发现非新颖性证据"，不是"已验证新颖"。**
> 全库 0/10,000 条含任何文献引用，因此**新颖性在缺乏文献检索的前提下不可判定**。
> 本列只提供**下界**：任何被扣到 1–2 的条目都有明确证据；留在 3 的条目需要人工核查。
> 这是本方案最大的已知局限，见第 5.1 节。

### 2.4 `proof_difficulty`（1–5）

```
pr = 2.0
   + 3.0  重大猜想锚点
   + 1.5  否则 ≥2 个深水术语
   + 1.0  否则 1 个
   + 0.5  全称 + 渐近
   + 0.5  无限族 + 渐近
   - 1.0  有限对象（英文块中检出，见第 4 节 bug #4）
```

### 2.5 `disproof_difficulty`（1–5）

与 `proof_difficulty` **独立评估**——一条猜想可能极难证明但极易反证，这正是本项目想捕捉的信号。

```
dp = 3.5
   - 1.5  有限对象
   - 1.0  含显式数值界（≤ ≥ at most exactly …）
   - 0.5  存在性断言
   - 0.5  含 ≥3 个数值
   + 1.0  渐近/密度/误差项断言（单个反例无法否证，必须无穷论证）
   + 0.5  全称 + 渐近
   + 0.5  重大猜想锚点
```

## 3. 结果

| 维度 | 0 | 1 | 2 | 3 | 4 | 5 | 中位 | 均值 |
|---|---|---|---|---|---|---|---|---|
| well_definedness_level | 7 | 192 | 853 | 6948 | 930 | 1070 | 3 | 3.18 |
| importance | — | 99 | 6001 | 2936 | 881 | 83 | 2 | 2.48 |
| novelty | — | 166 | 1041 | 8793 | — | — | 3 | 2.86 |
| proof_difficulty | — | 304 | 7395 | 1875 | 364 | 62 | 2 | 2.25 |
| disproof_difficulty | — | 145 | 1093 | 2470 | 5019 | 1273 | 4 | 3.62 |

**可读结论**：

1. **`disproof_difficulty` 中位数为 4，高于 `proof_difficulty` 的 2。** 直觉上"反证更容易"，但对**渐近/密度型**断言恰恰相反——单个反例无法否证"密度等于 X"，必须构造无穷论证。真正可下手的是 `dp ≤ 2` 的 **1,238 条（12.4%）**，这是反证工作的靶区。
2. **`importance` 高度集中在 2（60%）。** 这与 README 自己的免责声明（"早期生成质量较差"）一致。
3. **`novelty` 87.9% 落在 3**，即"无法判定"。这不是评分失败，而是**数据本身的属性**：全库零引用。
4. **`well_definedness` 有 1,052 条 ≤2**，即约 10.5% 的猜想在结构上就不合格——这是给生成器的最直接反馈（规则 5）。

## 4. 校准过程与修复的 5 个 bug

校准方法：分层抽样 36 条（覆盖 wd=5 / wd≤1 / imp=5 / imp=1 / dp=1 / nov=1 / pr=5 各桶），
逐条精读原文并与模型评分比对。**本轮发现并修复了 5 个真实缺陷**：

| # | 缺陷 | 影响面 | 修复 |
|---|---|---|---|
| 1 | `DEEP` 词表内部存在**子串重叠**（`motivic` 含 `motiv`）与**重复项**（`freiman` 出现两次） | 一个词被计为两件"深水机械"，importance/proof 虚高 | 加入 `_distinct()` 折叠重叠；去重词表 |
| 2 | `invariant subspace` 被当作**重大猜想锚点** | **28 条**文件误判 importance=5。该词在语料中多指普通术语（"invariant subspaces 的亏格"），并非"不变子空间问题" | 收窄为 `invariant subspace problem`，命中 28 → 0 |
| 3 | `goldbach` 在 `Waring-Goldbach` 内部被匹配 | 复合词被当作 Goldbach 猜想本身，importance/proof 直接顶格 | 引入连字符负向断言 `(?<![\w\-–])`，锚点总命中 90 → 52 |
| 4 | `FINITE_OBJ` 匹配到**中文译文里的"有限"** | **879 条**误判为"有限可验证对象"，proof/disproof 被错误下调 | 改为**只在英文块上**判定；命中 1297 → 425 |
| 5 | 量词正则 `any ` 匹配到 `many ` 内部 | "infinitely **many** primes" 被误判为含显式量词 | 改用 `\bany\b` 词边界；并补上 `For p ≥ 5` 这类量词形式 |

**第 5 项特别值得记录**：修复后量词命中率从 16.1% *下降到* 14.1%。这个下降是**修正**而非退化——旧值被 `many` 的假阳性抬高了。

## 5. 已知局限（必须随评分一起交给维护者）

### 5.1 新颖性不可判定（最重要）

全库 0/10,000 条含 `arXiv` / `doi` / `et al.` 引用。没有文献检索就无法判断一条猜想是否已有结论。
`novelty=3` 必须读作**"未发现反证证据"**。

**实例**：`00000001034` 提出"n ≥ 4 时不存在非平凡 Lee 完美码"——这正是 Golomb–Welch 猜想，**已于 2023 年被证明**。模型给 novelty=3，实际应为 1。任何基于关键词的模型都抓不到这种情况。

### 5.2 "Definition:" 标签被过度信任

模型只看是否存在 Definition 块。但块内可能只是**循环定义的术语堆**。例如 `00000008404`：

> Definition: The motivic stationary state: the minimal stable form of a motivic measure under the **involution closure**.

"involution closure" 不是标准术语，定义未给出内容。模型给 wd=5，人工判断应为 2–3。

### 5.3 关键词无法区分"解决"与"提及"

`00000008222` 提到"Langlands packet"即被赋予 importance=5，但其陈述（"符号调和后等于正则重数"）实为含糊措辞。**提到 Langlands ≠ 推进 Langlands。**

### 5.4 残余的量词漏检

`00000001702`「**For non-Pisot Parry numbers**, the count of poles …」——"For <名词短语>," 形式仍未被量词正则覆盖，wd 被压到 1。此类形式估计还有数百条。

### 5.5 存在语言损坏的条目

`00000002913` 英文块为：

> Definition: finite field this of injection polynomial map: jacobian conjecture of finite field plane.

语法破碎，疑似生成/翻译失败。模型给 wd=3。**语料中存在少量此类损坏条目**，值得单独提一个 issue。
