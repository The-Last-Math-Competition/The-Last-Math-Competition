## 2. 方法：为什么反证优先，以及怎么筛

README 规则 3 明确接受 disproof，且 `metadata.csv` 把 `proof_difficulty` 与 `disproof_difficulty` **独立成列**——这说明项目本身就把"找到反例"当作与"给出证明"并列的一等目标。

但**"反证更容易"是个需要修正的直觉**。本项目的评分数据显示：

- `proof_difficulty` 中位数 **2**
- `disproof_difficulty` 中位数 **4**

反证的难度中位数**高于**证明。原因很具体：绝大多数猜想是**渐近/密度型**断言（"密度等于…"、"误差项为 O(…)"），这类断言**单个反例无法否证**，必须构造无穷论证。真正可下手的是 `disproof_difficulty ≤ 2` 的 **1,238 条（12.4%）**。

triage 评分模型（`triage.py`）的加权逻辑：

```
+ (5 - disproof_difficulty) × 2.0    主驱动
+ 1.5  含显式数值界（≤ ≥ at most exactly）
+ 1.5  有限/特定对象
+ 1.0  主题为数论 / 组合 / 概率
+ 1.0  含 ≥3 个数值参数
+ 0.5  存在性断言（可穷举否证）
+ 0.5  陈述较短（歧义少、易形式化）
- 1.5  渐近/密度断言（反例无效）
```

## 3. 六条判定详情

### 3.1 A — `00000001243`：Wolfram 规则 30 中心列"无平方"

**原命题**

> Conjecture: This sequence is not eventually periodic, and among its factors of length < 2^k none contains a square: the central column is square-free over all prefixes of length 2^k; this rules out any short-period structure.

**证伪**

在字组合学中，"square"指形如 `uu` 的因子（相邻重复块）。规则 30 中心列是**二值序列**，而：

> **任意长度 ≥ 4 的二值字都含平方。**
> 证明：设首四项为 s₀s₁s₂s₃。若 s₀=s₁，则 s₀s₁ 是平方；否则 s₁≠s₀。若 s₁=s₂，则 s₁s₂ 是平方；否则 s₂=s₀。若 s₂=s₃，则 s₂s₃ 是平方；否则 s₃=s₁，于是 s₀s₁s₂s₃ = s₀s₁s₀s₁ = (s₀s₁)²。

所以命题对**任何**长度 ≥ 4 的前缀都不成立，与规则 30 的具体动力学无关。

**计算确认**（`target_quick.py`）：中心列前 32 项为

```
11011100110001011001001110101110
```

第 0–1 位即出现 `11`。**该命题在第二个字符处就被推翻。**

### 3.2 B — `00000001016`：`[84,12,12]` 自对偶码不存在

**原命题**

> Definition: The [84,12,12] binary extremal self-dual code is a candidate at the Griesmer boundary. Conjecture: This code does not exist; moreover, the automorphism group of every [84,12] binary self-dual code contains no element of order 11, and the minimum distance is at most 11.

**判定：不适定（定义矛盾）**

二进制自对偶码 C ⊂ F₂ⁿ 满足 C = C^⊥，因此**必有 dim C = n/2**。对 n = 84，自对偶码的维数**必须为 42**，而命题给的是 12。

故 `[84,12,12]` 这一对象**不可能自对偶**，命题讨论的对象不存在。命题本身不是"假"，而是**没有真值**。

（若要讨论长度 84 的自对偶码，参数应为 `[84,42,d]`。）

**这类问题值得单独提 issue**：`metadata.csv` 的 `well_definedness_level` 列正是为捕捉它而设，但目前全列为空。

### 3.3 C — `00000002222`：零因子图的 χ = ω（n ≤ 1000）

**原命题**

> Conjecture: No counterexample exists to chromatic number = clique number for the zero-divisor graph Γ(R) with R = Z_n for n ≤ 1000.

**判定：验证成立（范围内无反例）**

这是本次唯一一条**被确认**的猜想。Γ(Z_n) 的顶点为非零零因子，x ~ y ⟺ n | xy。

**关键方法（孪生类归约）**：设 n = ∏ p_i^{a_i}，对 x ∈ Z_n 记 v(x) = (v_{p_1}(x), …)。则

```
x ~ y  ⟺  v_i(x) + v_i(y) ≥ a_i  对所有 i 成立
```

邻接关系**只依赖估值向量**，因此估值相同的顶点是**孪生点**（邻域完全相同），且每个孪生类要么是团、要么是独立集。于是 Γ(Z_n) 是某个小商图的"膨胀"：

- 商图顶点数 **= ∏(a_i + 1) − 2**（排除 v = 0 的单位类与 v = a 的零类），**n ≤ 1000 时最多 30 个**（n = 840 = 2³·3·5·7，4·2·2·2 − 2 = 30）
- 类大小 |class(v)| = ∏ c_i(v_i)，其中 c_i(a_i) = 1，c_i(v) = φ(p_i^{a_i−v})
- 类是团 ⟺ 2v_i ≥ a_i 对所有 i

在此归约下可**精确**计算 ω（最大权团）与 χ（加权染色数），而非启发式估计。

**校验**：归约法已对 n ∈ [4, 120] 与**直接在真实图上暴力计算**逐一比对，**0 处不一致**（`validate_zd.py`）。

**结果**：n ∈ [4, 1000] 全部 **831** 个含零因子的 n（即区间内的全部合数，含素数幂），**χ = ω**，无反例。

ω 的实际范围是 **1 到 30**：最小值在 **n = 4** 处取到（Γ(Z_4) 只有一个顶点 2，ω = χ = 1），最大值在 **n = 961 = 31²** 处取到——此时 Γ(Z_961) 有 30 个顶点、两两相乘均为 0，即 **Γ(Z_961) ≅ K₃₀**，故 ω = χ = 30。

> **更正（2026-09-12，公开前的自查）**：本条早先有三处描述性数字是错的，已逐一重算更正：
>
> | 早先写法 | 正确值 | 性质 |
> |---|---|---|
> | 含零因子的 n 有 **997** 个 | **831** 个 | 997 是区间 [4,1000] 的长度，不是含零因子的 n 的个数（831 = 997 − 166 个素数） |
> | 最大 ω **仅为 5** | **30**（n = 961） | 计算遗漏了素数幂；n = p² 时 Γ ≅ K_{p−1}，ω = p − 1 无界 |
> | ω 范围 **2 到 30** | **1 到 30** | 下界由 n = 4 取到 |
>
> **判定结论（χ = ω）不受影响**——831 个 n 逐一重算，0 个反例。错误仅在描述性统计。但它们叠加的效果是让这条验证看起来比实际更平凡（"图很小、ω 很小"），故完整记录在此。

> 该命题在所述范围内**成立**。这也意味着它不是反证目标——triage 把它排在第 3 位，是因为机器无法区分"有限可验证"与"易于证伪"。这是 triage 方法的固有局限，已在 §5 记录。

### 3.4 D — `00000008540`：Con(L) 为布尔格 ⟺ L 次直不可约

**原命题**

> Conjecture: The congruence lattice of a finite lattice is Boolean exactly when the lattice is of subdirectly irreducible type; the number of congruences is at most 2^{n-1}, and the bound is optimal.

**证伪（最小反例是三元链 C₃，不是 2²）**

**第一反例：L = C₃（三元链 0 < 1 < 2）**

链上"块是区间"的分划恰为同余（若块非区间，取 x < z < y 同块、z 异块，则由 x∧z = x、y∧z = z 得 x ≡ z，矛盾）。故 |Con(Cₙ)| = 2^{n−1}，C₃ 有 **4 个同余**：

```
{0,1,2}
{0,1} | {2}
{0} | {1,2}
{0} | {1} | {2}
```

构成菱形 ⟹ **Con(C₃) ≅ 2² 是布尔格**。

但 C₃ **不是次直不可约**：它有显式次直分解，嵌入 C₂ × C₂：

```
φ(0) = (0,0),  φ(1) = (0,1),  φ(2) = (1,1)
```

两个投影都满射到 C₂，但都不是同构（C₃ 有 3 个元素，C₂ 只有 2 个）。等价地，Con(C₃) 有 **2 个原子**（{0,1}|{2} 与 {0}|{1,2}），而次直不可约要求恰有 1 个。

→ **C₃ 直接不可分解（两个非平凡格的直积至少有 4 个元素，而 C₃ 是链），却不是次直不可约**——这正是"次直不可约严格强于直接不可分解"的经典例证。**n = 2 时只有 C₂，其 Con 只有 1 个原子、是次直不可约的，故 C₃ 是最小反例。**

**一般化**：对一切 n ≥ 3，Cₙ 都是反例（Con 有 2^{n−1} 个元素、是布尔格，而原子数为 n−1 ≥ 2）。

**第二反例：L = 2²（四元布尔格 {0, a, b, 1}）**

`target_quick.py` 中的 `con_lattice_of_boolean_square()` 枚举全部 **15** 个划分（Bell 数 B₄ = 15，**不是 256**——256 既不是 4 元集的分划数，也不是其等价关系数，两者都等于 15），逐一代入同余相容性条件：

```
{0,a,b,1}
{0,a} | {b,1}
{0,b} | {a,1}
{0} | {a} | {b} | {1}
```

共 **4 个同余**，构成菱形，**故 Con(2²) 是布尔格**。而 2² = 2 × 2 是两个非平凡格的直积，**故 2² 不是次直不可约的**。

→ Con(2²) 为布尔格，而 2² 不是次直不可约 ⟹ "exactly when"（当且仅当）方向为假。

**一处方法说明**：首版代码只检查"每个块是子格"，对 2² 得出 11 个同余（含伪同余）、对 C₃ 得出 5 个。正确的同余条件还要求 **x ≡ y ⟹ f(x,z) ≡ f(y,z) 对所有 z 成立**。补上跨块相容性后分别得 4 和 4，与手算一致。**中间结果 196、11、5 都是错的**，记录在此以示区分。

**计数条款未被推翻**：|Con(C₃)| = 4 = 2^{3−1}，|Con(2²)| = 4 ≤ 2^{4−1} = 8。链恰好取到 2^{n−1}，与命题自称的"界最优"一致。**被推翻的是分类（双条件），不是计数界。**

### 3.5 E — `00000001619`：核 e^{−xy} 的 Fredholm 行列式

**原命题**

> Definition: The Fredholm determinant det(I−tK) of the kernel K(x,y) = e^{−xy} is defined on L²(0,∞). Conjecture: det(I−tK) = e^{−t²/4} explicitly; precisely, this determinant equals e^{−t²/4} … it is an entire function of order 2, and its zeros form conjugate purely imaginary pairs.

**判定：不适定（该行列式不存在）**

K(x,y) = e^{−xy} 在 L²(0,∞) 上对称有界（即 Laplace 变换，范数 √π ≈ 1.7725）。但 Fredholm 行列式要求算子**迹类**，从而必须 **Hilbert–Schmidt**，即 ∫∫|K|² < ∞。计算：

```
∫₀^∞ ∫₀^∞ e^{−2xy} dx dy
  = ∫₀^∞ [ 1/(2y) ] dy
  = +∞
```

发散来自 y → 0 处：核在对角线上无界。截断到 [0,L]² 后积分有限，但**按 ln L 发散**：

| L | ∫∫_{[0,L]²}\|K\|² | ln L + 0.7 |
|---|---|---|
| 5 | 2.2446 | 2.3094 |
| 10 | 2.9378 | 3.0026 |
| 20 | 3.6309 | 3.6957 |
| 40 | 4.3241 | 4.3888 |
| 80 | 5.0172 | 5.0820 |
| 160 | 5.7107 | 5.7751 |
| 320 | 6.4039 | 6.4683 |

（L 每翻倍增加约 ln 2 = 0.693 ✓）

故 K 非 Hilbert–Schmidt ⟹ 非迹类 ⟹ **det(I − tK) 无定义**。命题断言的 e^{−t²/4} 不是一个存在的量。

**独立佐证**：将 K 作用两次，

```
(K²f)(x) = ∫₀^∞ f(y) [ ∫₀^∞ e^{−z(x+y)} dz ] dy = ∫₀^∞ f(y)/(x+y) dy
```

即 K² 是核为 1/(x+y) 的 **Carleman 算子**，其在 L²(0,∞) 上的谱为**纯连续区间 [0, π]**。K² 没有特征值，故 K 也没有特征值——没有特征值就无从定义 det(I − tK)。

**一处方法说明（重要）**：我最初尝试用离散化矩阵的特征值来"演示"这一点，但**这个数值路线不可靠**——核在对角线上无界、矩阵严重病态，有限矩阵的特征值不可信（实测 λ_max 在 1.34–1.51 之间跳动，并未稳定趋近 √π）。**故本条的结论完全来自解析论证，不依赖数值**。保留此说明以免误导复核者。

### 3.6 F — `00000001668`：广义 Petersen 图的圆色数分类

**原命题**

> Conjecture: The complete classification table: χ_c(G(n,k)) = 3 when n ≡ 0 mod 3 and k ≡ 1 mod 3, and 4 otherwise (consistent with computations for n ≤ 30); the table is closed for all n and k.

**证伪（结构性，非边界情况）**

G(n,k) 是**三正则图**。由 **Brooks 定理**，连通图若最大度 Δ = 3，则 χ ≤ 3，除非该图是 K₄。又因**恒有 χ_c ≤ χ**，故对一切 G(n,k) ≇ K₄：

```
χ_c ≤ χ ≤ 3 < 4
```

即 "otherwise 分支 χ_c = 4" **在结构上永不可能成立**。这不是"某些 n, k 算错了"，而是分类框架整体错误。

**显式计算**（`target_ef.py`，圆色数由 (p,q)-染色存在性精确判定）：

| n | k | \|V\| | χ | **χ_c** | 命题预测 | 判定 |
|---|---|---|---|---|---|---|
| 5 | 1 | 10 | 3 | **5/2** | 4 | 推翻 |
| 5 | 2 | 10 | 3 | **3** | 4 | 推翻 |
| 6 | 1 | 12 | 2 | **2** | 3 | 推翻 |
| 7 | 1 | 14 | 3 | **7/3** | 4 | 推翻 |
| 7 | 2 | 14 | 3 | **3** | 4 | 推翻 |
| 7 | 3 | 14 | 3 | **3** | 4 | 推翻 |

**最小反例：G(5,1)（五角棱柱），χ_c = 5/2。** 此处 n = 5 不被 3 整除，命题预测 χ_c = 4；实际 χ_c = 2.5。

**扩大扫描**：对 n ∈ [5,20]、全部合法 k，共 **96** 个用例，**89 个被推翻**。

其余 **7** 个未被推翻的是 (9,1)、(9,4)、(12,4)、(15,1)、(15,4)、(15,7)、(18,4)。它们的特征需要说清楚，否则容易被误读：

> Phase 1 的判据只是 `χ ≥ 预测值`，这来自 **χ_c ≤ χ** 这条必要（非充分）条件。所以 "未被推翻" **不等于** "验证成立"，只表示"没有被这条界单独否证"。

这 7 个恰好满足 **n ≡ 0 (mod 3) 且 k ≡ 1 (mod 3) 且 χ ≥ 3**（即非二部）。注意 (6,1) **同样**满足 n≡0、k≡1，但 G(6,1) 是二部图（χ = 2），而命题预测 χ_c = 3，故它**也被推翻**——因为 χ_c ≤ χ = 2 < 3。同理 (12,1)、(18,7) 亦然。

所以"3 分支"同样有反例，只是需要 χ < 3 才能暴露；单靠 Brooks 界（χ ≤ 3）无法触及这一支。**完整结论是：两个分支都错，不存在"命题恰好蒙对"的分支。**

| ID | 陈述 | 实际情况 |

这不是评分模型的实现 bug，而是**方法论的硬边界**：全库 0/10,000 条含任何文献引用，任何基于文本的模型都无法判断"这条猜想是否已有结论"。**这一点必须随评分结果一起交付给维护者**，否则 `novelty` 列会被误读。

## 5. 方法的局限（诚实记录）

1. **triage 无法区分"有限可验证"与"易于证伪"。** `00000002222`（零因子图）被排在第 3 位，结果证明它是**成立的**——有限可计算不等于可证伪。triage 是"排序工具"，不是"判定工具"，人工精读不可省略。
2. **"证伪"依赖对原命题的正确解读。** 这些猜想措辞常含含糊成分（如 D 的"of subdirectly irreducible type"）。本报告对每条都注明了所采用的标准解读；若维护者意图不同，判定需相应修订。
3. **不适定 ≠ 假。** B 与 E 的结论是"命题无真值"，而非"命题为假"。二者在 `metadata.csv` 中应区分处理（建议 B、E 计入 `well_definedness_level`，而非 `disproven`）。

### 为什么 C（`00000002222`）没有提交

C 的**判定本身是可靠的**：孪生类归约已对真实图暴力校验（n ∈ [4,120]，0 处不一致），n ≤ 1000 全部 831 个含零因子的 n 逐一精确计算，0 个反例。

它没被提交，是因为它**没有通往"完整证明"的短路径**：

1. **ω 没有闭式。** 曾试图找一个能覆盖一切 n 的公式来替代 831 例穷举，候选 `∏ p^⌊a/2⌋ − 1` 在多数 n 上失败（如 n = 2310 预测 0 而实际 ω = 5），只在 n = p² 等少数情形恰好成立。因此不存在"一段短论证 + 小规模计算"的写法。
2. **它比 Smith 的完美图分类严格更弱。** 文献已知 Γ(Z_n) 为完美图当且仅当 n ∈ {p^a, p^a q^b, p^a q r, p q r s}。但 **n = 180 = 2²·3²·5 与 n = 420 = 2²·3·5·7 都 ≤ 1000、都非完美，却仍满足 χ = ω**。所以"χ = ω"**不能**由完美图分类推出，它确实是一个独立（且更弱）的命题——这意味着 C **不是**已知结果的复述，是一条真结论；但也意味着没有现成定理可以引用，必须自证。
3. **形式化一个 831 例的有限计算，成本远高于三条证伪。** 而它的收益是"确认一条本来就成立的猜想"，对项目的边际价值低于一条证伪。

**结论**：C 保留为"已判定但未提交"。若维护者认为"确认型结论"也有提交价值，请告知——它需要的是一条 `decide`-风格的有限计算 + 一个显式的 ω 计算证书，我可以补上。
