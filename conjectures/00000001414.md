# 00000001414

**HT-24 △** — source: 32_代数拓扑与同伦论.md

**English.** Definition: Lichtenbaum's conjecture for K_{4n}(Z) relates its order to Bernoulli numbers. Conjecture: |K_{10}(Z)| = B_{12}/(2·6!) (i.e. an integral value with the explicit denominator of 691/2³·3²·5·6! type); the difference between this value and the rank-1 part of Borel's computation is exactly the order of the torsion part.

**中文。** 定义：K_{4n}(Z) 的 Lichtenbaum 预言把其阶数与 Bernoulli 数联系。猜想：|K_{10}(Z)| = B_{12}/(2·6!)(即 691/2^{3}·3^{2}·5·6! 型显式分母的整化);该值与 Borel 计算的秩 1 部分之差恰为扭部分的阶。
