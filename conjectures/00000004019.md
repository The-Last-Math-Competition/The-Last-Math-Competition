# 00000004019

**English.** Definition: A controlled path is a path with a decomposition Y = Y'X + R, where R is the remainder. Conjecture: The Garsia-Rodemich-Romsen bound for the remainder has constant 4 on an interval and is corrected in the d-dimensional tensor product by an explicit lattice constant, with the correction at most 2^d. (exact value of the GRR constant)

**中文。** 定义：受控路径指具分解 Y = Y′X + R 的路径,R 为余项。猜想：余项的 Garsia–Rodemich–Romsen 界在区间上常数为 4,d 维张量积下由显式格子常数修正,修正不超过 2^d。（GRR 常数精确值）
