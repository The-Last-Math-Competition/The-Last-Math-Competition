# 00000001455

**English.** Definition: The lattice-point count N(K, t) = #(tK ∩ Z^d). Conjecture: For smooth positively curved convex bodies, N(K, t) = vol·t^d + O(t^{d−2+2/(d+1)}) (the optimal error exponent; weaker bounds are known).

**中文。** 定义：格点计数 N(K, t) = #(tK ∩ ℤ^d)。猜想：对光滑正曲率凸体,N(K, t) = vol·t^d + O(t^{d−2+2/(d+1)})(最优误差指数,已知更弱界)。
