# 00000000567

**CA-67 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: A cluster-tilting object of a finite-dimensional algebra Λ is a maximal object Ext-orthogonal to itself in the idempotent completion; ct(Λ) denotes the number of pairwise non-isomorphic ones. Conjecture: For the idempotent completion of the representation category of a Dynkin quiver, ct = ∏_{i=1}^{n}(e_i+h+1)/(e_i+1) (e_i the exponents, h the Coxeter number); for preprojective algebras, ct equals an explicit closed form for the number of cluster variables of the corresponding affine type.

**中文。** 定义：有限维代数 Λ 的 cluster-tilting 对象指其在幂等完备化中 Ext-正交的极大对象,其互不同构个数记 ct(Λ)。猜想：对 Dynkin 箭图表示范畴的幂等完备化,ct = ∏_{i=1}^{n}(e_i+h+1)/(e_i+1)(e_i 为指数,h 为 Coxeter 数);对 preprojective 代数,ct 等于相应仿射型簇变量数的显式闭式。
