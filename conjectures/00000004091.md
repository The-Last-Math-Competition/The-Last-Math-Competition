# 00000004091

**CG4-01 ◆** — source: 122_组合几何II_配置空间.md

**English.** Definition: The unordered configuration space Conf_n(X) is the quotient space of n pairwise distinct points on X. Conjecture: For a graph Gamma the first Betti number of Conf_n(Gamma) is invariant under barycentric subdivision and is a polynomial in the chromatic number of the graph of degree exactly n. (subdivision invariance of graph configuration Betti numbers)

**中文。** 定义：无序配置空间 Conf_n(X) 指 X 上 n 个两两互异点的商空间。猜想：图 Γ 的 Conf_n(Γ) 的第一 Betti 数在二分细分下不变,且为图色数的多项式,次数恰为 n。（图配置 Betti 细分不变性）
