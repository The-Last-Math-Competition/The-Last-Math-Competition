**English.** Definition: Communication-free: distributed randomized algorithms. Conjecture: There is a communication-accuracy trade-off for distributed algorithms (a trade-off law); the communication lower bound holds (a lower bound law); the bound is attained by algorithms (an attainment law); and the actual attainment depends on the latency model (a latency law). (distributed communication trade-off latency attainment)

**中文。** 定义：communication-free：分布式随机算法。猜想：分布式的（通信-精度的权衡）的（权衡律）；且权衡的下界（通信）的（下界律）；下界的达到的（算法）的（达到律）；达到的实际（延迟模型）的（延迟律）。
