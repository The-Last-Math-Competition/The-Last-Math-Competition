**English.** Definition: The Gauss diagram window is the combinatorial obstruction for a Gauss code to be realizable as a planar crossing diagram. Conjecture: Realizability holds if and only if the window count is even; the window count of the (2,n)-torus knot is the Euler number of n; and the minimal window count is the alternation depth. (Gauss window alternation depth)

**中文。** 定义：Gauss 图窗口指 Gauss 码可实现为平面交叉图的组合障碍。猜想：可实现当且仅当窗口数为偶；(2,n)-torus 结的窗口数为 n 的 Euler 数；最小窗口数为交错深度。（Gauss 窗口交错深度）
