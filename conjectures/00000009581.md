# 00000009581

**MSH-01 ★** — source: 305_高维极小曲面.md

**English.** Definition: The area spectrum a_1 < a_2 < ... of embedded minimal hypersurfaces in a closed manifold (minimal area in each index class) is guaranteed infinite by Almgren-Pitts theory; the growth order of areas is unknown. Conjecture: The k-th minimal hypersurface area satisfies the polynomial upper bound a_k <= C k^{1/(n+1)}, with C explicitly given by the volume and Ricci lower bound; for general metrics this upper bound is tight (equidistribution examples on cubical manifolds attain the same-order lower bound). (area spectrum polynomial law)

**中文。** 定义：闭流形中嵌入极小超曲面的面积谱 a_1<a_2<…（每个指标类取最小面积）由 Almgren–Pitts 理论保证无穷多存在；面积的增长阶未知。猜想：第 k 个极小超曲面的面积满足多项式上界 a_k ≤ C·k^{1/(n+1)}，常数 C 由体积与 Ricci 下界显式给出；一般度量下该上界紧致（方格流形等分布例达到同阶下界）。（面积谱多项式律）
