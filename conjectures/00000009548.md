# 00000009548

**QIC-28 ★** — source: 303_量子信道容量.md

**English.** Definition: Position-based verification protocols verify an adversary's position by response time; the security of the quantum version depends on the simulation cost of entangled adversaries, and single-round protocols are universally insecure. Conjecture: Any single-round position verification protocol of arbitrary dimension can be broken by two adversaries sharing entanglement, but breaking a k-round protocol requires Omega(dim^{k-1}) entanglement; and there is an explicit 2-round protocol whose breaking entanglement is Theta(dim squared), so the round-dimension barrier holds. (position verification round barrier)

**中文。** 定义：基于位置的验证协议以响应时间验证敌手位置，量子版本的安全性取决于纠缠敌手的模拟成本；单轮协议普遍不安全。猜想：任何单轮任意维位置验证协议可被两个共享纠缠的敌手攻破，但 k 轮协议的攻破所需纠缠为 Ω(dim^{k−1})；存在 2 轮显式协议使攻破纠缠量为 Θ(dim²)，轮数-维数壁垒成立。（位置验证轮数壁垒）
