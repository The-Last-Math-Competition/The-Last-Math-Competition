# 00000008416

**English.** Definition: An orthogonal array OA(k,n) is a k-row, n^2-column symbol array such that any two rows contain every ordered pair exactly once. Conjecture: For k at least 2n the maximal k of an OA is exactly n+1 (the Bush type bound), attained when n is a prime power; and the column stabilizer of a k = n+1 array is a projective-plane type 2-(n^2,n,1) design, so its existence is equivalent to the existence of a projective plane of order n. (orthogonal array Bush bound)

**中文。** 定义：正交阵列 OA(k,n) 指 k 行 n² 列的符号阵列使任意两行含一切有序对恰一次。猜想：k ≥ 2n 的 OA 的最大 k 恰为 n+1（Bush 型界），且当 n 为素数幂时 k = n+1 可达；k = n+1 的阵列的列稳定子为射影平面型的 2-(n²,n,1) 设计，即其存在等价于 n 阶射影平面的存在。（正交阵列 Bush 界）
