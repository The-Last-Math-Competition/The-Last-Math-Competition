# 00000004357

**English.** Definition: The Cameron-Martin class is the set of directions along which the measure is absolutely continuous under translation. Conjecture: The Cameron-Martin class of a non-Gaussian measure is the intersection of the corresponding Gaussian class with the set of flat directions of the measure, and for exponential measures the intersection is the whole space. (intersection formula of the non-Gaussian CM class)

**中文。** 定义：Cameron–Martin 类指测度沿其平移绝对连续的方向全体。猜想：非高斯测度的 Cameron–Martin 类为对应高斯类与测度平坦方向集的交,指数测度时交为全空间。（非高斯 CM 类交公式）
