# 00000007699

**English.** Definition: A Meyer set is a Delone set Y with Y-Y contained in F+Y for some finite F; pure-point diffraction means the diffraction is supported by countably many Bragg peaks. Conjecture: The diffraction of a Meyer set Y is pure point if and only if Y is a strict isomorphic copy of a regular model set; and the continuous part of the diffraction of a non-regular Meyer set vanishes when Y is forced of low complexity (patch counting function <= C n^d). (model-set characterization of Meyer diffraction)

**中文。** 定义：Meyer 集指 Delone 集 Y 使 Y-Y ⊆ F+Y（F 有限）。其衍射测度的纯点性指衍射在倒易空间由可数 Bragg 峰支撑。猜想：Meyer 集 Y 的衍射为纯点当且仅当 Y 为正则 model 集的严格同构像；且非正则 Meyer 集的衍射连续部分当 Y 为强制低复杂度（patch 计数函数 ≤ C n^d）时消失。
