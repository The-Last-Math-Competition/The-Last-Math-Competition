**English.** Definition: Meyer set denotes Delone set Y such that point of Y-Y ⊆ F+Y (F finite). its measure denotes in space by countable Bragg support. Conjecture: of Meyer set Y is point if and only if Y is strictly isomorphism image; of regular model set and nonpositive then continuous part when Y of Meyer set is strong complexity (patch counting function ≤ C n^d) when vanishes.

**中文。** 定义：Meyer 集指 Delone 集 Y 使 Y-Y ⊆ F+Y（F 有限）。其衍射测度的纯点性指衍射在倒易空间由可数 Bragg 峰支撑。猜想：Meyer 集 Y 的衍射为纯点当且仅当 Y 为正则 model 集的严格同构像；且非正则 Meyer 集的衍射连续部分当 Y 为强制低复杂度（patch 计数函数 ≤ C n^d）时消失。
