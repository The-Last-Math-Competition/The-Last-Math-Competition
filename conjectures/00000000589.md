# 00000000589

**English.** Definition: The Frobenius number g(S). Conjecture: For three-generated semigroups ⟨a,b,c⟩, g(S) ≤ √3·(abc)^{1/3}·(1+o(1)), and the constant √3 is optimal (Erdős–Graham type).

**中文。** 定义：Frobenius 数 g(S)。猜想：三生成半群 ⟨a,b,c⟩ 的 g(S) ≤ √3·(abc)^{1/3}·(1+o(1)),且常数 √3 最优(Erdős–Graham 型)。
