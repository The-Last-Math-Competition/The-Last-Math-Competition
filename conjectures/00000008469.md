# 00000008469

**English.** Definition: The L-space surgery set of a knot is the set of integer surgery coefficients producing L-spaces. Conjecture: The set is a semi-infinite interval whose endpoint p_0 is an explicit conversion of the moduli of nontrivial roots of the Alexander polynomial; and for Alexander-trivial knots the endpoint is 2g+1, a tight bound. (endpoint formula for L-space surgery sets)

**中文。** 定义：L-space surgery 集指使整数手术产生 L-space 的系数集合。猜想：该集为半无穷区间且端点 p₀ 由 Alexander 多项式非平凡根的模显式换算；Alexander 平凡结的端点为 2g+1 且该界紧。（L-space surgery 端点公式）
