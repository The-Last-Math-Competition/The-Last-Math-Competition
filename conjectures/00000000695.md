# 00000000695

**English.** Conjecture: The minimal-value sequence (v₁ < v₂ < …) of the closed hyperbolic 3-manifold spectrum satisfies v_{k+1} − v_k → 0, and every interval [a, a+ε] with a > v₁ contains a spectral point (the spectrum is dense at infinity).

**中文。** 猜想：闭双曲 3-流形的谱的最小值序列(v₁ < v₂ < …)满足 v_{k+1} − v_k → 0 且任意 [a, a+ε] 含谱点当 a > v₁(谱在无穷远处稠密)。
