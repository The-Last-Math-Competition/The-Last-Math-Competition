# 00000003837

**English.** Definition: The star involution * denotes the crystal involution reversing all simple arrow directions, always existing in finite type. Conjecture: The number of fixed points of * in B(λ) is always odd, and when λ = −w₀λ the number of fixed points is at least 3. (star fixed point parity)

**中文。** 定义：星对合 * 指同时反转所有简单箭头方向所得的晶体对合,有限型上恒存在。猜想：B(λ) 中 * 的不动点个数恒为奇数,且当 λ = −w₀λ 时不动点个数不少于 3。（星不动点奇偶）
