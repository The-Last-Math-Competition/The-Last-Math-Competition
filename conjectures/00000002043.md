# 00000002043

**English.** Definition: The digit sum s_q(n) is the sum of digits of the base-q representation. Conjecture: #{n ≤ x : s_q(3n) = s_q(n)} ~ c_q·x/(log x)^{1/2}; the constant c_q is explicit from the singularity at z = 1 of the generating function of a Stern–Brocot type bifurcation tree.

**中文。** 定义：数字和 s_q(n) 指 q 进制表示的数字之和。猜想：#{n≤x : s_q(3n) = s_q(n)} ~ c_q· x/(log x)^{1/2};常数 c_q 由 Stern–Brocot 型分叉树的生成函数在 z=1 的奇性显式。
