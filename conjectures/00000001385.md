# 00000001385

**English.** Definition: The spectral counting function N_T(λ) = dim of the eigenspace with spectral value ≤ λ of a measure-preserving transformation (taking values 1..ℵ₀..). Conjecture: The realizable value sequences of N_T are exactly the prefix-nested segments of {1, 2, …, ℵ₀, 2^{ℵ₀}}: once an infinite value occurs, all values above it are 2^{ℵ₀}; no alternating pattern exists; and the realization of infinite values is completely decided by the atomicity of the spectral measure.

**中文。** 定义：测度保持变换的谱计数函数 N_T(λ)=dim 谱 ≤λ 的特征子空间(取值 1..ℵ₀..)。猜想：N_T 的可实现值序列恰为 {1,2,…,ℵ₀,2^{ℵ₀}} 的前缀嵌套段:若某无穷值出现则其上皆为 2^{ℵ₀};不存在交错模式；且无穷值的实现由谱测度的原子性完全判别。
