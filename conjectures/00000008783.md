# 00000008783

**English.** Definition: Randomized diagonalization: random initialization of spectral methods. Conjecture: The convergence domain of random initialization has full measure (a full measure law); the dimension of the bad set is n-2 (a bad set dimension law); the measure-zero bad set has an explicit characterization (a characterization law); and the characterization is stable under perturbations (a stability law). (random initialization full measure bad set stability)

**中文。** 定义：随机对角化：谱方法的随机初始化。猜想：随机初始化的收敛域的全测度（全测度律）；且测度的坏集的维数（坏集维数律）的 (n-2) 的（维数律）；测度零的坏集的显式刻画（刻画律）；刻画的稳定（扰动的稳定）的（稳定律）。
