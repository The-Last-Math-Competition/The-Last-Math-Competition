# 00000002836

**English.** Definition: Tucker decomposition: the core-factor hierarchical low-rank representation of tensors. Conjecture: Rigidity of the Tucker rank spectrum: the space of rank vectors of core tensors is a monotone lattice, with the distance between maximal and minimal elements an explicit function of the core dimension. (Tucker rank lattice rigidity)

**中文。** 定义：Tucker 分解：张量的核心-因子的分层低秩表示。猜想：Tucker 秩谱的刚性：核心张量的秩向量空间为单调格且格的极大元与极小元的距离为核心维数的显式函数。（Tucker 秩格刚性）
