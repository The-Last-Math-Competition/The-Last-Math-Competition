# 00000000577

**CA-77 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: The Möbius function μ(0,1) of a geometric lattice measures its combinatorial complexity. Conjecture: Among geometric lattices on n elements of rank r, the maximum absolute value of the Möbius function is attained exactly at uniform matroids; and this extremal criterion is a complete classification for rank-two lattices. (Möbius absolute value uniform extremum)

**中文。** 定义：几何格的 Möbius 函数 μ(0,1) 度量格的组合复杂度。猜想：在 n 元素秩 r 的几何格中 Möbius 函数绝对值的最大值恰在均匀拟阵处取得；该极值判据在秩二的格中为完全分类。（Möbius 绝对值均匀极值）
