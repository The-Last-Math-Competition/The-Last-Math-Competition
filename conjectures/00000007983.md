# 00000007983

**English.** Definition: The convergence criterion for message passing of tornado-type LDPC graphs: the stability index S(G) of the spectral radius of the Tanner graph and the fixed point of message entropy evolution. Conjecture: S(G) = log(lambda_2(G) gamma) (gamma the channel parameter); for S < 0 convergence holds at speed e^{S t} (exponential); and the bifurcation at the critical value S = 0 is pitchfork type (symmetry breaking), the boundary between the attraction basins of the post-breaking stable fixed-point pair being the minimal support hyperplane of weight-3 dual codewords (an attraction basin-dual code correspondence). (tornado pitchfork dual-codeword basins)

**中文。** 定义：卷帘（tornado）型图的 LDPC 的消息传递的收敛准则：Tanner 图的谱半径与消息熵演化的不动点的稳定性指标 S(G)。猜想：S(G)=log(λ₂(G)·γ)（γ 为信道参数），S<0 时收敛且速度为 e^{S·t}（指数速度）；且 S 的临界值 S=0 的分岔行为为 pitchfork 型（对称破缺），破缺后的稳定不动点对的吸引域的边界为权 3 的对偶码字的最小支撑面（吸引域-对偶码对应）。
