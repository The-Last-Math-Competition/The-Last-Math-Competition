# 00000000097

**AG-08 ◆** — source: 07_代数几何与算术几何.md

**English.** Definition: The Koblitz conjecture. Conjecture: For every elliptic curve E/Q without complex multiplication and of rank 0, the set {p : #E(F_p) is prime} is infinite, with counting function ~ C_E·√x/log²x.

**中文。** 定义：Koblitz。猜想：对每条无复乘、秩 0 的 E/Q,集合 {p : #E(F_p) 为素数} 无穷,且计数 ~ C_E·√x/log²x。
