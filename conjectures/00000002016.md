# 00000002016

**PD-26 ★** — source: 52_偏微分方程II.md

**English.** Conjecture: The singular set of the gradient of the c-convex potential in optimal transport has dimension at most n−1 (i.e. the gradient is smooth off a set of codimension ≥ 1); the singular set is controlled by the folding structure of the transport map, and the dimension is exact.

**中文。** 猜想：最优传输的 c-凸势的梯度的奇异集维数 ≤n−1(即梯度在余维 ≥1 的集合外光滑);奇异集由传输映射的折叠结构控制,维数精确。
