# 00000001306

**CC-06 ★** — source: 29_多复变与复几何.md

**English.** Conjecture: The holomorphic automorphism group of a smooth bounded pseudoconvex domain is a Lie group, and when noncompact the domain is a ball (a quantitative Wong–Rosay version: an explicit comparison of automorphism-orbit escape speed with the ball metric).

**中文。** 猜想：光滑有界拟凸域的全纯自同构群为李群且无界时域为球(Wong–Rosay 型的定量版本:自同构轨道逃逸速度与球度量的显式比较)。
