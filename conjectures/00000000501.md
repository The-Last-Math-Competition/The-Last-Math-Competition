# 00000000501

**English.** Definition: The Castelnuovo–Mumford regularity reg(I). Conjecture: The edge ideal of the cycle graph C_n satisfies reg I(C_n) = ⌈(n−1)/3⌉ + 1 (programmatically verifiable, then to be stated in closed form).

**中文。** 定义：Castelnuovo–Mumford 正则度 reg(I)。猜想：循环图 C_n 的边理想满足 reg I(C_n) = ⌈(n−1)/3⌉ + 1(可编程验证后闭式化)。
