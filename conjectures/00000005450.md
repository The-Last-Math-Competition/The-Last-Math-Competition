# 00000005450

**English.** Definition: Computational complexity and group structure are two layers. Conjecture: There exist two class groups with the same complexity but non-isomorphic structures, and the separation is realized by an explicit family pair of same-scale discriminants. (same complexity-different structure class-group separation pair)
