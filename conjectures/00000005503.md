# 00000005503

**English.** Definition: Phase-type service has mixed-exponential service time distributions, with the product-form correction of the network. Conjecture: The product correction is always an explicit matrix expression of the phase count and the flow-class count, simplifying to a scalar ratio for invertible-phase networks; the spectral radius of the matrix expression is below 1 if and only if the network is stable; and the dimension of the correction is the phase count, with the product with the flow-class count giving the matrix size. (phase product-correction matrix expression)

**中文。** 定义：相位型服务：混合指数的服务时间分布；网络的乘积形式修正。猜想：乘积修正恒为相位数与流类数的显式矩阵式且可逆相位网络下化简为标量比；矩阵式的谱半径小于 1 当且仅当网络稳定；修正的维数为相位数且与流类数之积为矩阵规模。（相位乘积修正矩阵式）
