# 00000000769

**English.** Definition: The torsion part of the Milnor K-cohomology H^*(G_p, Z/p^n) of G_p = Gal(Q̄_p/Q_p). Conjecture: The order of H^i(G_p, μ_{p^n}^{⊗i}) is p^{n·c_i} with c_i explicit small integers (c_0 = c_1 = 1, and c_2 a function of [Q_p:Q_p]); this value is uniquely determined by the Bloch–Kato and Demushkin structures, with no q−1 type exceptional torsion.

**中文。** 定义：G_p=Gal(Q̄_p/Q_p) 的 Milnor K-上同调 H^*(G_p, Z/p^n) 的挠部分。猜想：H^i(G_p,μ_{p^n}^{⊗i}) 的阶为 p^{n·c_i},c_i 为显式小整数(c_0=c_1=1,c_2 为 [Q_p:Q_p] 的函数);该值由 Bloch–Kato 与 Demushkin 结构唯一确定,无 q−1 型例外挠。
