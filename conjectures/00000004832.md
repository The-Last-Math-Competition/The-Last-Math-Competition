# 00000004832

**English.** Definition: Maass forms are nonholomorphic cusp forms. Conjecture: The first nonzero eigenvalue for large level tends to one quarter, the error is an explicit negative power of the level, and the bound is attained by arithmetic quotients. (one-quarter limit of the first Maass eigenvalue)

**中文。** 定义：Maass 形指非全纯的尖形式。猜想：大模水平的第一非零特征值趋于四分之一,误差为模水平的负幂显式且界由算术商达到。（Maass 首特征值四分之一极限）
