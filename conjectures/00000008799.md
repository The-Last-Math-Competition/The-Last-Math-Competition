# 00000008799

**English.** Definition: Randomized kernel approximation: randomized features for RKHS. Conjecture: The error for universal kernels is the reciprocal square root of the feature count; and the kernel of the reciprocal is Monte Carlo variance. (random features Monte Carlo variance root error)

**中文。** 定义：随机 kernel 逼近为随机特征的 RKHS。猜想：通用核的误差为特征数根号倒数；且倒数的核为 Monte Carlo 方差。（随机特征 Monte Carlo 方差根号误差）
