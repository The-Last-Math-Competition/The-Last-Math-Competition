# 00000000309

**English.** Definition: Bad_p is the set of numbers uniformly badly approximable by prime denominators, i.e. there exists c > 0 with ‖pα‖ > c·p^{-1/2} for every prime p. Conjecture: Bad_p has full Lebesgue measure (its complement has measure zero) and is Schmidt winning; the proof requires only second-moment estimates for the prime sequence, with no twin-prime-type hypothesis.

**中文。** 定义：Bad_p 为对素数分母一致坏逼近的数集,即存在 c>0 使 ‖pα‖ > c·p^{-1/2} 对一切素数 p 成立。猜想：Bad_p 的 Lebesgue 测度为满(即补集为零测),且 Bad_p 为 Schmidt 赢集;其证明只需素数序列的二级均值估计而不需孪生素数型假设。
