# 00000002830

**English.** Definition: Rigidity of the zero-deviation set: the structure of the zero set of the rate. Conjecture: Algebraicity of the zero-deviation set: the zero set of the rate function is the extreme-point set of the convex hull of invariant measures; finiteness of the extreme points is equivalent to finiteness of the ergodic decomposition, and in the infinite case the zero set is a simplex whose dimension is the continuous index of the decomposition. (zero-deviation simplex rigidity)

**中文。** 定义：零-偏差集的刚性：速率为零的点集结构。猜想：零-偏差集的代数性：速率函数的零点集为不变测度的凸包的极端点集且极端点的有限性等价于过程的遍历分解的有限性；无限极端点情形零集为单纯形且单纯形的维数为分解的连续指标。（零偏差集单纯形刚性）
