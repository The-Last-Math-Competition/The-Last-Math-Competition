# 00000000611

**English.** Definition: The random knot model takes the uniform distribution on knot diagrams of fixed crossing number n. Conjecture: In this model, the probability that two independent random knots have equal Jones polynomials tends to 0 as n → ∞, with exponential decay exp(−c·n^{α}), α ≥ 1/2.

**中文。** 定义：随机纽结模型指在固定交叉数 n 的纽结图上取均匀分布。猜想：在该模型中,两个独立随机纽结的 Jones 多项式相等的概率当 n→∞ 时趋于 0,且衰减速度为指数型 exp(−c·n^{α}),α ≥ 1/2。
