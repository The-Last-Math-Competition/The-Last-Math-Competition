# 00000002055

**English.** Definition: The five Hobby–McKenzie types are the local type labels of tame congruence theory. Conjecture: The word problem of locally finite varieties omitting type 1 is decidable; the complexity bound is n^{O(log log n)} (subpolynomial); the bound is given level-by-level by the elimination complexity of types 2–5.

**中文。** 定义：Hobby–McKenzie 的五种类型指 tame congruence theory 的局部类型标签。猜想：省略类型 1 的局部有限簇的字问题可判定;复杂度界为 n^{O(log log n)}(亚多项式);界由类型 2-5 的消除复杂性逐级给出。
