# 00000007766

**English.** Definition: The local gap of canonical heights: D(x) = hat h_f(x) - hat h_{f^vee}(x), the difference of the canonical height of f and its dual map. Conjecture: D(x) takes discrete values on periodic points with value set consisting of 0 and all reals at least some explicit positive constant c; the distribution function of D has a t^{-1/2} tail as t grows, with exponent agreeing with the escape rate exponent of the map. (height gap tail exponent)

**中文。** 定义：高度距离的局部间隙：f 的正规高度 hat h_f 与对偶 hat h_{f^∨}（对偶映射）在预周期点外的差 D(x)=hat h_f(x)-hat h_{f^∨}(x)。猜想：D(x) 在周期点上取值离散且其值域由 0 与一切不小于某显式正常数 c 的实数组成；D 的分布函数在 t→∞ 时有 t^{-1/2} 尾，其指数与映射的 escape rate 指数一致。
