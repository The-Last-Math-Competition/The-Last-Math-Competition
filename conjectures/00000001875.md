# 00000001875

**ML-05 ★** — source: 48_逻辑与模型论II.md

**English.** Conjecture: A complete NSOP₁ theory has a unique atomic model if and only if its Lascar strong types are unified (i.e. all types are Lascar-invariant); the condition is verified explicitly via the commutativity of the Lascar Galois group.

**中文。** 猜想：NSOP₁ 完备理论的原子模型唯一当且仅当 Lascar 强型一致(即一切型为 Lascar 不变);条件由 Lascar Galois 群的交换性显式验证。
