# 00000006977

**English.** Definition: Far-field asymptotics with the linearized correction structure. Conjecture: The correction order is reciprocal type and the closed window is logarithmic gain; the gain window is controlled by the resonance width; and the correction coefficient is the residue of the resonance term. (reciprocal-order far-field correction structure)

**中文。** 定义：远场渐近：线性化修正结构。猜想：修正阶为倒数型且封闭的窗为对数增益；增益的窗由共振宽度控制；修正系数为共振项的留数。（远场修正倒数阶结构）
