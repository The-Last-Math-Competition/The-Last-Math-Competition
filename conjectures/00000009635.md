# 00000009635

**SMA-25 ★** — source: 306_Smale空间与符号动力学.md

**English.** Definition: Sturmian words have minimal complexity p(n) = n+1; the classification of multidimensional Sturmian tilings is open. Conjecture: Two-dimensional minimal-complexity translation-finite tilings are multidimensional Sturmian type if and only if the slope vector generates a real quadratic field; slopes over fields of degree three and higher necessarily exhibit a complexity jump, of size an explicit function of the discriminant. (multidimensional Sturmian classification)

**中文。** 定义：Sturmian 词具有极小复杂度 p(n)=n+1；多维 Sturmian 平铺的分类开放。猜想：二维极小复杂度平移有限平铺为多维 Sturmian 型当且仅当斜率向量生成实二次域；三次及以上域的斜率必然出现复杂度跳跃，跳跃量为判别式的显式函数。（多维 Sturmian 分类）
