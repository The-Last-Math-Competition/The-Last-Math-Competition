# 00000001008

**FG-08 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: A spread is a line family partitioning the point set. Conjecture: The number of equivalence classes of spreads of PG(3,q) is a polynomial correction of q³ + q² + q + 1 (spread counting).

**中文。** 定义：散布集(spread,划分点集的直线族)。猜想：PG(3,q) 的 spreads 的等价类数为 q³ + q² + q + 1 的多项式修正(spread 计数)。
