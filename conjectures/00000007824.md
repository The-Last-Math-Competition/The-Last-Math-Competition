# 00000007824

**English.** Definition: The Hodge ring on M_g x M_g: a class in R^*(M_g x M_g) is a Hodge class if it is of type (p,p) in every Hodge realization. Conjecture: The ring of Hodge classes on M_g x M_g is generated by tautological classes and the commuting-diagram classes I_t (classes containing t-sheeted commuting diagrams); and I_t is redundant once t exceeds 2g-3, the minimal number of generators of the redundancy relations being floor((t-2g+3)/2). (commuting-diagram Hodge generation)

**中文。** 定义：M_g×M_g 上的对角拉回型的 Hodge 环：类 α∈R^*(M_g×M_g) 称为 Hodge 类若其在一切 Hodge 实现为 (p,p) 型。猜想：M_g×M_g 上的 Hodge 类环由重言类与交换图类生成；且交换图类 I_t（含 t 次交换图）在度 t 大于 2g-3 时冗余，冗余关系的最小生成元个数为 ⌊(t-2g+3)/2⌋。
