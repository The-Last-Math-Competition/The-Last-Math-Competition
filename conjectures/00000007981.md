# 00000007981

**CD3-21 ★** — source: 251_编码理论III_列表解码与局部译码.md

**English.** Definition: The convex duality of the entropy function of asymptotic weight enumerators: the entropy function H(omega) of the weight distribution of code families (the exponent of the count of codewords of weight omega). Conjecture: H is concave on [0,delta] with H(0) = 0, H(delta) = 0, and max H = R (the rate); the Legendre transform H*(s) gives the complete envelope of the Delsarte region; and the endpoints of the support interval [omega_min, omega_max] are explicitly controlled by the Krawtchouk roots of the LP, with the slope of H at the endpoints infinite if and only if the code satisfies biorthogonality of the pure distance distribution (the pure code criterion). (weight entropy Legendre envelope)

**中文。** 定义：码的渐近权 enumerator 的熵函数的凸对偶：码族的重量分布的熵函数 H(ω)（权 ω 的码字数指数）。猜想：H 为区间 [0,δ] 上的凹函数且 H(0)=0, H(δ)=0, max H = R（码率）；凸对偶 H*(s) 的 Legendre 变换给出 Delsarte 区域的完整包络；且 H 的支撑区间 [ω_min,ω_max] 的端点由 LP 的 Krawtchouk 根显式控制，端点处的 H 的斜率为 ±∞ 的充要条件为码满足纯距离分布的双正交（纯码判据）。
