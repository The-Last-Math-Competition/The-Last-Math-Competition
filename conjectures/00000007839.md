# 00000007839

**MSE-29 ★** — source: 246_模空间与枚举几何II.md

**English.** Definition: The mixed Tate property of virtual fundamental classes: the weight filtration of the virtual structure sheaf on Mbar_{g,n}(X,beta). Conjecture: When X is toric, all graded pieces of the virtual Chern class have weights 0 and 1 (mixed Tate), and the property is invariant under window shifts of the window category of X; and the minimal example of a non-toric Fano threefold whose virtual Chern class contains a weight-2 part is given by deformation to a non-smooth toric boundary of the fan, with weight spectrum {0,1,2}. (virtual class mixed Tate window invariance)

**中文。** 定义：virtual 基本类的混合 Tate 性：Mbar_{g,n}(X,β) 的 virtual 结构层的权 filtrated 分段。猜想：当 X 为 toric 时 virtual 陈类的分段权数全部为 0 与 1（混合 Tate），且该性质在 X 的窗（window）范畴的窗口位移下不变；非 toric 的 Fano 三维簇的 virtual 陈类含权 ≥2 部分的最小例子由形变到扇目录的非平滑 toric 边界给出，权重谱为 {0,1,2}。
