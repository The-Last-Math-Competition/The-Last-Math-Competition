**English.** Definition: The simulation tape length of rule 110 is the minimal tape segment needed for universal computation. Conjecture: The minimal tape length required by rule 110 to simulate any tile system is a quadratic polynomial L(s) = O(s²) in the number of states, and the smallest instance realizing a universal Turing machine exists at bandwidth 5.

**中文。** 定义：rule 110 的模拟带长指其在实现通用计算时所需的最小 tape 段。猜想：rule 110 模拟任一瓦片系统所需的最小 tape 长度为状态数的二次多项式 L(s)=O(s²),且实现通用图灵机的最小实例在带宽 5 时存在。
