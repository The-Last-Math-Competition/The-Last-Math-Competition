# 00000002269

**English.** Definition: Bracketing entropy counts bracket covers. Conjecture: The bracketing-entropy constant of the class of monotone functions is an explicit sublinear correction of 1/ε (monotone class entropy constant).

**中文。** 定义：bracketing 熵(括号覆盖数)。猜想：单调函数类的 bracketing 熵常数为 1/ε 的显式次线性修正(单调类熵常数)。
