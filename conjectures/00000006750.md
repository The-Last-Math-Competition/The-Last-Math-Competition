# 00000006750

**English.** Definition: Cotilting classes and tilting classes are two layers. Conjecture: There exist two algebras with the same cotilting class but different tilting classes, and the separation is realized by an explicit opposite pair with the same cotorsion but different torsion. (same cotilting-different tilting opposite separation)

**中文。** 定义：余倾斜类与倾斜类指两层。猜想：存在两代数的余倾斜类相同而倾斜类不同,分离由同余挠异挠的显式反向对实现。（余倾斜同-倾斜异反向分离）
