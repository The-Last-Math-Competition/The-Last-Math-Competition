# 00000001808

**CV-28 ★** — source: 45_多复变II.md

**English.** Definition: The Kobayashi degeneracy set is the set of pairs of points with vanishing Kobayashi pseudometric. Conjecture: For wandering domains of iterated polynomial automorphisms of C², the degeneracy set is analytic under holomorphic motion; the degeneracy set is parametrized explicitly by the images of invariant algebraic curves of the wandering domain.

**中文。** 定义：Kobayashi 退化集指 Kobayashi 伪度量两两为零的点集。猜想：ℂ² 中多项式自同构迭代的游荡域的退化集在全纯运动下为解析集;退化集由游荡域的不变代数曲线的像显式参数化。
