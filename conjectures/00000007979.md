# 00000007979

**English.** Definition: The reconstruction number of the replacement single-neighborhood of a code: the k-deck problem, the minimal size k(n) of the substring multiset of a length-n string that uniquely determines the string. Conjecture: k(n) = floor(n/2) + O(1) for binary strings (a tightening of the Levenshtein bound with constant 2); the replacement reconstruction number for a code C of minimum distance d is a correction of type ceil(d/2) + 1 - ceil(d/(2n)); and the expected reconstruction number of random linear codes is 2 log n + O(1) (matching the information-theoretic lower bound). (k-deck reconstruction tightening)

**中文。** 定义：码的替换单邻域的重建数：码 C 的重建码字数（k-deck 问题）：长度 n 的串的子串多重集的最小规模 k(n) 使码字唯一确定。猜想：二元串的 k-deck 的 k(n)=⌊n/2⌋+O(1)（Levenshteen 界的紧化，常数 2）；且对码 C（最小距 d）的替换重建数（重建海的恢复）为 ⌈d/2⌉+1-⌈d/(2n)⌉ 型修正；线性码的重建数的期望（随机线性码）为 2log n+O(1)（信息论下界的匹配）。
