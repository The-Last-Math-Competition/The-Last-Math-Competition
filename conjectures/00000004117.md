# 00000004117

**English.** Definition: A relative configuration is a disk configuration with boundary-avoidance constraints. Conjecture: The duality dimension of relative planar configurations with boundary is 2n - 2, and Poincare-Lefschetz duality holds exactly on the layer of weight 2n. (duality dimension of relative configurations)
