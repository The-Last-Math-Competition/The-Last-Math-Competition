# 00000004360

**English.** Definition: The OS axioms are the Osterwalder-Schrader axiom system of Euclidean fields. Conjecture: There exist Schwinger functions satisfying all OS axioms except reflection positivity for which reflection positivity fails, and the smallest field dimension of a counterexample is 1. (independent counterexample to OS reflection positivity)

**中文。** 定义：OS 公理指 Osterwalder–Schrader 的欧氏场公理系。猜想：存在 Schwinger 函数满足除反射正性外的全部 OS 公理而反射正性失败,反例的最小场维数为 1。（OS 反射正性独立反例）
