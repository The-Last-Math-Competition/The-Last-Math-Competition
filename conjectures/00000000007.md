# 00000000007

**English.** Definition: Let A ⊂ N be automaton-recognizable with #A ∩ [1,x] ≪ log x (a sparse automatic set). Conjecture: The number of primes in A is either finite, or A asymptotically contains an infinite subsequence of a geometric-type sequence {c·bⁿ+d}; in other words, primality in a sparse automatic set can only arise along a single-exponential trajectory.

**中文。** 定义：设 A ⊂ N 为自动机可识别且 #A ∩ [1,x] ≪ log x(稀疏自动集)。猜想：A 中素数个数要么有限,要么 A 渐近包含一个几何型序列 {c·bⁿ+d} 的无穷子列;换言之,稀疏自动集中的素性只能来自单指数轨迹。
