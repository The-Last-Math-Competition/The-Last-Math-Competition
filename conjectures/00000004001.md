# 00000004001

**English.** Definition: The path signature S(X) is the tensor series of iterated integrals over all multi-indices. Conjecture: The expected squared norm of the n-th level of the Brownian signature is the explicit combinatorial expression E||S^n||^2 = n! * binom(d+n-1, n), and its generating function in n is rational. (Brown signature level-norm generating function)

**中文。** 定义：路径签名 S(X) 指全体多重指标迭代积分的张量级数。猜想：Brown 运动签名的第 n 层的期望平方范数为 E‖S^n‖² = n!·binom(d+n−1,n) 型显式组合式,且其关于 n 的母函数为有理函数。（Brown 签名层范数母函数）
