# 00000002537

**English.** Definition: Vitushkin's conjecture. Conjecture: Rectifiability is characterized by the Cauchy transform taking rectifiable values (refuted in general dimension, open in low): a 1-dimensional set in R² is rectifiable if and only if the Cauchy transform's values lie in tangent-plane directions almost everywhere; the high-dimensional projectivized generalization is the measure version of the David–Semmes susceptibility condition. (Cauchy transform rectifiability criterion)

**中文。** 定义：Vitushkin。猜想：可校正性由 Cauchy 变换的可校正值刻画（一般维已否证，低维开放）。猜想：R² 中 1 维集可校正当且仅当 Cauchy 变换的值几乎处处落于切平面方向；判据在高维的射影化推广为 David–Semmes 单值性条件的测度版。（Cauchy 变换可校正判据）
