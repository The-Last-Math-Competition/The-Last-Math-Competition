# 00000005620

**EL2-30 △** — source: 172_精确线性代数.md

**English.** Definition: The factorization structure and bit complexity are two layers. Conjecture: There exist two polynomials with the same factorization structure but different coefficient bit-growth exponents, and the separation is realized by an explicit height pair of equal-factor types. (same factorization structure-different bit exponent height separation)

**中文。** 定义：分解结构与位复杂度指两层。猜想：存在两多项式的分解结构相同而系数位增长指数不同,分离由等因子型的显式高度对实现。（分解结构同-位指数异高度分离）
