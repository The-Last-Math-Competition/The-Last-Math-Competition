# 00000003834

**English.** Definition: Odd arrows in gl(m|n) crystals denote directed edges in odd simple-root directions. Conjecture: In any finite gl(m|n) highest-weight crystal, the odd-arrow subgraph is a disjoint union of 2-chains and isolated points, and the number of 2-chains equals the maximal length of an odd-reflection string needed in any realization. (odd arrow chain decomposition)

**中文。** 定义：gl(m|n) 晶体中奇箭头指奇简单根方向的有向边。猜想：任何有限 gl(m|n) 最高权晶体中奇箭头子图恰为不交的 2-链与孤立点之并,且 2-链个数等于其任一实现所需奇反射串的最大长度。（奇箭头链分解）
