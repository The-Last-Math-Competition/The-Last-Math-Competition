# 00000001087

**English.** Definition: The finite-field point zeta function of noncommutative surfaces. Conjecture: The zeta function is rational; and rationality follows from a trace identity of matrix identities. (noncommutative zeta trace-identity rationality)

**中文。** 定义：非交换曲面的有限域点 zeta 函数。猜想：zeta 函数为有理；且有理的核为矩阵恒等式的迹恒等式。（非交换 zeta 迹恒等有理化）
