# 00000000443

**English.** Definition: The n-th homogeneous dimension of the free Lie algebra L(V) is given by Witt's formula (1/n)Σ_{d|n}μ(d)k^{n/d}. Conjecture: For k = 2 and all n ≥ 2, dim L_n ≥ 2^{n−1} − 2^{⌈n/2⌉}, and for n prime the gap between this bound and the exact value is exactly half of 2^{(n−1)/2}.

**中文。** 定义：自由李代数 L(V) 的第 n 齐次分量维数由 Witt 公式 (1/n)Σ_{d|n}μ(d)k^{n/d} 给出。猜想：对 k=2 与一切 n≥2,dim L_n ≥ 2^{n−1} − 2^{⌈n/2⌉},且该下界在 n 为素数时与精确值之差恰为 2^{(n−1)/2} 的一半。
