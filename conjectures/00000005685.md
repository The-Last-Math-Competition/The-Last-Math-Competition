# 00000005685

**English.** Definition: A crossed module object is a module across structures. Conjecture: The two-object classification table is given by the explicit enumeration of irreducible-character pairs, with dimension the product of character dimensions, and the classification is finite. (character-product classification table of two crossed objects)

**中文。** 定义：交叉模对象指跨结构的模。猜想：二对象的分类表由不可约特征标对的显式枚举给出,维数为特征标维数积且分类有限。（交叉二对象特征标积分类表）
