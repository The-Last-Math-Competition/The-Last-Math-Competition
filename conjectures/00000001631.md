# 00000001631

**English.** Definition: The geometric model of gentle algebras (marked ribbon surfaces). Conjecture: The number of isomorphism classes of indecomposable objects, for a fixed surface with intersection number ≤ k, is finite and counted explicitly by mapping-class orbit numbers (a gentle object count).

**中文。** 定义：gentle 代数的几何模型(带标记缠绕曲面)。猜想：不可分解对象同构类的个数在固定曲面与交织数 ≤ k 时有限且计数为曲面映射类的轨道数显式(gentle 对象计数)。
