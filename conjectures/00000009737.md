# 00000009737

**MAD-07 ★** — source: 310_数学的自动发现.md

**English.** Definition: Sample complexity of symbolic regression: the minimal sample count for recovering closed-form formulas from noisy data. Conjecture: Recovering depth-d symbolic formulas requires n^{c d} samples with optimal exponent constant c = 1; under noise level delta the sample complexity gains a log(1/delta) factor with order unchanged. (symbolic regression sample complexity)

**中文。** 定义：符号回归的样本复杂度：从噪声数据恢复闭式公式的最少样本数。猜想：恢复深度 d 的符号公式所需样本数为 n^{c·d} 且指数常数 c=1 为最优；样本复杂度在噪声水平 δ 下增加 log(1/δ) 的对数因子且阶不变。（符号回归样本复杂度）
