# 00000002115

**English.** Definition: The k-core of a random planar triangulation is the irreducible core structure. Conjecture: The concentration window width of the k-core size is c·n^{-1/3}; and the explicit value of c is the critical Map exponent. (triangulation core concentration window)

**中文。** 定义：随机平面三角剖分的 k-核为可约核结构。猜想：k-核尺寸的集中窗口宽度为 c·n^{-1/3}；且 c 的显式值为临界 Map 指数。（三角剖分核集中窗宽）
