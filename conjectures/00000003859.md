# 00000003859

**English.** Definition: The Airy-β process is the soft-edge limiting point process of β-gases. Conjecture: The right tail of its maximum satisfies P(λ_max > s) = exp(−βs³/12)·(1 + c_β s^{−3/2} + O(s^{−3})), with c_β = 0 if and only if β = 2. (Airy beta right tail first correction)

**中文。** 定义：Airy-β 过程指 β-气的 soft edge 极限点过程。猜想：其最大值的右尾满足 P(λ_max > s) = exp(−βs³/12)·(1 + c_β s^{−3/2} + O(s^{−3})),且 c_β 当且仅当 β = 2 时为零。（Airy-β 右尾首修正）
