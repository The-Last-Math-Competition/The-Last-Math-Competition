**English.** Definition: The convex polygon existence theorem states that large point sets contain convex subconfigurations. Conjecture: The exact parameter value of the heptagon is the known candidate, the lower bound is completed by explicit configuration enumeration, and it closes with the upper bound. (closed parameter value of the convex heptagon)
