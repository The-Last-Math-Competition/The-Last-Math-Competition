# 00000008410

**English.** Definition: The motivic invariant spectrum: the value spectrum of the motivic lifts of all birational invariants. Conjecture: The spectrum is countable and well-ordered with order type omega squared; two varieties have the same spectrum if and only if they are motivically equivalent; and the minimal dimension of a first difference in the spectrum is 3, given by a pair of motivically different varieties with equal Betti numbers. (birational motivic spectrum order type)

**中文。** 定义：母题不变量谱指一切双有理不变量的母题化的取值谱。猜想：谱为可数良序且其序型为 ω²；两个簇的谱相同当且仅当母题等价；谱的第一次差异的最小维数为 3，由同 Betti 数的母题差异对给出。（双有理母题谱序型）
