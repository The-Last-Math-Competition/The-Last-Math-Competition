# 00000000061

**AN-02 ★** — source: 04_分析与逼近论.md

**English.** Conjecture: There is no measurable set E ⊂ T for which the exponential system {e^{2πiλx}}_{λ ∈ {0}∪±P} forms an orthogonal basis of L²(E) (a "prime spectral set" does not exist).

**中文。** 猜想：不存在可测集 E ⊂ T,使指数系 {e^{2πiλx}}_{λ ∈ {0}∪±P} 构成 L²(E) 的正交基("素数谱集"不存在)。
