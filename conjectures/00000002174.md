# 00000002174

**English.** Definition: An L-intersecting family is one whose pairwise intersection sizes lie in a set L. Conjecture: The size of the maximal L-intersecting family mod p^k is an explicit power combination of p^{k−1} (the combination given by the mod-p structure of L); a tightening of Frankl–Wilson's projection argument.

**中文。** 定义：L-交族指两两交尺寸落在集合 L 中的族。猜想：mod p^k 的最大 L-交族的尺寸为 p^{k-1} 的显式幂组合(组合由 L 的 mod p 结构给出);由 Frankl–Wilson 的投影论证的紧化。
