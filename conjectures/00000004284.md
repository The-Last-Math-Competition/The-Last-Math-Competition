# 00000004284

**English.** Definition: The quotient spectrum of the BS group is the set of isomorphism types of its quotient groups. Conjecture: The quotient spectrum is always characterized by the orbits of an action of second-order integer matrices, and every orbit contains an explicit countable set of representatives. (orbit representative system of the BS quotient spectrum)

**中文。** 定义：BS 群的商谱指其商群同构型集合。猜想：商谱恒由二阶整数矩阵作用的轨道刻画；且每条轨道含可数显式代表。（BS 商谱轨道代表系）
