# 00000007753

**English.** Definition: The dynatomic polynomial Phi_{n,c}(x) = prod_{d|n} (f_c^d(x)-x)^{mu(n/d)} defines points of exact period n for f_c(x)=x^2+c; the Galois group of its special value Phi^*_{n,c}=Phi_{n,c}(0) is G_n. Conjecture: For all n>=1 with irreducible polynomial, G_n is S_n for odd n or a transitive subgroup of S_n containing an odd permutation for even n; and the exceptional parameters c making the polynomial reducible are finite in number for fixed n, at most 2^{n-1}. (dynatomic Galois classification)

**中文。** 定义：dynatomic 多项式 Φ_{n,c}(x)=Π_{d|n}(f_c^d(x)-x)^{μ(n/d)} 定义 f_c(x)=x^2+c 的周期恰为 n 的点；其特值 Φ^*_{n,c}=Φ_{n,c}(0) 的伽罗瓦群记 G_n。猜想：对一切 n≥1 与 c 使多项式不可约时，G_n 为 S_n（n 为奇）或 S_n 的超奇置换扩张（n 为偶时含一个奇置换的传递子群）；不可约性本身的例外参数 c 的个数在 n 固定时有限且不超过 2^{n-1}。
