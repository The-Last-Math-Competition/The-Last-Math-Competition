# 00000000401

**English.** Definition: LR coefficients c^ν_{λμ} = ⟨s_ν, s_λ s_μ⟩. Conjecture: For fixed λ = (k), every row of the matrix (c^ν_{(k)μ}) indexed by μ ⊂ ν is a gap-free sequence (a multiplicative structure beyond the Pieri rule: any two coefficients in the same row are coprime or equal).

**中文。** 定义：LR 系数 c^ν_{λμ} = ⟨s_ν, s_λ s_μ⟩。猜想：对固定 λ = (k), 索引 μ ⊂ ν 的矩阵 (c^ν_{(k)μ}) 的每行为无间隔序列(Pieri 规则之外的乘性结构:同行任意两系数互素或相等)。
