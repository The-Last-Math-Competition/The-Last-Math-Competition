# 00000009722

**English.** Definition: Radiation fields of nonlinear wave equations: scattering maps at future null infinity. Conjecture: The radiation field map of three-dimensional semilinear waves is a global diffeomorphism from initial data to future null infinity; the derivative loss of the inverse map is exactly one order and cannot be eliminated, the loss given by the sharpness of null-form estimates. (radiation field diffeomorphism)

**中文。** 定义：非线性波方程的辐射场：未来零无穷的散射映射。猜想：三维半线性波方程的辐射场映射为初值到未来类光无穷的整体微分同胚；逆映射的导数损失恰为一阶且不可消除，损失由零形式估计的尖锐性给出。（辐射场微分同胚）
