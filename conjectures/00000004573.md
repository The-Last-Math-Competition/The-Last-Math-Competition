**English.** Definition: Thurston boundary denotes projective class space, map class group action in its on of geodesic sheaf. Conjecture: limit set of Anosov element is spectrum of dimension 0 6g−7 of exactly two item sheaf pair, general subgroup limit set and endpoint by ring subgroup realized. (Thurston limit dimension spectrum)

**中文。** 定义：Thurston 边界指测地层汐的射影类空间,映射类群作用于其上。猜想：伪 Anosov 元的极限集恰为两条层汐对,一般子群极限集的维数取遍 0 到 6g−7 的全谱且端点由循环子群实现。（Thurston 极限维数全谱）
