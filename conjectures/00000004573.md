# 00000004573

**HA3-03 ★** — source: 138_双曲几何的解析面.md

**English.** Definition: The Thurston boundary is the projective class space of measured laminations, on which the mapping class group acts. Conjecture: The limit set of a pseudo-Anosov element is exactly a pair of laminations, the dimensions of the limit sets of general subgroups take the full spectrum from 0 to 6g-7, and the endpoints are realized by cyclic subgroups. (full spectrum of Thurston limit dimensions)

**中文。** 定义：Thurston 边界指测地层汐的射影类空间,映射类群作用于其上。猜想：伪 Anosov 元的极限集恰为两条层汐对,一般子群极限集的维数取遍 0 到 6g−7 的全谱且端点由循环子群实现。（Thurston 极限维数全谱）
