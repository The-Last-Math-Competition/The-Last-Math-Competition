# 00000008567

**NSP-07 ★** — source: 271_非自伴算子与无限图谱.md

**English.** Definition: The paving conjecture (Kadison-Singer): partition a matrix by rows into r subblocks so that each block has norm reduced to (1-epsilon)^2 of the full norm. Conjecture: The number of subblocks r needs only be of order epsilon^{-2} log n (a logarithmic dependence law); and the lower bound for this bound matches (a matching law); random sign families attain the worst case (a random sign family law); and the exact constant of minimal r is an explicit function of 12 (a twelve-constant law). (Kadison-Singer paving logarithmic twelve)

**中文。** 定义：铺路猜想（Kadison–Singer）：将矩阵按行划分为 r 个子块使每块的范数降至 (1-ε)²·全范数。猜想：子块数 r 只需 (ε^{-2}·log n) 量级（对数依赖律）；且该界的下界匹配（匹配律）；随机符号族达到最坏情形（随机符号族律）；极小 r 的精确常数为 12 的显式（十二常数律）。
