# 00000008381

**English.** Definition: Motivic measure: the formal measure on arc spaces defined by Kontsevich with values in a category of motives; motivically measurable sets are arc sets where this measure is defined. Conjecture: The class of motivically measurable sets is closed under complements, finite unions, and binary products, and the measure of every motivically measurable set is a convergent arc measure after realization; and a minimal example of non-motivic measurability must be a projective-limit type arc set that is not Kontsevich measurable, whose construction requires uncountable ascending chains. (motivic measurability closure)

**中文。** 定义：母题测度指弧空间上由 Kontsevich 定义、取值于母题范畴的形式测度，母题可测集指该测度有定义的弧集。猜想：母题可测集的类在补、有限并与二元乘积下封闭，且每个母题可测集的测度为实化后收敛的收敛弧测度；非母题可测的极小例子须为非 Kontsevich 可测的射影极限型弧集，其构造需不可数升链。（母题可测封闭性）
