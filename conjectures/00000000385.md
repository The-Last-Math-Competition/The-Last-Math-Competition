# 00000000385

**English.** Definition: Approximation on Conway's topograph game (the Markov tree). Conjecture: The set of cluster points of the constants along any infinite path of the Markov tree is closed and nowhere dense, and contains all quadratic-irrational Markov constants.

**中文。** 定义：Conway 的 Topograph game 上的逼近(Markov 树)。猜想：Markov 树上任意无穷路径的常数聚点集为闭无处稠密集,且包含全部二次无理 Markov 常数。
