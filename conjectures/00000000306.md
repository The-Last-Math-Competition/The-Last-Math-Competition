# 00000000306

**DA-06 ★** — source: 19_丢番图逼近与度量数论.md

**English.** Definition: Intrinsic approximation on the Cantor set means approximation by "fractions" c/d ∈ C(1/4) (pairs of points with 4-adic expansions using only 0 and 2). Conjecture: For almost every ξ ∈ C(1/4), there are infinitely many c/d ∈ C(1/4) with |ξ − c/d| < 1/(d² log d).

**中文。** 定义：Cantor 集上的内在逼近:用 C(1/4) 中的"分数"(4-进展开只含 0,2 的点对)逼近。猜想：对 a.e. ξ ∈ C(1/4),有无穷多 c/d ∈ C(1/4) 使 |ξ − c/d| < 1/(d² log d)。
