# 00000003981

**English.** Definition: The Nullstellensatz system NS is the proof system whose certificates are polynomial identities. Conjecture: Formulas based on the combinatorial expansion parameter t always satisfy the NS degree lower bound t - 1, with equality attained by Tseitin formulas on sparse graphs, so the bound cannot be improved. (exact NS degree-expansion)

**中文。** 定义：Nullstellensatz 系统 NS 指以多项式恒等式为证书的系统。猜想：基于组合扩张参数 t 的公式恒有 NS 度下界 t − 1,且等号由稀疏图 Tseitin 公式达到,界不可改进。（NS 度-扩张精确）
