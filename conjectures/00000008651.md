# 00000008651

**English.** Definition: The word problem: deciding whether a given word w in a group G represents the identity. Conjecture: The algebraic characterization of the class of groups with solvable word problem as recursively presentable plus locally indicable cannot be realized as a biconditional within finitely generated groups (a non-birealization law); the optimal complexity of the word problem for hyperbolic groups matches the linear-time lower bound (a linear matching law); and groups with linearly solvable word problem but not hyperbolic exist, with examples given by large nilpotency class groups (a nilpotent example law). (word problem linear matching nilpotent examples)

**中文。** 定义：字问题：群 G 中给定字 w 是否表示单位元的判定问题。猜想：字问题可解群的类的代数刻画为可呈现为递归呈现+局部可解递归的双条件在有限生成范畴内不可实现（不可双实现律）；且双曲群的字问题的最优复杂度为线性时间的下界匹配（线性匹配律）；非双曲的字问题线性可解的群的存在（非双曲线性例）的例为大幂零类群（幂零例律）。
