# 00000004632

**English.** Definition: The weight-one space V_1 of a holomorphic VOA is the realizable domain of dimensions under central charge c. Conjecture: For c below 24 the dimension of V_1 takes only 0 or 1, and it is 1 if and only if a weight-one squared cusp vector exists; for c between 24 and 48 the dimension lies in the explicit interval between 0 and c/2, with every integer realized by Niemeier-type lattice constructions; at c = 48 the realizable dimensions form a finite isolated set given by imaginary-magic-lattice-type structures. (interval constraints on weight-one dimensions)

**中文。** 定义：全纯 VOA 的权一空间 V₁：中心荷 c 下维数的可实现域。猜想：c < 24 时 V₁ 维数只能取 0 或 1 且取 1 当且仅当存在权一的平方尖点向量；24 ≤ c ≤ 48 时维数落在 0 与 c/2 的显式区间内且一切整点由 Niemeier 型格子构造实现；c=48 时维数的可实现值为有限孤立集且由虚魔幻格型结构给出。（权一维数区间约束）
