# 00000001308

**CC-08 ★** — source: 29_多复变与复几何.md

**English.** Definition: The Dirichlet problem with Levi-flat boundary concerns solvability on pseudoconvex domains. Conjecture: Solvability is always equivalent to the vanishing of the CR extension obstruction class in H²; and the obstruction class is given by Kohn–Rossi cohomology. (obstruction class KR cohomology criterion)

**中文。** 定义：Levi 平坦边界的 Dirichlet 问题指拟凸域上的可解性。猜想：可解性恒等价于 CR 延拓障碍类在 H² 中消没；且障碍类由 Kohn–Rossi 上同调给出。（障碍类 KR 上同调判据）
