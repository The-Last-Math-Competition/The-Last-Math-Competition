# 00000004482

**English.** Definition: The effective topos is the sheaf category defined by computable realizability. Conjecture: The table of countable algebraic objects inside it coincides with the classical table if and only if the object is a locally finite group, the coincidence domain is explicit, and the smallest counterexample is a Baer-Specker type group. (locally finite coincidence domain of the effective topos)

**中文。** 定义：有效拓扑斯指以可计算可实现性定义的层范畴。猜想：其内部的可数代数对象表与经典表重合当且仅当对象为局部有限群,重合域显式,最小反例为 Baer–Specker 型群。（有效拓扑斯局部有限重合域）
