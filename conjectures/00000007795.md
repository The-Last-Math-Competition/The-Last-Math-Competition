# 00000007795

**ACG-15 ★** — source: 245_渐近凸几何.md

**English.** Definition: Regularity stratification of lattice counting: the error E(t) = |tP intersect Z^n| - t^n vol(P) for the dilation tP. Conjecture: The optimal error for Lipschitz boundaries is O(t^{n-2+1/3}) and for C^2 boundaries O(t^{n-2}); no intermediate regularity exists between the exponents 1/3 and 0 (any Holder exponent alpha in (0,1) has the error order jumping when alpha crosses 1/2), the jump location being jointly determined by Fourier damping and the Diophantine properties of the lattice. (lattice-counting regularity jump)

**中文。** 定义：格点计数的正则性分界：体积 t·P（t 放缩）的格点计数误差 E(t)=|tP∩Z^n|-t^n vol(P)。猜想：Lipschitz 边界的误差最优为 O(t^{n-2+1/3})；C^2 边界为 O(t^{n-2})；两类边界的指数 1/3 与 0 之间不存在中间正则度（任何 Hölder 指数 α∈(0,1) 的边界的误差阶在 α 越过 1/2 时发生跳变），跳变位置由 Fourier 阻尼与格的 Diophantine 性质共同决定。
