# 00000004600

**HA3-30 △** — source: 138_双曲几何的解析面.md

**English.** Definition: The Selberg zeta zero-multiplicity spectrum is the spectrum arranged by multiplicities. Conjecture: There exist two hyperbolic surfaces with the same multiplicity spectrum but non-isomorphic mapping class groups, and the separation is realized by Sunada-type isometric covering pairs. (Selberg multiplicity-mapping class separation)

**中文。** 定义：Selberg zeta 零点重数谱指按重数排列的谱。猜想：存在两个双曲曲面的重数谱相同而映射类群不同构,分离由 Sunada 型等距覆盖对实现。（Selberg 重数-映射类分离）
