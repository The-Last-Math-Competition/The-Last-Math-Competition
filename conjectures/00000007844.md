# 00000007844

**English.** Definition: The mixing time T_mix(q,n) of the adjacent-transposition Markov chain on the Mallows permutation model P_n(q) (the uniform permutation distribution weighted by inversion count). Conjecture: The phase transition point of T_mix is q_c = 1 (uniform); for fixed q < 1 one has T_mix = Theta(n log n) with an explicit leading constant of type 2/(1-q) times log(1/q); and the critical window as q approaches 1 with n has width (1-q) n^{1/2}, inside which the mixing time is Theta(n^{3/2}). (Mallows chain mixing transition)

**中文。** 定义：Mallows 排列模型 P_n(q)（按逆序数加权的均匀排列分布）上相邻交换 Markov 链的混合时间 T_mix(q,n)。猜想：T_mix 的相变点为 q_c=1（均匀）；当 q<1 固定时 T_mix=Θ(n log n)，且常数系数为 2/(1-q)·log(1/q) 型显式式；q 随 n 趋于 1 的临界窗宽为 (1-q)n^{1/2}，窗内混合时间为 Θ(n^{3/2})。
