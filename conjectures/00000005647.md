# 00000005647

**English.** Definition: A balanced line is a line with equal color counts on each side, an equitable line. Conjecture: The two-color balanced conversion constant is the explicit formula of the crossing number of the color permutation, attained at alternating permutations; balanced lines always exist, at least 3; and the crossing-number threshold is n^2/4, with tight example the color-block-separated arrangement. (two-color crossing balanced constant conversion)

**中文。** 定义：平衡线：两侧色数相等的直线（ equitable line）。猜想：双色的平衡换算常数为色排列交叉数的显式公式且交替排列处达到；平衡线恒存在且个数至少为 3；交叉数阈值为 n²/4 且阈值的紧例为色块分离排列。（双色交叉平衡常数换算）
