# 00000008873

**English.** Definition: Short games: the inductive class of finite games. Conjecture: The class has the cardinality of the continuum realized by binary game trees; and the kernel of the trees is leaf depth. (short continuum binary leaf depth)

**中文。** 定义：short games 为有限游戏的归纳类。猜想：类的基数为连续统且实现为二叉博弈树；且树的核为叶深。（short 连续统二叉树叶深实现）
