# 00000002196

**English.** Definition: The Dedekind number M(n) counts monotone Boolean functions. Conjecture: The second coefficient of the asymptotic expansion is explicit: log M(n) = (log 2 − (log n)^{-1}(loglog n + c)²)·C(n,⌊n/2⌋)(1+o(1)), with c = −3/2.

**中文。** 定义：Dedekind 数 M(n) 指单调布尔函数的个数。猜想：M(n) 的渐近展开的第二项系数 c 为显式:log M(n) = (log 2 - (log n)^{-1}(loglog n + c)^{2})C{n}{⌊n/2⌋}(1+o(1)),c = -3/2。
