# 00000005870

**English.** Definition: The stability constant and the convergence spectrum are two layers. Conjecture: There exist two element pairs with the same stability constant but different convergence spectra, and the separation is realized by an explicit pair with the same stability but different approximation. (same stability constant-different convergence spectrum separation)

**中文。** 定义：稳定常数与收敛谱指两层。猜想：存在两单元对的稳定常数相同而收敛谱不同,分离由同稳定异逼近的显式对实现。（稳定常数同-收敛谱异分离）
