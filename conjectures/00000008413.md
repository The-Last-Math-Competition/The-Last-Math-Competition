# 00000008413

**English.** Definition: A perfect difference set is a difference set of Singer type (q^2+q+1, q+1, 1). Conjecture: Cyclic difference sets with parameters (n^2+n+1, n+1, 1) exist only when n is a prime power; difference sets with the same parameters on noncyclic abelian groups exist if and only if n is a prime power; and the smallest group order for such a difference set on a nonabelian group is the dihedral exception of order 21. (existence boundary of perfect difference sets)

**中文。** 定义：完美差集指 Singer 差集型 (q²+q+1, q+1, 1) 的差集。猜想：参数为 (n²+n+1, n+1, 1) 的循环差集仅当 n 为素数幂时存在；非循环 Abel 群上的同参数差集当且仅当 n 为素数幂；非 Abel 群上同参数差集的最小群阶为 21 的二面体例外。（完美差集存在分界）
