# 00000000360

**English.** Definition: Minkowski's linear-forms product conjecture asserts: for a product of n linear forms in n variables, there is a nonzero integer point with |L₁⋯L_n| ≤ (n!/n^n)·|det|. Conjecture: For n = 10, the constant n!/n^n cannot be improved for completely split diagonal forms, and the minimizing integer point can be found inside a convex body of volume at most C·n².

**中文。** 定义：Minkowski 线性型乘积猜想断言:对 n 个 n 元线性型的乘积,存在非零整点使 |L₁⋯L_n| ≤ (n!/n^n)·|det|。猜想：n=10 时该常数 n!/n^n 对完全拆分的对角型不可再改进,且最小化整点可在体积 ≤ C·n^{2} 的凸体内找到。
