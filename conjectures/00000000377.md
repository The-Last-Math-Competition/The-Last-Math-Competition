# 00000000377

**DA-77 ★** — source: 19_丢番图逼近与度量数论.md

**English.** Definition: The approximation dimension of an algebraic number ξ in the complex plane is the Hausdorff dimension of the set of rational-function parameters for which ξ is an accumulation point of periodic points of the Julia set of an iterate. Conjecture: On the boundary of the Mandelbrot set of the quadratic family z²+c, the set of parameters for which the multiplier of a parabolic periodic point is a Liouville number has dimension 1, while the set of parameters for which the multiplier is badly approximable is full-dimensional.

**中文。** 定义：复平面上代数数 ξ 的逼近维数指满足 ξ 为某有理函数族迭代Julia集周期点聚点的有理函数参数的 Hausdorff 维数。猜想：二次族 z²+c 的 Mandelbrot 集边界上,使抛物周期点的 multiplier 为 Liouville 数的参数点集的维数为 1,而使 multiplier 为坏逼近数的参数点集满维。
