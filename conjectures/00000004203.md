# 00000004203

**English.** Definition: The Yamabe invariant is the supremum of the Yamabe constants over all conformal classes. Conjecture: The first width and the Yamabe invariant satisfy the inequality W_1 >= c * Y^{n/2}, with the constant c explicit and equality attained by the sphere. (Yamabe-first width inequality)

**中文。** 定义：Yamabe 不变量指全体共形类 Yamabe 常数的上确界。猜想：首宽度与 Yamabe 不变量满足不等式 W₁ ≥ c·Y^{n/2},常数 c 显式且由球面达到等号。（Yamabe-首宽度不等式）
