# 00000004220

**HT2-10 △** — source: 126_组合代数拓扑_高阶树.md

**English.** Definition: The tree count vector is the sequence of higher tree counts arranged by dimension. Conjecture: There exist two triangulations with identical tree counts in all dimensions but non-isomorphic homology groups, and the smallest separation is already realized by two-dimensional complexes. (minimal dimension of tree count-homology separation)

**中文。** 定义：树计数向量指按维数排列的高维树计数列。猜想：存在两剖分的全维树计数相同而同调群不同构,最小分离在二维复形即可实现。（树计数-同调分离最小维）
