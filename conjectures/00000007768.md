# 00000007768

**English.** Definition: Algebraicity of Julia sets: the Julia set J(f) of a complex polynomial f is a closed subset of the plane. Conjecture: J(f) contains a dense open arc of an algebraic curve if and only if f is conjugate to z^d or a Chebyshev polynomial plus or minus T_d; in the exceptional cases the fractal dimension of J(f) takes the integer value 1, while otherwise it is a number greater than 1 which is transcendental for algebraic coefficients, with the exceptional family corresponding to countably many cusp-type parameters. (Julia algebraic-arc dichotomy)

**中文。** 定义：Julia 集的代数性：复多项式 f 的 Julia 集 J(f) 为复平面的闭子集。猜想：J(f) 包含一条代数曲线的稠密开弧当且仅当 f 共轭于 z^d 或 Chebyshev 多项式 ±T_d；且在例外情形下 J(f) 的分形维数取整数值 1，其他情形分形维数为 >1 的数，其超越性当系数为代数数时成立，例外族为可数个 cusp 型参数对应的映射。
