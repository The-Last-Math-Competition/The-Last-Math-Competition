# 00000009822

**English.** Definition: The Bellman function method: optimal constants of weighted inequalities from worst-case dynamic programming (Vasyunin's palace models have solved several). Conjecture: The Bellman function of paraproducts is a completely algebraic function: its extremal trajectories are piecewise linear with each segment slope an explicit function of the Muckenhoupt exponent; the algebraic degree does not exceed twice the weight exponent. (paraproduct Bellman algebraicity)

**中文。** 定义：Bellman 函数方法：加权不等式的最优常数由最坏局面动态规划给出（Vasyunin 宫模型已解多个）。猜想：抛积的 Bellman 函数为完全代数函数：其极值轨迹为分段线性且每段斜率为 Muckenhoupt 指标的显式函数；代数度不超过权指数的两倍。（抛积 Bellman 代数化）
