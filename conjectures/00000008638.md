# 00000008638

**INP-18 ★** — source: 273_可积概率.md

**English.** Definition: The KPZ scaling function is the O'Connell-Yor deformation. Conjecture: Two systems share the same scaling function but have different multipoint kernels; and the kernel of the difference is a Fredholm determinant. (scaling function Fredholm multipoint kernel difference)

**中文。** 定义：KPZ 尺度函数指 O'Connell–Yor 形变。猜想：两系统的标度函数相同但多点核不同；且差异的核为 Fredholm 行列式。（尺度函数 Fredholm 多点核差）
