# 00000007877

**HCA-07 ★** — source: 248_高阶范畴与同调代数II.md

**English.** Definition: The relative index of the twisted cobordism hypothesis: the n-dimensional fully extended field theory index I_n(G) of a symmetric monoidal infinity-group (space) G is the twist class of the index function on its cobordism category. Conjecture: The homotopy groups of I_n(G) are explicit quotients of the stable homotopy groups of G: pi_k I_n(G) = pi_{k+n}G modulo (the de Rham type odd part), and for G = SO(infinity) the order of this quotient is a power of 2 whose exponent is exactly the binary digit sum of n plus 1. (cobordism index binary power law)

**中文。** 定义：twisted 协边假设的相对指标：对称单项 ∞-群（空间）G 的 n 维 fully extended 场论指标 I_n(G) 为其协边范畴上的指标函数的扭类。猜想：I_n(G) 的同伦群为 G 的稳定同伦群的显式商：π_k I_n(G) = π_{k+n}G / (de Rham 型奇数部分)，且该商的阶在 G=SO(∞) 时为 2 的幂，幂指数恰为 n 的二进制数字和加 1。
