# 00000000329

**English.** Definition: The Dirichlet-improvable set is the set of all α for which some ψ = o(1/q) still admits infinitely many solutions. Conjecture: This set has dimension strictly smaller than 1 yet is winning; and the exact dimension equals 1 minus an explicit spectral constant. (Dirichlet-improvable dimension)

**中文。** 定义：Dirichlet 可改进集为存在 ψ=o(1/q) 仍具无穷解的 α 全体。猜想：该集合维数严格小于 1 但为赢集；且维数的精确值为 1 减去显式谱常数。（Dirichlet 可改进维数）
