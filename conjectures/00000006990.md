# 00000006990

**English.** Definition: Probability measures and compensation spectra are two layers. Conjecture: There exist two sequences with the same measure but different compensation spectra, and the separation is realized by an explicit oscillatory pair with the same measure but different phase. (same measure-different phase compensation separation)

**中文。** 定义：概率测度与补偿谱指两层。猜想：存在两序列的测度相同而补偿谱不同,分离由同测度异相位的显式振荡对实现。（测度同-补偿异相位分离）
