# 00000003928

**English.** Definition: Relative Floer homology is Hamiltonian Floer homology on a domain with boundary, and the puncture count is the number of punctures on the boundary. Conjecture: The puncture-count threshold up to which relative Floer is independent of the puncture positions is n+1; beyond the threshold the explicit position-dependent correction term is logarithmic in the number of punctures. (relative Floer puncture threshold)

**中文。** 定义：相对 Floer 指带边区域上的 Hamilton Floer,穿孔数指边界穿孔的个数。猜想：相对 Floer 不依赖穿孔位置的穿孔数阈值为 n+1;超过阈值后依赖穿孔的显式修正项为穿孔数的对数。（相对 Floer 穿孔阈值）
