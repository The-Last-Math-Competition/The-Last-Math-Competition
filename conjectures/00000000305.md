**DA-05 ◆** — source: 19_丢番图逼近与度量数论.md

**English.** Definition: A vector x ∈ R² is doubly badly approximable if x and its first coordinate x₁ both satisfy a one-dimensional bad-approximability condition (there exist c₁, c₂ > 0 with ‖qx₁‖ > c₁/q and max(‖qx₁‖, ‖qx₂‖) > c₂/q for all q). Conjecture: The set of doubly badly approximable vectors intersects any C¹ nondegenerate curve in a set of Hausdorff dimension 0, and for certain explicit parabolas this intersection has the cardinality of the continuum.

**中文。** 定义：向量 x∈R² 称双坏逼近,指 x 与其第一个坐标 x₁ 同时满足一维坏逼近条件(分别存在 c₁,c₂>0 使 ‖qx₁‖>c₁/q 与 max(‖qx₁‖,‖qx₂‖)>c₂/q 对一切 q)。猜想：双坏逼近向量集与任意 C¹ 非退化曲线的交的 Hausdorff 维数为 0,且对某类显式抛物线该交集基数为连续统。
