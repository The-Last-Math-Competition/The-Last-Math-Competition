# 00000007934

**English.** Definition: The string hypothesis of the Bethe ansatz: the string structure (nearly equidistant root clusters of increasing length) of Bethe roots of the XXZ chain (anisotropy Delta) in the thermodynamic limit. Conjecture: The strict string hypothesis (without nested string artifacts) holds only in the antiferromagnetic region Delta > 1; for |Delta| < 1 the string width has a logarithmic correction of type 1/log N, and the deviation of the string energy centers is N^{-1} c(Delta) (c an elliptic constant), consistent with the Luscher term (finite-size correction); and the maximal string length in the vacuum state is controlled by floor(N theta(Delta)/2 pi) (theta the imaginary period of the elliptic function). (XXZ string hypothesis log correction)

**中文。** 定义：Bethe ansatz 的串假设：XXZ 链（各向异性 Δ）的 Bethe 根在热力学极限下的串（string）结构（长度递增的近似等距根簇）。猜想：严格串假设（无嵌套串假象）仅在 Δ>1 的反铁磁区域成立；且 |Δ|<1 时串的宽度为 1/log N 型对数修正，串的能谱中心（弦能量）的偏差为 N^{-1}·c(Δ)（c 为Elliptic常数），修正与 Lüscher 项（有限尺寸修正）一致；串的长度的最大值在真空态被 floor(N·θ(Δ)/2π) 控制（θ 为椭圆函数的虚周期）。
