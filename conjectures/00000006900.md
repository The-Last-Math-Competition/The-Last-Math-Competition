# 00000006900

**English.** Definition: Border rank and degeneration spectra are two layers. Conjecture: There exist two tensors with the same border rank but different degeneration spectra, and the separation is realized by an explicit curve pair with the same boundary but different degeneration paths. (same border-different degeneration curve separation)

**中文。** 定义：边界秩与退化谱指两层。猜想：存在两张量的边界秩相同而退化谱不同,分离由同边界异退化路径的显式曲线对实现。（边界同-退化异曲线分离）
