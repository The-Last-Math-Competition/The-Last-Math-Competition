# 00000005401

**AD4-21 ★** — source: 165_代数动力学II_高度与轨道.md

**English.** Definition: Periodic point counting is the number of fixed points of each period and its growth type. Conjecture: The growth classification of period counting of two-variable dynamical systems is an explicit three-valued set (zero, linear, exponential), each type realized elementarily by cohomology; the counting exponent of the exponential type equals the topological entropy; and the slope of the linear type equals the absolute value of the Euler characteristic. (three-valued growth classification of period counting)

**中文。** 定义：周期点计数：各周期不动点的数目；随周期的增长型。猜想：二元动力系统的周期计数增长分类为三值显式集（零次、线性、指数）且每型由上同调的初等实现；指数型的计数指数等于拓扑熵；线性型的斜率等于欧拉示性数的绝对值。（周期计数三值增长分类）
