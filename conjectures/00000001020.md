# 00000001020

**English.** Definition: The optimal code function k(n,d) is the maximal dimension of a binary code. Conjecture: At superplanes n and half-power d, its value is a hypergraph algebra dimension; and the kernel of the algebra is the Turan tower value. (superplane Turan tower optimal code dimension)

**中文。** 定义：最优码函数 k(n,d) 为二元码最大维数。猜想：超平面 n 与 d 的二分之一次幂处的值为超图代数维；且代数的核为 Turan 塔值。（超平面 Turan 塔最优码维数）
