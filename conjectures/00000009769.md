**English.** Definition: Schatten of weighted Hilbert then Schatten p of: H_f with respect to weight v. Conjecture: weighted Hilbert belongs to Schatten p if and only if weight function satisfies regularity; p=2 degenerate of Carleson type embedding p dependence is Helson–Szegő conjugate and for all p<∞ continuous. (weighted Hilbert Schatten then)
