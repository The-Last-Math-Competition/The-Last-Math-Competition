# 00000000519

**English.** Definition: Multigraded regularity region: for a bigraded module M, the regularity set reg(M) ⊂ Z² is the complement of the index set where the local cohomology vanishes. Conjecture: For Segre–Veronese ideals of fixed bigraded type and fixed regularity, reg(M) is a convex lattice polyhedron whose vertex count is bounded by a constant depending only on the ring type and the generation degrees; and multigraded Boij–Söderberg decompositions exist uniformly over this region.

**中文。** 定义：多重分次正则性区域:双分次模 M 的正则度集合 reg(M)⊂Z²,即 H^i(β) 消没的指标集补集。猜想：对固定双分次类型与固定正则度的 Segre–Veronese 理想,reg(M) 为凸格多面体,且其顶点数不超过只依赖于环类型与理想生成次数的常数;多分次 Boij–Söderberg 分解在该区域上一致存在。
