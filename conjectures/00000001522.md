# 00000001522

**English.** Definition: The L-theoretic assembly is the spectral invariant for manifold classification. Conjecture: The order of the structure set of a nonpositively curved manifold is always of an explicit homology-group type; and the structure set is finite. (nonpositive curvature structure set formula)
