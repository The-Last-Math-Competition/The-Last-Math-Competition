# 00000002760

**English.** Definition: Engel-type matrix spaces: iterated vanishing of [X,Y]. Conjecture: The classification of Engel-type matrix spaces: the dimension of k-Engel linear spaces is n² − n + c(k), with correction c(k) monotonically decreasing to zero in k. (Engel space dimension correction)

**中文。** 定义：矩阵空间的 Engel 型：[X,Y] 迭代消失。猜想：Engel 型矩阵空间的分类：k-Engel 线性空间的维数为 n² − n + c(k) 且修正 c(k) 随 k 单调下降到零。（Engel 空间维数修正）
