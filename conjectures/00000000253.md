# 00000000253

**English.** Definition: u(n) is the maximum number of distinct unit distances determined by n points in the plane. Conjecture: The Erdős unit-distance problem satisfies u(n) = n^{1+o(1)} (known lower bound n^{1+c/log log n}, upper bound n^{4/3}/log n).

**中文。** 定义：u(n):n 个平面点决定的不同单位距离的最大个数。猜想：Erdős 单位距离问题 u(n) = n^{1+o(1)}(已知下界 n^{1+c/log log n},上界 n^{4/3}/log n)。
