# 00000003917

**English.** Definition: SH nullity is the vanishing of symplectic homology, and the filling slope is the set of slopes of the contact cone at the boundary of an exact filling. Conjecture: For an exact filling with pseudoconvex boundary, SH nullity holds if and only if the slope cone is a rationally closed cone; for the sphere with n holes removed, SH is nonzero if and only if n <= 2. (SH nullity-slope cone criterion)

**中文。** 定义：SH 零性指辛同调的消没,填充斜率指 exact 填充边界的切触锥的斜率集。猜想：具伪凸边界的 exact 填充的 SH 零性当且仅当斜率锥为有理闭锥;球去掉 n 个洞的情形 SH 非零当且仅当 n ≤ 2。（SH 零性-斜率锥判据）
