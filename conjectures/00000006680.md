**OT3-10 △** — source: 208_最优传输II_离散.md

**English.** Definition: The optimal value and the dual structure are two layers. Conjecture: There exist two transport problems with the same optimal value but different dual structures, and the separation is realized by an explicit degenerate cost pair with the same value but different support. (same value-different support separation)

**中文。** 定义：最优值与对偶结构指两层。猜想：存在两传输问题的最优值相同而对偶结构不同,分离由同值异支撑的显式退化费用对实现。（值同-对偶异支撑分离）
