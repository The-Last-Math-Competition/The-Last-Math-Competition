# 00000007957

**English.** Definition: The integrable-type Ramsey boundary: the fractal dimension d_adm of the admissible initial-value set (the set of initial points whose iteration orbits under an integrable map are admissible). Conjecture: d_adm = dimension minus kappa/log 2 (kappa the algebraic entropy); in the integrable limit kappa to 0, d_adm recovers full dimension (full Lebesgue); and for nonintegrable maps the pointwise spectrum of d_adm has self-similar scaling factors in parameter space equal to the inverse of a golden-ratio-type Pisot number (a universal scaling law for one-dimensional area-preserving maps). (admissible set Pisot scaling law)

**中文。** 定义：可积型的 Ramsey 边界：可积映射的迭代轨道的初始点的占位（admissible 初值集）的分形维数 d_adm。猜想：d_adm = 维数 - κ/log2（κ 为代数熵）；且可积极限 κ→0 时 d_adm 恢复为全维（Lebesgue 满）；对不可积映射 d_adm 的分形维数的点态谱在参数空间的自相似缩放因子为 golden ratio 型 Pisot 数的逆（一维保面积映射的普遍缩放律）。
