**English.** Definition: A tilting object generates the category and has no self-extensions. Conjecture: The minimal tilting-object table in the hereditary case is given explicitly by path algebras, closed for tree quivers, with count equal to the number of vertices. (hereditary minimal tilting path-algebra table)
