**English.** Conjecture: Minimal transitivity of prime orbits: in any minimal topological dynamical system (X, T), for every x ∈ X the orbit closure {T^{p_n}x : n ≥ 1} equals X.

**中文。** 猜想：素数轨道的极小传递性:在任何极小拓扑动力系统 (X, T) 中,对每个 x ∈ X,轨道闭包 {T^{p_n}x : n ≥ 1} = X。
