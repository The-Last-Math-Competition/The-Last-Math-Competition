# 00000006180

**English.** Definition: Counting asymptotics and limit shapes are two layers. Conjecture: There exist two graph classes with the same counting asymptotics but different limit shapes, and the separation is realized by an explicit class pair with the same singularity but different contours. (same counting asymptotics-different limit-shape separation)
