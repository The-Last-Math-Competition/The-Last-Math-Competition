# 00000001486

**English.** Definition: The fractal uncertainty principle (FUP). Conjecture: On any convex-cocompact hyperbolic surface, the FUP spectral-gap lower bound from the limit set is of the explicit δ(1−δ) type (an FUP constant for general limit sets).

**中文。** 定义：分形不确定性原理(FUP)。猜想：任意凸余紧双曲曲面上由极限集给出的 FUP 谱隙下界为 δ(1−δ) 型显式(一般极限集的 FUP 常数)。
