# 00000001477

**English.** Definition: The bit complexity of an SOCP is the total bit length of operations in the Turing model. Conjecture: Any exact algorithm for second-order cone programming has bit-model complexity lower bound Ω(L²·n), where L is the input bit length; that is, the bit complexity is quadratic in the input length, dual to the strongly polynomial property of the real model.

**中文。** 定义：SOCP 的位复杂度指其 Turing 模型下的运算位长总和。猜想：二阶锥规划的任何精确算法在位模型下的复杂度下界为 Ω(L²·n),L 为输入位长;即位复杂度与输入位长呈平方关系,与实数模型的强多项式性质对偶。
