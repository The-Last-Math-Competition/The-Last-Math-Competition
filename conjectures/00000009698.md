# 00000009698

**English.** Definition: The algebraic independence structure of odd zeta values zeta(2n+1): zeta(3) is known transcendental (Apery). Conjecture: The transcendence degree of the first k odd zeta values zeta(3),...,zeta(2k+1) is exactly k; and all Q-linear relations among odd-even double zeta values are generated by generalized double shuffle and regularization, with no new relations. (complete odd zeta spectrum)

**中文。** 定义：奇 ζ 值 ζ(2n+1) 的代数无关结构：已知 ζ(3) 超越（Apéry）。猜想：前 k 个奇 ζ 值 ζ(3),…,ζ(2k+1) 的超越次数恰为 k；奇偶双 ζ 的所有 Q 线性关系由广义 double shuffle 与正则化生成，无新关系。（奇 zeta 完全谱）
