# 00000001900

**ML-30 △** — source: 48_逻辑与模型论II.md

**English.** Definition: The Rudin–Keisler order type of a σ-complete ultrafilter is its equivalence class in the RK partial order. Conjecture: The realizable order types are explicit in the embedding order of the Woodin hierarchy (i.e. the order type is the canonical layering of the supercompact tower); there are no isolated RK types; and the layer structure of the order types is indexed by the critical-point sequences of embeddings.

**中文。** 定义：σ-完全超滤的 Rudin–Keisler 序型指超滤在 RK 偏序下的等价类。猜想：可实现序型由 Woodin 层次的嵌入序显式(即序型 = supercompact 塔的典范层);无孤立 RK 型；且序型的层结构由嵌入的临界点序列索引。
