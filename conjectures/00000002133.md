# 00000002133

**English.** Definition: The Dedekind number M(n) counts monotone Boolean functions. Conjecture: The exact value of M(10) is obtainable with present computational resources; and the computational complexity has an exponential lower bound. (Dedekind number M10 computationally feasible)
