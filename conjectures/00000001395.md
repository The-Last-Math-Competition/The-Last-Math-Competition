# 00000001395

**English.** Definition: The image of the J-homomorphism is the J-family in the stable homotopy of spheres detected by Adams q-operations. Conjecture: The element of minimal Adams filtration in the complement π_*^S ∖ im J is β₁ (with filtration 2, whereas the J-family has filtration 1); that is, the first non-J element occurs in Adams filtration 2.

**中文。** 定义：J 同态的像为球面稳定同伦中由 Adams q-运算检测的 J-族。猜想：补集 π_*^S∖im J 中 Adams 分滤最小的元素为 β₁(其分滤为 2,而 J-族分滤为 1);即非 J 元素的首例出现在 Adams 分滤 2。
