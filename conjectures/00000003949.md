# 00000003949

**English.** Definition: The graph burning number b(G) is the minimal number of rounds needed so that every vertex is covered by a fire source in some round. Conjecture: The burning number of the n by n square grid is exactly the ceiling of 2*sqrt(n) - 1, and for a general m by n grid with m <= n it is given by an explicit piecewise correction of this formula. (closed form for grid burning numbers)

**中文。** 定义：graph burning number b(G) 指使每点在某轮被火源覆盖所需的最小轮数。猜想：n × n 方形网格的燃烧数恰为 ⌈2√n − 1⌉;一般 m × n 网格 (m ≤ n) 的燃烧数为该式的显式分段修正。（网格燃烧数闭式）
