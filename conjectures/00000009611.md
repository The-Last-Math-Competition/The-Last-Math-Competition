# 00000009611

**SMA-01 ★** — source: 306_Smale空间与符号动力学.md

**English.** Definition: Mixing subshifts of finite type (SFT) are defined by allowed words of a nonnegative integer matrix A, with entropy h = log lambda for the Perron eigenvalue lambda; Lind proved that Perron numbers are exactly the realizable entropy values. Conjecture: The minimal size of a matrix realizing a Perron number lambda as an SFT entropy is an explicit function f(d) of the algebraic degree d(lambda), and f(d) = d if and only if the coefficients of the minimal polynomial of lambda satisfy the sign-alternating condition. (Perron minimal realization dimension)

**中文。** 定义：混合子移位有限型（SFT）由非负整矩阵 A 的允许词定义，其熵 h=log λ，λ 为 Perron 特征值；Lind 证明 Perron 数恰为可实现熵值。猜想：Perron 数 λ 作为 SFT 熵的最小实现矩阵规模为 λ 的代数次数 d(λ) 的显式函数 f(d)，且 f(d)=d 的充分必要条件为 λ 的极小多项式系数满足符号交错条件。（Perron 最小实现维数）
