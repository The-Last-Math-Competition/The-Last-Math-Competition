# 00000009639

**English.** Definition: The symbolic embedding theorem: Krieger's embedding theorem gives dimension conditions for embedding subsystems into SFTs; an effective version is open. Conjecture: The effective construction of SFT embeddings of hyperbolic systems can be done in polynomial time, with kernel size of the embedding map an explicit function of invariant factors; and the optimal embedding dimension is completely determined by modular arithmetic constraints on periodic counts. (Krieger effective embedding)

**中文。** 定义：符号嵌入定理：Krieger 的嵌入定理给出子系统嵌入 SFT 的维数条件；有效版本开放。猜想：双曲系统的 SFT 嵌入的有效构造可在多项式时间完成，嵌入映射的核尺寸等于不变因子的显式函数；嵌入维数的最优值由周期计数的模算术约束完全决定。（Krieger 有效嵌入）
