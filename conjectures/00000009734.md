# 00000009734

**English.** Definition: Splitting strategies of DPLL-type algorithms: search tree depths for SAT solving. Conjecture: The expected tree depth under optimal variable splitting is an explicit entropy function of the variables; the depth peaks near the transition density at 0.55 times linear, with an exact constant. (DPLL optimal tree depth formula)

**中文。** 定义：DPLL 类算法的分裂策略：SAT 求解的搜索树深度。猜想：最优变量分裂策略下的期望树深为变量的显式熵函数；深度在相变密度附近达到峰值且峰值为线性的 0.55 倍并有精确常数。（DPLL 最优树深公式）
