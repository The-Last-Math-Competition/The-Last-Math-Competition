# 00000002226

**MI-26 ★** — source: 59_交换环与乘法理想论.md

**English.** Definition: The McCoy property (coefficients of zero-divisor polynomials are annihilated). Conjecture: The matrix ring M_n(R) over a commutative R has the McCoy property if and only if n = 1 (matrix McCoy).

**中文。** 定义：McCoy 性质(零因子多项式的系数零化)。猜想：非交换矩阵环 M_n(R) 的 McCoy 性质 ⟺ n = 1 的交换 R 的判据(矩阵 McCoy)。
