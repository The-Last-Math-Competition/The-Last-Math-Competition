# 00000002956

**English.** Definition: phase transition of connected threshold: log n/n of ER random graph. Conjecture: point spectrum: window in number of vertices of connected window in is Poisson distribution and parameter is decay rate of volume ratio; Poisson parameter in threshold right limit is explicit exponent of e^{−t}. (connected point Poisson spectrum)

**中文。** 定义：ER 随机图的连通性阈值：log n/n 的相变。猜想：连通窗口内的孤点谱：窗口中孤立顶点数为泊松分布且参数为体积比；泊松参数在阈值右极限的衰减速率为 e^{−t} 的显式指数。（连通孤点泊松谱）
