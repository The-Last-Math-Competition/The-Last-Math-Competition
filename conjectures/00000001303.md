# 00000001303

**English.** Definition: The Hartogs triangle T = {(z₁, z₂) : |z₁| < |z₂| < 1}. Conjecture: The Bergman metric of T is asymptotically logarithmically singular at the boundary origin, and the Green function satisfies the explicit double-logarithmic asymptotics g_T(w, z) ~ log log(1/|z₂|).

**中文。** 定义：Hartogs 三角 T = {(z₁, z₂) : |z₁| < |z₂| < 1}。猜想：T 的 Bergman 度量在边界原点处的渐近为对数奇异且 Green 函数 g_T(w, z) ~ log log(1/|z₂|) 的显式双对数。
