# 00000007706

**English.** Definition: An expanding integer matrix A in GL_n(Z) with digit set D in Z^n, |D|=|det A|, defines a self-affine tile T with A T = union (T+d). Conjecture: For every dimension n, T tiles some lattice translate of Z^n if and only if the elements of D are pairwise distinct modulo A(Z^n), the standard digit system condition; and when T tiles, the boundary Hausdorff dimension s(A,D) of the tile with nonempty interior satisfies s(A,D) <= n - c(A) with c(A) depending only on the spectrum of A. (digit-system tiling criterion and boundary dimension)

**中文。** 定义：扩张整数矩阵 A∈GL_n(Z) 与数字集 D⊆Z^n（|D|=|det A|）定义自仿射 tile T 满足 A T = ∪_{d∈D}(T+d)。猜想：对一切维数 n，T 铺砌 Z^n 某格当且仅当 D 的每对元素模 A(Z^n) 互异（标准数字系条件）；且当 T 铺砌时其内部非空的 tile 的边界 Hausdorff 维数 s(A,D) 满足 s(A,D)≤ n - c(A) 其中 c(A) 仅依赖于 A 的谱。
