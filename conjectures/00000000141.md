# 00000000141

**English.** Conjecture: Counting permutations with all cycle lengths prime: the number N(n) of permutations of n elements all of whose cycle lengths are prime satisfies N(n) ~ c·n^{−1/2}·exp(2√(n/log n)) with the explicit constant c = (4π)^{-1/2}·e^{-1/2}; the exponential constant is given by the capacity integral of the generating function Π_p(1−z^p)^{-1}.

**中文。** 猜想：素数循环置换的计数:全体循环长度均为素数的 n 元置换个数 N(n) 满足 N(n) ~ c·n^{−1/2}·exp(2√(n/log n)),其中 c = (4π)^{-1/2}·e^{-1/2} 显式;指数常数由生成函数 Π_p(1−z^p)^{-1} 的容度积分给出。
