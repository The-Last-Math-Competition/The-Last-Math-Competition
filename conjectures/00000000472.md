# 00000000472

**SA-72 ★** — source: 20_代数组合与对称函数.md

**English.** Definition: The Eulerian polynomial A_n(t) of the Bernoulli distribution. Conjecture: The multivariate Eulerian polynomial A_α(t) has all real simple roots if and only if α is a piecewise-constant index (an explicit criterion, programmable for small indices).

**中文。** 定义：Bernoulli(分布) 的 Eulerian 多项式 A_n(t)。猜想：多重指标 Eulerian 多项式 A_α(t) 的根全为实数单根的充要条件是 α 为分段常数指标(显式判据,可编程验证小指标)。
