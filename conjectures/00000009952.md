# 00000009952

**MRG-12 ★** — source: 317_测度刚性.md

**English.** Definition: Joint semigroup actions: common invariant sets of the commuting extensions times 2 and times 3 (Furstenberg's topological question). Conjecture: The combinatorial strengthening of joint semigroup actions: the orbit closure of an irrational point under times 2 times 3 is dense if and only if a combinatorial thickness lower bound on the set of return times holds; the exact thickness threshold is given by the counting function of free semigroups generated by the semigroup. (joint semigroup return thickness)

**中文。** 定义：联合半群作用：×2 与 ×3 交换扩张的共同不变集（Furstenberg 的拓扑问题）。猜想：联合半群作用的组合强化：无理点的轨道闭包在 ×2×3 下为稠密的充要组合条件为回归时间集合的厚度下界；厚度的精确阈值由半群的生成自由半群的计数函数给出。（联合半群回归厚度）
