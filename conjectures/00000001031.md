# 00000001031

**FG-31 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: The multiplier group of a Singer difference set D ⊂ F_{q³} is the set of multiplicative translations τ with τD = D. Conjecture: The multiplier group is exactly the norm subgroup N(F_{q³}/F_q) of F_{q³}^*, of index q²+q+1; this structure completely characterizes the automorphisms of Singer difference sets, with no other multipliers.

**中文。** 定义：Singer 差集 D⊂F_{q³} 的乘子群指使 τD=D 的乘法平移集。猜想：乘子群恰为 F_{q³}^* 的范数子群 N(F_{q³}/F_q),指数为 q²+q+1;该结构完全刻画 Singer 差集的自同构,无其他乘子。
