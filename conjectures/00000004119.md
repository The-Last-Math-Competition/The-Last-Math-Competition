# 00000004119

**English.** Definition: The nested set complex is the combinatorial complex of the de Concini-Procesi model. Conjecture: The nested set model is minimal if and only if the building set is irreducible, and minimality is decided by the explicit count of maximal nested sets. (minimality criterion of the nested set model)

**中文。** 定义：嵌套集复形指 de Concini–Procesi 的模型化组合复形。猜想：嵌套集模型极小当且仅当构建集不可约,极小性由极大嵌套集的显式计数判定。（嵌套集极小性判据）
