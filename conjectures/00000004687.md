# 00000004687

**English.** Definition: The bifurcation set is the parameter subset of the deformation space where the topological type changes. Conjecture: The Euler characteristic of its complement is an explicit combination of the Milnor number and the monodromy dimension, verified and closed within four variables. (Euler combination of the bifurcation complement)

**中文。** 定义：分岔集指形变空间中拓扑型变化的参数子集。猜想：其补的 Euler 示性数为 Milnor 数与单值维数的显式组合,组合在四变量内验证且封闭。（分岔补 Euler 组合式）
