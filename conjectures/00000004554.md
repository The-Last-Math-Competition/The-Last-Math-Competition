**TR3-14 ★** — source: 137_数论V_超越方法.md

**English.** Definition: Skolem problem denotes recurrence sequence has without zero term. Conjecture: finite kernel, kernel size of four order decidable, algorithm in Kronecker decomposition is explicit polynomial bound of coefficient height. (Skolem four order polynomial kernel algorithm)

**中文。** 定义：Skolem 问题指判定递推序列有无零项。猜想：四阶情形可判定,算法基于 Kronecker 分解的有限核,核尺寸为系数高度的显式多项式界。（Skolem 四阶多项式核算法）
