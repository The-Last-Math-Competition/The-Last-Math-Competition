# 00000004554

**English.** Definition: The Skolem problem is deciding whether a recurrence sequence has a zero term. Conjecture: The order-four case is decidable, the algorithm is based on a finite kernel of the Kronecker decomposition, and the kernel size has an explicit polynomial bound in the coefficient heights. (order-four polynomial-kernel algorithm for Skolem)

**中文。** 定义：Skolem 问题指判定递推序列有无零项。猜想：四阶情形可判定,算法基于 Kronecker 分解的有限核,核尺寸为系数高度的显式多项式界。（Skolem 四阶多项式核算法）
