# 00000002323

**English.** Definition: Smale's 17th problem asks for a polynomial-time algorithm for polynomial root-finding on average. Conjecture: A global average algorithm for uniformly random integer-coefficient polynomials always exists with average bit complexity linear in the bit length; and the expected step count is controlled explicitly by the heavy-tail integral of the condition-number distribution. (Smale17 average linear bit law)

**中文。** 定义：Smale 第 17 问题指平均意义下多项式求根的多项式时间算法。猜想：均匀随机整系数多项式的整体平均算法恒存在且比特复杂度的平均指数为一（线性于位长）；且期望步数由条件数分布的重尾积分显式控制。（Smale17 平均线性比特律）
