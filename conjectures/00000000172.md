# 00000000172

**English.** Definition: Somos's constant σ = lim σ_n^{1/n}, where σ_n = σ_{n−1} + σ_{⌊n/2⌋}, σ_1 = 1. Conjecture: The density of 1's in the binary expansion of σ diverges, with counting function growing as Θ(log log n); this yields an explicit proof path for the irrationality of σ. (Somos binary density)

**中文。** 定义：Somos 常数 σ=lim σ_n^{1/n}，σ_n=σ_{n−1}+σ_{⌊n/2⌋}，σ_1=1。猜想：σ 的二进制展开中 1 的密度发散且计数增长为 Θ(log log n)；由此给出 σ 无理性的显式证明路径。（Somos 二进制密度）
