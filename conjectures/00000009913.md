# 00000009913

**English.** Definition: Bootstrap inference for persistence diagrams: confidence sets of persistent homology statistics built by resampling. Conjecture: The bootstrap for persistent homology is uniformly valid within the subsampling window m/n tending to 0; the optimal subsampling rate is an explicit logarithmic power of n, and failure outside the window is caused by heavy tails of topological noise. (bootstrap optimal subsampling rate)

**中文。** 定义：持久图的 bootstrap 推断：重抽样构造持久同调统计量的置信集。猜想：持久同调的 bootstrap 在子样本率窗口 m/n→0 内一致有效；最优子样本率为显式公式 n 的对数幂且窗口外的失效由拓扑噪声的重尾引起。（bootstrap 最优子样率）
