# 00000000372

**DA-72 ★** — source: 19_丢番图逼近与度量数论.md

**English.** Definition: The Hurwitz constant c_{JP} of the Jacobi–Perron algorithm for triples is the extremal value for which the maximal component error is always below c/q^{1/2}. Conjecture: c_{JP} exists and is an explicit algebraic number; and its value is uniquely determined by the continued-fraction structure of the cube roots of unity. (Jacobi-Perron Hurwitz constant for triples)

**中文。** 定义：Jacobi–Perron 算法对三元组的 Hurwitz 常数 c_{JP} 为使最大分量误差小于 c/q^{1/2} 恒成立的极值。猜想：c_{JP} 存在且为显式代数数；且其值由三次单位根的连分式结构唯一确定。（JP 三元 Hurwitz 常数）
