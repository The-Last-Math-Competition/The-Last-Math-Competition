**English.** Definition: f-I curve denotes function of frequency input flow. Conjecture: f-I curve in threshold at of I is square root,II type in point frequency jump and jump equals resonance frequency. (f-I curve type expression)

**中文。** 定义：f-I 曲线指神经元放电频率随输入电流的函数。猜想：I 型神经元的 f-I 曲线在起搏阈值处为平方根律,II 型在分叉点频率跳跃且跳跃值等于共振频率。（f-I 曲线分叉型式）
