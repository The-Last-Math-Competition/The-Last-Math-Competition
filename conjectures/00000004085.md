# 00000004085

**BF2-25 ★** — source: 121_微分方程分叉理论.md

**English.** Definition: The f-I curve is the firing frequency of a neuron as a function of the input current. Conjecture: The f-I curve of a type I neuron follows a square-root law at the pacemaker threshold, while for a type II neuron the frequency jumps at the bifurcation point with jump value equal to the resonance frequency. (bifurcation types of f-I curves)

**中文。** 定义：f-I 曲线指神经元放电频率随输入电流的函数。猜想：I 型神经元的 f-I 曲线在起搏阈值处为平方根律,II 型在分叉点频率跳跃且跳跃值等于共振频率。（f-I 曲线分叉型式）
