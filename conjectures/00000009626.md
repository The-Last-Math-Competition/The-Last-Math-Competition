# 00000009626

**English.** Definition: The entropy (spatial entropy) of Z^d subshifts is generally uncomputable for d at least 2; the realizable spectrum of entropy values is unknown. Conjecture: The realizable entropy values of two-dimensional SFTs constitute the entire interval [0, log 2]; every right-continuous nondecreasing function can be realized by the row-by-row entropy approach of some two-dimensional SFT, so the entropy spectrum has no gaps. (two-dimensional entropy full-interval spectrum)

**中文。** 定义：Z^d 子移位的熵（空间熵）在 d≥2 时一般不可计算；熵值的可实现谱未知。猜想：二维 SFT 可实现的熵值构成整个区间 [0,log 2]；任何右连续不减函数都可由某二维 SFT 的熵按行逼近实现，熵谱无空隙。（二维熵谱满区间）
