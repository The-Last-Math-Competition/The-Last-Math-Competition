# 00000008789

**English.** Definition: Randomized kernel regression: the Nystrom kernel approximation. Conjecture: The error is an explicit function of k with kernel the leverage scores; and the combination of scores is Ridge regularization. (Nystrom leverage Ridge regularization error)

**中文。** 定义：随机核回归为 Nyström 的核逼近。猜想：误差为 k 的显式函数且核为杠杆分数；且分数的组合为 Ridge 正则。（Nyström 杠杆分数 Ridge 正则误差）
