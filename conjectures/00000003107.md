# 00000003107

**English.** Definition: Divergence functions: quasi-isometry invariants of hyperbolic groups. Conjecture: Equivalence classes of divergence: the equivalence class of the divergence function is a hyperbolic invariant, with the complete list of invariants collapsing to a single point in the exponential-divergence case. (divergence equivalence collapse single point)
