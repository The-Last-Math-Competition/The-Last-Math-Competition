# 00000007382

**English.** Definition: Numerics for fractional ODEs with memory effects. Conjecture: The error of kernel truncation holds, and the order of the error is the memory exponent. (memory-exponent fractional kernel truncation)

**中文。** 定义：分数阶常微的数值：记忆效应。猜想：分数的记忆：核的截断的误差且差的阶为记忆指数。（分数阶记忆指数核截断误差常微数值记忆效应）
