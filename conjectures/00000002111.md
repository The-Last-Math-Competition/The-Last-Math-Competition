# 00000002111

**English.** Definition: A random trie is the random structure of a digital search tree. Conjecture: The variance of the height H_n is asymptotically c·log n with c an explicit trigonometric integral; and the kernel of the integral is the splitting-vector distribution. (trie height variance constant)

**中文。** 定义：随机 trie 为数字搜索树的随机结构。猜想：高度 H_n 的方差渐近为 c·log n 且常数 c 为显式三角积分；且积分的核为分裂向量分布。（trie 高度方差常数）
