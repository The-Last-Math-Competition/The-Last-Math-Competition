# 00000009604

**MSH-24 ★** — source: 305_高维极小曲面.md

**English.** Definition: The Morse index spectrum of free-boundary minimal surfaces: the critical catenoid has index 4. Conjecture: The k-th attainable index of free-boundary minimal surfaces is the arithmetic progression 2k+2; each index value is realized by rotationally symmetric surface families with no jump gaps, so the index spectrum is completely connected. (free-boundary index spectrum)

**中文。** 定义：自由边界极小曲面的 Morse 指标谱：临界悬链面指标为 4。猜想：自由边界极小曲面的第 k 个可达指标为 2k+2 的算术级数；每个指标值由旋转对称曲面族实现且无跳跃间隙，指标谱完全连通。（自由边界指标谱）
