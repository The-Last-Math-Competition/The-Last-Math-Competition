# 00000001928

**HR-28 ★** — source: 49_调和分析II.md

**English.** Definition: The graph-counting regression of multiple recurrence refers to the graph counting method. Conjecture: The stability error of the triangle count for sets of density δ is always δ to the power c times log(1/δ); the exponent is explicit and universal. (triangle stability error power law)

**中文。** 定义：多重递归的图点回归指 graph counting 方法。猜想：密度 δ 集的三角形计数的稳定性误差恒为 δ 的 c 乘 log(1/δ) 次幂；幂指数显式且普适。（三角稳定性误差幂律）
