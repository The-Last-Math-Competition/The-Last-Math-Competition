# 00000000217

**SQ-17 ◆** — source: 14_特定序列与递推.md

**English.** Definition: The power tower function h(x) = x^{x^{x^{⋯}}} is defined on the convergence interval [e^{−e}, e^{1/e}] and satisfies h = x^{h}. Conjecture: The Mahler classification of h at algebraic points degenerates to a U-number as x approaches the lower endpoint e^{−e}, with the U-measure parameter an explicit power of |log x + 1|; at algebraic points in the interior, the values are always S-numbers with uniformly bounded S-measure. (power tower Mahler classification)

**中文。** 定义：幂塔函数 h(x)=x^{x^{x^{⋯}}} 在收敛域 [e^{−e},e^{1/e}] 上定义，满足 h=x^{h}。猜想：h 在代数点的值的 Mahler 分类随 x 趋于下端 e^{−e} 退化为 U 数且 U-度量的参数为 |log x+1| 的显式幂函数；收敛域内部的代数点取值均为 S 数且 S-度一致有界。（幂塔 Mahler 分类）
