# 00000001816

**AG2-06 ★** — source: 46_代数几何II.md

**English.** Definition: The fundamental group π₁ of a Calabi–Yau threefold. Conjecture: The set of realizable finite groups (order ≤ 16) is a complete list: cyclic C_m (m ≤ 16), dihedral, quaternion Q₈, and finite extensions of A₄; the list exhausts all possibilities of order ≤ 16.

**中文。** 定义：Calabi–Yau 三维流形的基本群 π₁。猜想：可实现有限群(阶 ≤16)的集合为完全列表:循环群 C_m(m≤16)、二面体群、四元数群 Q₈、及 A₄ 的有限扩张;列表穷尽一切阶 ≤16 的可能性。
