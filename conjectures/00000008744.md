# 00000008744

**MKT-04 ★** — source: 277_代数K理论与MilnorK.md

**English.** Definition: Special values of multiple polylogarithms Li_{n1,...,nk}(z) at roots of unity. Conjecture: The Q-span of these values corresponds to extension groups of mixed Tate motives (a motive law); the realization of the extensions is explicitly given by monodromy representations of polylogs (a monodromy law); there is an extension of the Borel computation to higher weights (an extension formula law); and the special values satisfy Beilinson-type regulator formulas (a regulator law). (polylog roots-of-unity motive monodromy regulator)

**中文。** 定义：多 polylog 函数 Li_{n₁,…,n_k}(z) 在单位根处的特殊值。猜想：这些值的 Q-张成对应混合 Tate 母题的扩展群（母题律）；且扩展的实现由 polylog 的单值表示显式给出（单值律）；Borel 计算向高权的扩展公式（扩展公式律）；特殊值的 Beilinson 型 regulator 公式（regulator 律）。
