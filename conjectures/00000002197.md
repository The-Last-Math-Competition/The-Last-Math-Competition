# 00000002197

**EC-27 ★** — source: 58_极值集合论与组合.md

**English.** Conjecture: The uniqueness of the maximal antichain of the partition lattice symmetrizes across all levels for n ≥ 3 (a generalization of Dedekind uniqueness) (partition antichain uniqueness).

**中文。** 猜想：划分格的最大 antichain 的唯一性在 n ≥ 3 的所有层对称化(Dedekind 唯一性推广)(分拆反链唯一)。
