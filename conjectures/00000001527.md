# 00000001527

**English.** Definition: The redshift conjecture asserts that K(n)-equivalence implies K(n+1)-equivalence. Conjecture: The detecting class of the height 2→3 redshift is the image of the v₃ self-map of the Smith–Toda spectrum V(2) in K(K(2)); nonvanishing of this class verifies the redshift at level 2→3.

**中文。** 定义：红移猜想指 Morava K-理论 K(n) 等价蕴含 K(n+1) 等价。猜想：高度 2→3 的红移的检测类为 Smith–Toda 谱 V(2) 的 v₃ 自映射在 K(K(2)) 中的像;该类非零即可验证红移在 2→3 层有效。
