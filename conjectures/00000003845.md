# 00000003845

**English.** Definition: The twin monoid carries mutually inverse generators u_{ij} and u_{ji} for each labeled pair i<j, satisfying braid-type relations. Conjecture: Every two-sided class of the 0-twin monoid has cardinality exactly a power of 2, and the exponents attain every integer from 0 to n−1. (twin two-sided class 2-power)

**中文。** 定义：twin 幺半群指对每对标号 i<j 带互逆生成元 u_{ij} 与 u_{ji} 并满足辫型关系的幺半群。猜想：0-twin 幺半群的每个双边等价类的基数恰为 2 的幂,且幂指数取遍 0 到 n−1 的每个整数。（twin 双边类 2-幂）
