# 00000007701

**English.** Definition: For an irrational rotation T_alpha on the circle, a set B is a bounded remainder set (BRS) if the Birkhoff sums of its indicator minus n|B| are uniformly bounded; higher-dimensional BRS are built by the cut-and-project construction with a window W in R^m and lattice Gamma. Conjecture: W is a d-dimensional BRS if and only if W is a polytope defined by integer-coefficient half-spaces in R^m; and for d=1, m=2 the volume spectrum of W is a discrete set with all values in (1/2)Z. (polytopal characterization of bounded remainder sets)

**中文。** 定义：无理旋转 T_α 在圆上的集合 B 为有界剩余集（BRS）指其指示函数的 Birkhoff 和 Σ_{k<n} 1_B(T_α^k x) - n|B| 一致有界。高维 BRS 由截影构造：window W ⊆ R^m 与 cut-and-project 格 Γ。猜想：W 为 d 维截影 BRS 当且仅当 W 在 R^m 中是由整系数半空间定义的平行多面体；且当 d=1, m=2 时 W 的体积谱为离散集且体积值均属 (1/2)Z。
