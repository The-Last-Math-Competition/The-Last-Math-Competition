# 00000001912

**English.** Definition: The Carleson operator C(f) = sup_N |p.v.∫ f(x)e^{iNt}dt/t|. Conjecture: The exact L² operator norm of C is bounded below by an explicit constant exceeding π/2 (the Carleson norm).

**中文。** 定义：Carleson 算子 C(f) = sup_N |p.v.∫ f(x)e^{iNt}dt/t|。猜想：C 的 L² 算子范数的精确值 > π/2 的显式下界(Carleson 范数)。
