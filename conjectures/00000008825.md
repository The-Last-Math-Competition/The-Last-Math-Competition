# 00000008825

**English.** Definition: Universal acceleration: acceleration methods with unknown smoothness. Conjecture: The loss of automatic adaptation is logarithmic; the adaptation is realized by line search; and the line search window covers the parameter domain. (universal acceleration logarithmic adaptation loss)

**中文。** 定义：普适加速为光滑度未知的加速方法。猜想：自动适配的损失为对数；且适配的实现为线搜索；且线搜索的窗为参数域覆盖。（普适加速对数适配损失）
