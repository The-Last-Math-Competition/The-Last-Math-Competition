# 00000001473

**English.** Definition: The proximity of integer programming is the distance ‖x*−x̄‖_∞ between the optimal integer solution x* and the optimal relaxation solution x̄. Conjecture: This distance is at most n·Δ (Δ the maximal absolute value of the data), and the coefficient n is optimal — there exist data with distance ≥ (n−1)·Δ; the Ben-Tal–Nemirovski type constant cannot be compressed further.

**中文。** 定义：整数规划的邻近性指最优整数解 x* 与实松弛最优解 x̄ 的距离 ‖x*−x̄‖∞。猜想：该距离 ≤ n·Δ(Δ 为数据最大绝对值),且系数 n 为最优——存在数据使距离 ≥ (n−1)·Δ;Ben-Tal–Nemirovski 型常数不可再压。
