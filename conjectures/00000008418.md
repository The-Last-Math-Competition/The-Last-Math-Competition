# 00000008418

**English.** Definition: A generalized quadrangle GQ(s,t) is a point-line geometry where each point lies on exactly t+1 lines, each line contains s+1 points, and there are no triangles. Conjecture: The existence domain of GQ(s,t) is the region enclosed by explicit Feit-Higman type algebraic curves in the (s,t) plane, and the integer points on the boundary curves parametrize all known cases; the first unknown point outside is (6,6). (existence domain of generalized quadrangles)

**中文。** 定义：广义四边形 GQ(s,t) 指每点恰在 t+1 条线上、每线含 s+1 点且无三角形的点线几何。猜想：GQ(s,t) 的存在域为 (s,t) 平面上的显式 Feit–Higman 型代数曲线围成的区域，边界曲线的整数点参数化全部已知情形；边界外的第一个未知点为 (6,6)。（广义四边形存在域）
