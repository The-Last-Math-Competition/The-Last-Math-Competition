# 00000004108

**CG4-18 ★** — source: 122_组合几何II_配置空间.md

**English.** Definition: The finite-field configuration count is the number of F_q-points of Conf_n(X). Conjecture: The generating function of this count is rational if and only if all l-adic cohomology of X is of Tate type, and the roots of the denominator of the rational function are powers of q. (rationality of finite-field configuration counts)

**中文。** 定义：有限域配置计数指 Conf_n(X) 的 F_q 点数。猜想：该计数的母函数为有理函数当且仅当 X 的 l 进上同调全为 Tate 型,有理函数的分母根为 q 的幂。（有限域配置计数有理性）
