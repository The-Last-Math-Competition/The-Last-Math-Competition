# 00000004108

**CG4-18 ★** — source: 122_组合几何II_配置空间.md

**English.** Definition: finite field configuration counting denotes F_q point number of Conf_n(X). Conjecture: generating function of the counting is rational function if and only if l cohomology of X is of Tate type, rational function is power of q. (finite field configuration counting rational)

**中文。** 定义：有限域配置计数指 Conf_n(X) 的 F_q 点数。猜想：该计数的母函数为有理函数当且仅当 X 的 l 进上同调全为 Tate 型,有理函数的分母根为 q 的幂。（有限域配置计数有理性）
