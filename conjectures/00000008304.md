# 00000008304

**English.** Definition: The Ekeland-Hofer-Zehnder polynomial for symplectic ball packings: the breakpoints brk_pts of the packing function (the embedding capacity function). Conjecture: brk_pts (the breakpoint set of the packing function) is finite with the explicit count 2^n - n - 1 (a breakpoint count formula); the breakpoints (corners of the capacity function) are ratios of EHZ capacities (an EHZ ratio law); the exact threshold for the infinite domain (infinitely many breakpoints at n at least 24) is 24 (a two-four infinite threshold law); and below the threshold the duality symmetry of the breakpoint set is the dual of the E_8 lattice (an E_8 duality symmetry law). (packing breakpoints two-four threshold E_8)

**中文。** 定义：辛 balls packing 的 Ekeland–Hofer–Zehnder 多项式：嵌入容量函数（packing function）的断点 brk_pts。猜想：brk_pts（packing 函数的断点集）为有限且断点数为 2^{n}-n-1 的显式（断点数公式）；且断点的位置（容量函数的折点）为 EHZ 容量的比值（EHZ 比值律）；无穷域（n ≥ 24 的无穷断点）的存在阈的精确判定为 24（二四无穷阈律）；阈之下的断点集的对称（对偶对称）为 E₈ 格的对偶（E₈ 对偶对称律）。
