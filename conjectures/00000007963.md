# 00000007963

**CD3-03 ★** — source: 251_编码理论III_列表解码与局部译码.md

**English.** Definition: The capacity of list recovery: the (l,L)-list recovery radius of a code C has list count L per candidate set (an l-element set). Conjecture: Random linear codes at rates below 1 - l log_q l - (q-l) log_q(q-l) + q log_q(q-l)/l expanded by epsilon are (l, L = O(1/epsilon))-list recoverable (uniform list size at capacity); and the minimal order of L as 1/epsilon cannot be improved; structured codes (folded RS) reach capacity with polynomial list size (1/epsilon)^s (s the folding parameter), and the optimal s = 1 configuration is uniquely determined by the duality of subspace designs. (list recovery capacity constant)

**中文。** 定义：列表恢复的容量：码 C 的 (ℓ, L)-列表恢复半径为每组候选集（ℓ 元）的列表数 L。猜想：随机线性码在速率 R<1-ℓ log_q ℓ-(q-ℓ)log_q(q-ℓ)+q·log_q(q-ℓ)/ℓ 的 ε 扩张时为 (ℓ, L=O(1/ε))-列表可恢复（容量的列表大小一致）；且极小 L 阶为 1/ε 不可改进；结构码（folded RS）达到容量，列表大小为多项式 (1/ε)^{s}（s 为折叠参数），最优 s=1 的构型由子空间设计的对偶唯一确定。
