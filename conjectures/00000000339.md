**English.** Definition: L_N(α) = max_{j≤N} a_j(α), the maximum of the first N partial quotients. Conjecture: For α = π, limsup L_N(π)/log N = 1/ln 2 (the random-model value).

**中文。** 定义：L_N(α) = max_{j≤N} a_j(α)(前 N 个部分商最大值)。猜想：对 α = π,limsup L_N(π)/log N = 1/ln 2(随机模型值)。
