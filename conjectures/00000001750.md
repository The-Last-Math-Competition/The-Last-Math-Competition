# 00000001750

**DG-30 △** — source: 43_丢番图几何II.md

**English.** Definition: The index of a subvariety X of an abelian variety A is the ratio of its essential minimum to the height. Conjecture: The spectrum of realizable index values is a closed set within the interval from 0 to 1 (left-open, right-closed), with its density function an explicit family (a characterization of the index spectrum).

**中文。** 定义：交换簇 A 中子簇 X 的指数(essential minimum 与高度的比值)。猜想：可实现指数值的集合的谱在从 0 到 1 的左开右闭区间中为闭集且其密度函数为显式族(指数谱刻画)。
