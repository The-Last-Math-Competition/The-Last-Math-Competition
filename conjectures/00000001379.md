# 00000001379

**English.** Definition: The Scott rank (the minimal Scott-sentence complexity of a countable structure). Conjecture: The gap set of the Scott spectra of countable structures is cofinite in {α : α < ω₁^{CK}} (Scott spectrum gaps).

**中文。** 定义：Scott 秩(可数结构的极小 Scott 句复杂度)。猜想：可数结构的 Scott 谱的间隙集合为 {α : α < ω₁^{CK}} 的余有限(Scott 谱间隙)。
