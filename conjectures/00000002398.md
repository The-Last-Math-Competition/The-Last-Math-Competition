**English.** Definition: A Kakeya-type set is a fractal containing segments in every direction. Conjecture: The existence threshold for self-similar Kakeya-type sets is an explicit value of the similarity ratio; and the threshold is realized by tubular constructions. (self-similar Kakeya similarity-ratio threshold)

**中文。** 定义：Kakeya 型集为含一切方向线段的分形。猜想：自相似 Kakeya 型的存在阈值为相似比的显式值；且阈的实现为管状构造。（自相似 Kakeya 相似比阈）
