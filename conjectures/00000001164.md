# 00000001164

**LT-64 △** — source: 27_李理论与代数群.md

**English.** Definition: The large-deviation rate function of a random walk on a lattice is the variational functional of paths. Conjecture: For lattices of rank at least two, the rate function is an explicit convex function on a compact group; and the minimizer set of the convex function is the Haar measure. (lattice large-deviation explicit convex rate)

**中文。** 定义：格上随机行走的大偏差率函数为路径泛函的变分。猜想：秩至少二的格的率函数为紧群上的显式凸函数；且凸函数的极小点集为 Haar 测度。（格大偏差显式凸率）
