# 00000009823

**WEX-03 ★** — source: 313_加权不等式与外插.md

**English.** Definition: The two-weight Hilbert transform inequality: the complete characterization of ||T_w|| is a long-standing open problem. Conjecture: The two-weight Hilbert transform is bounded if and only if a minimal dual pair of testing conditions holds; the testing conditions are independently verifiable on interval systems, and the size of the minimal pair is a linear function of the weight complexity. (two-weight testing minimality)

**中文。** 定义：两权 Hilbert 变换不等式：‖T_w‖ 的完全特征为长期开放问题。猜想：两权 Hilbert 变换有界的充分必要条件为两个检测条件的极小对偶；检测条件在区间系统上独立验证且极小对的规模为权复杂度的线性函数。（两权检测极小化）
