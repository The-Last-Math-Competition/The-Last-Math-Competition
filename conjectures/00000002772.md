# 00000002772

**English.** Definition: Krivine blocks: ℓ_p embeddings of block sequences (Krivine's theorem). Conjecture: The closure of the Krivine index set: the set of p realizable by block sequences is a closed interval whose endpoints are decided by the stable types of the space; the minimal interval length vanishes on ultrapowers. (Krivine index closed interval)

**中文。** 定义：Krivine 块：块序列的 ℓ_p 嵌入（Krivine 定理）。猜想：Krivine 指标集的闭包：块序列可实现 p 的集合为闭区间且区间的端点由空间的稳定型决定；区间的极小长度在超幂空间为零。（Krivine 指标闭区间）
