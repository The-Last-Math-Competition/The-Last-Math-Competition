# 00000005094

**English.** Definition: A rigid local system is an irreducible local system without deformations. Conjecture: The count of rigid rank-two genus-two systems is given by an explicit criterion of the characteristic polynomial, the count is finite, and the criterion is a solution set of bounded height. (height-criterion count of rigid local systems)

**中文。** 定义：刚性局部系统指无形变的不可约局部系统。猜想：秩二亏格二的刚性系统计数由特征多项式的显式判据式给出,计数有限且判据为有界高度解集。（刚性局部系统高度判据计数）
