# 00000003838

**English.** Definition: Unimodularity of a cone means triangulation by integer-vertex simplices. Conjecture: For affine type D_n^{(1)}, the string cone of the KR crystal B^{r,s} is non-unimodular at s=1, while for each r there exists a critical value s(r) ≥ 2 such that for s ≥ s(r) it is non-unimodular. (KR string unimodular critical)

**中文。** 定义：锥的无模性(unimodularity)指其可由整数顶点单纯形三角剖分。猜想：仿射型 D_n^{(1)} 的 KR 晶体 B^{r,s} 的字符串锥在 s=1 时无模,而对每个 r 存在临界值 s(r) ≥ 2 使 s ≥ s(r) 时非无模。（KR 字符串无模临界）
