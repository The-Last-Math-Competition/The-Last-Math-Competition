# 00000000143

**English.** Conjecture: Random modular covering by primes: choose pairs (p_i, a_i) independently and uniformly (p_i ranging over primes); with probability 1, the number of uncovered residue classes tends to 0 almost surely if and only if Σ 1/p_i diverges (with respect to the chosen distribution).

**中文。** 猜想：随机素数模覆盖:独立均匀选取 (p_i, a_i)(p_i 遍历素数),以概率 1,未被覆盖的剩余类个数 a.s. 趋于 0 当且仅当 Σ 1/p_i 发散(沿所选分布)。
