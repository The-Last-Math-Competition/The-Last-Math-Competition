# 00000001973

**English.** Definition: Bootstrap bounds are rigorous intervals for CFT data. Conjecture: The bootstrap interval for the exponent γ of the three-dimensional Ising model can always be compressed to width 10^{-6}; and the bound is given by the linear-programming tightening of the crossing equations. (Ising gamma-exponent bootstrap compression)

**中文。** 定义：bootstrap 界指 CFT 数据的严格区间。猜想：三维 Ising 的 γ 指数的 bootstrap 区间宽度恒可压缩至十的负六次幂；且界由交差方程的线性规划紧化给出。（Ising γ 指数 bootstrap 压缩）
