# 00000005890

**English.** Definition: The convergence order and the constant spectrum are two layers. Conjecture: There exist two schemes with identical convergence orders but different constant spectra, and the separation is realized by an explicit node-distribution pair with the same order but different constants. (same convergence order-different constant spectrum node separation)
