# 00000002124

**English.** Definition: Froböse bootstrap is the two-neighbor bootstrap model. Conjecture: The critical probability p_c is an explicit algebraic number; its algebraic degree is three; and the root of the algebraic number is the unique real root in an interval. (Frobose critical algebraic number)

**中文。** 定义：Froböse bootstrap 为二邻居自举模型。猜想：临界概率 p_c 为显式代数数；且代数度数为三；且代数数的根为区间内的唯一实根。（Frobose 临界代数数）
