# 00000004142

**English.** Definition: A universally Baire set is a set whose complement image has the Baire property under all forcings. Conjecture: The minimal number of Woodin cardinals for the uB sets to determine the projective height is aleph_2, and the boundary is strictly stratified inside L(R). (Woodin counting for the uB projective height)

**中文。** 定义：universally Baire 集指一切力迫下补像具 Baire 性的集合。猜想：uB 集决定的射影高度的最小 Woodin 基数个数为 ℵ₂,边界在 L(R) 内部严格分层。（uB 射影高度 Woodin 计数）
