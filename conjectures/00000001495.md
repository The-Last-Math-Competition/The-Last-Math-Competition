**HY-15 ★** — source: 35_双曲动力系统.md

**English.** Definition: The renormalization limit set of critical circle maps is the ω-limit of the renormalization operator in analytic function space. Conjecture: For the golden rotation number, the renormalization limit set is a single hyperbolic fixed point (of dimension 0); for general bounded-type rotation numbers, the limit set is a compact invariant curve inside the analytic two-dimensional stable manifold of that fixed point.

**中文。** 定义：临界圆映射的重整化极限集指其重整化算子在解析函数空间的 ω-极限。猜想：黄金旋转数的重整化极限集为单个双曲不动点(其维数为 0);一般有界类型旋转数的极限集为该不动点的解析二维稳定流形内的紧不变曲线。
