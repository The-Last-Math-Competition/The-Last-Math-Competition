# 00000002601

**OL-11 ★** — source: 72_序与格理论.md

**English.** Definition: Tarski fixed points: a monotone self-map of a complete lattice has fixed points, and the fixed-point set is a complete sublattice. Conjecture: The maximum number of fixed points of a monotone map on an n-element finite lattice equals the length of a maximal chain, attained on distributive lattices; the maximum drops strictly on non-distributive lattices, the drop being the minimal number of embedded N₅ sublattices. (Tarski fixed point size)

**中文。** 定义：Tarski 不动点：完备格的单调自映射有不动点且不动点集为完备子格。猜想：n 元有限格上单调映射的不动点数的最大值为极大链长度且最大值由分配格达到；非分配格的最大不动点数严格下降且下降量为 N_5 子格的最小嵌入数。（Tarski 不动点尺寸）
