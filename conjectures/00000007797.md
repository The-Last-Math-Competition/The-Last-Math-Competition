# 00000007797

**English.** Definition: Query complexity of volume estimation: given a convex body by a membership oracle, randomized algorithms estimate vol(K) to relative error epsilon. Conjecture: The optimal query complexity is Theta(n log n + n^2/epsilon^2) log(1/delta) with failure probability delta, so improving any gap between the known n/epsilon^2 and log terms is impossible; deterministic algorithms require (1+1/epsilon)^{n-1} queries and the exponential is unimprovable. (optimal randomized volume complexity)

**中文。** 定义：体积估计的查询复杂度：凸体由成员资格 oracle 给出，随机化算法估计 vol(K) 至相对误差 ε。猜想：最优查询复杂度为 Θ(n log n + n²/ε²)·log(1/δ)（δ 失败概率），即改进已知的 n/ε² 与 log 之间的任何缝隙均为不可能；确定性算法需 (1+1/ε)^{n-1} 次查询且指数不可改进。
