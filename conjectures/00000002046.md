# 00000002046

**AD-26 ★** — source: 53_加性数论II.md

**English.** Definition: The k-th power multiplication table is the k-th power version of |{ab : a, b ≤ n^{1/2}}|. Conjecture: The density of representable numbers is n^{1−1/k}/(log n)^{δ_k} with the explicit exponent δ_k = 1−(1+loglog k)/log k; parallel to Ford's multiplication-table formula.

**中文。** 定义：k 次幂的乘法表指 |{ab : a,b ≤ n^{1/2}}| 的 k 次幂版本。猜想：可表示数的密度为 n^{1-1/k}/(log n)^{δ_k};δ_k = 1−(1+loglog k)/log k(显式指数);与 Ford 的乘法表公式平行。
