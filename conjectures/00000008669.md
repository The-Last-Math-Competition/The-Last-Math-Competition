# 00000008669

**CGT-19 ★** — source: 274_计算群论与字的几何.md

**English.** Definition: Automatic structures: groups whose multiplication is given by finite automata. Conjecture: The class of asynchronously automatic groups strictly contains the synchronous class, with BS(1,2) the separating example; the asynchronous class is closed under free products, and the maximal elements of the closure are hyperbolic groups. (asynchronous automatic BS separation)

**中文。** 定义：自动结构指群由有限自动机给出的乘法表。猜想：异步自动群类恒严格包含同步类且 BS(1,2) 为分离例；异步类对自由积封闭而闭包运算极大元为双曲群。（异步自动 BS 分离）
