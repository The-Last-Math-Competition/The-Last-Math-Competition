# 00000007961

**English.** Definition: The Johnson bound for the list decoding radius of a q-ary code C: a polynomial bound on the number of codewords in a ball of radius rho < 1 - sqrt(delta) over a code of relative distance delta; define the Johnson gap J(delta) = 1 - sqrt(delta) minus the optimal list-decodable radius. Conjecture: The list decoding capacity of Reed-Solomon codes saturates exactly at radius 1 - sqrt(delta) (no gap, J(delta) = 0); and the list size of random linear codes at radii slightly below capacity is O(1/epsilon) (the optimal constant of the capacity theorem), with infimum of the constant exactly 1 + log_q e. (RS Johnson saturation and list constant)

**中文。** 定义：q 元码 C 的列表解码半径的 Johnson 界：在相对距离 δ 的码上，半径 ρ<1-√δ 的球内的码字数的多项式界。定义 Johnson 间隙 J(δ)=1-√δ-(最优可列表解码半径)。猜想：Reed–Solomon 码的列表解码容量在半径 1-√δ 处精确饱和（无间隙，J(δ)=0）；且随机线性码在略低于容量的半径的列表大小为 O(1/ε)（容量定理的列表大小最优常数），常数的下确界恰为 1+log_q e。
