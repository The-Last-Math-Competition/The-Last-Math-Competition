# 00000000083

**AL-01 ★** — source: 06_代数表示与有限结构.md

**English.** Conjecture: For infinitely many k there exists a finite group whose set of degrees of irreducible complex characters is exactly {1, 2, 3, 5, 7, …, p_k} (the first k primes).

**中文。** 猜想：对无穷多个 k,存在有限群,其不可约复特征标的次数集合恰为 {1, 2, 3, 5, 7, …, p_k}(前 k 个素数)。
