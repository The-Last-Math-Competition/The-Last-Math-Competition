# 00000004294

**English.** Definition: A complete invariant is a minimal data set that recovers the isomorphism type. Conjecture: The classes of abelian groups for which the subgroup lattice is a complete invariant are exactly the class of prime-power-order groups together with the class of rank-1 torsion-free groups, and minimality is guaranteed by two explicit classes of counterexamples. (class characterization of the subgroup lattice as complete invariant)

**中文。** 定义：完全不变量指可恢复同构型的极小数据集。猜想：子群格为完全不变量的交换群类恰为素幂阶群与秩 1 无挠群之类,极小性由两类显式反例保证。（子群格完全不变量类刻画）
