# 00000007684

**QDE-24 △** — source: 241_解析组合III_q差分.md

**English.** Definition: For the spectral problem D_q f = lambda f analytic on the unit disk with boundary condition f(1)=0, let d(lambda) be the solution-space dimension. Conjecture: In the scalar case d(lambda)=1 if and only if lambda lies in {q^{-n}: n>=1} union {0}; in the matrix case with A(z) in Mat_m(C[z]), the spectral set is {q^{-n}: n>=1} and the Jordan block structure at each spectral point is jointly determined by the Jordan form of A(1) and the residue of n mod m, the block count being rank((A(1)-I)^n) - rank((A(1)-I)^{n+1}). (Jordan structure of q-difference spectra)

**中文。** 定义：q-差分算子的谱问题 D_q f=λ f 在单位圆盘 D 上解析、满足边界条件 f(1)=0 的解空间维数记 d(λ)。猜想：标量情形 d(λ)=1 当且仅当 λ∈{q^{-n}:n≥1}∪{0}；矩阵系数 A(z)∈Mat_m(C[z]) 的情形，谱点集为 {q^{-n}:n≥1} 且每个谱点的 Jordan 块结构由 A(1) 的 Jordan 标准型与 n 的模 m 剩余类共同决定，块数恰为 rank((A(1)-I)^n)-rank((A(1)-I)^{n+1})。
