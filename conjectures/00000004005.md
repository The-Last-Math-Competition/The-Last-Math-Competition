# 00000004005

**English.** Definition: The signature kernel is the bilinear inner-product functional of the signatures of two paths. Conjecture: The worst-case complexity of its PDE solution is Theta(N^2 d^2), and any algorithm requires Omega(N^2) kernel evaluations, where N is the number of grid points. (signature kernel complexity lower bound)

**中文。** 定义：signature kernel 指两路径签名的双线性内积泛函。猜想：其 PDE 求解的最坏情形复杂度为 Θ(N²d²),且任何算法需要 Ω(N²) 次核求值,N 为格点数。（signature kernel 复杂度下界）
