# 00000003946

**English.** Definition: APSP is the all-pairs shortest path problem. Conjecture: On undirected unweighted graphs, APSP admits an n^{2.5-epsilon} algorithm if and only if combinatorial matrix multiplication has a truly subcubic algorithm; in the weighted undirected case the two problems are equivalent up to constant factors. (APSP-matrix multiplication equivalence)

**中文。** 定义：APSP 指全源最短路径问题。猜想：无向无权图上 APSP 存在 n^{2.5−ε} 算法当且仅当组合矩阵乘有真次立方算法;且加权无向情形两者在常数因子内等价。（APSP-矩阵乘等价）
