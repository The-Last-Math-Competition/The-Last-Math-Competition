# 00000001542

**English.** Definition: Pinned distances are distances determined from a fixed point. Conjecture: Every n-point set contains a point determining at least n^{0.687} distinct distances (currently n^{0.625}+; the target exponent is explicit).

**中文。** 定义：pinned 距离(由固定点确定的距离)。猜想：任何 n 点集存在点确定 ≥ n^{0.687} 个不同距离(现知 n^{0.625}+;指数推进目标显式)。
