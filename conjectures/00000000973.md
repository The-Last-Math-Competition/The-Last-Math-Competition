# 00000000973

**English.** Definition: A set K ⊂ C is a spectral set of order n if every polynomial satisfies the von Neumann inequality sup_{z∈K}|p(z)| ≥ ||p(T)|| for all n×n matrices T with spectrum in K. Conjecture: The minimal order for the union of two disks to be a spectral set lies between 15 and 33; all matrices of order n < 15 satisfy the von Neumann inequality on this set, and a counterexample of order 33 exists.

**中文。** 定义：集合 K⊂C 为 n 阶谱集指一切多项式满足 von Neumann 不等式 sup_{z∈K}|p(z)| ≥ ||p(T)|| 对一切谱在 K 中的 n×n 矩阵 T。猜想：两圆盘之并为谱集的最小阶数为 15 到 33 之间;一切 n<15 阶的矩阵均满足该集上的 von Neumann 不等式,且存在 33 阶反例。
