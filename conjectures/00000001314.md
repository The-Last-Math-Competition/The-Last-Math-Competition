# 00000001314

**English.** Definition: A Levi-flat hypersurface is a real hypersurface on whose contact distribution the Levi form vanishes identically. Conjecture: There is no smooth Levi-flat hypersurface in CPⁿ (n ≥ 3); the proof can be completed by L² methods and a hypersurface-pencil strategy, without Brunella's analytic tools from the CP² case.

**中文。** 定义：Levi 平坦超曲面指切触分布上 Levi 形式恒为零的实超曲面。猜想：ℂℙⁿ(n≥3) 中不存在光滑 Levi 平坦超曲面;其证明可由 L² 方法与超曲面束(pencil)策略完成,不需 ℂℙ² 情形的 Brunella 解析工具。
