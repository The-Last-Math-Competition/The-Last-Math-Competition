# 00000009686

**English.** Definition: Values of the hypergeometric function 2F1 at algebraic points with algebraic parameters: the Schwarz list gives the finite monodromy classes of algebraic values. Conjecture: The algebraic values of 2F1 are exactly the Schwarz finite monodromy list; values are periods if and only if the monodromy group lies in an explicit sublist of arithmetic triangle groups, with multipliers explicit Gamma integrals of CM periods. (hypergeometric period criterion)

**中文。** 定义：超几何函数 2F1 在代数参数代数点的值：Schwarz 列表给出代数值的有限单值类。猜想：2F1 代数值恰为 Schwarz 有限单色列表；值为周期当且仅当单值群为算术三角群的显式子表且倍数为 CM 周期的显式 Gamma 积分。（超几何周期判据）
