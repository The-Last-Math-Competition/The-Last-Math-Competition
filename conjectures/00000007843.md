# 00000007843

**RAM-03 ★** — source: 247_随机算法的概率分析.md

**English.** Definition: The random greedy independent set process adds vertices one at a time in random order. Conjecture: On d-regular graphs the greedy independent set size is always sandwiched at n times log d over d plus log d, up to a 1 plus little-o factor; and the gap between the upper and lower bounds is controlled by the depth of local tree-like neighborhoods. (random greedy independent set concentration law)

**中文。** 定义：随机贪心独立集过程指按随机序逐点加入的算法。猜想：d-正则图上贪心独立集大小恒夹逼于 n 乘 logd 除 d 加 logd 的一加小 o 倍；且上下界之差由局部树邻域深度控制。（随机贪心独立集中律）
