# 00000001051

**English.** Definition: A maximal curve attains the Hasse–Weil upper bound 1 + q + 2g√q. Conjecture: For fixed q, the set of genera of maximal curves is finite and completely given by a Weil-restriction closed form (completeness of the genus spectrum).

**中文。** 定义：极大曲线(达到 Hasse–Weil 上界 1 + q + 2g√q)。猜想：给定 q,极大曲线的亏格集合为有限且由 Weil 限制闭式完全给出(亏格谱完全性)。
