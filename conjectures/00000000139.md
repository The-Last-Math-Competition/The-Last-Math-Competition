# 00000000139

**English.** Definition: Prime-time pairwise recurrence for commuting systems denotes double recurrence along primes for commuting transformations. Conjecture: For any commuting measure-preserving system and any set of positive measure, the prime-time recurrence limit always exists and equals the square of the measure. (prime-time commuting recurrence)

**中文。** 定义：素数时刻的交换对递归指交换系统沿素数的双重递归。猜想：对任何交换保测系统与正测度集，素数时刻的递归极限恒存在且等于测度平方。（素数交换对递归）
