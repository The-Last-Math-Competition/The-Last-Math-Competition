# 00000004663

**English.** Definition: The Milnor number mu and the Tyurina number tau of an isolated hypersurface singularity are the dimension of the Jacobian algebra and the dimension of the deformation tangent space. Conjecture: For mu at most 12 the realizable set of the difference mu - tau is an explicit finite set characterized by weights: odd-weight germs always have mu = tau; for even-weight germs the difference lies in {0,2,4,6,8}, each value realized by an explicit germ; and the mod 2 class of the difference is an isomorphism invariant of the germ. (realizable set of small Milnor-number differences)

**中文。** 定义：孤立超曲面奇点的 Milnor 数 μ 与 Tyurina 数 τ：雅可比代数维数与形变切空间维数。猜想：μ ≤ 12 时差值 μ-τ 的可实现集为显式有限集且由权刻画——奇权芽恒有 μ=τ；偶权芽的差值落在 {0,2,4,6,8} 内且每个值由显式芽实现；差值的模 2 同余类为芽的同构不变量。（小 Milnor 数差值可实现集）
