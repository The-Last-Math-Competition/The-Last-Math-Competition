# 00000002631

**MF-11 ★** — source: 73_模形式与Jacobi形式II.md

**English.** Definition: Hermitian Jacobi forms: the Jacobi-like theory over imaginary quadratic fields. Conjecture: An explicit main term exists for the Hermitian Jacobi dimension formula, with leading coefficient a linear function of the class number of the field; for genus-1 fields the formula degenerates to the classical Eichler–Zagier, and the degeneration map is injective. (Hermitian dimension formula)

**中文。** 定义：Hermitian Jacobi 形式：虚二次域上的类 Jacobi 理论。猜想：Hermitian Jacobi 的维数公式存在显式主项且主项系数为域的类数的线性函数；亏格 1 域的公式退化为经典 Eichler–Zagier 且退化映射为单射。（Hermitian 维数公式）
