# 00000009906

**GBR-26 ★** — source: 315_箭图表示与Auslander-Reiten理论.md

**English.** Definition: Block theory after dihedral blocks: stable equivalence classes of semidihedral and quaternion defect groups. Conjecture: The complete list of stable equivalence classes of blocks with semidihedral and quaternion defect groups is algorithmically generable; the finiteness of the list follows from explicit compression of the parameter spaces of source algebras, with algebraic compression maps. (block stable classes algorithmization)

**中文。** 定义：二面体块之后的块论：半二面体与四元数亏群的稳定等价类。猜想：半二面体与四元数亏群的块的稳定等价类的完全列表可算法化生成；列表的有限性由源代数的参数空间的显式压缩给出且压缩映射为代数。（块稳定类算法化）
