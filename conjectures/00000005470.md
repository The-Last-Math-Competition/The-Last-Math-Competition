# 00000005470

**English.** Definition: Sieve constants and asymptotic errors are two layers. Conjecture: There exist two prime-density sieves with the same main constant but different error terms, and the separation is realized by an explicit pair of weighted sieves. (same sieve main constant-different error term separation)

**中文。** 定义：筛常数与渐近误差指两层。猜想：存在两种素数密度筛法的主常数相同而误差项不同,分离由显式的加权筛对实现。（筛主常数同-误差项异分离）
