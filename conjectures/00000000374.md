# 00000000374

**English.** Definition: P(τ) is the set of reals approximable by infinitely many algebraic numbers α of degree ≤ 2 with |ξ − α| < H(α)^{−τ}. Conjecture: For τ > 3, the Hausdorff dimension of P(τ) equals 3/τ, while for τ ≤ 3, P(τ) = R; the dimension formula is continuous at τ = 3.

**中文。** 定义：P(τ) 为可被无穷多个次数 ≤ 2 的代数数 α 以 |ξ−α| < H(α)^{−τ} 逼近的实数集。猜想：τ > 3 时 P(τ) 的 Hausdorff 维数等于 3/τ,τ ≤ 3 时 P(τ) = R;维数公式在 τ=3 处连续。
