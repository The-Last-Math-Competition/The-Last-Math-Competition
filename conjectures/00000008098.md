# 00000008098

**English.** Definition: The Broue mean-value invariant of blocks of fusion systems: the ratio br(B) of the block counting invariant k(B) (the number of irreducible characters) to the defect group order |D|. Conjecture: The Brauer-type bound k(B) <= |D| is preserved in blocks (virtual blocks) of fusion systems (a fusion Brauer bound); the tightness (equality) of the bound is realized in fusion by abelian defect groups with trivial inertia (an abelian-trivial equality law); and the explicit c in the lower bound k(B) >= |D|^{c/2} (the lower-bound exponent) is the normalization (1/2) 1/[S:D] (a lower-bound normalization formula). (fusion Brauer abelian equality normalization)

**中文。** 定义：融合系统的块的 Broué 平均值不变量：块的计数不变量 k(B)（不可约特征数）与亏群阶 |D| 的比值 br(B)。猜想：k(B) ≤ |D| 的 Brauer 型界在融合系统的块（虚拟块）中保持（融合 Brauer 界）；且界的紧性（等号）的融合实现为交换亏群+平凡惯性（交换-平凡等号律）；k(B) 的下界 |D|^{c/2} 的显式 c（下界指数）为 1/2·1/[S:D] 的规范化（下界规范化公式）。
