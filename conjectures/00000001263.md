# 00000001263

**English.** Definition: Binomial complexity is the counting complexity of binomial coefficients of partial words. Conjecture: The second order of binomial complexity is Θ(n); and the explicit value of the constant is given by the maximal run of allowed blocks. (binomial complexity linear order)

**中文。** 定义：二项复杂度为部分词的计数复杂度。猜想：二项复杂度的第二阶为 Θ(n)；且常数的显式值由允许块的极大游程给出。（二项复杂度线性阶）
