# 00000007804

**ACG-24 ★** — source: 245_渐近凸几何.md

**English.** Definition: Ramsey-type convex position: the existence of a monochromatic convex m-gon in any k-coloring of a planar point set in general position (an Erdos-Szekeres colored version). Conjecture: The minimal point count R_c(m,2) in the two-color case is 2^{cm+o(m)} with c = log_2(3) - 1, from matching construction and upper bound; and in dimension d the monochromatic convex chain length is Theta(log log n) in the point count n, with constants given by a double-logarithmic formula in vertex count and color count. (colored Erdos-Szekeres exponent)

**中文。** 定义：凸位置的 Ramsey 型：任意 k 色染色的平面一般位置点集 S 中同色凸 m 边形的存在性（Erdős–Szekeres 型染色版）。猜想：最小点数 R_c(m,2)（两色情形）为 2^{cm+o(m)} 且 c=log_2(3)-1（由构造与上界的匹配给出）；d 维情形同色凸链长度为 Θ(log log n)（n 为点数），其常数由顶点数与色数的双重对数公式决定。
