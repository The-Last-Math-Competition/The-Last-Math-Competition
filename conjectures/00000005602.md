# 00000005602

**English.** Definition: The root factor is the key quality measure of lattice basis reduction, the ratio of the first vector to the shortest vector. Conjecture: The worst case is always an explicit function of the dimension, with lower bound given by the Gaussian heuristic of random lattices; the gap between worst and average is exponentially small; and the gap vanishes if and only if the lattice spectrum is of spectral-gap type, with gap width a logarithmic factor. (Gaussian-heuristic exponential gap of root factors)

**中文。** 定义：根因子：格基规约质量的关键刻画量（首向量与最短向量之比）。猜想：最坏情形恒为维数的显式函数且下界由随机格的高斯启发给出；最坏与平均的间隙为指数小；间隙的消失当且仅当格的谱为谱隙型且隙宽为对数因子。（根因子高斯启发指数间隙）
