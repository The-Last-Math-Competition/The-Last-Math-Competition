# 00000002569

**CM-09 ★** — source: 71_计算复杂性中的数学.md

**English.** Definition: A totally unimodular matrix is an integer matrix all of whose subdeterminants lie in {0,±1}. Conjecture: The minimal number of layers in decomposing totally unimodular matrices into network matrices is always a constant; the constant is at most four, attained on grid graphs. (totally unimodular network decomposition layers)

**中文。** 定义：全幺模矩阵指一切子式都属于 {0,±1} 的整数矩阵。猜想：全幺模矩阵分解为网络矩阵的最小层数恒为常数；且常数的界为四并在网格图达到。（全幺模网络分解层数）
