# 00000002353

**English.** Definition: An nc rational function is an element of the free skew field. Conjecture: Its realization domain (matrix well-definedness) is a matrix-convex free semialgebraic set; and the domain has an explicit LMI representation: domain = {X : A + BXC + CX^TB + DX^*EX ≥ 0} (finite linear matrix inequalities).

**中文。** 定义：nc 有理函数指自由分式域的元素。猜想：其可实现域(矩阵良定义)为矩阵凸的自由半代数集;且域有显式 LMI 表示:域 = {X: A+BXC+CX^TB+DX^*EX ≥0}(有限线性矩阵不等式)。
