# 00000006630

**English.** Definition: Correlation inequalities and equilibria are two layers. Conjecture: There exist two lattice-gas models with identical inequalities but different equilibria, and the separation is realized by an explicit violation with the same inequalities but different configuration counting. (same inequality-different configuration separation)

**中文。** 定义：关联不等式与平衡态指两层。猜想：存在两格气模型的一切不等式相同而平衡态不同,分离由同不等式异构型计数的显式破坏实现。（不等式同-平衡异构型分离）
