# 00000006550

**English.** Definition: The Fredholm index and the dimension spectrum are two layers. Conjecture: There exist two triples with the same Fredholm index but different dimension spectra, and the separation is realized by an explicit deformation with the same index but different unitary. (same index-different dimension-spectrum unitary separation)
