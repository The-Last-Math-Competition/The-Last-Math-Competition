# 00000001573

**English.** Definition: The scattering map of the finite nonperiodic Toda chain. Conjecture: The image of the scattering data is an explicit regular domain, and the Jacobian of the inverse map is an explicit square of the tau function (the scattering Jacobian).

**中文。** 定义：有限非周期 Toda 链的散射映射。猜想：散射数据的像为显式正则域且逆映射的 Jacobi 行列式为 τ 函数的显式平方(散射 Jacobi)。
