# 00000008193

**CNT-23 ★** — source: 258_计算数论.md

**English.** Definition: The graph constraints on solving S-unit equations: the computation of the finiteness constant su_bound(S) for the number of solutions of the S-unit equation x + y = 1. Conjecture: The explicit upper bound of su_bound is exp(exp(c |S|)) (a double-exponential bound); the actual solution count (for all known S) is |S|^{2+o(1)} (a solution-count-cardinality law); the tightening of the gap between the double-exponential bound and actuality (theoretical slack) is |S|^4 (a four-parameter tightening); and the complexity of the optimal de Weger type search algorithm for S-unit solutions is |S|^2 log^{O(1)} C (a two-parameter logarithmic law). (S-unit double-exponential four-parameter tightening)

**中文。** 定义：S-单数方程的求解的图约束：S-unit 方程 x+y=1 的解数的有限性常数的计算 su_bound(S)。猜想：su_bound 的显式上界为 exp(exp(c·|S|))（双指数界）；且实际解数（一切已知 S）为 |S|^{2+o(1)}（解数-基数律）；双指数界与实际的间隙（理论的松弛）的紧化为 |S|^{4}（四参紧化）；S-unit 的解的搜索算法的最优（de Weger 型）的复杂度为 |S|^{2}·log^{O(1)}C（二参-对数律）。
