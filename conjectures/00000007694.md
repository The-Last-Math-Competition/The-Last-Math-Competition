**English.** Definition: topological entropy h_top of translation space (X,T) is exponential growth lim (log N(L))/L^d of graph number N(L) of defined to be edge long L. Conjecture: by X on h_top=0 of finite prototile set T generates if and only if X is translation space of factor; in particular, prototile generates of system if minimal then entropy is zero, prototile generates positive entropy minimal system.

**中文。** 定义：平移铺砌空间 (X,T) 的拓扑熵 h_top 定义为沿边长 L 方盒的图案数 N(L) 的指数增长率 lim (log N(L))/L^d。猜想：由有限 prototile 集 T 生成的 X 上 h_top=0 当且仅当 X 可被提升为某个替换系统的因子；特别地，任何单 prototile 生成的平移铺砌空间若极小则熵为零，而双 prototile 可产生正熵极小系统。
