# 00000004427

**English.** Definition: The density threshold of the six-vertex model is the vanishing parameter of the frozen-liquid interface. Conjecture: The threshold of the inhomogeneous six-vertex model is an explicit rational expression in four parameters, and the homogeneous limit degenerates to the known exact value with no correction. (six-vertex threshold rational formula)
