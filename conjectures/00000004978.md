# 00000004978

**English.** Definition: A Korobov lattice is the rank-one quadrature rule given by a generating vector. Conjecture: The rank-one optimal generating vector for dimension four with one hundred and one points is an explicit table, verified by exhaustive indices with unique optimal value. (explicit optimal vector table of four-dimensional Korobov)

**中文。** 定义：Korobov 格指由生成向量的秩一求积法则。猜想：四维一百零一点的秩一最优生成向量为显式表,经穷举指标验证且最优值唯一。（Korobov 四维显式最优向量表）
