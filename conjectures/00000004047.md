**English.** Definition: An exact Borel subalgebra is a triangular subalgebra satisfying the homological control condition. Conjecture: An exact Borel exists if and only if the quiver admits an adapted orientation for quasi-heredity, with the criterion given by an explicit inequality between the length of the root-ideal chain and the number of vertices. (existence criterion for exact Borel subalgebras)

**中文。** 定义：正合 Borel 子代数指满足同调控制条件的三角子代数。猜想：正合 Borel 存在当且仅当箭图具有拟遗传的适配定向,判据由根理想链长与顶点数的显式不等式给出。（正合 Borel 存在判据）
