# 00000002790

**English.** Definition: Asymptotic structures {X}_n: the set of n-point asymptotic types. Conjecture: The cardinality of asymptotic type sets: the element count of {X}_n has an exponential upper bound in the dimension, controlled by the branching degree of the asymptotic game; the logarithm of the cardinality is exactly the information entropy of the game. (asymptotic type set cardinality entropy)
