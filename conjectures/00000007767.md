**English.** Definition: let f,g is commute polynomial, periodic point set of P^1 on -fold number ≥2 is Per(f)∩Per(g). Conjecture: the set is infinite if and only if f and g has iteration (exists m,n such that f^m=g^n); and set non- infinite when two map same is symmetric monomial part in composition of iteration (Ritt type characterizes), its Ritt decomposition of one map h equivalent under unique.

**中文。** 定义：设 f,g 为 P^1 上次数 ≥2 的可交换多项式，公共周期点集为 Per(f)∩Per(g)。猜想：该集合为无限当且仅当 f 与 g 有公共迭代（存在 m,n 使 f^m=g^n）；且集合非空无限时两映射同为某单一映射 h 的迭代（Ritt 型刻画），其 Ritt 分解的对称单项式部分在复合等价意义下唯一。
