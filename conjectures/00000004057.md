# 00000004057

**English.** Definition: The rank variety is the variety defined by the rank loci of the commutator matrices of the generators. Conjecture: The dimension of each irreducible component is read off from an explicit rank table of the commutator matrices, and the number of components is at most the number of generators. (component dimension table of rank varieties)

**中文。** 定义：秩 variety 指由生成元交换矩阵的秩轨迹定义的簇。猜想：其每个不可约分量的维数由交换矩阵的显式秩表读出,分量个数不超过生成元个数。（秩 variety 分量维数表）
