# 00000001465

**English.** Definition: The Moreau envelope of a convex function f is M_λf(x) = inf_y{f(y) + |x−y|²/(2λ)}. Conjecture: The critical parameter for M_λf to be C¹ is λ*(f) = 1/L(f), where L(f) is the minimal Lipschitz constant of f; for λ < λ*, all envelopes are C¹, while for λ > λ* there exists f whose envelope is nondifferentiable at a minimizer.

**中文。** 定义：凸函数 f 的 Moreau 包络 M_λf(x)=inf_y{f(y)+|x−y|²/(2λ)}。猜想：M_λf 为 C¹ 的临界参数为 λ*(f)=1/L(f),L(f) 为 f 的最小 Lipschitz 常数;λ<λ* 时一切包络 C¹,λ>λ* 时存在 f 使包络在最小点处不可微。
