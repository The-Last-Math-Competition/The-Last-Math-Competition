# 00000002328

**NG-08 ★** — source: 63_数值代数几何.md

**English.** Definition: A witness set is the tangent-space-plus-points representation of a variety in numerical algebraic geometry. Conjecture: The expected approximation error of witness points is h²·C(condition length) (with C explicitly the average condition number of the path); the error scales quadratically with the tracking step size.

**中文。** 定义：witness set 指数值代数几何中簇的切空间+点的表示。猜想：witness 点的期望逼近误差为 h²· C(条件长)(C 显式为路径的平均条件数);误差与追踪步长的平方标度。
