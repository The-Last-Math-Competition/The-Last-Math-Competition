# 00000000274

**English.** Definition: The Kannan–Lovász–Simonovits (KLS) constant: the reciprocal of the worst-case escape probability of an isotropic log-concave measure through half-spaces. Conjecture: The KLS constant is uniformly bounded below by an absolute constant c > 0 (both the slicing and thin-shell conjectures are consequences).

**中文。** 定义：Kannan–Lovász–Simonovits(KLS)常数:各向同性归一化 log-凹测度对半空间的最坏逃逸概率的倒数。猜想：KLS 常数被绝对常数 c > 0 一致下界( slicing/thin-shell 皆为其推论)。
