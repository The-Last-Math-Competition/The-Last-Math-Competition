# 00000003884

**CA3-04 ★** — source: 115_交换代数III_正特征.md

**English.** Definition: F-jumping numbers are the values of parameter c at which the test ideal τ(c) jumps. Conjecture: For homogeneous ideals of fixed dimension d, the F-jumping number sequences converge as p → ∞ at rate O(p^{−1/d}), and the exponent 1/d is optimal. (F-jumping convergence rate)

**中文。** 定义：F-跳跃数指参数 c 使 test ideal τ(c) 发生跳跃的值。猜想：固定维数 d 的齐次理想的 F-跳跃数列随 p → ∞ 收敛,收敛速率为 O(p^{−1/d}),且指数 1/d 最优。（F-跳跃收敛速率）
