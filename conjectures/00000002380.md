# 00000002380

**OF-30 △** — source: 64_算子理论II_函数演算与自由分析.md

**English.** Conjecture: There exists a subnormal operator whose spectrum is a Cantor set and all of whose nontrivial reducing subspaces have spectra dense in the original spectrum; the construction uses binary splitting of weighted shifts.

**中文。** 猜想：存在亚正规算子其谱为 Cantor 集且一切非平凡约化子空间的谱稠密于原谱;构造由加权移位的二进分裂。
