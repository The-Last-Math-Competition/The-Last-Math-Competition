# 00000008479

**English.** Definition: Arithmetic Mane: the set of all extremal values of Birkhoff-type averages of polynomial orbits {P(n) mod 1}. Conjecture: The arithmetic Lagrange spectrum is dual to the classical Lagrange spectrum (a dual spectrum law); the Hausdorff dimension of the difference set of the two spectra is 1/2 (a half-dimension difference law); the arithmetic closure of the difference set is a closed interval (a closed interval closure law); and the minimal endpoint of the interval is the explicit value 1/2 (a half-endpoint law). (arithmetic Lagrange dual half-dimension interval)

**中文。** 定义：算术 Mañé：多项式轨道 {P(n) mod 1} 的 Birkhoff 型平均的极值的全体取值。猜想：算术 Lagrange 谱与经典 Lagrange 谱对偶（对偶谱律）；且两谱的差集的 Hausdorff 维数为 1/2（半维差律）；差集的算术闭包为闭区间（闭区间闭包律）；闭区间的最小端点为 1/2 的显式值（半端点律）。
