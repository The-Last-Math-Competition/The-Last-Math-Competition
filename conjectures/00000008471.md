# 00000008471

**ERO-01 ★** — source: 268_遍历优化.md

**English.** Definition: The maximization problem of a continuous function f on a dynamical system (X,T): find the invariant probability measures mu with integral of f d mu attaining the supremum; the set of maximizing measures is M(f). Conjecture: The number of atoms of measures in M(f) does not exceed the number of locked periodic orbits of f; and for Baire-generic f the function is locked, i.e. M(f) consists only of equidistributions on finitely many periodic orbits (a universal locking law); the complement of the set of locked functions is a dense open set (a dense open complement law). (generic locking of maximizing measures)

**中文。** 定义：动力系统 (X,T) 上连续函数 f 的极大化问题：求不变概率测度 μ 使 ∫f dμ 达到上确界，极大化测度集记 M(f)。猜想：M(f) 中测度的原子数不超过 f 的锁定周期轨道数；且在 Baire 意义下通有的 f 为锁定的，即 M(f) 仅由有限条周期轨道上的等分布构成（普遍锁定律）；锁定函数集的补为稠密开集（稠密开补律）。
