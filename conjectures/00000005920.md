# 00000005920

**English.** Definition: The limit persistence diagram and the sampling spectrum are two layers. Conjecture: There exist two noise distributions with the same limit persistence diagram but different finite sampling spectra, and the separation is realized by an explicit distribution pair with the same limit but different tails. (same limit diagram-different sampling spectrum tail separation)

**中文。** 定义：极限持久图与采样谱指两层。猜想：存在两噪声分布的极限持久图相同而有限采样谱不同,分离由同极限异尾部的显式分布对实现。（极限图同-采样谱异尾部分离）
