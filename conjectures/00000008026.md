# 00000008026

**English.** Definition: The tamed version of Andre-Oort (tame AO): the explicit exceptional-set exponent AO_tam for density theorems of special points of mixed Shimura varieties inside o-minimal curves and surfaces. Conjecture: The count of special points in an o-minimal set X obeys N_sp(X,H) <= C H^{dim(sp-closure)}; positive density outside the exceptional set occurs if and only if X contains a positive-dimensional part of the special closure; and the constant of AO_tam is an explicit Euler product of Mass formulas (a product of CM class numbers), the product attaining its minimum at the minimal class numbers of negative discriminants (the h = 1 discriminant list). (tame Andre-Oort Mass Euler constant)

**中文。** 定义：André–Oort 型的驯化（tame AO）：混合 Shimura 纹的特殊点在 o-极小曲线/曲面中的分布密度定理的显式例外集指数 AO_tam。猜想：o-极小集 X 中的特殊点的计数 N_sp(X,H) ≤ C·H^{dim(sp-闭包)}；且特例外的正阶（非例外特殊点正密度）当且仅当 X 含特殊闭包的正维部分；AO_tam 的常数为 Mass 公式的显式 Euler 积（CM 类数乘积），乘积在负判别式的极小类数（h=1 判别式列表）取到极小值。
