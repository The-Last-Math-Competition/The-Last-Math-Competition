# 00000002042

**AD-22 ★** — source: 53_加性数论II.md

**English.** Definition: An exact covering system covers every integer by exactly one congruence class. Conjecture: The count of exact covering systems with distinct moduli is asymptotically c·N^{1/2} (with c of the explicit 2/π type); the count is controlled by the enumeration of Znám-type trees.

**中文。** 定义：精确覆盖系统指每个整数恰被一个同余类覆盖的系统。猜想：不同余模数的精确覆盖系统的计数渐近为 c· N^{1/2}(c = 2/π 型显式);计数由 Znám 型树的枚举控制。
