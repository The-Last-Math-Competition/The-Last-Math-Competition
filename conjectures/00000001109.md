# 00000001109

**LT-09 ★** — source: 27_李理论与代数群.md

**English.** Definition: The exponents of a Coxeter system (the characteristic polynomial). Conjecture: The exponent set of a non-crystallographic Coxeter group contains, besides (h, 1), some exponent of multiplicity ≥ 2 (universality of multiplicity structure).

**中文。** 定义：Coxeter 系统的指数(特征多项式)。猜想：非晶体 Coxeter 群的指数集包含 (h, 1) 之外的重数 ≥ 2 的指数(重数结构普遍性)。
