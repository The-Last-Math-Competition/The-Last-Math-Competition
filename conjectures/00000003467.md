**English.** Definition: The core of a Cayley graph is the coloring-carrying subgraph, with structure constrained by group theory. Conjecture: The edge count of the core of an abelian Cayley graph is a linear function of the generating-set size with slope half the group rank; in the nonabelian case the core size is bounded by the centralizer index, with equality attained by minimal nonabelian groups. (Cayley core generator bound)

**中文。** 定义：Cayley 图的核为染色承载子图，其结构受群论约束。猜想：交换群 Cayley 图的核的边数为生成集大小的线性函数且斜率为群秩的一半；非交换情形核的规模以中心化子指标为上界且等号由极小非交换群达到。（Cayley 核生成元界）
