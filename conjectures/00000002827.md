# 00000002827

**English.** Definition: The interface between concentration inequalities and LDP: deviations of Talagrand's convex distance. Conjecture: The exponential threshold of convex distance: the interface window between convex concentration and LDP is of the order of the variance, and within the window the deviation distribution is controlled by the logarithmic Sobolev constant. (convex distance interface window constant)

**中文。** 定义：集中不等式与 LDP 的交界：Talagrand 凸距离的偏差。猜想：凸距离的指数阈：凸集中与 LDP 的交界窗为方差的量级且窗内偏差的分布由对数 Sobolev 常数控制。（凸距交界窗常数）
