# 00000001354

**AN2-24 ★** — source: 30_解析数论II_L函数与自守.md

**English.** Definition: The square-phase prime sum is Σ_{p≤x} e(√p). Conjecture: Σ_{p≤x} e(√p) ≪ x^{1/4+ε}; and the same upper bound holds uniformly after replacing √p by α√p for any fixed 0 < α ≤ 1 — square-root cancellation for prime sums with square-root phases, uniformly.

**中文。** 定义：平方相位素数和指 Σ_{p≤x} e(√p)。猜想：Σ_{p≤x} e(√p) ≪ x^{1/4+ε};且把 √p 换为 α√p(任意固定 0<α≤1)后同一上界一致成立,即平方根相位的素数和有均匀平方根抵消。
