**English.** Definition: Hausdorff dimension of dimension geometry: transcendental number set of algebraically independent set and box dimension. Conjecture: Hausdorff dimension of all algebraically independent transcendental number set is dimension 1 and box dimension spectrum of its complement set is explicit interval; algebraically independent number set in Lebesgue measure under of [0,1/2] is measure dense Gδ. (algebraically independent dimension spectrum)

**中文。** 定义：代数无关集合的维数几何：超越数集的 Hausdorff 维数与盒维数。猜想：一切代数无关超越数集的 Hausdorff 维数为满维 1 且其补集的盒维数谱为 [0,1/2] 的显式子区间；代数无关数集在 Lebesgue 测度下为满测度稠密 Gδ。（代数无关维数谱）
