# 00000000545

**CA-45 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: Markov bases (quadratic-quadratic). Conjecture: The toric ideal of the graph ring of K_n has an entirely quadratic Markov basis if and only if n ≤ 5 (a criterion beyond Hosten–Sullivant).

**中文。** 定义：Markov 基(二次二次)。猜想：K_n 的图环 toric 理想有全部二次 Markov 基当且仅当 n ≤ 5(Hosten–Sullivant 之外的判定)。
