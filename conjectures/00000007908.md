**English.** Definition: Lokvenec-Gulesir conjecture is special counting N(H) (height ≤H) of point (CM point) of Hilbert module surface X of special point density: field F on of Hilbert module variety. Conjecture: N(H) ~ c · H^{1/2}(log H)^{b} (b is entire function); of class number of F and distribution measure mutual pair Bergman metric of special point is explicit constant of not uniform (CM point set in measure singularity), set is stable order average 1/2 · 1/ζ_F(2) of elliptic point.

**中文。** 定义：Lokvenec-Gulesir 猜想转述为 Hilbert 模 variety 的特殊点密度：全实域 F 上的 Hilbert 模曲面 X 的特殊点（CM 点）的计数 N(H)（高度 ≤H）。猜想：N(H) ~ c·H^{1/2}(log H)^{b}（b 为 F 的类数的半整函数）；且特殊点的等分布测度相对 Bergman 度量为绝不一致（CM 点聚集于测度奇点），聚集率的显式常数为椭圆点的稳定阶平均 1/2·1/ζ_F(2)。
