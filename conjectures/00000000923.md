# 00000000923

**English.** Definition: The decomposition rank dr(A) and stable rank sr(A) of nuclear algebras. Conjecture: The existing inequality dr(A) ≤ n ⟹ sr(A) ≤ ⌊n/2⌋+1 can be strengthened to sr(A) ≤ ⌈(n+1)/3⌉, attained on generalized circle algebras of dimension n = 3; no smaller universal bound exists.

**中文。** 定义：核代数的降秩维数 dr(A) 与稳定秩 sr(A)。猜想：dr(A) ≤ n 蕴含 sr(A) ≤ ⌊n/2⌋+1 的既有不等式可加强为 sr(A) ≤ ⌈(n+1)/3⌉,且该界在维数 n=3 的推广圆代数上达到;不存在更小的普适界。
