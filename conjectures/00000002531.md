# 00000002531

**English.** Definition: k-dimensional Hausdorff measure H^k and spherical density: the density of a set E at a point x is θ(x) = lim_{r→0} H^k(E∩B_r)/r^k. Conjecture: For every H^k-measurable set the density limit exists modulo H^k-null sets and takes values in {0,1}; the exceptional set where the limit fails to exist has dimension strictly below k, and the exceptional upper bound k−1 is tight. (density dichotomy exceptional dimension)

**中文。** 定义：k 维 Hausdorff 测度 H^k 与球密度：集合 E 在点 x 的密度 θ(x)=lim_{r→0} H^k(E∩B_r)/r^k。猜想：一切 H^k 可测集的密度极限在不计 H^k 零集意义下存在且取值于零与一；密度极限不存在的例外集的维数严格小于 k 且例外维数上界 k−1 为紧。（密度二值律例外维）
