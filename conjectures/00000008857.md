**English.** Definition: Monotonicity and game equilibria. Conjecture: The Nash equilibrium set of monotone games is always nonempty; and the equilibrium set is closed convex and contains the solution set of the monotone inclusion. (monotone game equilibrium nonemptiness)

**中文。** 定义：单调性与对策均衡。猜想：单调博弈的 Nash 均衡集恒非空；且均衡集为闭凸并包含单调包含的解集。（单调博弈均衡非空）
