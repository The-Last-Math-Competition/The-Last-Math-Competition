# 00000004331

**English.** Definition: A constructive functional integral is an infinite-dimensional integral defined by compatible measures on finite-dimensional projections. Conjecture: For the P(phi)_2 Euclidean field, convergence of the constructive measure has an explicit coupling threshold, beyond which no stable translation-invariant measure exists. (coupling threshold of constructive measures)

**中文。** 定义：构造性泛函积分指由有限维投影相容测度定义的无穷维积分。猜想：P(φ)₂ 欧氏场的构造测度收敛存在耦合的显式阈值,超过阈值的稳定平移不变测度不存在。（构造测度耦合阈值）
