# 00000000534

**CA-34 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: The ghost components of Witt vectors are w_n = Σ x_i^{p^n−i}. Conjecture: The minimal degrees of freedom of polynomial sequences x_i forcing all w_n ≡ 0 mod p^N equal N(N+1)/2 (the ghost-zero dimension).

**中文。** 定义：Witt 向量幽灵分量 w_n = Σ x_i^{p^n-i}。猜想：多项式 x_i 序列使所有 w_n ≡ 0 mod p^N 的最小自由度 = N(N+1)/2(幽灵零维数)。
