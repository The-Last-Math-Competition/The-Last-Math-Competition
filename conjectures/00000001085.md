# 00000001085

**English.** Definition: The depth spectrum of a code is a Sebo-type combinatorial quantity. Conjecture: The depth spectrum of a binary linear code is an additive subgroup other than zero; and the combination of subgroups is the tower of derivations. (depth spectrum derivation-tower additive subgroup)

**中文。** 定义：码的深度谱为 Sebő 型组合量。猜想：二进制线性码的深度谱为除零外的加法子群；且子群的组合为导子塔。（深度谱导子塔加法子群）
