# 00000002798

**English.** Definition: Gowers' tree spaces: local embeddings of tree metrics. Conjecture: The asymptotic structure of tree spaces: the asymptotic type set of the Gowers tree space is of pure ℓ₁ type, and the resolution (distinguishing power) of the type set is the branching height of the tree. (Gowers tree type resolution)

**中文。** 定义：Gowers MA 的树空间：树度量的局部嵌入。猜想：树空间的渐近结构：Gowers 树空间的渐近型集为纯 ℓ₁ 型且型集的分辨率（区分度）为树的分叉高度。（Gowers 树型分辨率）
