**English.** Definition: Connes embedding is the property that a II₁ factor is finitely approximated by matrix algebras; MIP*=RE implies L(F₂) fails it. Conjecture: The smallest matrix order involved in certifying non-embeddability of L(F₂) — the gap between the optimal value of a self-adjoint polynomial inequality on matrix tensors and its factor value — is 2^{20}; no distinguishing counterexample inequality exists below order 2^{10}.

**中文。** 定义：Connes 嵌入指 II₁ 因子可被矩阵代数有限维逼近的性质;MIP*=RE 定理推出 L(F₂) 不满足之。猜想：验证 L(F₂) 非嵌入所需的最小不等式(自伴随多项式在矩阵张量上的最优值与因子值之差)涉及的最小矩阵阶数为 2^{20};不存在 2^{10} 阶以下可区分的反例不等式。
