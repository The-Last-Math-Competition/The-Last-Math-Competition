# 00000000193

**CS-27 ★** — source: 13_常数与级数.md

**English.** Definition: S = Σ_{n≥1} 1/(n!+n). Conjecture: S is irrational with μ(S) ≤ 2 + 1/log 2; the bound is attained by approximations with denominators lcm(1,…,N), the approximation error exponent being an explicit rational number. (n!+n series measure)

**中文。** 定义：S=Σ_{n≥1} 1/(n!+n)。猜想：S 无理且 μ(S) ≤ 2+1/log 2；界由分母 lcm(1,…,N) 的逼近给出且逼近误差的指数为显式有理数。（n!+n 级数度量）
