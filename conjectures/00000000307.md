# 00000000307

**English.** Definition: Weighted bad approximation Bad(i,j) is the set of pairs simultaneously badly approximable when the two coordinates are weighted by q^{1+i} and q^{1+j}. Conjecture: For i+j = 0, Bad(i,j) is a full-dimensional winning set; moreover, for every weighting with i+j < 0, the intersection remains full-dimensional, with winning given explicitly by a Schmidt-game strategy. (weighted bad approximation full-measure winning set)

**中文。** 定义：加权坏逼近 Bad(i,j) 指两坐标分别以 q^{1+i} 与 q^{1+j} 为权重尺度时同时坏逼近的数对集合。猜想：i+j=0 时 Bad(i,j) 为全维赢集；且对一切 i+j<0 的权选择交集仍为满维且赢性由 Schmidt 博弈策略显式给出。（加权坏逼近满维赢集）
