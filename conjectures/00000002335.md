# 00000002335

**English.** Definition: The Lebesgue constant is the norm of the interpolation operator. Conjecture: The constant for Chebyshev nodes is always a linear function of log n plus the constant 8·log2/π; and the remainder is 1/n². (Chebyshev Lebesgue second term)

**中文。** 定义：Lebesgue 常数指插值算子的范数。猜想：Chebyshev 节点的常数恒为 logn 的线性式加常数八倍 log2 除 π；且余项为一除 n 平方。（Chebyshev Lebesgue 第二项）
