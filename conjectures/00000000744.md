# 00000000744

**PA-44 ★** — source: 23_p进分析与局部域.md

**English.** Definition: The p-adic Mandelbrot set M_p = {c ∈ Z_p : the 0-orbit of x² + c is bounded}. Conjecture: M_p is a closed-and-open subset of Z_p whose Haar measure is rational and explicit in p mod 4 (computability of the measure).

**中文。** 定义：p-adic Mandelbrot 集 M_p = {c ∈ ℤ_p : x² + c 的 0 轨道有界}。猜想：M_p 为 ℤ_p 的闭开子集,其 Haar 测度为有理数且对 p mod 4 显式(测度可计算性)。
