# 00000002201

**English.** Definition: The ideal class semigroup S(I) = {(I^n : I^n) : n} has stabilizer ring (I : I). Conjecture: The type of the stabilizer ring of a principal ideal of a Noetherian domain satisfies an explicit bound by dim R (a stabilizer-ring type bound).

**中文。** 定义：理想类半群 S(I) = {(I^n : I^n) : n} 的稳定环 (I : I)。猜想：Noether 整环的主理想的稳定环的型(type)≤ dim R 的显式界(稳定环型界)。
