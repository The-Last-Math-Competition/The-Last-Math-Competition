# 00000008161

**English.** Definition: The renormalized gauge fixing of gauge theory: the index st_keep of the RG preservation of the BRST Slavnov-Taylor identities. Conjecture: st_keep (the flow invariance of the ST identities) is preserved under all linear gauges (a linear gauge preservation law); the minimal number of correction (anomaly cancellation) terms for the breaking under nonlinear gauges (ST breaking) equals the rank of the gauge group (a rank-cancellation correspondence); and the residue after cancellation (the true anomaly) is a representative of the BRST cohomology H^1(s|d) (an anomaly representative law), the coefficient c of the representative's central charge being the 4d-cycle characteristic class (a characteristic class anomaly formula). (Slavnov-Taylor rank anomaly representative)

**中文。** 定义：规范理论的重整化规范固定：BRST 的 Slavnov–Taylor 恒等式的 RG 保持的指标 st_keep。猜想：st_keep（ST 恒等式的流的不变性）在一切线性规范下保持（线性规范保持律）；且非线性规范的破坏（ST 破缺）的修正（反常抵消）的最少抵消项数 = 规范群的秩（秩-抵消对应）；抵消后的留数（真反常）为 BRST 上同调 H¹(s|d) 的代表元（反常代表律），代表元的系数的中心荷 c 为 4d 循环示性类（示性反常公式）。
