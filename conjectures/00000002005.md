# 00000002005

**English.** Definition: Soliton decomposition of wave maps. Conjecture: The threshold solution of 2+1 dimensional corotational wave maps is exactly the explicit scaling family of stirred harmonic maps (threshold uniqueness).

**中文。** 定义：波映射的 soliton 分解。猜想：2+1 维 corotational 波映射的 threshold 解恰为搅拌谐波映射的显式缩放族(threshold 唯一性)。
