# 00000000174

**CS-08 ◆** — source: 13_常数与级数.md

**English.** Definition: P(3) = Σ_p p^{−3} is the value of the prime zeta function at three. Conjecture: The irrationality measure of P(3) satisfies μ(P(3)) ≤ 5/2; the bound is attained by truncated Euler products with denominators q_N = ∏_{p≤N} p³, with error exponent −(2+o(1)) log q_N. (P3 measure upper bound)

**中文。** 定义：P(3)=Σ_p p^{−3} 为素数 zeta 在奇点的值。猜想：P(3) 的无理性度量 μ(P(3)) ≤ 5/2；界由截断 Euler 积的分母 q_N=∏_{p≤N}p³ 的逼近达到且误差指数为 −(2+o(1))log q_N。（P3 度量上界）
