# 00000001122

**English.** Definition: Character sheaves. Conjecture: The values of the trace functions of Lusztig's character sheaves at F_q-points are algebraic integers with denominators involving only ℓ (integrality of denominators).

**中文。** 定义：character sheaf(特征标层)。猜想：Lusztik 的 character sheaf 的特征标层的迹函数在 F_q 点的值为代数整数且分母仅 ℓ(整性分母)。
