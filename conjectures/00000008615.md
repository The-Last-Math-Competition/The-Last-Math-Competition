# 00000008615

**English.** Definition: Adaptivity of shape-restricted regression. Conjecture: Monotone regression automatically attains the n^{-4/5} type rate at smooth points of the true function; and the global n^{-2/3} versus pointwise n^{-4/5} interpolate with the true smoothness. (monotone pointwise rate interpolation)

**中文。** 定义：Shape-restricted 回归的适应性。猜想：单调回归在真函数光滑点自动达到 n^{−4/5} 型；全局 n^{−2/3} 与点态 n^{−4/5} 由真光滑度插值。（单调点态速率插值）
