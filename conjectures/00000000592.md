# 00000000592

**English.** Definition: The graded canonical module ω of a semigroup-graded ring. Conjecture: The minimal number of generators of ω equals the type, and its set of degrees is exactly the pseudo-Frobenius numbers plus a constant (an aligned correspondence, verified up to dimension 4).

**中文。** 定义：半群 ℤ-分级环的分次 canonical 模 ω。猜想：ω 的极小生成元数 = type,且其度数集合恰为伪 Frobenius 数 + 常数(对应对齐,验证至 dim 4)。
