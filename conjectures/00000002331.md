# 00000002331

**English.** Definition: A Kostlan/Shub–Smale random system is a polynomial system with invariant Gaussian coefficients. Conjecture: The variance of the number of real roots is asymptotically exactly √2/4 times the square root of d; and the third central moment is O(1). (random real-root variance constant)

**中文。** 定义：Kostlan/Shub–Smale 随机系统指具不变高斯系数的多项式。猜想：实根数的方差渐近恒为 d 的二分之一次幂乘根号二除四；且三阶中心矩为 O(1)。（随机实根方差常数）
