# 00000009621

**SMA-11 ★** — source: 306_Smale空间与符号动力学.md

**English.** Definition: The Artin-Mazur zeta function zeta(z) = exp(sum p_n z^n/n) of an SFT is rational; the combinatorial characterization of realizable periodic count sequences (p_n) is open. Conjecture: A sequence (p_n) is the periodic count of some mixing SFT if and only if its generating exponent lambda is a Perron number and the numerator polynomial of the zeta function satisfies an explicit finite list of integrality and positivity constraints. (periodic count realizability)

**中文。** 定义：SFT 的 Artin–Mazur zeta ζ(z)=exp(Σ p_n z^n/n) 为有理函数；可实现周期计数序列 (p_n) 的组合刻画开放。猜想：序列 (p_n) 为某混合 SFT 的周期计数当且仅当其生成指数 λ 为 Perron 数且 zeta 函数的分子多项式满足整系数与正性约束的显式有限列表条件。（周期计数可实现性）
