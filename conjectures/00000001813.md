# 00000001813

**English.** Definition: The order #Aut(X) of the automorphism group of a general-type surface X. Conjecture: #Aut(X) ≤ 42(g−1)²; the tight bound is c·g² with c = 42 (improvable to c = 4 if the index of the canonical invariant group of X is ≥ 2); the optimal constant c = 4 is asymptotically attained by products of Hurwitz-type curves.

**中文。** 定义：一般型曲面 X 的自同构群阶 #Aut(X)。猜想：#Aut(X) ≤ 42(g−1)²;紧界为 c·g² 中 c = 42(可改进至 c = 4,若 X 的惯群指数 ≥ 2)。最优常数 c = 4 对 Hurwitz 型曲线的曲面乘积渐近达到。
