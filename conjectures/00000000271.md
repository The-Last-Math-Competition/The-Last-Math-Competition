**English.** Definition: A Hadamard matrix is a ±1 square matrix with pairwise orthogonal rows. Conjecture: For every 4 | n, a Hadamard matrix of order n exists (all cases with 4n ≤ 664 have been verified by search, with no exceptions).

**中文。** 定义：Hadamard 矩阵(±1 方阵,行两两正交)。猜想：对每个 4 | n,n 阶 Hadamard 矩阵存在(已知 4n ≤ 664 的全部情形经搜索验证,无例外)。
