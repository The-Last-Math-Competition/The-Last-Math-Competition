# 00000007695

**English.** Definition: The universality of an aperiodic Wang tile set W means some tiling T in X(W) encodes the space-time trace of any given Turing machine M via local substitutions. Conjecture: Every aperiodic Wang tile set is universal; conversely there exist tile sets with decidable tiling problem but no universality, whose minimal cardinality in dimension 3 is at most 5. (universality of aperiodic Wang sets)

**中文。** 定义：非周期 Wang 瓦集 W 的普适性指存在铺砌 T∈X(W) 使任意给定 Turing 机 M 的时空轨迹可经局部替换编码进 T 的某个局部图案序列。猜想：每个非周期 Wang 瓦集都是普适的；反之存在可判定铺砌问题但无普适性的周期可迫集，其最小基数在 3 维不超过 5。
