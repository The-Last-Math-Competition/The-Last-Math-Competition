# 00000004128

**English.** Definition: Class forcing is forcing over proper classes, and the forcing theorem is the equivalence of forcing truth with membership. Conjecture: The forcing theorem for class forcing holds if and only if the forcing relation is tamely definable, and any weakening of the tame condition produces a counterexample. (tame necessary-and-sufficient condition for class forcing)

**中文。** 定义：类力迫指对真类的力迫,力迫定理指真值与隶属的等价性。猜想：类力迫的力迫定理成立当且仅当力迫关系为 tamely 可定义,tame 条件的任何减弱均产生反例。（类力迫 tame 充要条件）
