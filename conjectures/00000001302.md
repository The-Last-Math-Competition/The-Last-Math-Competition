# 00000001302

**English.** Definition: The Diederich–Fornæss index DF(Ω) of a pseudoconvex domain is the supremum of ε for which the smoothed weight δ̃^ε is plurisubharmonic. Conjecture: There exists an explicit family of smooth bounded pseudoconvex domains with any prescribed DF index in (0,1), and the index of the worm domain is an exact irrational supremum.

**中文。** 定义：Diederich–Fornæss 指数 DF(Ω)(拟凸域上满足 \tilde δ^ε 平滑权的上确界 ε)。猜想：存在具任意 DF 指数 ∈ (0, 1) 的光滑有界拟凸域的显式族,且 worm 域的指数为精确无理值上确界。
