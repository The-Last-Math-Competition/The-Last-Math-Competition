# 00000003868

**English.** Definition: The inverse participation ratio IPR = Σv_i⁴ measures the concentration of eigenvector mass. Conjecture: For β-gases with analytic potentials, E(IPR) = (3/(βN))·(1 + c β^{−1}/N + O(N^{−2})), with c a potential-independent universal constant. (IPR first universal correction)

**中文。** 定义：逆参与率 IPR = Σv_i⁴ 指特征向量质量的集中度。猜想：任意解析位势 β-气的特征向量满足 E(IPR) = 3/(βN)·(1 + cβ^{−1}/N + O(N^{−2})),其中 c 为位势无关的普适常数。（IPR 一阶普适校正）
