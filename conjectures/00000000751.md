# 00000000751

**English.** Definition: The p-adic Fatou decomposition. Conjecture: For iterations of rational functions over Q_p, the Fatou set within the field of uniformly rational functions is completely invariant and open, and the Julia set is nonempty if and only if the degree is ≥ 2 (a complex-p parallel structure).

**中文。** 定义：p-adic Fatou 分解。猜想：ℚ_p 上有理函数迭代的一致有理函数域的 Fatou 集为完全不变开集且 Julia 集非空的充要条件为度 ≥ 2(复 p 平行结构)。
