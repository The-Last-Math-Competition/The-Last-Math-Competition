# 00000001005

**FG-05 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: A Rédei-type blocking set is a small blocking set formed by the graph of a function on a line together with the line itself. Conjecture: All minimal nontrivial blocking sets of size 3q/2 are of Rédei type; their isomorphism classes correspond to the linear-part equivalence classification of the functions f: F_q → F_q, with the class count of explicit (q−1)/2 type for prime q.

**中文。** 定义：Rédei 型阻塞集指由直线上的函数图与其直线本身构成的小阻塞集。猜想：尺寸为 3q/2 的最小非平凡阻塞集全部为 Rédei 型;其同构类由相应函数 f:F_q→F_q 的线性部分等价分类,类数为素 q 的 (q−1)/2 型显式。
