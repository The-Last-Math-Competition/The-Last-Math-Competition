# 00000009689

**English.** Definition: Gelfond values e^{pi sqrt d}: the algebraic independence of values at squarefree d. Conjecture: The values e^{pi sqrt d_i} for finitely many squarefree positive integers d_i are algebraically independent; the joint transcendence degree of these values with the algebraic values of the j function at the corresponding CM points is the count of the d_i plus one. (Gelfond value algebraic independence)

**中文。** 定义：Gelfond 值 e^{π√d}：平方无关 d 的值的代数无关性。猜想：有限个平方无关正整数 d_i 对应的 e^{π√d_i} 代数无关；这些值与 j 函数在对应 CM 点的代数值的联合超越次数为 d 的个数加一。（Gelfond 值代数无关）
