# 00000001570

**GM-30 △** — source: 37_组合几何.md

**English.** Definition: Unit-area triangles (triples enclosing area 1). Conjecture: The number of unit-area triangles determined by an n-point set is O(n^{9/4+ε}) (the known upper bound is O(n^{44/19+ε}); the target exponent is 9/4).

**中文。** 定义：单位面积三角形(面积为 1 的三点组)。猜想：n 点集确定的单位面积三角形数为 O(n^{9/4+ε})(已知上界 O(n^{44/19+ε});目标指数 9/4)。
