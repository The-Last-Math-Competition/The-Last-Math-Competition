# 00000007749

**English.** Definition: The free group factor isomorphism problem reduces to the arithmetic of the microstate ratio delta(m,n) = log(m-1)/log(n-1). Conjecture: For all m,n >= 2, if L(F_m) is isomorphic to L(F_n) then m=n; the strengthening: the tensor invariant comparing the least common multiple spectra of subgroup indices differs for all pairs except the known exceptional pairs (2,8),(3,infinity)-type, so the microstate method has no new coincidences beyond the known 2-4-16 chain. (no new free factor coincidences)

**中文。** 定义：自由群因子的微缩不变量：L(F_m) 与 L(F_n) 的同构问题归结为微缩 δ(m,n)=log(m-1)/log(n-1) 的算术性。猜想：对所有 m,n ≥ 2，若 L(F_m)≅L(F_n) 则 m=n；其强化：L(F_m) 与 L(F_n) 的张量不变量为比较子群指标的最小公倍数谱，该谱对 (m,n)≠(2,8),(3,∞) 型例外对相异，即微缩法除已知的 2↔4↔16 链外无新重合。
