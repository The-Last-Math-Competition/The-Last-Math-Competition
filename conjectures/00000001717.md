# 00000001717

**English.** Definition: Bounded remainder sets (BRS) are truncation sets with bounded discrepancy. Conjecture: The parameterization domain of BRS for three-dimensional cut-and-project sets is an explicit band condition (star-shaped polyhedra) (3D BRS parameterization).

**中文。** 定义：有界剩余集(BRS,偏差有界的截断集)。猜想：三维 cut-and-project 的 BRS 的参数化域为显式带状条件 (星形多面体)(3D BRS 参数化)。
