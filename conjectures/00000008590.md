# 00000008590

**English.** Definition: The positive completion problem for operator matrices: conditions for completing a partially specified operator matrix to a positive operator. Conjecture: The criterion for positive completion is given by Parrott type inequalities (a Parrott criterion law); the saturation constant of the minimal completion norm radius is 2 (a double saturation law); the minimal completion is unique if and only if the missing block lies at a corner (a corner uniqueness law); and the completion domain for cyclically missing blocks is convex (a convex completion domain law). (operator matrix Parrott positive completion)

**中文。** 定义：算子矩阵的正补全问题：部分块给定的算子矩阵补全为正算子的条件。猜想：正补全的判据由 Parrott 型不等式给出（Parrott 判据律）；且补全的最小范数半径的饱和常数为 2（双饱和律）；极小补全唯一当且仅当缺失块位于角部（角部唯一律）；循环缺失块的补全域为凸集（凸补全域律）。
