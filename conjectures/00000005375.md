# 00000005375

**English.** Definition: A commensurability class is the equivalence class sharing a finite-index subgroup. Conjecture: The complete invariant table in dimension three is the pairing classification of trace fields with quaternion orders, given by standard data, and the classification is closed. (complete pairing classification of three-dimensional commensurability)
