# 00000004506

**English.** Definition: A locale is a point-free topological object, and a point is a morphism to the two-point locale. Conjecture: Point existence for compact regular locales admits a constructive proof, and the minimal computational complexity of a point selector is linear with an optimal bound. (linear point selector for locales)

**中文。** 定义：Locale 指点自由的拓扑对象,点指其到二点 Locale 的态射。猜想：紧正则 Locale 的点存在性可构造性证明,点选择子的最小计算复杂度为线性且界最优。（Locale 点线性选择子）
