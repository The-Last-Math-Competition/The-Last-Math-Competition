# 00000000333

**English.** Definition: The inhomogeneous approximation measure m(W_β(ψ)) for fixed β. Conjecture: In the convergent case, m(W_β(ψ)) = 0 for every β, and in the divergent case the measure is full for a.e. β.

**中文。** 定义：对固定 β 的非齐次逼近测度 m(W_β(ψ))。猜想：收敛情形 m(W_β(ψ)) = 0 对每个 β 成立,且发散情形对 a.e. β 为全测度。
