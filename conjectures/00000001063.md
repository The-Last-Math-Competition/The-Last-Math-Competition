# 00000001063

**English.** Definition: A Kakeya set in F_q² contains a line in every direction. Conjecture: The minimal size of a Kakeya set is exactly q(q+1)/2, attained by an affine-translation construction taking one segment on each of q lines of increasing slope; that is, the optimal constant in Dvir's lower bound c·q² is c = 1/2.

**中文。** 定义：F_q² 中 Kakeya 集含每个方向的线。猜想：最小 Kakeya 集的尺寸恰为 q(q+1)/2,由在 q 条斜率递增线上各取一段的仿射平移构造取得;即 Dvir 下界 c·q² 的最优常数 c=1/2。
