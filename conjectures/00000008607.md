# 00000008607

**English.** Definition: Sketching is regression by random low-dimensional projection. Conjecture: The optimal sketch dimension is linear in n with constant 1; below that dimension the risk diverges at rate (n/m)^{1/2}. (sketch dimension criticality)

**中文。** 定义：sketching 指随机低维投影回归。猜想：最优 sketch 维度为 n 的线性且常数 1；低于该维的风险发散率为 (n/m)^{1/2}。（sketch 维度临界）
