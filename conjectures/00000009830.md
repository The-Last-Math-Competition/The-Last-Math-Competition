# 00000009830

**English.** Definition: Reverse Hoelder inequalities: self-improvement of A_p weights to RH_s. Conjecture: The cusp function of RH self-improvement has a completely explicit piecewise form: the phase diagram of the improvement exponent s(p,epsilon) is piecewise linear; the breakpoints of the diagram are the critical value set of the A_p exponent. (RH self-improvement cusp phase diagram)

**中文。** 定义：反向 Hölder 不等式：A_p 权的自改进到 RH_s。猜想：RH 自改进的尖点函数有完全分段显式形式：改进指数 s(p,ε) 的相图为分段线性；相图的折点为 A_p 指标的临界值集合。（RH 自改进尖点相图）
