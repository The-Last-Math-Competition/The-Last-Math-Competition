# 00000001019

**FG-19 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: The Griesmer bound n ≥ Σ⌈d/q^i⌉. Conjecture: The dimensions of codes attaining the Griesmer bound admit a finite classification up to (q^k − 1)/(q − 1) − k (a classification of extremal codes).

**中文。** 定义：Griesmer 界 n ≥ Σ⌈d/q^i⌉。猜想：达到 Griesmer 界的码的维数 ≤ (q^k − 1)/(q − 1) − k 的有限分类(极值码分类)。
