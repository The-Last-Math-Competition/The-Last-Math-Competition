# 00000001190

**English.** Definition: N_p is the number of elements of prime order p in GL_n(F_q). Conjecture: N_p = Σ_{r|n, r prime} Θ_r(q), where Θ_r(q) = q^{n²−r}(q−1)^{-1}·∏_{i=1}^{r−1}(q^{n−i}−1); this formula covers all prime-order elements with zero error.

**中文。** 定义：GL_n(F_q) 的素阶元素个数 N_p。猜想：N_p = Σ_{r|n, r 素} Θ_r(q),其中 Θ_r(q) = q^{n²−r}(q−1)^{-1}·∏_{i=1}^{r-1}(q^{n-i}−1),且该公式覆盖全部素阶元素,误差为零。
