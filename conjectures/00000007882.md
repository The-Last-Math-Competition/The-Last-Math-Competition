# 00000007882

**HCA-12 ★** — source: 248_高阶范畴与同调代数II.md

**English.** Definition: The geometricity criterion for A-infinity categories: a dg-category C is geometric if it is equivalent to Perf of a smooth proper variety; the criterion index g(C) is the minimal vanishing order of the negative-weight part of Hochschild cohomology. Conjecture: Geometricity of C implies g(C) <= dim; and when g(C) = dim the non-formality obstruction of C is the nonvanishing of the Maslov class mu(C) of the Gerstenhaber algebra, with the order of mu(C) exactly g(C)+1, an equality valid for all categories of Calabi-Yau dimension g, consistent with the symplectic duality of non-formality. (Maslov class non-formality order)

**中文。** 定义：A∞-范畴的几何性判据：dg-范畴 C 称 geometric 若等价于某光滑 proper 簇的 Perf。判据指数 g(C) 定义为 Hochschild 上同调的负权部分的最小消失阶。猜想：C geometric 蕴含 g(C) ≤ dim；且 g(C)=dim 时 C 的非形式性障碍为 Gerstenhaber 代数的马斯洛夫类 μ(C) 的非零性，μ(C) 的阶恰为 g(C)+1，该等式对一切 CY 维数为 g 的范畴成立（与非形式性的辛几何对偶一致）。
