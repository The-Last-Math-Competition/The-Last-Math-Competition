# 00000002795

**English.** Definition: Enflo type of Banach spaces: the geometric strengthening of Lipschitz type. Conjecture: The equivalence of Enflo type and linear type: p-Enflo type and linear p-type are uniformly equivalent for p < 2 with dimension-independent constants; the equivalence carries a logarithmic correction at p = 2. (Enflo type equivalence constants)

**中文。** 定义：Banach 空间的 Enflo 型：Lipschitz 型的几何加强。猜想：Enflo 型与线性型的等价：p-Enflo 型与线性 p-型在 p<2 一致等价且等价常数为维数的独立界；等价在 p=2 有对数修正。（Enflo 型等价常数）
