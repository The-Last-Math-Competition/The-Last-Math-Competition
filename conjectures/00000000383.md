# 00000000383

**English.** Definition: Another famous constant pair for Littlewood's conjecture. Conjecture: Littlewood holds for the pair (ζ(3), π); and the proof can be derived explicitly from the irrationality measure of ζ(3). (Littlewood for the pair zeta3-pi)

**中文。** 定义：Littlewood 猜想的另一著名常数对。猜想：Littlewood 对 (ζ(3),π) 成立；且证明可由 ζ(3) 的无理性度量显式导出。（Littlewood zeta3-pi 特例）
