# 00000009614

**English.** Definition: The dimension group of an SFT is the ordered K_0(Z^n A, Z^n_+), whose ordered isomorphism type is a flow invariant. Conjecture: The dimension groups of two mixing SFTs are order-isomorphic if and only if the Perron eigenvalues lambda_A and lambda_B generate the same real algebraic number field with agreeing unit group cosets; explicit examples of equal entropy over different fields are given by an explicit criterion for coprime Perron numbers. (dimension group ordered classification)

**中文。** 定义：SFT 的维数群为有序 K_0(Z^n A, Z^n_+)，其有序同构型是流不变量。猜想：两个混合 SFT 的维数群有序同构当且仅当 Perron 特征值 λ_A 与 λ_B 生成相同的实代数数域且单位群陪集一致；同熵异域的显式例子由互素 Perron 数的显式判据。（维数群有序分类）
