# 00000003849

**English.** Definition: Arrow reversal of a crystal B gives the dual crystal B^∨; equivalence classes are classes invariant under reversal. Conjecture: B^∨≅B if and only if the weight set of B is centrally symmetric in the weight lattice, and the criterion is verifiable in polynomial time. (crystal duality criterion)

**中文。** 定义：晶体 B 的箭头反转指将所有箭向取反得到的对偶晶体 B^∨,等价类指反转下不变的晶体类。猜想：B^∨≅B 当且仅当 B 的权集在权格的中心对称,且判据可在多项式时间验证(晶体对偶判据)。
