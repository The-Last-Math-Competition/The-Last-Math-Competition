# 00000001026

**English.** Definition: The Gray map. Conjecture: The count of isomorphisms between the Lee-weight enumeration of a Z₄-linear code and the Hamming weights of its binary image is 2^{k} (a count of bilinear correspondences).

**中文。** 定义：格雷码(Gray map)。猜想：ℤ₄ 线性码的 Lee 重量枚举与二进制像的 Hamming 重量之间的同构计数为 2^{k}(双线性对应计数)。
