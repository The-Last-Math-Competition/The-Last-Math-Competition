# 00000000279

**English.** Definition: The Mandelbrot set M is the set of parameters c for which the critical orbit of z ↦ z²+c is bounded; its area A ≈ 1.5066 is computable to arbitrary precision. Conjecture: A is transcendental; more strongly, the field generated by A and the hyperbolicity-density parameter of M has transcendence degree at least 2, and the irrationality-measure lower bound for A is given by an explicit function of the boundary dimension. (Mandelbrot area transcendence)

**中文。** 定义：Mandelbrot 集 M 为使二次映射 z↦z²+c 的临界轨道有界的参数 c 全体，其面积 A≈1.5066 可计算至任意精度。猜想：A 是超越数；更强地，A 与 M 的双曲密度参数生成的域超越次数至少为 2，且面积的无理性度量下界由边界维数的显式函数给出。（Mandelbrot 面积超越性）
