# 00000000297

**English.** Definition: Wang tiles are unit squares tiled by matching edge colors only. Conjecture: There exists an aperiodic prototile set of only 2 tiles without rotations, and no single rotation-free aperiodic tile exists (the minimal rotation-free aperiodic set is exactly 2).

**中文。** 定义：Wang 瓦片:仅以边颜色匹配拼接的单位正方形。猜想：存在仅 2 张瓦片、免旋转的非周期原型集,且不存在单张免旋转非周期瓦片(免旋转意义下最小非周期集恰为 2)。
