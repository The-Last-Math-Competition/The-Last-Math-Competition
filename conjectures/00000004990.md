# 00000004990

**English.** Definition: Approximation rate and sample complexity are two learning measures. Conjecture: There exist two function classes with the same approximation rate but different sample complexity exponents, and the separation is realized by an explicit embedding mismatch of two spaces. (same approximation rate-sample exponent separation)

**中文。** 定义：逼近速率与样本复杂度指两层学习度量。猜想：存在两函数类的逼近速率相同而样本复杂度指数不同,分离由两类空间的显式嵌入失配实现。（逼近速率同-样本指数分离）
