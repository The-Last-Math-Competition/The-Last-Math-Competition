# 00000005213

**English.** Definition: The minimal incompressible size is the size of the first noncompressible example. Conjecture: The minimal incompressible size of third-order tensors is an explicit subset of cubic sizes, given by transversal counting and exact. (exact minimal incompressible size of third order)

**中文。** 定义：不可压缩最小尺寸指首个非压缩例的规模。猜想：三阶张量的不可压缩最小尺寸为立方尺寸的显式子集,由横截计数给出且尺寸精确。（三阶不可压缩最小尺寸精确）
