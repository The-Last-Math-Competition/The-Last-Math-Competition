# 00000002204

**MI-04 ★** — source: 59_交换环与乘法理想论.md

**English.** Conjecture: The divisor class group of the simple polynomial pre-domain R + XK[X] of a Krull domain R is an explicit quotient of Cl(R) ⊕ Z (pre-domain class group).

**中文。** 猜想：Krull 域 R 的单多项式预域 R + X K[X] 的除子类群为 Cl(R) ⊕ ℤ 的显式商(预域类群)。
