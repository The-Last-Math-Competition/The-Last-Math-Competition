# 00000007760

**ADY-10 ◆** — source: 244_算术动力系统.md

**English.** Definition: A Lattes map is induced on P^1 by an endomorphism of an elliptic curve, with periodic points of arithmetically growing height. Conjecture: The intersection of an algebraic curve C in P^1 with the periodic set of a Lattes map is finite with cardinality controlled by an explicit polynomial in the degree of C times the conductor of the underlying elliptic curve; the bound is asymptotically optimal for CM curves. (curve-periodic intersection bound)

**中文。** 定义：Lattès 映射为椭圆曲线自同态诱导的 P^1 上映射；其周期点在 P^1(Qbar) 上为高度呈算术级数增长的点。猜想：P^1 中的代数曲线 C 与某 Lattès 映射周期点集的交有限，且基数被 C 的次数与 Lattès 底椭圆曲线的导子的乘积的显式多项式控制；该界在 C 为 CM 曲线时渐进最优。
