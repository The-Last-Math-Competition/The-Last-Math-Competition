# 00000002314

**English.** Definition: A coclass tree is the tree-shaped classification of p-groups by coclass. Conjecture: An explicit formula for the branch density of high-coclass (r ≥ 3) trees: the branch period is p−1; the density is a periodic multiple along the infinite paths of the tree (a computable periodic structure).

**中文。** 定义：coclass 树指按 coclass 组织的 p-群的树形分类。猜想：高 coclass(r≥3)的树的分支密度的显式公式:分支周期为 p-1;密度为树的无限路径上的周期倍数(周期结构的计算化)。
