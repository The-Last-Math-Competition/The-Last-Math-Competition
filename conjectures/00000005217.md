# 00000005217

**English.** Definition: The index spectrum is the set of all possible subfactor indices. Conjecture: The isolated index points in the interval [4,5] are an explicit finite sum of cosine values, with term count from the length count of the Weyl group; the isolated points have 4 as the only accumulation point in its neighborhood, of order 2; and each isolated index is realized by an explicit tower of logarithmic height. (cosine count sum of isolated index points)

**中文。** 定义：指标谱：子因子可能指标的全集。猜想：区间 [4,5] 的孤立指标点为余弦值的显式有限和且项数由外尔群长度计数；孤立点集在 4 的邻域内以 4 为唯一聚点且聚点阶为 2；每个孤立指标由显式塔实现且塔高为对数型。（指标孤立点余弦计数和）
