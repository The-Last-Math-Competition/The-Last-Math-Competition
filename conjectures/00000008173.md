# 00000008173

**CNT-03 ★** — source: 258_计算数论.md

**English.** Definition: The constant of the heuristic complexity of the number field sieve (NFS): the constant c_NFS in the running time c L_N[1/3, (64/9)^{1/3}] of GNFS for factoring N. Conjecture: The explicit value of c_NFS is the constant combination (64/9)^{-2/3} (3/2)^{1/3} pi (from substituting the optimal smoothing parameter formula for c); the deviation of the actual (measured) c_NFS from theory is below 10% (constant tightness); faster sieves exist (the SNFS exception: c halved for SNFS, a half-constant law); and the tail of the optimal distribution of Murphy-alpha values for polynomial selection is Gumbel (an alpha-Gumbel law), with Gumbel scale parameter 1/sqrt(log N) (a scale formula). (NFS constant Murphy-alpha Gumbel law)

**中文。** 定义：数域筛法（NFS）的启发式复杂度的常数：GNFS 分解 N 的运行时间的 c·L_N[1/3,(64/9)^{1/3}] 的常数 c_NFS。猜想：c_NFS 的显式值 = (64/9)^{-2/3}·(3/2)^{1/3}·π 型常数组合（c 的最优平滑参数公式的代入）；且 c_NFS 的实际（实测）与理论的偏差小于 10%（常数紧性）；更快的筛（SNFS 的例外：SNFS 的 c 减半，半常数律）；多项式选择的 Murphy-α 值的最优分布的尾部为 Gumbel（α-Gumbel 律），Gumbel 的尺度参数 = 1/√(log N)（尺度公式）。
