# 00000008474

**English.** Definition: The Lagrange spectrum of Sturmian optimization: the set of all extremal values of Birkhoff averages at Sturmian word frequencies for circle rotations. Conjecture: The spectrum is a ray starting from a quadratic irrational (a ray law); its first element is the golden ratio value 1/sqrt 5 (a golden first-element law) and is unique; and the maximal gap of the spectrum is the explicit value sqrt 5 - 2 (an explicit gap law), whose arithmetic type agrees with the initial end of the Hall ray of the classical Markov spectrum. (Sturmian Lagrange ray golden gap)

**中文。** 定义：Sturmian 优化的 Lagrange 谱：圆旋转中 Sturmian 词频率对应的 Birkhoff 平均极值的全体取值。猜想：该谱为一条由二次无理数出发的射线（射线律）；谱的首元为黄金比值 1/√5（黄金首元律）且首元唯一；谱的最大间隙为 √5-2 的显式值（间隙显式律），间隙的算术型与经典 Markov 谱的 Hall 射线首端一致。
