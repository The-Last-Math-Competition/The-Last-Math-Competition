# 00000009527

**QIC-07 ★** — source: 303_量子信道容量.md

**English.** Definition: The less-noisy order phi preceq_ln psi is defined by I(ensemble; phi) at most I(ensemble; psi) for all input ensembles, with I the Holevo mutual information; this partial order is used to describe capacity regions of broadcast channels. Conjecture: The two-receiver broadcast sum-capacity upper bound for less-noisy pairs (phi,psi) is given by optimizing the single-letter difference delta = I(.;psi) - I(.;phi) and is asymptotically attainable; the less-noisy order is a closed partial order on channel space whose unique maximal element is the completely depolarizing channel. (less-noisy broadcast capacity region)

**中文。** 定义：少噪序 φ⪯_ln ψ 定义为对一切输入系综成立 I(系综;φ)≤I(系综;ψ)，I 为 Holevo 互信息；该半序用于广播信道的容量域刻画。猜想：少噪对 (φ,ψ) 的双接收广播和容量上界由单字母差分 δ=I(·;ψ)−I(·;φ) 的最优化给出且渐近可达；少噪序在信道空间中为闭半序，其极大元恰为完全去极化信道。（少噪广播容量域）
