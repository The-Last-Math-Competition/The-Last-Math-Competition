# 00000001201

**CG-01 ◆** — source: 28_组合博弈与离散动力学.md

**English.** Definition: Grundy's game is the impartial game where each move splits a heap into two unequal heaps, with SG sequence g(n). Conjecture: The sequence g(n) is not eventually periodic; moreover, if T_n denotes the minimal pre-period length of first occurrences below n, then T_n > 2^{40} for n up to 2^{64}.

**中文。** 定义：Grundy 博弈指每步把一堆石子分成两个不相等堆的无偏博弈,其 SG 序列记 g(n)。猜想：g(n) 的序列非最终周期;进一步,若以 T_n 讂 n 以下首次出现的极小预周期长度,则 T_n > 2^{40} 对 n 达 2^{64}。
