# 00000000471

**English.** Definition: A hypertree of the r-uniform complete hypergraph K_n^{(r)} is a minimally connected subhypergraph of its edge set; t(K_n^{(r)}) denotes their count. Conjecture: For r = 3, t(K_n^{(3)}) = n^{C(n−1,2)−1}·∏_{i=1}^{n−1}f(i) with the explicit polynomial f(i) = i² − i + 1; this formula covers all known values for n ≤ 6.

**中文。** 定义：r-均匀完全超图 K_n^{(r)} 的超树指其超边集的极小连通子超图(hypertree),计数记 t(K_n^{(r)})。猜想：r=3 时 t(K_n^{(3)}) = n^{C(n−1,2)−1}·∏_{i=1}^{n−1}f(i),其中 f(i) 为显式多项式 f(i)=i²−i+1;该公式覆盖 n≤6 的全部已知值。
