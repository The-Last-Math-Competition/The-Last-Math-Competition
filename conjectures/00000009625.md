# 00000009625

**English.** Definition: Aperiodic Wang tile sets are finite tile sets admitting only aperiodic tilings; the Jeandel-Rao 11-tile set is currently the smallest. Conjecture: The minimal cardinality of an aperiodic Wang tile set is 11, with the Jeandel-Rao set unique up to local substitution; and the computable classification of all 11-tile aperiodic sets is a finite list. (minimal aperiodic tile count)

**中文。** 定义：非周期王砖集为只有非周期平铺的有限砖集；Jeandel–Rao 的 11 砖集为当前最小。猜想：非周期王砖集的最小基数为 11 且 Jeandel–Rao 集在模局部替换意义下唯一；一切 11 砖非周期集的可计算分类为有限列表。（最小非周期砖数）
