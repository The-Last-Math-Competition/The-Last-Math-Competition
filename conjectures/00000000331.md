# 00000000331

**English.** Definition: The Duffin–Schaeffer theorem (the divergent case was proven by Koukoulopoulos–Maynard, 2019). Conjecture: The inhomogeneous version: Σ ψ(n)/n = ∞ implies that for a.e. α there are infinitely many n with |α − a/n| < ψ(n) (a arbitrary but fixed). This inhomogeneous version remains open.

**中文。** 定义：DS 定理(M. Koukoulopoulos–Maynard 2019 已证发散情形)。猜想：非齐次版:Σ ψ(n)/n = ∞ 蕴含对 a.e. α 存在无穷多 n 使 |α − a/n| < ψ(n)(a 任意给定)。此非齐次版仍开放。
