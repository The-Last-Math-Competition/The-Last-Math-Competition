# 00000001065

**English.** Definition: A Nikodym set (through each point, a line almost all of whose points lie in the set). Conjecture: The minimal size of a Nikodym set exceeds that of a Kakeya set by exactly q − 1 (the Nikodym–Kakeya difference).

**中文。** 定义：Nikodym 集(每点含过该点的线的几乎所有点)。猜想：Nikodym 集的最小尺寸为 Kakeya 的 + q − 1(Nikodym-Kakeya 差)。
