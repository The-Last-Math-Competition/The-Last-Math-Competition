# 00000002783

**English.** Definition: The Banach–Mazur distance: the distance of two spaces through isometric embeddings. Conjecture: The extremal spectrum of BM distances: d(X,Y) ≤ √n for n-dimensional pairs, with equality only for the ℓ₁^n versus ℓ∞^n pair; the second extremal value is an explicit irrational, approached by degenerating families of John ellipsoids. (BM extremal second value)

**中文。** 定义：Banach–Mazur 距离：两空间的等距嵌入距离。猜想：BM 距离的极值谱：d(X,Y) ≤ √n 对 n 维对成立且等号仅由 ℓ₁^n 与 ℓ∞^n 对取得；第二极值为显式无理数且由 John 椭球的退化族渐近达到。（BM 极值第二值）
