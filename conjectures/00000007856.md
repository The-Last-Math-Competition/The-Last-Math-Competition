# 00000007856

**English.** Definition: The regularity phase transition of MCMC: the approximability threshold lambda_a of an FPRAS for lattice systems such as the hard-core model versus the tree uniqueness threshold lambda_c, as functions of the activity lambda. Conjecture: For the hard-core model on the Z^2 lattice, lambda_a = lambda_c, so approximability coincides with the phase transition; and for lambda < lambda_c the Glauber dynamics mixing time is O(n log n) via the spectral gap interpolation gap^{-1} = O(n) Phi(lambda) with Phi the bottleneck ratio, Phi diverging as (lambda_c - lambda)^{-1/2} with critical exponent 1/2 as lambda rises to lambda_c. (hard-core approximability transition)

**中文。** 定义：MCMC 的正则相变：格点系统（如硬核模型）的计数近似 FPRAS 在活动度 λ 下的可近似性阈值 λ_a 与树自旋阈值 λ_c 的关系。猜想：对硬核模型于 Z² 格点，λ_a = λ_c（可近似性与相变重合）；且当 λ<λ_c 时 Glauber 动力混合时间为 O(n log n) 的谱隙插值：gap^{-1}=O(n)·Φ(λ)（Φ 为瓶颈比），Φ(λ) 在 λ↑λ_c 时发散为 (λ_c-λ)^{-1/2} 的临界指数 1/2。
