# 00000002194

**English.** Definition: The speed of a hereditary property is the counting growth rate of its n-vertex graphs. Conjecture: The limit-point set of speeds equals the Alekseev–Bollobás sequence {α_r} ∪ {2} (complete); the explicit table of limits is computed by transcendental functions of the parameter r.

**中文。** 定义：遗传性质的速度指其 n 点图的计数增长率。猜想：速度的极限点集 = Alekseev–Bollobás 序列 {α_r}∪{2}(完备);极限的显式值表由参数 r 的超越函数计算。
