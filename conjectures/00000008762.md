# 00000008762

**MKT-22 ★** — source: 277_代数K理论与MilnorK.md

**English.** Definition: The tame kernel: the kernel of the global symbol on K_2 of a number field. Conjecture: The tame kernel is finite (a finiteness law); its order is explicit (an explicitness law); the Birch-Tate conjecture: the order is given by the value of zeta_F(-1) (a B-T law); and there is a numerical verification domain (a verification domain law). (tame kernel finiteness Birch-Tate)

**中文。** 定义：tame kernel：数域的 K_2 的整体符号的核。猜想：tame kernel 有限（有限律）；且其阶的显式（显式律）；Birch–Tate 猜想：阶由 ζ_F(-1) 的值给出（B-T 律）；数值验证域（验证域律）。
