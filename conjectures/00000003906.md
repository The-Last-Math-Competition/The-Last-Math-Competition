# 00000003906

**English.** Definition: An F-injective ring is one for which the Frobenius-induced maps on local cohomology are injective. Conjecture: Three-dimensional F-finite F-injective normal rings have only finitely many birational classes of mod p reductions, and the F-jumping number sets within each class are uniformly bounded. (F-injective three-dimensional finiteness)

**中文。** 定义：F-注入环指 Frobenius 诱导的局部上同调映射单射的环。猜想：三维 F-有限 F-注入正常环的模 p 约化型只有有限多个双有理类,且每个类的 F-跳跃数集一致有界。（F-注入三维有限性）
