# 00000004904

**English.** Definition: The sensitive set is the directional limit set of the value function as the discount tends to one. Conjecture: The attainable domain of sensitive set dimensions of ergodic MDPs is the full integer interval from zero to the number of states minus one, each value realized by explicit sparse-reward constructions. (full-interval realization of sensitive set dimensions)

**中文。** 定义：灵敏集指折扣趋于一时值函数的方向极限集。猜想：遍历 MDP 的灵敏集维数可达域为从零到状态数减一的整区间,每个值由稀疏奖励的显式构造实现。（灵敏集维数全区间实现）
