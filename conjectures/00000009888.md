# 00000009888

**GBR-08 ★** — source: 315_箭图表示与Auslander-Reiten理论.md

**English.** Definition: Schur root criterion: combinatorial conditions for dimension vectors to be Schur roots (Schofield's criterion is known). Conjecture: A general dimension vector admits an indecomposable representation if and only if the value of its Euler quadratic form lies in an explicit integer window; the window endpoints are computed from the Schofield general subrepresentation list of the vector, and the criterion is polynomial-time. (indecomposable existence window)

**中文。** 定义：Schur 根判据：维数向量为 Schur 根的组合条件（Schofield 判据已知）。猜想：一般维数向量存在不可分解表示当且仅当其 Euler 二次型的取值落在显式整数窗口内；窗口的端点由向量的 Schofield 一般子表示列表计算且判据为多项式时间。（不可分解存在窗口）
