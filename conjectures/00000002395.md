# 00000002395

**English.** Definition: A fractal Loewner carpet is a fractal planar domain satisfying a modulus inequality. Conjecture: The constant c of the modulus inequality always satisfies c ≥ the reciprocal of the carpet modulus constant; and saturation is attained by the standard square carpet. (carpet modulus constant square saturation)

**中文。** 定义：分形 Loewner 地毯指满足模不等式的分形平面区域。猜想：模不等式的常数 c 恒满足 c 不小于地毯模常数的倒数；且饱和情形由标准方格地毯取得。（地毯模常数方格饱和）
