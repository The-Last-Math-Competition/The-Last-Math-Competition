# 00000000059

**English.** Conjecture: A prime version of Prouhet–Tarry–Escott: for every k there exist disjoint sets of primes {p₁,…,p_k} ≠ {q₁,…,q_k} such that Σpᵢ^j = Σqᵢ^j holds simultaneously for j = 0, 1, …, k−1.

**中文。** 猜想：Prouhet–Tarry–Escott 的素数版:对每个 k,存在互不相交的素数集合 {p₁,…,p_k} ≠ {q₁,…,q_k} 使 Σpᵢ^j = Σqᵢ^j 对 j = 0,1,…,k−1 同时成立。
