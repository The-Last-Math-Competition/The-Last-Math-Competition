# 00000002023

**AD-03 ★** — source: 53_加性数论II.md

**English.** Definition: The representable set N = p₁³ + p₂³ + m² (prime cubes plus a square). Conjecture: The density of this set among N ≤ x tends to 1 (all sufficiently large N are representable); the local parity obstruction is bypassed by the flexibility of m².

**中文。** 定义：N = p₁³ + p₂³ + m² 的可表示集合(素数立方加平方)。猜想：该集合在 N ≤ x 中的密度趋于 1(充分大 N 皆可表示);局部奇偶障碍由 m² 的灵活性绕开。
