# 00000009564

**TCH-14 ★** — source: 304_Teichmuller动力.md

**English.** Definition: The illumination problem for rational polygons asks whether light rays from any point can reach any point; it is equivalent to minimality of the straight flow on the covering surface. Conjecture: A rational polygon is illuminable if and only if the corresponding covering surface is completely periodic (cylinder decompositions in every direction); among non-illuminable polygons, the unreachable point set is a dense G-delta whose Hausdorff dimension is strictly below the area dimension. (illumination dichotomy)

**中文。** 定义：有理多边形的照明问题问从任一点发出的光线能否到达任一点；等价于覆盖曲面上直线流的极小性。猜想：有理多边形可照明当且仅当对应覆盖曲面为完全周期型（一切方向柱面分解）；不可照明多边形中不可达点集为稠密 Gδ 且其 Hausdorff 维数严格小于面积维。（照明二分律）
