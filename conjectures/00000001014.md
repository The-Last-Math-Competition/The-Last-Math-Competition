# 00000001014

**FG-14 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: An NMDS code is a genus-one almost-MDS code. Conjecture: The weight enumeration of NMDS codes of length q+2 is explicit via elliptic curve point counts; and the kernel of the explicit formula is a sum of elliptic twists. (NMDS elliptic point-count weight enumeration)

**中文。** 定义：NMDS 码为亏格一的几乎 MDS 码。猜想：长度 q+2 的 NMDS 权计数由椭圆曲线点数显式；且显式的核为椭圆扭的求和。（NMDS 椭圆点数权计数显式）
