# 00000009838

**English.** Definition: Dimension-free weighted weak-type inequalities. Conjecture: The dimension-free constant of the weighted weak-(1,1) maximal function exists if and only if the weight satisfies log-convex L log L decay; necessity follows from angular condensation constructions of radial weights. (weighted dimension-free weak one)

**中文。** 定义：维数无关加权弱型：带权的 dimension-free 不等式。猜想：加权弱一型最大函数的 dimension-free 常数存在当且仅当权满足对数凸的 L log L 衰减；必要性由径向权的角向凝聚构造。（加权无维弱一型）
