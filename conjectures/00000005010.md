# 00000005010

**English.** Definition: The number of moduli components and the enumerative invariants are two layers. Conjecture: There exist two CY threefolds with the same number of special Lagrangian moduli components but different mirror enumerations, and the separation is realized by an explicit pair of Fourier partners. (same components-different enumeration separation pair)
