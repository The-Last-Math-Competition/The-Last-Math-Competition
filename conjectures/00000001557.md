# 00000001557

**English.** Definition: A Kakeya set contains a unit segment in every direction. Conjecture: The Hausdorff dimension of Kakeya sets in R³ is 3; any construction attaining dimension below 2.6 must make the direction function unrealizable outside an exponentially sparse set of spherical measure, and this obstruction is made explicit by a local regularity inequality.

**中文。** 定义：Kakeya 集指含一切方向线段的集合。猜想：ℝ³ 中 Kakeya 集的 Hausdorff 维数为 3;达到维数 <2.6 的构造必须使方向函数在球面测度的指数级稀疏集外不可实现,该障碍由局部正则性不等式显式化。
