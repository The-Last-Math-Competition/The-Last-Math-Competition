# 00000001004

**English.** Definition: Let m₂(n,q) denote the maximal cap size in PG(n,q). Conjecture: For fixed n ≥ 5, m₂(n,q) = c_n·q^{⌈n/2⌉}·(1+O(q^{-1})), with constants c_n explicit from quadric caps (c_5 = 1, c_6 = 2); the asymptotic constants are improved by higher hypersurfaces for n ≥ 7.

**中文。** 定义：PG(n,q) 的最大 cap 尺寸记 m₂(n,q)。猜想：固定 n≥5 时 m₂(n,q) = c_n·q^{⌈n/2⌉}·(1+O(q^{-1})),常数 c_n 由二次曲面 cap 的计数显式给出,c_5=1,c_6=2;渐近常数在 n≥7 时由高阶超曲面改进。
