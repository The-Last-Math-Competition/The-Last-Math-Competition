# 00000009950

**MRG-10 ★** — source: 317_测度刚性.md

**English.** Definition: Quasi-isometric rigidity: metric rigidity of groups (the Schwarz-Milnor framework). Conjecture: Extensions of the quasi-isometry group of a closed hyperbolic surface are compact: the kernel of the extension is finite with order bounded above by the torsion element table of the mapping class group; the bound is attained on Hurwitz extremal surfaces. (quasi-isometric extension compactness)

**中文。** 定义：拟等距刚性：群的度量刚性（Schwarz–Milnor 框架）。猜想：闭双曲曲面的拟等距群的延伸为紧：延伸的核为有限且阶的上界由映射类群的挠元表给出；上界在 Hurwitz 极限曲面达到。（拟等距延伸紧性）
