# 00000005459

**English.** Definition: The root factor measures reduction quality. Conjecture: Its formula is an explicit spectral function of the block parameter, given by the balance of enumeration cost with the projection factor, and the prediction error is small. (spectral balance-function formula of root factors)

**中文。** 定义：根因子指规约质量的度量。猜想：其公式为块参数的显式谱函数,由枚举代价与投影因子的平衡给出且预测误差小。（根因子谱平衡函数公式）
