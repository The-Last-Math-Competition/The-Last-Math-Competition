# 00000006140

**English.** Definition: The virtual dimension and obstruction groups are two layers. Conjecture: There exist two obstruction theories with the same virtual dimension but non-isomorphic obstruction groups, and the separation is realized by an explicit zero-term addition with the same dimension but different amplitude. (same virtual dimension-different obstruction zero-term separation)

**中文。** 定义：虚维与障碍群指两层。猜想：存在两障碍理论的虚维相同而障碍群不同构,分离由同维数异振幅的显式零项加添实现。（虚维同-障碍群异零项分离）
