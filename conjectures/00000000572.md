**CA-72 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: Maximal green sequences (MGS). Conjecture: An affine-type cluster algebra 𝒜 admits an MGS if and only if the mutation equivalence class of its valuated quiver contains an acyclic representative (a purely combinatorial characterization of existence).

**中文。** 定义：maximal green sequence(MGS)。猜想：仿射型 𝒜 有 MGS ⟺ valuated quiver 的 mutation 等价类包含 acyclic(存在性判据的纯粹组合刻画)。
