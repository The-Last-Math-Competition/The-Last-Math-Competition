# 00000004802

**English.** Definition: The (2,1) type is the Hodge component of the middle cohomology. Conjecture: For three-dimensional Fanos the dimension of this component equals exactly the dimension of the deformation space, it is zero if and only if the type is rigid, and the criterion is complete. (Hodge (2,1)-deformation dimension identity)
