# 00000001755

**English.** Definition: The Deligne category Rep(S_t) (t ∈ C) is the complex parameterization of symmetric-group categories. Conjecture: The isomorphism classes of indecomposable tilting objects for t ∉ N are indexed by an explicit finite table of partition pairs (λ, μ): pairs with tilting dimension ≤ n (= ⌈t⌉) satisfy |λ|+|μ| ≤ n; the table is complete for all non-integral t.

**中文。** 定义：Deligne 范畴 Rep(S_t)(t∈C) 指对称群范畴的复参数化。猜想：不可分解 tilting 对象在 t∉N 的同构类由分拆对 (λ,μ) 的显式有限表索引:tilting 维数 ≤ n(=⌈t⌉) 的对满足 |λ|+|μ|≤n;表对一切非整 t 完备。
