# 00000004168

**English.** Definition: Smooth Waring is the Waring problem with summands restricted to smooth numbers. Conjecture: The minimal value of the threshold parameter is 1/(2k), and below the threshold the number of solutions decays at exponential speed. (smooth Waring threshold 1/(2k))

**中文。** 定义：光滑 Waring 指被加数限制为光滑数的 Waring 问题。猜想：其阈值参数的最小值为 1/(2k),低于阈值时解数按指数速度衰减。（光滑 Waring 阈值 1/2k）
