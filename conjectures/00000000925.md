# 00000000925

**English.** Definition: A polynomially compact operator is an operator T for which p(T) is compact. Conjecture: For deg p = 3, existence of T with p(T) compact yet T having no nontrivial invariant subspace is equivalent to the discriminant Δ(p) > 0; when Δ(p) < 0, every polynomially compact T has an invariant subspace (the complete dichotomy in the cubic case).

**中文。** 定义：多项式紧算子指使 p(T) 为紧算子的算子 T。猜想：deg p=3 时,存在使 p(T) 紧但 T 无非平凡不变子空间的 T 的充要条件为 p 的判别式 Δ(p)>0;Δ(p)<0 时一切多项式紧 T 均有不变子空间(三次情形的完全分界)。
