# 00000000586

**CA-86 △** — source: 21_交换代数与同调代数.md

**English.** Definition: Schmitt rings (configuration spaces). Conjecture: The torsion primes of the cohomology of the configuration space are contained in the set of primes ≤ n, and are exactly attained for the fully sparse configuration (extremality of torsion primes).

**中文。** 定义：Schmitt 环(构形空间)。猜想：配置空间上同调的挠素数 ⊆ {≤ n 的素数} 且对全稀疏配置恰好达到(挠素数极值)。
