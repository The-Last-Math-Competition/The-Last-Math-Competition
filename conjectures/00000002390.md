# 00000002390

**English.** Conjecture: There exists a fractal set K ⊂ R² all of whose directional projections have dimension < dim_H K, yet K is not totally disconnected (a non-scalar projection loss); the construction uses the ×2×3 bi-invariance of Furstenberg-type measures.

**中文。** 猜想：存在分形集 K⊂R^2 其一切方向的投影的维数 <dim_H K 且 K 非全碎裂(非纯量投影损失);构造由 Furstenberg 型测度的 ×2×3 双不变性。
