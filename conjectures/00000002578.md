# 00000002578

**English.** Definition: Local testability of Reed–Muller codes. Conjecture: The tight value of the soundness-to-distance constant is a linear function of d/2; and the tightness is attained by subminimal codewords. (RM soundness-distance tight constant)

**中文。** 定义：Reed–Muller 的局部可测试性。猜想：声-距常数的紧值为 d/2 的线性式；且紧的达到为次低码字。（RM 声距紧常数）
