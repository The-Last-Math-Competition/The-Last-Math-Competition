# 00000004716

**English.** Definition: A special factor is a factor admitting only one-sided extensions in a word. Conjecture: The generating function of its count is an explicit table of rational functions, given by the first differences of the complexity, and it degenerates to a closed form in the Sturmian case. (rational generating function table of special factors)

**中文。** 定义：特殊因子指词中仅单侧延拓的因子。猜想：其计数的母函数为有理函数的显式表,由复杂度一阶差给出且在 Sturmian 情形退化闭合。（特殊因子有理母函数表）
