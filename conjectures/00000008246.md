# 00000008246

**EGT-16 ★** — source: 260_数理经济与博弈的数学.md

**English.** Definition: The Banzhaf-Shapley spectrum of power indices of cooperative games: the extremal value pol_dist of the distance between the Banzhaf index B and the Shapley index S. Conjecture: pol_dist (the maximal distance between B and S) is Theta(1/sqrt n) (a square-root distance law); the extremal games for the distance are oceanic games (an oceanic extremal law); the minimal number of agents for the paradox of inversion of power indices (a minimal-power agent with maximal index, the chairman paradox) is 3 (a three-agent chairman example), with maximal quantified paradox ratio (chairman index-to-control ratio) 1/2 (a half-control upper bound). (Banzhaf-Shapley oceanic square-root chairman)

**中文。** 定义：合作博弈的权力指标的 Banzhaf–Shapley 谱：权力指标（Banzhaf B 与 Shapley S）的距离 dist(B,S) 的极值 pol_dist。猜想：pol_dist（B 与 S 的最大距离）= Θ(1/√n)（平方根距离律）；且距离的极值博弈的结构为 oceanic 博弈（大洋博弈极值律）；权力指标的反转（最小权力代理的最大指标）的悖论（主席悖论）的最小代理数为 3（三代理主席例），悖论的量化（主席的指标-控制比）的最大值为 1/2（半控制上界）。
