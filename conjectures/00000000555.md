# 00000000555

**CA-55 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: The number of direct summands of a tilting module. Conjecture: For canonical singularities, the number of summands of a tilting module equals the rank of K₀ (a locality constant: verified for A_n and D_n up to n = 8).

**中文。** 定义：Tilting 模的直和项数。猜想：对 canonical singularity 的 tilting 的项数 = rank K₀(区域性常数:验证 A_n, D_n 至 n = 8)。
