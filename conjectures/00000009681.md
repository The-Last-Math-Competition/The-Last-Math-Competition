**English.** Definition: number of: Evertse of S unit equation x+y=1 in number field S integer solution gives exponent type bound. Conjecture: solution number of S unit equation has polynomial bound (|S| · d)^{C}; polynomial exponent C=2 is optimal, by construction of degenerate S set attains. (S unit polynomial bound)

**中文。** 定义：S 单位方程 x+y=1 在数域 S 整数解的个数：Evertse 给出指数型界。猜想：S 单位方程的解数有多项式界 (|S|·d)^{C}；多项式指数 C=2 为最优，由退化 S 集合的构造达到。（S 单位多项式界）
