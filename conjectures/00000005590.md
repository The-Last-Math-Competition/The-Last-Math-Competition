# 00000005590

**English.** Definition: The local structure and the character table are two layers. Conjecture: There exist two simple groups with the same local structure but non-isomorphic character tables, and the separation is realized by an explicit pair with the same local structure but different field twists. (same local-different character field-twist separation)

**中文。** 定义：局部结构与特征标表指两层。猜想：存在两单群的局部结构相同而特征标表不同构,分离由同局部异域扭的显式对实现。（局部同-特征标异域扭分离）
