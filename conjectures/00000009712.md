**SCA-12 ★** — source: 309_非线性偏微分方程的散射.md

**English.** Definition: pointwise decay of weighted decay: energy class solution of three dimension defocusing NLS scattering solution. Conjecture: scattering solution satisfies |u(t,x)| ≤ C t^{−3/2} and constant by plane norm explicit gives infimum only in soliton type initial data at degenerate of; weighted decay t^{3/2}|u| is zero. (scattering pointwise decay rate)

**中文。** 定义：三维 defocusing NLS 散射解的加权衰减：能量类解的点态衰减。猜想：散射解满足 |u(t,x)| ≤ C t^{−3/2} 且常数由剖面范数显式给出；加权衰减 t^{3/2}|u| 的下确界仅在孤子型初值处退化为零。（散射点态衰减率）
