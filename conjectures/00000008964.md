**ISO-14 ★** — source: 284_孤立子与逆散射的代数.md

**English.** Definition: dressing denotes by solution construction new solution. Conjecture: its kernel is finite rank if and only if initial data is N- soliton type and rank is exactly soliton number. (dressing finite rank)

**中文。** 定义：dressing 指由裸解构造新解。猜想：其核为有限秩当且仅当初值为 N-孤子型且秩恰为孤子数。（dressing 有限秩判定）
