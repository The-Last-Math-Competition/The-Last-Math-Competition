# 00000000503

**English.** Definition: The Eisenbud–Goto regularity bound asserts reg(R/I) ≤ deg(R/I) − codim + 1. Conjecture: The regularized version still holds for smooth projective varieties (not only ACM ones); and the tightness of the bound is attained by Castelnuovo-type curves. (Eisenbud-Goto smooth generalization)

**中文。** 定义：Eisenbud–Goto 正则性界断言 reg(R/I) ≤ deg(R/I) − codim + 1。猜想：对光滑投影簇（而非仅限 ACM）的正则化版本仍成立；且界的紧性由 Castelnuovo 型曲线达到。（Eisenbud-Goto 光滑推广）
