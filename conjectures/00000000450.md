# 00000000450

**English.** Definition: C_n(q,t) at q = ζ, t = ζ^{-1}. Conjecture: For every relevant root of unity ζ of order dividing n, C_n(ζ, ζ^{-1}) = (n+1)^{(n-1)/2} (when ζ is a primitive n-th root; numerically verifiable).
