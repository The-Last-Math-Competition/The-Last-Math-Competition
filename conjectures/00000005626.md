**English.** Definition: classical point set construction; edge spectrum of recurrence construction set: without (Horton type). Conjecture: edge spectrum counting is explicit formula — four edge counting of recurrence depth is polynomial type, five edge is linear, six edge is zero; counting depth and step size is subset of constant times; arbitrary 6 point of depth always contains five edge and Horton type is unique counterexample family. (recurrence set spectrum depth)
