**AD-07 ★** — source: 53_加性数论II.md

**English.** Definition: A Linnik-type representation is N = p + a² + b². Conjecture: The representation count has the lower bound c·N^{1/2}/log N·𝔖(N) (𝔖 the singular series, c = 1/4); the bound is unconditional for all sufficiently large N (parallel to Linnik's theorem).

**中文。** 定义：Linnik 型表示指 N = p + a² + b²。猜想：表示数的下界为 c·N^{1/2}/log N·𝔖(N)(𝔖 为奇异级数,c=1/4);下界在一切充分大 N 上无条件的(与 Linnik 定理平行)。
