# 00000001089

**FG-89 △** — source: 26_有限几何与编码理论.md

**English.** Definition: The binary [72,36,16] self-dual code is a candidate extremum of minimum distance. Conjecture: This code does not exist; under equivariant search (fixed automorphism group) with weighted counting, the dimension of the code space that any proof must examine has the lower bound 2^{20}, given by the count of fixed spaces of an order-7 automorphism.

**中文。** 定义：二元 [72,36,16] 自对偶码为最小距离候选极值。猜想：该码不存在;在等变搜索(固定自同构群)的加权计数下,任何证明需检查的码空间维数下界为 2^{20},且该下界由 7 阶自同构的固定子空间计数给出。
