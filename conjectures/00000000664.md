# 00000000664

**KT-64 ★** — source: 22_纽结与低维拓扑.md

**English.** Definition: The graded root (the tree-shaped digest of knot Floer homology). Conjecture: The number of leaves of the graded root is at least 2·g₃(K)+1, with equality if and only if K is fibered (a structural characterization).

**中文。** 定义：graded root(纽结 Floer 的树形摘要)。猜想：graded root 的叶数 ≥ 2·g₃(K)+1,且叶数 = 2g₃+1 当且仅当 K 为纤维化(结构刻画)。
