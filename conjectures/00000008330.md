# 00000008330

**English.** Definition: The arithmetic sums of Cantor sets: the higher-dimensional products beyond the known C + C = [0,2] for the middle-thirds Cantor set C. Conjecture: The product C x C has the critical dimension sum 4/3 (a critical sum law); the complete list of gaps of the difference set C - C (complement intervals) is the double gap (-2,-1) union (1,2) (a double gap law); and the fullness criterion for arithmetic sums of digit-restricted sets (base-b digit-restricted sets) is critical at the Newhouse threshold dim_1 + dim_2 = b (a Newhouse fullness threshold law). (Cantor critical sum double gap Newhouse)

**中文。** 定义：Cantor 集的算术和：中段 Cantor 集 C 的和 C+C=[0,2]（已知）的高维积 cantor_sum。猜想：C×C 的积的维数和 4/3 的临界维数的和（临界和律）；且 C 的差集 C-C 的洞（差集的补的区间）的完全列表为 (-2,-1)∪(1,2) 的双洞（双洞律）；数字受限集（b 进制数字限制集）的代数和的满性判据（和满判据）的临界为 Newhouse 阈值 dim₁+dim₂=b 的满阈（Newhouse 满阈律）。
