# 00000006979

**English.** Definition: Approximation with the first-order error structure. Conjecture: The conversion constant is explicit for the error order and the second-order coefficient is given by the scattering square; the coefficient is the trace of the Gelfand-Levitan kernel; and the convergence domain of the error is small potentials. (second-order error coefficient conversion)

**中文。** 定义：近似：一阶近似的误差结构。猜想：换算常数为误差阶的显式且二阶系数由散射平方给出；系数为 Gelfand–Levitan 核的迹；误差的收敛域为小位势。（误差二阶系数换算常数）
