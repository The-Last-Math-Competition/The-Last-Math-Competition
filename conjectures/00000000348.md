# 00000000348

**English.** Definition: Twin partial quotients means two adjacent partial quotients being equal. Conjecture: There exists α whose partial quotients satisfy a_n = a_{n+1} = ⌊τ(n)⌋ with τ the divisor function; and this α is constructed as an explicit series. (twin partial quotients via divisor function)
