# 00000007717

**English.** Definition: The spectral gap of a periodic tessellation cell graph, the quotient 1-skeleton, is the first nonzero eigenvalue lambda_1 of its combinatorial Laplacian. Conjecture: For all periodic tessellation cell graphs of bounded geometry (vertex degree <= D, cell edge count <= E), lambda_1 >= c/D^2 for a universal constant c>0; and the optimal c is attained by the hexagonal tiling with c = lambda_1(hex)/4 = 3/16. (universal spectral gap of tessellation graphs)

**中文。** 定义：周期铺砌胞腔图（tessellation 的 1-骨架商图）的谱隙指其组合 Laplacian 的第一非零特征值 λ_1。猜想：对所有有界几何（顶点度 ≤D、胞腔边数 ≤E）的周期铺砌胞腔图，λ_1 ≥ c/D² 对普适常数 c>0 成立；且 c 的最优值由六边形铺砌取到，c=λ_1(hex)/4=3/16。
