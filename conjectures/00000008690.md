# 00000008690

**OTW-10 ★** — source: 275_最优传输与Wasserstein几何.md

**English.** Definition: Transport on graphs: discrete Wasserstein transport of graph measures. Conjecture: The discrete geodesics are explicit (an explicitness law); the shortest representation of geodesics (flow decomposition) is a minimal flow (a minimal flow law); the decomposition tree has depth log n (a tree depth law); and the continuous limit (graph to manifold) converges at rate 1/n (a harmonic convergence law). (graph transport minimal flow tree depth)

**中文。** 定义：图上的传输：离散 Wasserstein 的图测度的传输。猜想：离散测地的显式（显式律）；且测地的最短表示（流分解）的最小流（最小流律）；流的分解的（分解树）的树深 log n 的（树深律）；连续极限（图→流形）的收敛速率的 1/n 的（调和收敛律）。
