# 00000008119

**NAG-09 ★** — source: 256_非交换代数几何.md

**English.** Definition: The categorical index of stability of the Serre duality functor of noncommutative varieties: the fixed point set fixed(S^n) of the n-th iterate S^n of the Serre functor S_A. Conjecture: fixed(S^n) is nonempty if and only if n is a multiple of the Serre dimension (a multiple criterion); fixed point objects are unique up to homological sphere equivalence (a unique fixed-point law); and the endomorphism algebra of a fixed point is a graded Clifford algebra (a Clifford fixed-point law), the rank of the Clifford quadratic form equaling the Calabi-Yau dimension (a dimension-rank law). (Serre iterate Clifford fixed points)

**中文。** 定义：非交换簇的 Serre 对偶函子的稳定性的范畴指标：Serre 函子 S_A 的 n 次迭代 S^n 的内点集 fixed(S^n)。猜想：fixed(S^n) 非空当且仅当 n 为 Serre 维数的倍数（倍数判据）；且内点对象（fixed 点）在同调球面等价类的意义下唯一（唯一内点律）；内点的自同态代数为分次 Clifford 代数（Clifford 内点律），Clifford 的二次型的秩 = CY 维数（维数-秩律）。
