# 00000008806

**English.** Definition: Interior point methods: central path methods with self-concordant barriers. Conjecture: The iteration complexity is the square root of the barrier parameter times the logarithm of the precision (a root law); and self-concordance is equivalent to the Nesterov-Nemirovski framework. (interior point root-nu self-concordant framework)

**中文。** 定义：内点法为自和谐障碍的中心路径法。猜想：迭代复杂度为根号障碍参数乘对数精度的根律；且自和谐的等价为 Nesterov–Nemirovski 框架。（内点根 ν 律自和谐框架）
