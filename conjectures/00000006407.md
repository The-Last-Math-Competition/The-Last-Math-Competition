# 00000006407

**SD3-07 ★** — source: 199_几何测度V_对称差问题.md

**English.** Definition: The complementary window is the symmetric parameter interval of the symmetric-difference structure in the complement formula. Conjecture: The window is always a symmetric interval and the window width equals the sum of the two measures; the extreme values of the window are attained by disjoint set pairs. (symmetric width-sum complementary window)

**中文。** 定义：互补窗口指余集公式中对称差结构的对称参数区间。猜想：窗口恒为对称区间且窗宽等于两测度之和；窗口的极值由不相交集合对取得。（互补窗口对称宽度和）
