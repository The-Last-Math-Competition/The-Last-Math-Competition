# 00000000030

**AC-04 ◆** — source: 02_组合数论与加性组合.md

**English.** Conjecture: Sparsification of intersective sets: there exists an absolute c > 0 such that whenever A ⊂ [N] with |A| ≥ N^{1/2−c}, the set {a² : a ∈ A} is intersective (it has nonempty intersection with every set of positive density).

**中文。** 猜想：相交集的稀疏化:存在绝对 c > 0,使得只要 A ⊂ [N],|A| ≥ N^{1/2−c},则 {a² : a ∈ A} 是相交集(每个正密度集与之有非零交)。
