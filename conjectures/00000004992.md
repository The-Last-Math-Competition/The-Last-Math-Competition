# 00000004992

**English.** Definition: Novikov cohomology is the twisted cohomology of closed form classes. Conjecture: On a compact G_2 manifold the Novikov number of any closed form class vanishes when the class norm is below the minimal critical value of the harmonic representative, and the threshold is an explicit spectral value and attainable. (spectral threshold of Novikov vanishing)

**中文。** 定义：诺维科夫上同调指闭形式类的扭曲上同调。猜想：紧 G₂ 上任意闭形式类的诺维科夫数在类范数低于谐调代表的最小临界值时消没,阈值为显式谱值且可达。（诺维科夫消没谱阈值）
