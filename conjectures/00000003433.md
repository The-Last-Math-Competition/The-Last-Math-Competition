# 00000003433

**English.** Definition: Linear widths: the error of best linear approximation. Conjecture: The spectral formula of linear widths: the width is the (r+1)-st singular value of the operator, with the optimality of the formula the Schmidt decomposition. (linear width Schmidt singular value formula)
