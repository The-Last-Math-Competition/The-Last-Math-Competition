# 00000000413

**SA-13 ★** — source: 20_代数组合与对称函数.md

**English.** Definition: The descent set Des(T) of a standard Young tableau is the set of descent positions. Conjecture: For fixed shape λ, descent sets are uniformly distributed over any family without long three-term arithmetic progressions; and the deviation from pseudorandomness is exponentially small in the shape weight. (descent set pseudorandom uniformity)

**中文。** 定义：标准 Young 表的下降集 Des(T) 为下降位置集合。猜想：固定形状 λ 的下降集在任意无长三等差集族上均匀分布；且伪随机性的偏差为形状权重的指数小。（下降集伪随机均匀）
