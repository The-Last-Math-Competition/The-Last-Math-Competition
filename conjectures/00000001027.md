# 00000001027

**English.** Definition: Let N(v) denote the number of non-isomorphic Steiner triple systems STS(v). Conjecture: log N(v) = v²·log(v/e²)/6 + O(v·log v); the leading coefficient in the second term O(v log v) is 1/2, so the two-term expansion of log N(v) is completely determined, via the counting templates of Wilson and Keevash.

**中文。** 定义：Steiner 三元系 STS(v) 的非同构个数记 N(v)。猜想：log N(v) = v²·log(v/e²)/6 + O(v·log v);第二项 O(v log v) 中的主项系数为 1/2,即 log N(v) 的两项展开完全确定,由 Wilson 与 Keevash 计数模板给出。
