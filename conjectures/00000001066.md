# 00000001066

**FG-66 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: A Sidon set B ⊂ F_p (all pairwise differences distinct). Conjecture: |B| ≤ p^{1/2} + 1, and p^{1/2} is attained for prime p (finite-field Sidon extremality).

**中文。** 定义：Sidon 集 B ⊂ F_p(差分两两不同)。猜想：|B| ≤ p^{1/2} + 1 且素 p 达到 p^{1/2}(有限域 Sidon 极值)。
