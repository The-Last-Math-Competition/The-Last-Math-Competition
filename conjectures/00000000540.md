# 00000000540

**CA-40 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: The k-th thickening of an edge ideal is a monomial-generated perturbation family. Conjecture: The Betti table limit at any thickening degree is a pure monomial ideal; and the convergence rate is an inverse polynomial in the perturbation parameter. (thickening Betti limit pure type)

**中文。** 定义：边理想的 k 次加厚为单项式生成的摄动族。猜想：任何加厚度的 Betti 表的极限为纯单项式理想；且极限的收敛速度为摄动参数的逆多项式。（加厚 Betti 极限纯型）
