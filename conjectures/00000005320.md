# 00000005320

**English.** Definition: Asymptotic classes and motives are two layers. Conjecture: There exist two algebraic families with the same asymptotic classes but non-isomorphic motives, and the separation is realized by an explicit pair of hypersurfaces with the same counting but different motives. (same asymptotic class-different motive hypersurface separation)

**中文。** 定义：渐近类与母题指两层。猜想：存在两代数族的渐近类相同而母题不同构,分离由同计数异母题的显式超曲面对实现。（渐近类同-母题异超曲面分离）
