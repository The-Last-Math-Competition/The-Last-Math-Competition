# 00000000008

**English.** Definition: The count of prime values of a square-free integer-coefficient quadratic polynomial f. Conjecture: There exists a constant c_f > 0 such that the number of prime values of f admits the explicit main-term lower bound c_f·x/log x. (quadratic prime-value lower bound)

**中文。** 定义：无重根整系数二次多项式 f 的素值计数。猜想：存在常数 c_f 大于零使 f 取素值的计数有下界 c_f 乘 x 除 log x 的显式主项。（二次素值下界）
