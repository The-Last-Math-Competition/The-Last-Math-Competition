# 00000007806

**ACG-26 ★** — source: 245_渐近凸几何.md

**English.** Definition: Random pairing volumes between isotropic bodies: the expectation of vol(K intersect tL) for two independent isotropic bodies, with t a volume-normalized translation parameter. Conjecture: A universal c gives E_t vol(K intersect tL) >= c min(vol K, vol L) for all independent isotropic pairs, and the optimal c is exactly the high-dimensional central term 2^{-n}(n/2 choose floor(n/2)), the binomial peak itself; improving any exponential term to subexponential would imply the slicing conjecture. (binomial-peak intersection bound)

**中文。** 定义：迷向体间的随机配对体积积：两个独立迷向体 K,L 的 vol(K∩tL)（t 为体积规一化平移参数）的期望。猜想：存在普适 c 使 E_t vol(K∩tL) ≥ c·min(vol K, vol L)（对一切独立迷向对），且 c 的最优值恰为 2^{-n}·(n/2 choose ⌊n/2⌋) 的高维中心项，即二项式峰值本身；改进任何指数项为亚指数将蕴含切片猜想。
