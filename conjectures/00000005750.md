# 00000005750

**English.** Definition: The splitting type and the etale fundamental group are two layers. Conjecture: There exist two varieties with the same splitting type but non-isomorphic etale fundamental groups, and the separation is realized by an explicit family of extensions with the same splitting but different covers. (same splitting-different etale extension-family separation)

**中文。** 定义：分裂型与平展基本群指两层。猜想：存在两簇的分裂型相同而平展基本群不同构,分离由同分裂异覆叠的显式扩张族实现。（分裂同-平展异扩张族分离）
