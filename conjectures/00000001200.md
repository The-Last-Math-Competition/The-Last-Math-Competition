# 00000001200

**English.** Conjecture: The spectrum of the eigenvalue differences of the Cherednik chirp operators on nonsymmetric Macdonald polynomials has, as n → ∞, the explicit Calogero–Sutherland gaps (chirp gaps).

**中文。** 猜想：非对称 Macdonald 多项式的啁啾算子(Cherednik)的特征值差的谱在 n → ∞ 为 Calogero–Sutherland 的间隙显式(啁啾间隙)。
