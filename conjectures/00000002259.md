# 00000002259

**English.** Definition: A normal function is bounded under the hyperbolic metric. Conjecture: A normal function of infinite order has a positive explicit lower bound for the infimum of its amplitude on dense open sets (normal-function amplitude).

**中文。** 定义：normal function(双曲度量下的有界)。猜想：挠率为无穷的 normal function 在稠密开集上的振幅的下确界为正的显式常数(normal 振幅)。
