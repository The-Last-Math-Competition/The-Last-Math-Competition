# 00000006190

**English.** Definition: Reflection difference and forbidden density are two layers. Conjecture: There exist two graphs with the same reflection difference but different forbidden densities, and the separation is realized by an explicit complement pair with the same reflection but different containment. (same reflection-different forbidden complement separation)

**中文。** 定义：反射差与禁密度指两层。猜想：存在两图的反射差相同而禁密度不同,分离由同反射异包含的显式补图对实现。（反射差同-禁密度异补对分离）
