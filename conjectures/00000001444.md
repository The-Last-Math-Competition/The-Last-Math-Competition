# 00000001444

**English.** Definition: The tip multifractal spectrum f(α) of SLE_κ is the fractal spectrum of the curve near the tip. Conjecture: The Fyodorov–Bouchaud formula holds for all κ ∈ (0,8): f(α) = α + ((8−κ)/(4κ))·α² + c(κ), with c an explicit constant; the extension beyond the proven range (several values with κ ≤ 4) is verified explicitly via the local martingale measure at the tip.

**中文。** 定义：SLE_κ 的 tip 多重分形谱 f(α) 指尖端附近曲线的分形谱。猜想：Fyodorov–Bouchaud 公式对一切 κ∈(0,8) 成立:f(α) = α + ((8−κ)/(4κ))·α² + c(κ),c 为显式常数;已证范围(κ≤4 的若干值)之外的延拓由 tip 的局部 martingale 量测显式验证。
