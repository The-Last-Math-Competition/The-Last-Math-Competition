**English.** Definition: Rogers–Ramanujan type identities: side-by-side finite forms. Conjecture: For every N, the RR identity admits a "truncated" version in which the coefficient differences on both sides take only the values ±1 within [0, N] (minimal error of finite identities).

**中文。** 定义：Rogers–Ramanujan 型恒等式:side-by-side 有限形式。猜想：∀N,RR 恒等式有"截断"版使得两端系数差在 [0, N] 内只取 ±1(有限恒等式的最小误差)。
