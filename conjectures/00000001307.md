# 00000001307

**English.** Definition: A closed subset E of the ball Bⁿ is a peak set if some holomorphic function has boundary limit 1 exactly on E and modulus strictly less than 1 inside; an interpolation set is one for which the restriction operator H∞(B) → H∞(E) is onto. Conjecture: E is a peak set if and only if E is a closed subset of an interpolation set; the equivalence loop between the two notions (p-interpolation ⟺ isolation + Carleson condition) closes at the p = ∞ endpoint.

**中文。** 定义：球 Bⁿ 的闭子集 E 为 peak 集指存在 E 上恒为 1、球内严格小于 1 的全纯函数的边界极限;插值集 I(B) 指限制算子 H∞(B)→H∞(E) 满射。猜想：E 为 peak 集当且仅当 E 为插值集的闭子集;两个概念的等价回路(p-interpolation ⟺ 孤立性+Carleson 条件)在 p=∞ 端封闭。
