# 00000002704

**English.** Definition: Dynamical applications of the p-adic Jacobi inverse function theorem: iteration of local inverses. Conjecture: The convergence radius of the p-adic local inverse is an explicit function of the multiplier norm; iteration within the radius converges linearly, with convergence constant the logarithm of the multiplier norm. (p-adic local inverse convergence)

**中文。** 定义：p-adic Jacobi 逆函数定理的动力学应用：局部逆的迭代。猜想：p-adic 局部逆的收敛半径为乘子模的显式函数；半径内的迭代收敛为线性且收敛常数为乘子模的对数。（p-adic 局部逆收敛）
