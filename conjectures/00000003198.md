# 00000003198

**English.** Definition: Hilbert functions: the dimension spectrum of graded modules. Conjecture: Rationality of Hilbert functions: the function is eventually a quasipolynomial, with quasiperiod the least common multiple of the regression numbers h. (Hilbert quasipolynomial regression number)

**中文。** 定义：Hilbert 函数：分次模的维数谱。猜想：Hilbert 函数的有理性：函数最终为准多项式且准周期为回归数 h 的最小公倍。（Hilbert 准多项式回归数）
