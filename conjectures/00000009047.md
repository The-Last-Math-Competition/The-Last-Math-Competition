# 00000009047

**English.** Definition: Finite type submanifolds: finiteness of the spectrum of coordinate functions. Conjecture: The characterization of finiteness is always harmonic polynomial type; the height of the type is a finite index; and the minimal element of the spectrum corresponds to the first harmonic component of the coordinates. (finite type harmonic polynomial characterization)

**中文。** 定义：子流形的有限型为坐标函数的谱有限性。猜想：有限性的刻画恒为调和多项式型；且型的高度为有限指标；且谱的极小元对应坐标一次调和分量。（有限型调和多项式刻画）
