# 00000001698

**EG-08 ★** — source: 42_遍历论II.md

**English.** Definition: Hardy-field sequences are elements of the field of slowly growing and slowly decreasing functions; joint ergodicity means the averages along all rotations converge to a constant. Conjecture: (f₁(n), f₂(n)) is jointly ergodic if and only if every integer linear combination a·f₁ + b·f₂ differs from a linear polynomial by a Weyl growth condition (a complete resonance criterion).

**中文。** 定义：Hardy 域序列指缓增、缓减函数域的元素;联合遍历性指其平均沿一切旋转收敛于常数。猜想：(f₁(n),f₂(n)) 联合遍历当且仅当一切整数线性组合 a·f₁+b·f₂ 与线性多项式的差满足 Weyl 增长条件(共振判据完备)。
