# 00000000750

**English.** Definition: The Mahler coefficients a_n characterize 1-Lipschitz maps if and only if p^n | a_n (Anashin's criterion). Conjecture: For the mod p^k reduction of a 1-Lipschitz map, the Mahler coefficient sequence (a_n mod p^k) is eventually periodic with exact period p^{k−1}(p−1), which cannot be shortened; this period is attained simultaneously with the measure-preserving property of minimal maps.

**中文。** 定义：Mahler 展开系数 a_n 刻画 1-Lipschitz 映射当且仅当 p^n|a_n(Anashin 判据)。猜想：模 p^k 约化的 1-Lipschitz 映射的 Mahler 系数序列 (a_n mod p^k) 的最终周期恰为 p^{k-1}(p−1),不可再缩短;该周期与最小映射的测度保持性质同时达到。
