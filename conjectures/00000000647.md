# 00000000647

**KT-47 ★** — source: 22_纽结与低维拓扑.md

**English.** Definition: The smooth 4-genus g₄(K) and Rasmussen's invariant s(K). Conjecture: The equality g₄(K) = s(K)/2 holds if and only if K is quasi-positive; in particular, all knots with s(K) = 0 but g₄(K) > 0 form an explicitly constructible non-quasi-positive family.

**中文。** 定义：光滑 4-亏格 g₄(K) 与 Rasmussen 不变量 s(K)。猜想：等式 g₄(K)=s(K)/2 成立当且仅当 K 为 quasi-positive 纽结;特别地,一切 s(K)=0 而 g₄(K)>0 的纽结均为非 quasi-positive 的显式可构造族。
