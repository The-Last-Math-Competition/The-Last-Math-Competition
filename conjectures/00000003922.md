# 00000003922

**FL-12 ★** — source: 116_辛拓扑II_Floer同调.md

**English.** Definition: An undistorted element is a bounding cochain b for which the deformed multiplication m_0^b vanishes. Conjecture: The distortion of a compact monotone spin Lagrangian can be eliminated by a deformation within its homology class if and only if its crossing discriminant is disjoint from the Novikov value set. (distortion elimination criterion)

**中文。** 定义：非扭曲元指使形变乘法 m₀^b 为零的 bounding cochain b。猜想：紧致单调自旋 Lagrange 的扭曲可经同调类内的形变消除当且仅当其穿越判别式与 Novikov 值集不交。（扭曲消除判据）
