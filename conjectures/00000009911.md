# 00000009911

**English.** Definition: Bottleneck distance stability: bottleneck distance upper bounds for persistence diagrams under Hausdorff perturbation (the tight constant is known to be one half). Conjecture: The inverse problem of stability constants: point-set families attaining the worst ratio are explicit two-point degenerate configurations, with the ratio one half realized only asymptotically by this configuration; for general-position point sets the ratio strictly halves to one quarter. (stability constant inverse problem)

**中文。** 定义：瓶颈距离稳定性：持久图在 Hausdorff 扰动下的瓶颈距离上界（紧常数已知为二分之一）。猜想：稳定性常数的逆问题：达到最坏比值的点集家族为双点退化的显式构型且比值为二分之一仅在此构型渐近实现；一般位置点集的比值严格减半为四分之一。（稳定性常数逆问题）
