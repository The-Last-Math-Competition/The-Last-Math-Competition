# 00000008110

**English.** Definition: The cardinality of the minimal model of a fusion system: the carrier order min_ord(F) of the minimal local finite group realizing F (the minimal carrier of the centric linking system). Conjecture: min_ord(F) = |S| 2^{c(F)} (a doubling law, c(F) a transitivity constant); c(F) <= rank(S) + 1 (a transitivity upper bound); systems with c(F) = 0 are group-realized (a zero-transitivity group-source criterion); and the minimal positive value c = 1 occurs at the first twist of the Borel of a Lie type group (a Borel single-twist origin law), the classification of single-twist systems being a unique system for each odd value of the prime p (an odd-prime single-twist uniqueness law). (minimal model doubling Borel twist law)

**中文。** 定义：融合系统的极小模型的基数：实现 F 的极小局部有限群（centric linking 系统的极小载体）的载体阶 min_ord(F)。猜想：min_ord(F) = |S|·2^{c(F)}（双倍律，c(F) 为传递常量）；且 c(F) ≤ rank(S)+1（传递上界）；c(F)=0 的系统为群实现（零传递-群源判据）；c 的极小正值为 1 的系统为 Lie 型群 Borel 的第一次扭（Borel 单扭起源律），单扭系统的分类为素数 p 的每个奇值的唯一系（奇素单扭唯一律）。
