# 00000000746

**PA-46 ★** — source: 23_p进分析与局部域.md

**English.** Definition: The p-adic Schröder function (a p-adic Koenigs theorem). Conjecture: The Schröder function of an attracting fixed point is a convergent power series whose coefficient denominators contain only the first power of p (divisibility structure of coefficients).

**中文。** 定义：p-adic Schröder 函数(Koenigs 定理的 p 进版)。猜想： attracting 不动点的 Schröder 函数为收敛幂级数且系数分母仅有 p 的一次幂(系数整除结构)。
