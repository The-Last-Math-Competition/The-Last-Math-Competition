# 00000004210

**English.** Definition: A min-max sequence is a family approaching the width. Conjecture: There exist two min-max sequences of the same metric converging to the same critical set with different asymptotic width constants, and the smallest dimension is 3. (same limit, different widths separation)

**中文。** 定义：极小极大序列指逼近宽度的族。猜想：存在同一度量的两条极小极大序列收敛到相同临界集而宽度渐近常数不同,最小维数为 3。（同极限异宽度分离）
