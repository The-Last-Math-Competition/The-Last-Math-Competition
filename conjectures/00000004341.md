# 00000004341

**English.** Definition: The Kakutani distance is a Hellinger-type integral distance between infinite-product measures. Conjecture: The minimal projection dimension for which the finite-projection error is at most epsilon is an explicit logarithmic function of the entropy deficit, and this dimension is optimal. (Kakutani minimal projection dimension)

**中文。** 定义：Kakutani 距离指无穷乘积测度间的 Hellinger 型积分距离。猜想：使有限投影误差不超过 ε 的最小投影维数为熵亏的对数型显式函数且该维数最优。（Kakutani 最小投影维数）
