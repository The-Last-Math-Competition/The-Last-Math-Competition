# 00000001337

**AN2-07 △** — source: 30_解析数论II_L函数与自守.md

**English.** Definition: Applying μ to the values of μ(n), i.e. μ(μ(n)) (with μ(n) ∈ {−1, 0, 1}, setting μ(±1) = 1 and μ(0) = 0). Conjecture: The mean (1/x)Σ_{n≤x} μ(μ(n)) does not converge to 0 but diverges to a 6/π²-type limit — the value statistics of μ interact with its zero density to produce a main term.

**中文。** 定义：μ(n) 的值域上的再取 μ,即 μ(μ(n))(当 μ(n)∈{−1,0,1},规定 μ(±1)=1、μ(0)=0)。猜想：均值 (1/x)Σ_{n≤x} μ(μ(n)) 不收敛于 0 而发散至 6/π² 型极限,即 μ 的值域统计与零密度相互作用产生主项。
