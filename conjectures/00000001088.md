# 00000001088

**FG-88 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: Hopf-algebraic codes. Conjecture: The determinant of the bilinear form of the code structure of a Hopf–Galois extension is ±|G|^n (the Hopf code discriminant).

**中文。** 定义：Hopf 代数码。猜想：Hopf-Galois 扩张的码结构的双线性形式的行列式为 ±|G|^n(Hopf 码判别式)。
