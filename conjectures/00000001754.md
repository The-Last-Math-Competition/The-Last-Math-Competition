# 00000001754

**RT-04 △** — source: 44_表示论II.md

**English.** Definition: An involution model of a group G is a Gelfand model arranged by involution conjugacy classes (with relevant characters). Conjecture: The Monster group admits an involution model (most conjugacy classes already verified); the model character values on the remaining classes are completed by explicit modular-form coefficients.

**中文。** 定义：群 G 的 involution 模型指其按对合共轭类的排列模型(相关特征标)。猜想：Monster 群存在 involution 模型(已验证多数共轭类);剩余类的模型特征标的值由显式模形式系数补全。
