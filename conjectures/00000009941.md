# 00000009941

**English.** Definition: Diagonal entropy jumps of diagonal flows: the entropy lower-bound structure of invariant measures of diagonal flows on SL(n,R)/SL(n,Z) along each parameter component (partially solved by Einsiedler-Katok-Lindenstrauss). Conjecture: The entropy jump phenomenon of diagonal-flow invariant measures is completely classified: vanishing entropy of a measure in some parameter implies invariance along the corresponding one-parameter subgroup; the jump set is an explicit union of hyperplanes in the weight space of the root system. (diagonal entropy jump classification)

**中文。** 定义：对角流的对角熵跳跃：SL(n,R)/SL(n,Z) 对角流的不变测度的熵沿每个参数分量的下界结构（Einsiedler–Katok–Lindenstrauss 部分解决）。猜想：对角流不变测度的熵跳跃现象完全分类：测度在某参数的熵为零蕴含测度沿对应单参数群不变；跳跃集为根系权空间的显式超平面并。（对角熵跳跃分类）
