# 00000003955

**English.** Definition: The rank-width is a width parameter satisfying, with treewidth t, the classical inequality t <= 3r - 1. Conjecture: The constant 3 in the inequality t <= 3r - 1 is optimal, with an explicit family of graphs of rank-width r and treewidth exactly 3r - 1; moreover the kernelization kernel size for distance-hereditary graphs is constant. (optimal rank-width-treewidth constant)

**中文。** 定义：rank-width 指宽度参数,与树宽满足 t ≤ 3r − 1 的经典不等式。猜想：不等式 t ≤ 3r − 1 中的常数 3 最优,存在秩宽 r 树宽恰 3r − 1 的显式图族;且距离遗传图的核化核尺寸为常数。（秩宽-树宽常数最优）
