# 00000002056

**English.** Definition: n-permutable congruences satisfy θ₀∘θ₁∘⋯∘θ_{n−1} = 1. Conjecture: The minimal polynomial set of the Maltsev condition for varieties that are exactly n-permutable but not (n−1)-permutable is an explicit list (of size n+1); the minimality of the list is verified by multivariate constructions.

**中文。** 定义：n-置换同余指 θ₀∘θ₁∘⋯∘θ_{n-1}=1。猜想：恰 n-可换但不 (n-1)-可换的最小簇的 Maltsev 条件的极小多项式集为显式列表(集的大小为 n+1);列表的极小性由多类别构造验证。
