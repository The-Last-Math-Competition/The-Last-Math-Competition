# 00000002305

**English.** Conjecture: The number of conjugacy classes satisfies k(G) ≥ c·[G:H] for maximal H (c = 1/2); the sharpened constant is c = 1/2 (improvable to (1/2)·(1−ε(G))); tightness of the bound is verified by AGL(1,p)-type groups.

**中文。** 猜想：共轭类数 k(G) ≥ c·[G:H](H 极大)(c=1/2);锐化常数为 c=1/2(可改进至 (1/2)·(1-ε(G)));界的紧性由 AGL(1,p) 型验证。
