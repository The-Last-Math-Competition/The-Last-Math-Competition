# 00000004042

**English.** Definition: An interval algebra is an algebra constructed from a poset with repdim = 3. Conjecture: The realizable values of repdim are dense above 3, and the class of algebras with repdim = 3 is closed under derived equivalence. (density and closure of realizable repdim values)

**中文。** 定义：间隔代数指由 poset 构造的 repdim = 3 型代数。猜想：repdim 的可实现值在 3 以上稠密;repdim = 3 的代数类在导出等价下封闭。（repdim 可实现值稠密与封闭）
