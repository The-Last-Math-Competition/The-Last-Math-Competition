# 00000000373

**English.** Definition: The Guivarc'h–Le Page algorithm on GL₂ is a matrix generalization of continued fractions. Conjecture: The gap value of its Lyapunov spectrum is an explicit logarithm; and the rigidity of the gap follows from the central limit theorem for random matrix products. (GL2 algorithm Lyapunov gap)

**中文。** 定义：GL₂ 上的 Guivarc'h–Le Page 算法为连分数的矩阵推广。猜想：其 Lyapunov 谱的间隙值为显式对数；且间隙的刚性由随机矩阵乘积的中心极限给出。（GL2 算法 Lyapunov 间隙）
