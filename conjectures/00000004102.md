# 00000004102

**English.** Definition: The tree braid group is the braid group on a tree graph, and the Dehn function is the isoperimetric function of the word problem. Conjecture: The order of the Dehn function of a tree braid group is determined solely by the vertex-degree spectrum of the tree: path type is linear, branching type is quadratic, and no higher order occurs. (degree-spectrum dichotomy of tree braid Dehn functions)

**中文。** 定义：树辫群指树图上的辫群,Dehn 函数指字问题的等词膨胀函数。猜想：树辫群的 Dehn 函数阶仅由树的顶点度谱决定,路径型为线性,含分叉为二次,无更高阶。（树辫 Dehn 度谱二分）
