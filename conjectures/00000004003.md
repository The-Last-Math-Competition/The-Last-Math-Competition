# 00000004003

**RP2-03 ★** — source: 119_随机分析II_粗路径.md

**English.** Definition: The expected signature E[S(X)] is the integral of the signature against the process distribution. Conjecture: The expected signature determines the distribution if and only if the Carleman condition for the moment problem of the distribution family holds; within this class the first floor(d/2) levels never determine the distribution, and all levels up to infinity are required. (determinacy boundary of the expected signature)

**中文。** 定义：期望签名 E[S(X)] 指签名对过程分布的积分。猜想：期望签名唯一决定分布当且仅当分布族的矩问题 Carleman 条件成立;且在此类内首 ⌊d/2⌋ 层不决定分布,需至无穷层。（期望签名决定性边界）
