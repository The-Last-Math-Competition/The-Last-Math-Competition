# 00000001388

**English.** Definition: Symbolic extension entropy (Boyle–Downarowicz). Conjecture: The minimal tree height of a symbolic extension of given entropy h is the length of the binary expansion of h (minimal extension height); and the tree height is exactly the number of bits of the binary expansion of the entropy h.

**中文。** 定义：符号扩张熵(Boyle–Downarowicz)。猜想：给定熵 h 的符号扩张的最小树高为 h 的二元展开长度(扩张最小高度)；且树高恰为熵 h 的二元展开的位数。
