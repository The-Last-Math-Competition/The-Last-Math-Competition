# 00000001611

**SP-11 ◆** — source: 39_泛函分析III_算子谱问题.md

**English.** Definition: The Borg–Levinson theorem (a potential is uniquely determined by one full spectrum plus norming constants). Conjecture: The minimal overdetermination for the mixed inverse problem of one finite-interval spectrum plus one two-interval spectrum, within n eigenvalues, is 2n+1 (minimal data for mixed inverse problems).

**中文。** 定义：Borg–Levinson 定理(一位势由全谱与范数常数唯一确定)。猜想：有限区间 + 两区间谱的混合反问题在 n 个特征值内的最小超定数为 2n+1(混合反问题的最小数据)。
