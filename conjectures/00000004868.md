# 00000004868

**English.** Definition: The Busemann function is the distance-type function to a boundary point. Conjecture: Its boundary integral is square integrable if and only if the measure dimension exceeds one half, the threshold is one half, and the boundary example is a dimension-critical self-similar set. (half-dimension threshold of Busemann square integrability)

**中文。** 定义：Busemann 函数指到边界点的距离型函数。猜想：其边界积分的平方可积性当且仅当测度维数过半,阈值为二分之一且边界例为维数临界自相似集。（Busemann 平方可积半维数阈）
