# 00000000735

**English.** Definition: h_n is the class number of the n-th layer of the cyclotomic Z_p-tower. Conjecture: The density of levels n with p | h_n among the first N levels converges to 1 − (1−p^{−1})·c_p, where c_p is the explicit Euler product ∏_{i≥2}(1−p^{−i}); this density is a direct arithmetic consequence of the Iwasawa main conjecture.

**中文。** 定义：分圆 Z_p-塔的第 n 层类数 h_n。猜想：使 p 整除 h_n 的层 n 在前 N 层中的密度收敛到 1−(1−p^{-1})·c_p,c_p 为显式 Euler 积 ∏_{i≥2}(1−p^{-i});该密度是 Iwasawa 主猜想算术化的直接推论。
