# 00000009744

**English.** Definition: Predictability of integer sequences: minimal description length thresholds of sequence inference engines. Conjecture: OEIS-type integer sequences are compressible by more than half if and only if their automaton complexity is sublinear; minimal description length relates to autocorrelation dimension by an explicit hyperbola, with a phase transition of inference success rate at the threshold. (integer sequence compression threshold)

**中文。** 定义：整数序列的可预测性：序列推断引擎的最小描述长度阈值。猜想：OEIS 型整数列的可压缩率超过一半当且仅当其自动机复杂度为次线性；最小描述长度与自相关维数呈显式双曲关系且阈值处发生推断成功率的相变。（整数列压缩阈值）
