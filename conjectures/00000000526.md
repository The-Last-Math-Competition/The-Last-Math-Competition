# 00000000526

**CA-26 ★** — source: 21_交换代数与同调代数.md

**English.** Definition: Hilbert–Kunz multiplicity e_HK(I). Conjecture: e_HK(x² + y³ + z⁵, R = k[x,y,z]) equals a rational number times an explicit log 2 correction (a "superconvergent" structure outside Monsky's counterexample family, verified up to p < 200).

**中文。** 定义：Hilbert–Kunz 多重性 e_HK(I)。猜想：e_HK(x² + y³ + z⁵, R = k[x,y,z]) = 有理数 × 显式 log 2 修正(Monsky 反例族之外的"超收敛"结构,验证至 p < 200)。
