# 00000001468

**CX-18 ★** — source: 34_凸分析与最优化.md

**English.** Definition: Shadow-vertex paths of the simplex method. Conjecture: On random Gaussian polytopes, the expected length of the shadow-vertex path is Θ(d²σ^{-2}) with the exact constant (the smooth-path constant).

**中文。** 定义：单纯形法的影子顶点路径。猜想：随机高斯多胞体上影子顶点路径期望长度为 Θ(d² σ^{-2}) 的精确常数(光滑路径常数)。
