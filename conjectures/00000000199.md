# 00000000199

**English.** Definition: Σ_{n≥0} 1/(n²+n+2), with a denominator irreducible over Q. Conjecture: The sum is an explicit Q-linear combination of values of the digamma function at cube roots of unity; the irrationality of the sum is equivalent to that of ψ(ω)-type values (ω³ = 1), the equivalence following from an explicit partial-fraction decomposition. (quadratic-denominator psi representation)

**中文。** 定义：Σ_{n≥0} 1/(n²+n+2)，分母在 Q 上不可约。猜想：和可表为 ψ 函数在三次单位根的值的显式 Q 组合；该和的无理性等价于 ψ(ω) 型值（ω³=1）的无理性，等价性由部分分式的显式分解给出。（二次分母 psi 表示）
