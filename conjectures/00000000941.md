# 00000000941

**English.** Definition: A super-property of Banach spaces is one preserved under all ultrapowers (such as super-reflexivity). Conjecture: The identity between Enflo type p and Rademacher type p is closed under ultrapowers: X has super-type p if and only if all its ultrapowers have a uniform type constant; consequently metric super-type and linear super-type coincide, completing the type portion of the Ribe program.

**中文。** 定义：Banach 空间的超性质指其在一切超幂下保持的性质(如超自反性)。猜想：Enflo 型 p ⟺ Rademacher 型 p 的等式在超幂下封闭:空间 X 有超型 p 当且仅当其一切超幂有一致型常数;由此度量超型与线性超型重合,完成 Ribe 程序的型部分。
