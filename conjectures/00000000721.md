# 00000000721

**English.** Definition: Let trdeg denote the transcendence degree of Q̄_p over Q̄. Conjecture: The set {Σ_{n≥1} a_n p^{−n!} : a_n ∈ {0,…,p−1}} contains a subfamily of cardinality 2^{ℵ₀} algebraically independent over Q̄; i.e. a maximal algebraically independent family can be constructed explicitly from Mahler-type Lambert series.

**中文。** 定义：Q̄_p 关于 Q̄ 的超越次数记 trdeg。猜想：集合 {Σ_{n≥1} a_n p^{-n!} : a_n∈{0,...,p−1}} 中存在基数 2^{ℵ₀} 的子族在 Q̄ 上代数无关;即可由 Mahler 型 Lambert 级数显式构造极大代数无关族。
