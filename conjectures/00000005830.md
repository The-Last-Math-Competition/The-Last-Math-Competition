# 00000005830

**English.** Definition: The Harnack constant and the asymptotic type are two layers. Conjecture: There exist two equations with the same constant but different asymptotic types, and the separation is realized by an explicit equation pair with the same constant but different decay. (same Harnack-different asymptotic equation separation)

**中文。** 定义：哈纳克常数与渐近型指两层。猜想：存在两方程的常数相同而渐近型不同,分离由同常数异衰减的显式方程对实现。（哈纳克同-渐近异方程分离）
