# 00000000548

**English.** Definition: The minimal number ι(I) of irreducible decompositions is the least number of components. Conjecture: ι(I) ≤ β₀(I); and the combinatorial control of the decomposition number is verified up to n = 12 for monomial ideals, with tightness attained by complete intersections. (irreducible decomposition number upper bound)
