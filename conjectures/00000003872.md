# 00000003872

**RM3-22 ◆** — source: 114_随机矩阵III_beta系综.md

**English.** Definition: The counting function N(B) is the number of points falling in interval B. Conjecture: In the bulk, Var(N(B)) = (1/βπ²)·log|B| until |B| ~ N, saturating at (1/βπ²)·logN + O(1) with the O(1) term a universal constant. (counting variance saturation constant)

**中文。** 定义：计数函数 N(B) 指落在区间 B 中的点数。猜想：bulk 中 Var(N(B)) = (1/βπ²)log|B| 直至 |B| ~ N 才饱和,饱和值为 (1/βπ²)logN + O(1),且 O(1) 项为普适常数。（计数方差饱和常数）
