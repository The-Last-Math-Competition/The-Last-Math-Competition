# 00000009967

**MRG-27 ★** — source: 317_测度刚性.md

**English.** Definition: Periodicity forcing of Delone sets: thresholds at which local rules force global periodicity. Conjecture: The size of the minimal set of finite local matching rules forcing periodicity is an explicit exponential function of the entropy of configuration space; forcing occurs at the zero-entropy threshold, computable from the strongly connected components of the de Bruijn graph. (periodicity forcing threshold)

**中文。** 定义：Delone 集的周期性强迫：局部规则性迫使整体周期的阈值。猜想：有限局部匹配规则强迫周期的最小规则集的规模为构型空间的熵的显式指数函数；熵为零的阈值处强迫发生且阈值可由 de Bruijn 图的强连通分量计算。（周期性强迫阈值）
