# 00000000055

**English.** Definition: A transitive subtournament is a fully transitive subgraph of a tournament. Conjecture: Every n-vertex tournament contains a transitive subtournament of order ⌈log₂n⌉ + O(1); and this order is optimal. (tournament transitive subtournament logarithmic order)

**中文。** 定义：传递子竞赛指竞赛图中全传递的子图。猜想：每个 n 点竞赛图包含阶为 log₂n 上取整加 O(1) 的传递子竞赛；且该阶为最优。（竞赛传递子对数阶）
