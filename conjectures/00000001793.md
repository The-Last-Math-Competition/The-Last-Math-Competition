# 00000001793

**CV-13 ★** — source: 45_多复变II.md

**English.** Definition: The k-Hessian cone is the set of Kähler classes for which the k-Hessian equation is solvable. Conjecture: The k-Hessian cone contains (1−k/n)·(Kähler cone) (a pure cone inclusion); the inclusion is strict and cannot be improved (by classes attaining equality on symmetric varieties).

**中文。** 定义：k-Hessian 锥指使 k-Hessian 方程可解的 Kähler 类集合。猜想：k-Hessian 锥 ⊇ (1−k/n)·Kähler 锥(纯锥包含);包含为严格且不可改进(由对称簇上达到等式的类)。
