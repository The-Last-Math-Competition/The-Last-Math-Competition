# 00000004277

**English.** Definition: The type lattice is the lattice of all types under joins and meets. Conjecture: The number of maximal chains of the type lattice has the cardinality of the continuum, and the order type of every maximal chain is uniformly the sum of omega with the reverse of omega. (unified order type of maximal type chains)

**中文。** 定义：类型格指全体类型在上下确界下形成的格。猜想：类型格的极大链条数与实数等势,且每条极大链的序型统一为 ω 与反向 ω 的和。（类型极大链统一序型）
