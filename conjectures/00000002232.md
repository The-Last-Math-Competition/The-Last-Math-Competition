# 00000002232

**NV-02 ★** — source: 60_亚纯函数与NevanlinnaII.md

**English.** Definition: The projective deficiency relation Σδ(a,f) ≤ 2 (entire functions). Conjecture: The quadratic difference f ↦ f(z+1) − f(z) preserves finiteness of the deficiency spectrum (difference deficiencies); and the proof path for preservation is a difference analogue of the Second Main Theorem.

**中文。** 定义：射影缺值关系 Σδ(a,f) ≤ 2(整函数)。猜想：二次差分 f ↦ f(z+1) − f(z) 保持缺度谱有限(差分缺度)；且差分保持的证明路径为第二主定理的差分类比。
