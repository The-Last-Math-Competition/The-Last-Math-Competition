# 00000003322

**English.** Definition: Edge ideals: the algebraic side of graphs. Conjecture: The regularity-acyclicity of edge ideals: regularity equals the matching number if and only if the graph is a bipartite forest (a conjecture in the spirit of Kohnert), with the generalization Cohen–Macaulay trees. (edge ideal matching equivalence bipartite forest)

**中文。** 定义：边理想（edge ideal）：图的代数侧。猜想：边理想的正则性-无圈数：正则性等于匹配数当且仅当图为二部森林（Kohnert 猜想）且猜想的推广为 Cohen–Macaulay 树。（边理想匹配等价二部森林）
