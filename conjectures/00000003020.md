# 00000003020

**English.** Definition: Entanglement Hamiltonians: the virtual temperature structure of reduced density matrices. Conjecture: Equivalence of entanglement spectra: the eigenvalue spectrum of the reduced density matrix corresponds one-to-one with the spectrum of a boundary local Hamiltonian, with virtual temperature an explicit function of the modular transformation. (entanglement spectrum virtual temperature correspondence)
