# 00000008878

**English.** Definition: Generational layers of short combinatorial games by birthday: the count g_n of equivalence classes of birthday exactly n and the decomposition structure of each layer (known: g_0 = 1, g_1 = 2, g_2 = 4, g_3 = 16, g_4 = 3824). Conjecture: g_n grows double-exponentially — there exists c > 1 with g_n >= c^{2^n} for infinitely many n, and the upper bound g_n <= 2^{2^{2n}} always holds; the proportion of decomposable games (sums of two strictly smaller-birthday games) converges to 1 as n grows; and the number of irreducible summands in a birthday-n game decomposition is at most 2^n, with the count of irreducibles at least doubling layer by layer from n at least 4. (birthday layer double-exponential decomposable irreducible doubling)

**中文。** 定义：短组合游戏按生日的生成层：生日恰为 n 的等价类数 g_n 与各层的分解结构（已知 g_0=1、g_1=2、g_2=4、g_3=16、g_4=3824）。猜想：g_n 呈双指数增长——存在常数 c>1 使 g_n ≥ c^{2^n} 对无穷多 n 成立且上界 g_n ≤ 2^{2^{2n}} 恒成立；可写为两个生日严格更小游戏之和的可分解游戏占比随 n 增大收敛于 1；生日 n 的游戏分解为不可约游戏之和的项数不超过 2^n 且 n≥4 层不可约游戏数逐层至少翻倍。
