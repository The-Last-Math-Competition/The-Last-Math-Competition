# 00000004011

**RP2-11 ★** — source: 119_随机分析II_粗路径.md

**English.** Definition: An RDE is a rough differential equation dY = V(Y)dX. Conjecture: The tail of the solution norm satisfies the Fernique-type bound P(||Y|| > t) <= 2 exp(-t^2/c), where the constant c depends only on the growth constant of the vector fields and the tail parameters of the driver. (universal constant of the RDE tail bound)

**中文。** 定义：RDE 指粗糙微分方程 dY = V(Y)dX。猜想：解范数尾部满足 Fernique 型界 P(‖Y‖ > t) ≤ 2exp(−t²/c),常数 c 仅依赖向量场增长常数与驱动尾参数。（RDE 尾界普适常数）
