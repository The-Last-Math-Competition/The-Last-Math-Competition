**English.** Definition: The simultaneous polynomial approximation exponent ω_n(α₁,…,α_n) measures the order of simultaneous polynomial approximation. Conjecture: For almost every real n-tuple, the exact identity ω_n = n holds, with an exceptional set of dimension 1; and the exceptional set is winning. (simultaneous exponent full-measure identity)

**中文。** 定义：多项式联立逼近指数 ω_n(α₁,…,α_n) 度量联立多项式逼近的阶。猜想：对几乎处处的实数组有精确等式 ω_n=n 且例外集的维数为 1；且例外集为赢集。（联立指数满测等式）
