# 00000004040

**English.** Definition: A finite component is an AR-component isomorphic to a Dynkin quiver. Conjecture: There exists a family of algebras with bounded representation dimension whose number of finite components is arbitrarily large, whereas for a fixed quiver the number of finite components is at most the number of vertices. (component count versus representation dimension separation)

**中文。** 定义：有限分量指同构于 Dynkin 箭图的 AR-分量。猜想：存在表示维数有界的代数族使有限分量个数任意大;而固定箭图时有限分量个数不超过顶点数。（分量个数-表示维数分离）
