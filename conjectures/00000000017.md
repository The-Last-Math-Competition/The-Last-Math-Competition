# 00000000017

**NT-17 ★** — source: 01_数论.md

**English.** Conjecture: Let R(p) denote the length of the longest run of consecutive quadratic residues mod p: (i) for all primes p, R(p) ≤ C·log p; (ii) for a density-one set of primes, R(p) ≤ log₂p + O(log log log p).

**中文。** 猜想：设 R(p) 为 mod p 最长连续二次剩余段的长度:(i) 对一切素数 p,R(p) ≤ C·log p;(ii) 对密度 1 的素数 p,R(p) ≤ log₂p + O(log log log p)。
