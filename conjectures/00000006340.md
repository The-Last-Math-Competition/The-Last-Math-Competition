**CM4-30 △** — source: 196_组合矩阵论III.md

**English.** Definition: The rigidity function and spectral rigidity are two layers. Conjecture: There exist two matrices with the same rigidity function but different spectral rigidity, and the separation is realized by an explicit orthogonal pair with the same rank changes but different eigenvalues. (same rigidity function-different spectral rigidity separation)

**中文。** 定义：刚性函数与谱刚性指两层。猜想：存在两矩阵的刚性函数相同而谱刚性不同,分离由同秩变更异特征值的显式正交对实现。（刚性函数同-谱刚性异分离）
