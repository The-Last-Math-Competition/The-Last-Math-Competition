# 00000001010

**FG-10 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: A perfect difference set of the affine plane AG(2,q) (D with neighbor balance). Conjecture: Perfect difference sets of AG(2,q) exist only when q ≡ 3 mod 4, and are then of Paley type (a classification of perfect difference sets).

**中文。** 定义：仿射平面 AG(2,q) 的完全差集(D(邻点平衡))。猜想：#AG(2, q) 的完全差集仅当 q ≡ 3 mod 4 且为 Paley 型(完全差集分类)。
