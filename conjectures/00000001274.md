# 00000001274

**English.** Definition: The spectrum of minimal-entropy mixing SFTs. Conjecture: The set of entropy values in [0, log 2] is closed, with isolated points only 0 and log φ (isolated points of the entropy spectrum).

**中文。** 定义：最小熵的 mixing SFT 的谱。猜想：熵值的集合在 [0, log 2] 为闭集,孤立点仅有 0 与 log φ(熵谱孤立点)。
