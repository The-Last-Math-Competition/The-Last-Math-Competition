# 00000001260

**English.** Definition: The factor complexity p(n) of a primitive substitution counts distinct factors of length n. Conjecture: The optimal upper bound is p(n) ≤ n+2 within the purely substitutive class, attained by three-letter substitution families beyond the Tribonacci word; p(n) = n+1 occurs only for Sturmian words.

**中文。** 定义：primitive 替换的因子复杂度 p(n) 指长度 n 的相异因子数。猜想：p(n) 的最优上界为 p(n) ≤ n+2(在纯替换类中),且该界由 Tribonacci 词以外的三字母替换族达到;p(n)=n+1 仅限 Sturmian。
