# 00000001742

**English.** Definition: The higher Hall problem concerns gaps between polynomial pairs of degree ≥ 4. Conjecture: For systems of type X⁴ ≈ Y⁵, the gap 0 < |X⁴−Y⁵| < X^{3/4−ε} has infinitely many solutions with an explicit upper bound ε ≤ 1/20; systems of degree five and above no longer have positive-density asymptotic small gaps.

**中文。** 定义：高阶 Hall 问题指次数 ≥4 的多项式对的间隙问题。猜想：对 X^4≈Y^5 型系统,间隙 0<|X^4−Y^5|<X^{3/4−ε} 有无穷多解的 ε 显式上界为 1/20;五次以上系统不再有正密度的渐近小间隙。
