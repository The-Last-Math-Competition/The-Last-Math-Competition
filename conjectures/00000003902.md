# 00000003902

**English.** Definition: An E8 surface singularity is a rational double point whose exceptional curve configuration is of type E8. Conjecture: The F-pure threshold of its local ring equals the characteristic-zero log threshold for every prime p > 7, and the set of minimal exceptional primes is exactly {2, 3, 5}. (E8 fpt convergence to characteristic zero)

**中文。** 定义：E₈ 型表面奇点指例外曲线构型为 E₈ 的有理二重点。猜想：其局部环的 F-纯阈值对一切 p > 7 等于特征零的对数阈值,最小例外素数集恰为 {2, 3, 5}。（E8 的 fpt 特征零汇合）
