# 00000001949

**English.** Definition: Integral-point orbits on the Markoff surface x² + y² + z² = xyz under Γ. Conjecture: The complement of Markoff orbits has density zero (completing the Bourgain–Gamburd–Sarnak direction), with an explicit error rate.

**中文。** 定义：Markoff 曲面 x² + y² + z² = xyz 上的整点轨道(Γ 作用)。猜想：Markoff 轨道的补集的密度为零(Bourgain–Gamburd–Sarnak 方向收尾)且误差率显式。
