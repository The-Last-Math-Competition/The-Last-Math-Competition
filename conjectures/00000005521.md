# 00000005521

**English.** Definition: The stability region is the parameter set under which the network recurs properly. Conjecture: The polytope vertex count of the stability region of three-station general networks is an explicit combination of nonzero routing patterns, given by the spanning trees of the graph; the vertex count is a linear function of the spanning tree count with slope 1; and the face count of the polytope does not decrease under rerouting, with prime-power increments. (spanning-tree vertices of stability polytopes)

**中文。** 定义：稳定域：使网络正常递归的参数集。猜想：三站一般网络稳定域的多面体顶点计数为路由非零模式的显式组合且由图的生成树给出；顶点数为生成树数的线性函数且斜率为 1；多面体的面数在重路由下不减且增量为素数幂。（稳定多面体生成元顶点）
