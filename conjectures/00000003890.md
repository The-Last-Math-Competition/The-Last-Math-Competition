# 00000003890

**CA3-10 △** — source: 115_交换代数III_正特征.md

**English.** Definition: The F-jumping number set of a fixed ideal is the set of all jump parameters of its test ideal. Conjecture: The jumping set of a fixed ideal is always finite; but there exist sequences of ideals on a fixed ring whose unions of jumping sets are dense in (0,1). (F-jumping finite-dense boundary)

**中文。** 定义：固定理想的 F-跳跃数集指其 test ideal 的全部跳跃参数。猜想：固定理想的跳跃数集恒有限;但存在固定环上的理想序列使各跳跃数集之并在区间 (0,1) 中稠密。（F-跳跃有限-稠密分界）
