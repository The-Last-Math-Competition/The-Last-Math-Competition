# 00000009785

**English.** Definition: Characteristic function models of contractions: function models of Sz.-Nagy-Foias theory. Conjecture: Pure point criterion for the spectra of Blaschke-Potapov factors of characteristic functions: pure point if and only if the deficiency sequence of the factor satisfies the Carleson condition; the criterion is finitely verifiable when deficiencies are uniformly bounded. (characteristic function pure point criterion)

**中文。** 定义：压缩的特征函数模型：Sz.-Nagy–Foiaş 理论的函数模型。猜想：特征函数的 Blaschke–Potapov 因子的谱的纯点判据：纯点当且仅当因子的亏数序列满足 Carleson 条件；判据在亏数一致有界时有限验证。（特征函数纯点判据）
