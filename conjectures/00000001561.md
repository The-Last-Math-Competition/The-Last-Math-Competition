# 00000001561

**English.** Definition: The spherical diametric problem asks for the maximal measure of a subset of S² with pairwise spherical distances at most π/2. Conjecture: The extremal set is a closed hemisphere; the second-extremal set is the angle-bisector cap of an isosceles spherical triangle, with measure ratio 3/4 to the hemisphere.

**中文。** 定义：球面等径问题指 S² 上两两球面距离 ≤π/2 的点集的最大面积。猜想：极值集为闭半球;第二极值集为等腰球面三角的角平分帽,其测度与半球测度之比为 3/4。
