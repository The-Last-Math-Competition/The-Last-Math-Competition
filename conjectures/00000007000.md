# 00000007000

**English.** Definition: Box norms and scattering spectra are two layers. Conjecture: There exist two functions with identical box norms but different scattering spectra, and the separation is realized by an explicit permutation pair with the same norms but different phase. (same box norms-different scattering permutation separation)

**中文。** 定义：箱范数与散射谱指两层。猜想：存在两函数的一切箱范数相同而散射谱不同,分离由同范数异相位的显式置换对实现。（箱范数同-散射异置换分离）
