# 00000002792

**English.** Definition: Order-finite treeability of Banach spaces: combinatorial control of block trees. Conjecture: The bounded tree property: a space contains no ℓ₁ if and only if the tree index is bounded, with the upper bound of the tree index a linear function of cotype. (bounded tree index cotype law)

**中文。** 定义：Banach 空间的序有限树性：块树的组合控制。猜想：有界树性质：空间不含 ℓ₁ 当且仅当树指数有界且树指数的上界为 cotype 的线性函数。（有界树指数 cotype 律）
