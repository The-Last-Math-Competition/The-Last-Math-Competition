# 00000008477

**English.** Definition: The geometry of the zero set (equilibrium set) of the large deviation rate function I(nu) of empirical measures. Conjecture: The zero set is connected, compact, and convex (a connectivity law); a sufficient condition for the zero set to be finite is strict convexity of the pressure function (a strict convexity criterion); the number of equilibrium states is bounded by the number of locked periodic orbits (a periodic upper bound law); and the Lipschitz constant of Hausdorff continuity of the equilibrium set under observable perturbations is controlled by the second derivative of the pressure (a pressure constant law). (equilibrium zero set connectivity pressure control)

**中文。** 定义：经验测度的大偏差速率函数 I(ν) 的零集（平衡态集）的几何。猜想：零集为连通紧凸集（连通律）；且零集有限的充分条件为压力函数严格凸（严格凸判据）；平衡态个数的上界为锁定周期轨道数（周期上界律）；平衡态集关于观测扰动的 Hausdorff 连续性的 Lipschitz 常数由压力的二阶导数控制（压力常数律）。
