# 00000000916

**English.** Definition: The UCT (universal coefficient theorem) asserts that nuclear C*-algebras admit a six-term exact sequence under KK functors. Conjecture: UCT for all nuclear algebras reduces to verification for a black-box algebra C in a separable bootstrapping class: the connecting sum of C with O₂ satisfies UCT; this reduction turns the UCT problem into an explicit check on finitely generated algebras.

**中文。** 定义：UCT(普适系数定理)断言核 C*-代数在 KK 筆数下有六项正合列。猜想：UCT 对一切核代数成立可归约为对满足可分 bootstrapping 类的黑箱代数 C 的验证:C 与 O₂ 的连接和满足 UCT;该归约把 UCT 问题化为有限生成代数的显式检查。
