# 00000002272

**MG-12 ★** — source: 61_鞅与随机分析.md

**English.** Conjecture: Beyond the (known) uniqueness theorem for the inverse problem of the Brownian signature: the minimal reconstruction path length from the first k levels of the signature is explicit of the (k−1)! type (signature reconstruction length).

**中文。** 猜想：Brown 签名的逆问题的唯一性定理(已知)之外的:签名的前 k 层的最小重构路径长度为 (k − 1)! 型显式(签名重构长度)。
