# 00000008570

**NSP-10 ★** — source: 271_非自伴算子与无限图谱.md

**English.** Definition: Local constancy of the Fredholm index in the norm topology. Conjecture: The index is constant on every connected component of the Fredholm domain (a constancy law); the complete classification of components is given by index plus essential spectrum (a classification law); the descent constant of the index in the family version is 1 (a unit descent law); and the topological index equals the analytic index for families (an Atiyah-Singer family law). (Fredholm index component classification)

**中文。** 定义：Fredholm 算子的指标在范数拓扑下的局部常值性。猜想：指标在 Fredholm 域的每个连通分量上恒定（常值律）；且分量的完全分类由指标加本质谱给出（分类律）；族版本的指标下降常数为 1（单位下降律）；族的拓扑指标与解析指标的相等（Atiyah–Singer 族律）。
