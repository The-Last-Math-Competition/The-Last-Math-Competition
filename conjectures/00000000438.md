# 00000000438

**English.** Definition: The copying structure of noncommutative symmetric functions Sym. Conjecture: As a coalgebra, the primitive Lie algebra of Sym is isomorphic to the generalized Lie n-algebra, whose n-th homogeneous dimension equals the Eulerian number A(n, 1) (verifiable for n ≤ 10).

**中文。** 定义：非交换对称函数 Sym 的拷贝结构。猜想：Sym 作为余代数的本原李代数与广义 Lie n-代数同构,其第 n 齐次维数 = 欧拉数 A(n, 1)(可验证 n ≤ 10)。
