# 00000001096

**FG-96 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: The VC dimension of a function class is the maximal number of points it shatters. Conjecture: The VC dimension of polynomial functions of degree ≤ d over F_q^n is exactly n·d (for d < q); this value is realized explicitly by lexicographic supports of monomial coordinates x_1^{a_1}⋯x_n^{a_n}.

**中文。** 定义：函数类的 VC 维指可打散的最大点数。猜想：F_q^n 上次数 ≤ d 的多项式函数类的 VC 维恰为 n·d(对 d<q);该值由单项式坐标 x_1^{a_1}⋯x_n^{a_n} 的字典序支撑集显式实现。
