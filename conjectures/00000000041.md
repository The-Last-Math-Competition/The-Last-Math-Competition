# 00000000041

**AC-15 ★** — source: 02_组合数论与加性组合.md

**English.** Conjecture: The additive energy of the set of primes P_x = {p ≤ x} satisfies E(P_x) = (c+o(1))·x³/log⁴x, where c is the explicit constant given by the averaged Goldbach singular series.

**中文。** 猜想：素数集 P_x = {p ≤ x} 的加性能量满足 E(P_x) = (c+o(1))·x³/log⁴x,其中 c 为平均 Goldbach 奇异级数给出的显式常数。
