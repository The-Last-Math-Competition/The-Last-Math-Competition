# 00000000849

**English.** Definition: The singular set of the free boundary of the three-dimensional obstacle problem is the set of nonregular points. Conjecture: The singular set is a locally finite union of C¹ curves, each tangent direction uniquely determined by the rotational symmetry of the tangent cone; and the number of curves is at most the number of connected components of the rank-deficiency locus of the obstacle's Hessian.

**中文。** 定义：三维障碍问题自由边界的奇异集指非正则点的集合。猜想：奇异集为局部有限条 C¹ 曲线的并,且每条曲线的切向由切锥的旋转对称性唯一确定;曲线的个数不超过障碍函数 Hessian 的秩亏位置的连通分量数。
