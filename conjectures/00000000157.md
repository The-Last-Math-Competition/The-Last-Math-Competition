# 00000000157

**C2-04 ★** — source: 12_组合代数与几何II.md

**English.** Conjecture: Polyhedra with all-prime face data: there exist infinitely many 3-connected planar graphs for which every face size and every vertex degree lies in {3, 5} (the dodecahedron realizes the (5,3) type).

**中文。** 猜想：全素数面度的多面体:存在无穷多个 3-连通平面图,使所有面的边数与所有顶点度数都属于 {3, 5}(十二面体给出 (5,3) 型)。
