# 00000005594

**English.** Definition: A modular linear system is an integer-coefficient system with a modulus. Conjecture: The bit-length bound of solution generators is an explicit linear expression of the coefficient bit length, given by the successive minima of the solution lattice, and attained by extreme lattices. (successive-minima bit-length bound of modular solution lattices)

**中文。** 定义：模线性系统指带模的整系数方程组。猜想：解生成元的位长界为系数位长的显式线性式,由解格逐次极小给出且极端格达到。（模解格逐次极小位长界）
