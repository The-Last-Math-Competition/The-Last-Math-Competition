# 00000005950

**KZ2-30 △** — source: 183_KPZII.md

**English.** Definition: Symmetry groups and universal kernels are two layers. Conjecture: There exist two systems with the same symmetry group but different universal kernels, and the separation is realized by an explicit boundary-value problem pair with the same symmetry but different transport. (same symmetry-different kernel boundary-value separation)

**中文。** 定义：对称性与普适核指两层。猜想：存在两系统的对称群相同而普适核不同,分离由同对称异迁移的显式边值问题对实现。（对称群同-普适核异边值分离）
