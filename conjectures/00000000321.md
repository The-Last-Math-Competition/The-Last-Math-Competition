# 00000000321

**English.** Definition: For a set S of allowed partial quotients, M_S is the Markov spectrum of numbers using only partial quotients from S. Conjecture: There exists a three-element S for which M_S contains an interval; and the list of minimum-cardinality S with this property is completely enumerated up to symmetric difference. (three-symbol spectrum contains an interval)

**中文。** 定义：部分商限制集 S 生成的 Markov 谱 M_S 指仅用 S 中部分商的数的常数谱。猜想：存在三元素 S 使 M_S 含区间；且含区间的最小势 S 的列表为对称差的完全枚举。（三符号谱含区间）
