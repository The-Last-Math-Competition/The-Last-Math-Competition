# 00000008844

**English.** Definition: Firm nonexpansiveness of resolvent operators. Conjecture: Resolvent operators are always firmly nonexpansive; and their fixed point set is exactly the zero set of the monotone operator. (resolvent firm fixed points zeros)

**中文。** 定义：预解算子的 Firm 非扩张性。猜想：预解算子恒 Firm 非扩张；且其不动点集恰为单调算子的零点集。（预解 Firm 不动点零点）
