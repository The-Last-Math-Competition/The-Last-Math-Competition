# 00000007870

**English.** Definition: The spectral characterization of first passage for random processes: the generating function phi_A(z) = E[z^{T_A}] of the hitting time T_A of a target set A by a chain on a graph G started from the stationary distribution pi. Conjecture: phi_A(z) is rational, and for random d-regular graphs with random A of size alpha n the root set of its denominator converges in distribution to a log-normal root cloud with log-mean -d log(d-1) + log alpha; and the reciprocal of the dominant pole (smallest-modulus root) concentrates at -log(alpha) + c(d) with c an explicit combinatorial function of d, giving a full spectral explanation of the logarithmic first-passage asymptotics on large networks. (first-passage rational log-normal root cloud)

**中文。** 定义：随机过程首达的谱刻画：图 G 上从 π 出发的链在目标集 A 的首达时间 T_A 的生成函数 φ_A(z)=E[z^{T_A}]。猜想：φ_A(z) 为有理函数，其分母的根集合在随机 d-正则图与随机 A（|A|=αn）时依分布收敛为 log-normal 的根云，云的 log-均值为 -d·log(d-1)+log α；且主导极点（最小模根）的倒数集中在 -log(α)+c(d)（c 为 d 的显式组合式），给出大规模网络上首达时间对数渐近的全谱解释。
