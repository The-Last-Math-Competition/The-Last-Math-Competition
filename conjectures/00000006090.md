# 00000006090

**NC3-20 △** — source: 188_非凸数值优化.md

**English.** Definition: Asymptotic convergence and the finite-scale spectrum are two layers. Conjecture: There exist two algorithms with the same asymptotic convergence rate but different finite-scale behavior, and the separation is realized by an explicit step-size pair with the same limit but different pre-asymptotics. (same asymptotics-different finite-spectrum step-size separation)

**中文。** 定义：渐近收敛与有限尺度谱指两层。猜想：存在两算法的渐近收敛率相同而有限尺度行为不同,分离由同极限异预渐近的显式步长对实现。（渐近同-有限谱异步长分离）
