# 00000001392

**English.** Definition: The Kervaire-invariant-one problem asks in which dimensions n = 2^{j+1}−2 there exist elements of Kervaire invariant one (HHR excluded all j ≥ 7; j = 6, i.e. n = 126, remains open). Conjecture: Kervaire invariant one does not exist at n = 126; the exclusion is completed by an explicit nonzero computation of the d_{2^{6}−1} differential in the Adams spectral sequence at that element.

**中文。** 定义：Kervaire 不变量一的问题问哪些维数 n=2^{j+1}−2 存在 Kervaire 不变量为 1 的元素(HHR 已排除 j≥7 之外的一切,j=6 即 n=126 未决)。猜想：n=126 处 Kervaire 不变量一不存在;其排除由 Adams 谱序列中 d_{2^{6}−1} 微分在该元素的显式非零计算完成。
