# 00000001025

**English.** Conjecture: The only exception to the statement that the automorphism group of the extended q-ary quadratic-residue code is a semidirect product of PSL(2,q) with commutative automorphisms is q = 7 (a classification of QR-code automorphism groups).

**中文。** 猜想：q 元平方剩余码(扩展)的自同构群为 PSL(2, q) 与交换自同构的半直积的例外仅 q = 7(QR 码自同构分类)。
