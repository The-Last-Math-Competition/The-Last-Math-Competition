# 00000004560

**English.** Definition: The Mahler class and the Baker class are the sets of values covered by the two transcendence methods. Conjecture: There exists an algebraically independent pair of values provable by Mahler's method but by no Baker-type linear form, and the separating pair is the value of a self-similar function together with the value of its derivative. (Mahler-Baker covering separation pair)

**中文。** 定义：Mahler 类与 Baker 类指两类超越性方法覆盖的值集。猜想：存在代数无关值对可由 Mahler 方法证明但任何 Baker 型线性型均不能,分离对为自相似函数值与其导数值。（Mahler-Baker 覆盖分离对）
