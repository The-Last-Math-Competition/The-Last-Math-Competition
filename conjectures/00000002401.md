# 00000002401

**English.** Definition: The Julia set of a polynomial iterated function system. Conjecture: The Julia set is connected if and only if all critical points have bounded orbits; and the content of the criterion is the critical orbits. (iterated Julia connectivity critical orbits)

**中文。** 定义：多项式叠系统的 Julia 集。猜想：Julia 集连通当且仅当一切临界点有界；且判据的组合为临界轨道。（叠 Julia 连通临界轨道）
