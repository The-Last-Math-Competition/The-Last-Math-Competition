# 00000005410

**English.** Definition: The zeta function and the height structure are two layers. Conjecture: There exist two maps with the same dynamical zeta function but different canonical height structures, and the separation is realized by an explicit pair of product maps with the same periods but different heights. (same zeta-different height product-map separation)

**中文。** 定义：zeta 函数与高度结构指两层。猜想：存在两映射的动力 zeta 函数相同而典范高度结构不同,分离由同周期异高度的显式积映射对实现。（zeta 同-高度异积映射分离）
