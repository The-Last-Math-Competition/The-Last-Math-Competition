# 00000006309

**English.** Definition: The special-value identity links function values with group orders. Conjecture: The ratio of group order to value for totally real fields is the Tamagawa number; the table of the framework is complete; and the integrality of the Tamagawa number is divisibility by the class number of the totally real field. (complete Tamagawa framework of totally real fields)

**中文。** 定义：特殊值等式联系函数值与群阶。猜想：全实域的群阶与值之比为玉河数；且框架的表完全；且玉河数的整性为全实域的类数整除。（玉河数框架全实完全）
