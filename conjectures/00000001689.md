# 00000001689

**GT-29 ★** — source: 41_图论III.md

**English.** Definition: Measure trees (tree limits of graph limits). Conjecture: On the space of compact separable tree limits under the Gromov-weak topology, there exists an explicit metrizable distance together with a complete set of subtree-density functionals (complete functionals for tree limits); and the complete functional set is uniquely generated by subtree-counting densities.

**中文。** 定义：量度树形(measure tree,图极限的树极限)。猜想：紧可分树极限空间上的 Gromov-弱拓扑的可度量化的显式距离与子树密度泛函完备集(树极限完备泛函)；且完备泛函集由子树计数密度唯一生成。
