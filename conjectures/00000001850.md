# 00000001850

**English.** Definition: The maximum process of the Airy line ensemble is M(t) = max over Airy lines. Conjecture: Its upper fluctuations are t^{1/3}·(log t)^{2/3} (a logarithmic correction); a t^{1/3+ε} behavior is impossible — the maximal value of ε is 0 (rigidity is optimal).
