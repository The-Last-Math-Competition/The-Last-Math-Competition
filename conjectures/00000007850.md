# 00000007850

**RAM-10 ★** — source: 247_随机算法的概率分析.md

**English.** Definition: The error-bit exchange function R_epsilon(f) of randomized protocols in the communication complexity model. Conjecture: The randomized communication complexity of the composition f composed with g satisfies R(f composed with g) = Omega(R(f) log R(g)) (a product-type lower bound separating the critical gap between exponential and logarithmic factors); the bound is asymptotically tight for f the greater-than function and g the index function; and the bottleneck function deciding the separation is gap-Hamming, with structure constant the quadratic (1-2epsilon)^2 in epsilon. (composition lower bound via gap-Hamming)

**中文。** 定义：通信复杂度模型下随机化协议的错误-比特交换函数 R_ε(f)。猜想：f 与 g 的复合 f∘g 的随机通信复杂度满足 R(f∘g)=Ω(R(f)·log R(g))（乘积型下界分离指数与对数因子的临界间隙）；且该下界在 f=_gt（大于函数）、g=index 时渐近紧；判定分离的瓶颈函数为 gap-Hamming，其结构常数为 ε 的二次函数 (1-2ε)^2。
