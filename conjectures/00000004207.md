# 00000004207

**English.** Definition: The Tonelli class is the class of functions admitted by the parametric min-max. Conjecture: The class is closed under min-max if and only if it is contained in the functions of bounded variation; BV is the complete threshold and cannot be relaxed. (Tonelli BV completeness threshold)

**中文。** 定义：Tonelli 类指参数极小极大容许的函数类。猜想：类对极小极大闭合当且仅当类含于有界变差函数,BV 为完备阈值且不可放宽。（Tonelli BV 完备阈值）
