# 00000008182

**CNT-12 ★** — source: 258_计算数论.md

**English.** Definition: The difference brauer_gap(n) between the length l(n) of the shortest addition chain for an integer n and the length of the shortest Brauer chain. Conjecture: The infimum of brauer_gap is 0 with the density of zero-gap integers equal to 1, so the Brauer relation is almost always an identity; the smallest n with nonzero gap is 12509, a known rigidity; and the asymptotics of l(n) is explicitly expressed via log_2 n and the Hamming weight, with optimal correction constant 4/3. (Brauer gap 12509 four-thirds correction)

**中文。** 定义：整数 n 的最短加法链长度 l(n) 与最短星链长度的差记 brauer_gap(n)。猜想：brauer_gap 的下确界为 0 且无差素数密度为 1，Brauer 关系几乎恒等；且差非零的最小 n 为 12509，为已知刚性；l(n) 的渐近由 log₂n 与 Hamming 重量显式表达，最优修正常数为 4/3。
