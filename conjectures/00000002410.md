# 00000002410

**English.** Conjecture: There exists a measure on a 1/2-dimensional homogeneous Cantor set whose Fourier transform does not decay to zero (a fractal version of Rajchman counterexamples); the construction uses ×4-invariant (not ×2) blocking.

**中文。** 猜想：存在 1/2-维齐次 Cantor 集上的测度其 Fourier 变换不衰减到零(Rajchman 反例的分形版);构造由 ×4-不变性(非 ×2)的分块。
