# 00000000556

**English.** Definition: The centrality property π₀ of Hochschild cohomology HH^*(Λ). Conjecture: HH¹ = 0 if and only if Λ is representation-finite and rigid (a rigidity characterization by trivial center, verified for string algebras).

**中文。** 定义：Hochschild 上同调 HH^*(Λ) 的中心性质 π₀。猜想：HH¹ = 0 ⟺ Λ 为 representation-finite rigid(中心平凡性的刚性刻画,对 string 代数验证)。
