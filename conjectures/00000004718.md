# 00000004718

**EC4-28 ★** — source: 142_遍历论的组合_熵与计数.md

**English.** Definition: Combinatorial complexity is the function counting factors of length n. Conjecture: The attainable values of the first difference of the complexity form an explicit restricted set, the set over the low-complexity interval contains at most finitely many values, and the boundary is exact. (restricted set of complexity first differences)

**中文。** 定义：组合复杂度指长 n 因子的个数函数。猜想：复杂度一阶差的可达值为显式受限集,低复杂度区间的集合至多含有限个值且边界精确。（复杂度一阶差受限集）
