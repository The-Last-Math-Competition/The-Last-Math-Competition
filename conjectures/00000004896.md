**English.** Definition: Transfinite induction is the induction principle along ordinals, with effective domain in first-order arithmetic. Conjecture: The effective domain below epsilon_0 is explicitly indexed by termination sequence lengths, consistent with the proof-theoretic ordinal; the index length is strictly monotone under base changes of the Gamma_0 power tower; the induction schema for each ordinal alpha is provable if and only if the canonical embedding terminates, with termination proof length an elementary function of alpha. (termination-length index of transfinite induction)
