# 00000002609

**English.** Definition: Interval orders: the class forbidding 2+2 and 3+1 subposets. Conjecture: The edge-count upper bound of interval orders is a quarter of the square of the point count plus an integrality correction given by integer constraints on interval lengths; the tightness of the bound is attained by unit interval graphs. (interval order edge bound)

**中文。** 定义：区间序：禁止 2+2 与 3+1 子偏序的类。猜想：区间序的边数上界为点数平方的四分之一加整性修正且修正由区间长度的整约束给出；界的紧性由单位区间图达到。（区间序边数界）
