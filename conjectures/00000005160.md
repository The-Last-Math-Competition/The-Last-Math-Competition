# 00000005160

**English.** Definition: The period map and motives are two layers of invariants. Conjecture: There exist two varieties with the same period map but different motivic cohomology, and the separation is realized by an explicit pair with the same periods but different motives. (same period map-different motive separation pair)

**中文。** 定义：周期映射与母题指两层不变量。猜想：存在两簇的周期映射相同而母题上同调不同,分离由同周期异母题的显式对实现。（周期映射同-母题异分离对）
