# 00000005779

**IG2-09 ★** — source: 178_统计推断的几何_信息几何.md

**English.** Definition: The invariance classification is the transformation class preserving the metric. Conjecture: The two-dimensional classification is the explicit dichotomy of sufficient statistics, coordinate transformation or Markov embedding; the embedding preserves Fisher information if and only if the embedding is a function of sufficient statistics; and the image of a Markov embedding is an exponential family with invariant rank. (two-dimensional invariance dichotomy classification)

**中文。** 定义：不变性分类：保持度规的变换类。猜想：二维的分类为充分统计量的显式二择——坐标变换或马尔可夫嵌入；二择的分界由嵌入了保持 Fisher 信息当且仅当嵌人为充分统计量的函数；马尔可夫嵌入的像为指数族且族的秩不变。（二维不变性二择分类）
