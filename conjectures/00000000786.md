# 00000000786

**PA-86 ★** — source: 23_p进分析与局部域.md

**English.** Definition: The p-adic weight space (weight polytope). Conjecture: The interior of the weight polytope W(ρ) is nonempty if and only if ρ is crystal ball-admissible (a nonemptiness criterion for the weight space).

**中文。** 定义：p-adic 权空间(权多面体)。猜想：权多面体 W(ρ) 的内部非空 ⟺ ρ 为 crystal ball-admissible(权空间非空判据)。
