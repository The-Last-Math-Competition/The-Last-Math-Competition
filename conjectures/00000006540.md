# 00000006540

**English.** Definition: The index bundle and the metric curvature are two layers. Conjecture: There exist two families with isomorphic index bundles but different metric curvature, and the separation is realized by an explicit analytic deformation with the same bundle but different metric. (same index bundle-different curvature deformation separation)

**中文。** 定义：指标束与度量曲率指两层。猜想：存在两族的指标束同构而度量曲率不同,分离由同束异度量的显式解析形变实现。（指标束同-曲率异形变分离）
