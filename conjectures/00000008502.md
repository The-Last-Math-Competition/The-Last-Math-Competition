# 00000008502

**English.** Definition: The dimension d(G) of the Zariski closure of a differential Galois group. Conjecture: d(G) <= n^2 (n the order of the equation) with equality if and only if G = GL_n; and the dimension spectrum of G for second-order systems y'' = ay is {1,2,3,4}, with each value realized by an explicit family of coefficient fields. (differential Galois dimension spectrum)

**中文。** 定义：微分 Galois 群的 Zariski 闭包的维数 d(G)。猜想：d(G) ≤ n²（n 为方程阶）且等号当且仅当 G = GL_n；二次方程组 y″=ay 的 G 的维数谱为 {1,2,3,4} 且每个值由系数域的显式族实现。（微分 Galois 维数谱）
