# 00000000691

**KT-91 ★** — source: 22_纽结与低维拓扑.md

**English.** Definition: A pseudo-diagram is a knot diagram without over-under information. Conjecture: The least over-under information by which a pseudo-diagram determines the knot type is logarithmic in the crossing number; and the window is an information-theoretic lower bound. (pseudo-diagram information-theoretic log window)

**中文。** 定义：伪图为无过欠信息的纽结图。猜想：伪图决定纽结型的最少过欠信息为交叉数的对数；且窗的组合为信息论下界。（伪图信息论对数窗）
