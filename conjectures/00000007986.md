# 00000007986

**English.** Definition: The symmetry and covering depth of codes: the relation between the covering radius rho(C) and length n for codes with 2-transitive automorphism group. Conjecture: rho(C) <= n - sqrt(n d) for codes with nontrivial 2-transitive automorphism group (a covering-distance square-root law); equality is attained by Reed-Solomon type affine group codes; the number of orbits on the covering shell equals the rank of the 2-transitive group (orbit-rank correspondence), and the count of codewords on shells is given by the spherical design strength t of the orbit: the shell is a t-(n,w,lambda) design if and only if the group is t-transitive (a transitivity criterion for design strength). (2-transitive covering shell designs)

**中文。** 定义：码的对称性与覆盖深度：自同构群为 2-传递的码的覆盖半径 ρ(C) 与长 n 的关系。猜想：非平凡 2-传递自同构群的码的 ρ(C) ≤ n - √(n·d)（覆盖-距离平方根律）；且等号由 Reed–Solomon 型仿射群码取得；覆盖球壳的轨道数恰为 2-传递群的秩（轨道-秩对应），壳上码字数的计数由轨道的球面设计强度 t 给出：壳为 t-(n,w,λ) 设计的充分必要条件为群为 t-传递（设计强度的传递性判据）。
