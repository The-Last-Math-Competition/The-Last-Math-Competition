# 00000004450

**English.** Definition: The scaling function is the O'Connell-Warren deformation function of KPZ scale invariants. Conjecture: There exist two KPZ systems with the same scaling function but different multipoint distribution kernels, and the separation is realized by the log-gamma and beta-Whittaker polymers. (scaling-kernel separation by a polymer pair)

**中文。** 定义：标度函数指 KPZ 尺度不变量的 O'Connell–Warren 形变函数。猜想：存在两个 KPZ 系统的标度函数相同而多点分布核不同,分离由 log-gamma 与 beta-Whittaker 聚合物实现。（标度-核分离聚合物对）
