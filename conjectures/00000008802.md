# 00000008802

**English.** Definition: The black-box first-order model: an oracle accessing only function values and gradients. Conjecture: The optimal first-order complexity for composite (smooth plus simple convex) problems is epsilon^{-1/2} (a square-root law); the optimal algorithm is unique, characterized by a difference equation (a characterization law); nonsmooth problems (mirror descent) require epsilon^{-1} (a reciprocal law); and structured (simple structured term) problems retain the intermediate epsilon^{-1/2} (a retention law). (black-box first-order square-root uniqueness)

**中文。** 定义：黑盒一阶模型：仅访问函数值与梯度的预言机。猜想：复合（光滑+简单凸）问题的最优一阶复杂度为 ε^{-1/2}（平方根律）；且最优算法的唯一性（差分方程刻画）的（刻画律）；非光滑的（镜面下降的）ε^{-1} 的（倒数律）；结构化（结构简单项的）的中间 ε^{-1/2} 的保持（保持律）。
