# 00000002045

**AD-25 ★** — source: 53_加性数论II.md

**English.** Definition: A digit-sum prime pair is an n for which s(n) and s(n+1) are both prime. Conjecture: There exist infinitely many n with s(n) and s(n+1) simultaneously prime; the counting asymptotics is c·x/(log x)² (with c computed from the local densities of digit-sum distributions).

**中文。** 定义：数字和素对指 s(n) 与 s(n+1) 皆为素数的 n。猜想：存在无穷多 n 使 s(n) 与 s(n+1) 同时为素;计数渐近为 c· x/(log x)^2(c 由数字和分布的局部密度计算)。
