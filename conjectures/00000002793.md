# 00000002793

**English.** Definition: Interpolation rigidity of Kalton–Werner spaces: the type spectrum of intermediate spaces. Conjecture: Convexity of the type spectrum of interpolation pairs: the type index is convex along the interpolation scale, with convexity constant controlled by the symmetric difference of the K-functional. (interpolation type spectrum convexity)

**中文。** 定义：Kalton–Werner 空间的插值刚性：中间空间的型谱。猜想：插值对的型谱的凸性：型指标在插值尺度上为凸函数且凸性的常数由 K-泛函的对称差控制。（插值型谱凸性）
