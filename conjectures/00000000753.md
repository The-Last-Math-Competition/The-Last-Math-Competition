# 00000000753

**English.** Definition: Coefficients of polynomials with Lipschitz constant 1. Conjecture: The number of polynomials with coefficients satisfying |a_i|_p ≤ p^{−i} termwise is a count of the explicit form p^{i(i+1)/2} (an exact counting formula).

**中文。** 定义：Lipschitz 常数 1 的多项式的系数。猜想：系数逐项满足 |a_i|_p ≤ p^{−i} 的多项式个数为 p^{i(i+1)/2} 型计数(严格计数公式)。
