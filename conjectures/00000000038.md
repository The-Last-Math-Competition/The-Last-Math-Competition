# 00000000038

**AC-12 ★** — source: 02_组合数论与加性组合.md

**English.** Conjecture: For every δ > 0 there exists k(δ) such that any A ⊂ [N] of density at least δ contains k elements (nontrivially, allowing repeated choices) with Σxᵢ = Πxᵢ.

**中文。** 猜想：对每个 δ > 0 存在 k(δ),使得任何密度 ≥ δ 的 A ⊂ [N] 含 k 个元素(允许重复选取时非平凡)满足 Σxᵢ = Πxᵢ。
