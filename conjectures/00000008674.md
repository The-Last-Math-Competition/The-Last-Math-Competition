# 00000008674

**English.** Definition: Gromov product characterization of word hyperbolicity: delta-thin triangles. Conjecture: There is a polynomial algorithm for the optimal estimate of the thinness constant delta for a given generating set (a polynomial law); the optimal conversion between delta and hyperbolic area is the linear delta <= C A (a linear conversion law); the certificate of non-hyperbolicity is of NP type (an NP type law); and the length of the shortest non-hyperbolicity certificate is polynomial (a polynomial evidence law). (thin triangle polynomial NP certificate)

**中文。** 定义：字 hyperbolicity 的 Gromov 乘积：δ-瘦三角。猜想：瘦常数 δ 的最优估计（给定生成集）的多项式算法（多项式律）；且 δ 与双曲面积的最优换算（换算律）为 δ ≤ C·A 的（线性换算律）；双曲性判定的（非双曲的证书）的证书的 NP 型（NP 型律）；证书的长度（最短非双曲证据）为多项式的（多项式证据律）。
