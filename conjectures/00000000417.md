# 00000000417

**SA-17 ★** — source: 20_代数组合与对称函数.md

**English.** Definition: The shifted hook walk is the Greene–Nijenhuis–Wilf algorithm on shifted Young diagrams (uniformly choosing a shifted cell and removing it). Conjecture: Its normalized occupation density converges to a limit shape whose boundary is given parametrically by x = c₁(e^u−1), y = c₂(e^{−u}−1) with c₁c₂ = 1/2; the deviation from the unshifted Vershik–Kerov curve is an explicit translation.

**中文。** 定义：移位钩行走指在移位 Young 图上的推广 Greene–Nijenhuis–Wilf 算法(均匀选择移位格并移去)。猜想：其归一化占据密度收敛到极限形状,该形状的边界由参数方程 x = c₁(e^u−1),y = c₂(e^{−u}−1) 给出,常数 c₁c₂ = 1/2;与未移位 Vershik–Kerov 曲线的偏差为显式平移。
