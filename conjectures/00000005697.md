# 00000005697

**TW2-17 ★** — source: 175_范畴的表示_2表示论.md

**English.** Definition: A class function is conjugation-invariant. Conjecture: In two dimensions it is indexed doubly by conjugacy classes with centralizer representations, complete, and the combination of the index is the class sum. (double-index class sums of class functions)

**中文。** 定义：类函数为共轭不变的函数。猜想：二维时由共轭类与中心化子表示的二重索引给出且完全；且索引的组合为类和。（类函数二重索引类和）
