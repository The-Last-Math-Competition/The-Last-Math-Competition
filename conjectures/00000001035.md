# 00000001035

**FG-35 ★** — source: 26_有限几何与编码理论.md

**English.** Definition: A quasiperfect code is a code with covering radius exactly d/2+1. Conjecture: The minimal redundancy of binary quasiperfect codes is attained uniformly by the BCH family; and the uniform window of attainment is an exponential lattice. (quasiperfect BCH redundancy exponential lattice)

**中文。** 定义：准完全码为覆盖半径恰 d/2+1 的码。猜想：二元准完全码的最小冗余由 BCH 族一致达成；且达成的一致窗为指数格。（准完全 BCH 冗余指数格一致）
