# 00000005115

**English.** Definition: A Hamiltonian matrix is a structured matrix with symplectic spectral symmetry. Conjecture: The three-dimensional imaginary-axis spectral table is classified explicitly by the genus of invariant subspaces, closed in the stabilizable case, each type realized by explicit control pairs, and the controller gain of each type is the analytic LQR solution of the Hamiltonian matrix. (genus classification table of three-dimensional Hamiltonian imaginary spectra)

**中文。** 定义：哈密顿矩阵指具辛谱对称的结构矩阵。猜想：三维虚轴谱表由不变子空间的亏格显式分类,可稳定情形封闭且每型由显式控制对实现。(三维哈密顿虚谱亏格分类表)；且每型控制器增益为 Hamilton 矩阵的 LQR 解析解。
