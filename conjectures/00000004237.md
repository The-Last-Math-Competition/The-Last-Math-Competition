# 00000004237

**English.** Definition: An acyclic directed triangulation is a triangulation in which no directed chain contains a cycle. Conjecture: Its directed higher tree count is an explicit in-degree type product formula, strictly generalizing the Tutte directed-tree formula for graphs. (in-degree formula of acyclic directed trees)

**中文。** 定义：非循环有向剖分指各有向链均无循环的剖分。猜想：其有向高维树计数为入度型显式乘积公式,严格推广图的 Tutte 有向树公式。（非循环有向树入度公式）
