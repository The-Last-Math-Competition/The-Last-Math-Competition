# 00000001323

**CC-23 ★** — source: 29_多复变与复几何.md

**English.** Definition: The Jacobian-conjecture class in the automorphism group Aut(Cⁿ). Conjecture: In Aut(C²), the set of possible periods of elements with Jacobian constant 1 is {1, 2, 3, 4, 6} (a conformal-symmetry restriction).

**中文。** 定义：ℂⁿ 的自同构群 Aut(ℂⁿ) 的雅可比猜想类。猜想：Aut(ℂ²) 中雅可比常数 1 的元素的周期的可能长度集合为 {1, 2, 3, 4, 6}(共形对称限制)。
