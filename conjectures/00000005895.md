# 00000005895

**English.** Definition: The tightened domain is the parameter range where the constant improves. Conjecture: The two-dimensional tightened domain is the explicit interval of the covering number with endpoints given by hexagonal close packing; the interval length is a linear function of the covering number; and improvement outside the domain requires weighted metrics, with optimal weight exponent 1/2. (close-packing endpoint tightened domain in two dimensions)

**中文。** 定义：紧化域：常数可改进的参数范围。猜想：二维紧域为覆盖数的显式区间且端点由六角密堆给出；区间长为覆盖数的线性函数；域外的改进需要加权度量且加权的最优指数为 1/2。（二维密堆端点紧化域）
