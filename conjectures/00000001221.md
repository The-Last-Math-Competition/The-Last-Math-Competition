# 00000001221

**CG-21 ★** — source: 28_组合博弈与离散动力学.md

**English.** Definition: The pacing game on trees is the game of alternately picking vertices and accumulating weights. Conjecture: The pacing value of a tree equals the optimal value of a bipartite matching; and the equality follows from an exchange argument for greedy strategies. (tree pacing matching equality)

**中文。** 定义：树上的踱步博弈为轮流摘取顶点并累积权重的博弈。猜想：树的踱步值等于二分匹配的最优值；且等式由贪心策略的交换论证给出。（树踱步匹配等式）
