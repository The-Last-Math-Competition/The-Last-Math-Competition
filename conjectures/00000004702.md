# 00000004702

**EC4-12 ◆** — source: 142_遍历论的组合_熵与计数.md

**English.** Definition: A multiplier set is a set whose difference set falls into its multiple structure. Conjecture: The optimal exponent of quantitative recurrence is an explicit function of the smallest element of the difference set, given by the threshold of weighted pseudorandomness and not improvable. (optimal exponent function of multiplier recurrence)

**中文。** 定义：乘子集合指差集落入其倍数结构的集合。猜想：定量回归的最优指数为差集最小元的显式函数,函数由权伪随机的阈值给出且不可改进。（乘子回归最优指数函数）
