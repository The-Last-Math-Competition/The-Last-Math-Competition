# 00000004424

**English.** Definition: The random six-vertex model is the random configuration model satisfying the ice rule, and the height function is its configuration accumulation. Conjecture: Its deterministic limit is the entropy solution class of an Euler-type hyperbolic equation, and the Riemann invariants of the solution class are explicit functions of the vertex weights. (six-vertex Euler Riemann invariants)

**中文。** 定义：随机六顶点模型指满足冰规则的随机配位模型,高度函数指其配位累积。猜想：其确定性极限为 Euler 型双曲方程的熵解类,解类的黎曼不变量为顶点权的显式函数。（六顶点 Euler 黎曼不变量）
