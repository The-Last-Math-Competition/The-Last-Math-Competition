# 00000001687

**English.** Definition: τ_n is the fraction of the minimum feedback arc set of the random tournament. Conjecture: τ_n concentrates around ν − Θ(n^{-1/2}), where ν is the Fourier ordering constant; the phase-transition window width is exactly c·n^{-1/2} with c = √(2π/3) explicit.

**中文。** 定义：随机 tournament 的最小反馈弧集的比例 τ_n。猜想：τ_n 集中于 ν−Θ(n^{-1/2}),ν 为 Fourier 排序常数;相变窗口宽度恰为 c·n^{-1/2},c=√(2π/3) 显式。
