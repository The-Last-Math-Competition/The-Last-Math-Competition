# 00000009688

**English.** Definition: The common zero set of two algebraic-coefficient exponential polynomials: intersection theory of exponential polynomials. Conjecture: The number of common zeros is an explicit function of the intersection of the two exponent sets; when the intersection is empty, an explicit zero-separation constant exists and is given by a Bezout-type inequality. (exponential polynomial intersection bound)

**中文。** 定义：两个代数系数指数多项式的公共零点集：指数多项式的相交理论。猜想：公共零点个数为两组指数集合的交的显式函数；交为空集时零点分离的显式常数存在且可由 Bezout 型不等式给出。（指数多项式相交界）
