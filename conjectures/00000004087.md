# 00000004087

**English.** Definition: A fractional-order system is a system whose derivative order alpha lies between 0 and 2. Conjecture: The stability boundary of the fractional Hopf bifurcation in the frequency-order plane is an explicit curve, the phase-angle constant is alpha pi / 2, and the boundary coincides with the Matignon criterion. (stability angle formula of the fractional Hopf bifurcation)

**中文。** 定义：分数阶系统指导数阶 α 介于 0 与 2 的系统。猜想：分数阶 Hopf 的稳定边界在频率-阶平面上为显式曲线,相角常数为 απ/2,边界与 Matignon 判据重合。（分数 Hopf 稳定角公式）
