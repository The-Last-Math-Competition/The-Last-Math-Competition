# 00000001971

**MP-11 ◆** — source: 51_数理物理.md

**English.** Definition: A unitary VOA is a vertex operator algebra with a positive-definite Hermitian form. Conjecture: The list of superconvergent subclasses with central charge between one and twenty-five is finite; and the table contains all examples with c below one, beyond tensor products. (superconvergent VOA finite list)

**中文。** 定义：酉 VOA 指具正定 Hermitian 型的顶点算子代数。猜想：中心荷在一与二十五之间的超收敛子类列表有限；且表中包含一切 c 小于一的张量积之外的例。（超收敛 VOA 有限列表）
