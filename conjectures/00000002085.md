# 00000002085

**SY-05 ★** — source: 55_辛几何与镜像对称.md

**English.** Definition: The symplectic ball packing function of a rational polytope is the maximal volume function of disjointly embedded balls. Conjecture: For high dimensions (n ≥ 5), the breakpoint set of the staircase structure of the packing function is finite; all breakpoints are an explicit list of rationals (exhausted by EHZ obstructions).

**中文。** 定义：有理多面体的辛球 packing 函数指内嵌不相交球的最大体积函数。猜想：高维(n≥5)的 packing 函数的阶梯结构的断点集有限;一切断点为有理数的显式列表(由 EHZ 障碍穷举)。
