# 00000000248

**English.** Definition: For an r-partite hypergraph, τ is the transversal number (minimum number of points covering all edges) and ν the matching number (maximum number of pairwise disjoint edges). Conjecture (Ryser, r = 4): τ ≤ 3ν for all 4-partite hypergraphs (the case r = 3 is proven by Aharoni; general r is open).

**中文。** 猜想：定义:r-部超图的横数 τ(覆盖所有边的最小点数)与匹配数 ν(两两不交边最大数)。猜想(Ryser, r = 4):τ ≤ 3ν 对一切 4 部超图(r = 3 已由 Aharoni 证明,一般 r 开放)。
