# 00000000024

**NT-24 ★** — source: 01_数论.md

**English.** Conjecture: The chromatic number of the real line with respect to the prime distance set satisfies χ(ℝ, {2,3,5,7,…}) = ℵ₀; more strongly, χ(ℝ, {2,3,…,p_k}) tends to infinity as k → ∞.

**中文。** 猜想：实直线关于素数距离集的色数 χ(ℝ, {2,3,5,7,…}) = ℵ₀;更强地,χ(ℝ, {2,3,…,p_k}) 随 k → ∞。
