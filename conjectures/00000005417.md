# 00000005417

**HM2-07 ◆** — source: 166_分析II_调和测度.md

**English.** Definition: The attainable dimension domain is the set of possible measure dimensions. Conjecture: The attainable domain of multiply connected planar domains is an explicit characterization between one and two, the lower end attained by simply connected domains, the upper end approached by nested slit sequences, with no holes. (characterization of the multiply connected dimension domain)

**中文。** 定义：维数可达域指可能的测度维数集合。猜想：多连通平面域的可达域为一到二之间的显式刻画,下端由单连通达到,上端由嵌套裂隙序列渐近达到且无空洞。（多连通维数可达域刻画）
