# 00000000741

**English.** Definition: Let n(p) denote the number of periodic points (counting distinct periodic orbits) of f(x) = x² on Z_p. Conjecture: For a density-one set of primes, n(p) = 3 (the fixed points 0, 1 and −1); the exceptional primes (with extra periodic points) have count ≤ x^{1/2+ε}, and all exceptions are characterized by p² − 1 containing large power factors.

**中文。** 定义：f(x)=x² 在 Z_p 上的周期点个数(计相异周期轨道点)记 n(p)。猜想：对密度 1 的素数集,n(p)=3(不动点 0,1 与 −1);例外素数(存在附加周期点)的计数 ≤ x^{1/2+ε},且全部例外由 p²−1 含大幂因子刻画。
