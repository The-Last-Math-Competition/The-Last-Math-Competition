# 00000004187

**English.** Definition: The width spectrum difference Delta_p is W_{p+1} - W_p. Conjecture: Delta_p > 0 always holds on every closed manifold, and the limit inferior of Delta_p is zero if and only if the manifold admits countably infinitely many pairwise disjoint minimal hypersurfaces. (positive width differences and the disjoint-family criterion)

**中文。** 定义：宽度谱差 Δ_p 指 W_{p+1} − W_p。猜想：一切闭流形上 Δ_p > 0 恒成立,且 Δ_p 的下极限为零当且仅当流形容纳可数无穷个两两不交的极小超曲面。（宽度正差与不交族判据）
