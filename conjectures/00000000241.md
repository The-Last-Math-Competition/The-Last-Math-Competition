# 00000000241

**GE-10 ◆** — source: 15_图与极值参数.md

**English.** Definition: The illumination number of a convex body K is the least number of directions such that every boundary point is "illuminated" by some direction. Conjecture (Levi): Every n-dimensional convex body has illumination number at most 2ⁿ (equivalent to a Borsuk-type covering bound 2ⁿ; known for n = 2).

**中文。** 猜想：定义:凸体 K 的照明数:使每点被某方向"照亮"的最小方向数。猜想(Levi):每个 n 维凸体的照明数 ≤ 2ⁿ(等价于 Borsuk 型覆盖数 ≤ 2ⁿ;n = 2 已知)。
