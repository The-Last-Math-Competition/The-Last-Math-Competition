# 00000004021

**English.** Definition: A linear functional of the signature is a linear combination of the coordinates of the first N levels. Conjecture: For every Lipschitz functional there exists a linear functional of the first N levels approximating it uniformly with error C * N^{-1/2}, where the constant C is explicit and the order N^{-1/2} is optimal. (optimal N^{-1/2} signature approximation)

**中文。** 定义：签名的线性泛函指首 N 层坐标的线性组合。猜想：对 Lipschitz 泛函存在首 N 层线性泛函以误差 C·N^{−1/2} 一致逼近,常数 C 显式且阶 N^{−1/2} 最优。（签名逼近最优 N^{-1/2}）
