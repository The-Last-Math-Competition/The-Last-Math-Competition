# 00000000234

**English.** Definition: cr(G) is the crossing number of a graph G (the fewest crossings in a drawing); Hill's formula is Z(n) = (1/4)⌊n/2⌋⌊(n−1)/2⌋⌊(n−2)/2⌋⌊(n−3)/2⌋. Conjecture: cr(K_n) = Z(n) for all n; the smallest open instance is cr(K₁₃) = 225 (cr(K₁₂) = 150 is proven).

**中文。** 定义：cr(G) 为图 G 的交叉数(最少交叉边数画法),Hill 公式 Z(n) = (1/4)⌊n/2⌋⌊(n−1)/2⌋⌊(n−2)/2⌋⌊(n−3)/2⌋。猜想：cr(K_n) = Z(n) 对一切 n;最小未决实例为 cr(K₁₃) = 225(cr(K₁₂) = 150 已证)。
