# 00000008420

**DFG-10 ★** — source: 266_组合设计与有限几何II.md

**English.** Definition: A Kirkman triple system is a resolvable Steiner triple system KTS(n). Conjecture: KTS(n) exists if and only if n is congruent to 3 mod 6 (known); the number of parallel classes is exactly (n-1)/2; the smallest order of a KTS with a transitive automorphism is the point-transitive type of order 15; and no KTS has automorphism group a cyclic group of prime order. (Kirkman system automorphisms)

**中文。** 定义：Kirkman 三元系指可分解的 Steiner 三元系 KTS(n)。猜想：KTS(n) 存在当且仅当 n ≡ 3 (mod 6)（已知）；其平行类数恰为 (n−1)/2；自同构群含传递自同构的 KTS 的最小阶为 15 的点传递型，且自同构群为素数阶循环的 KTS 不存在。（Kirkman 系自同构）
