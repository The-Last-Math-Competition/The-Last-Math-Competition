# 00000000310

**DA-10 ★** — source: 19_丢番图逼近与度量数论.md

**English.** Definition: The absolutely badly approximable set Bad^abs consists of those x ∈ R² for which, uniformly over all unit vectors e ∈ S¹, there exists c(e) > 0 with ‖q(e·x)‖ > c(e)/q. Conjecture: Bad^abs has Hausdorff dimension 2 (full), and it is absolute winning, so its intersection with any full-dimensional Cantor set remains full-dimensional.

**中文。** 定义：绝对坏逼近集 Bad^abs 指对一切单位向量 e∈S¹ 一致地存在 c(e)>0 使 ‖q(e·x)‖>c(e)/q 的 x∈R² 全体。猜想：Bad^abs 的 Hausdorff 维数为 2(满维),且它是绝对赢集(absolute winning),从而与任意满维 Cantor 集的交仍满维。
