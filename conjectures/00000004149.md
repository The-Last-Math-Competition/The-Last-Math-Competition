**English.** Definition: A hybrid model is an inner model where HOD and the mice structure overlap. Conjecture: The regular measure count of a hybrid model is always given by an explicit value of a transfinite recursion; the counting function is closed at countable layers and has rational-type asymptotics. (regular measure count of hybrid models)

**中文。** 定义：混合模型指 HOD 与 mice 结构交叠的内模型。猜想：混合模型的正则测度计数恒由超穷递归的显式值给出；计数函数在可数层封闭且有理型渐近。（混合模型正则测度计数）
