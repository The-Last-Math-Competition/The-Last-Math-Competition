# 00000002017

**English.** Definition: The inverse source problem for the fractional Laplacian recovers a fractional-order source from boundary data. Conjecture: The recovery error for a Hölder-α source is an explicit power of the data error; and for nonlinear sources the exponent degenerates to the minimum of the two fractional orders. (inverse source Hölder recovery exponent)

**中文。** 定义：分数 Laplacian 的反源问题指由边界数据恢复分数阶源项。猜想：Hölder 指数 α 的源的恢复误差为数据误差的显式幂；且指数在非线性源时退化为两分数阶的最小值。（反源 Hölder 恢复指数）
