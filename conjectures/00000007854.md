# 00000007854

**RAM-14 △** — source: 247_随机算法的概率分析.md

**English.** Definition: The conflict graph of randomized incremental convex hulls: the total S_n = sum C_i of the conflict counts C_i (faces visible to the i-th inserted point). Conjecture: E[S_n] = Theta(n log n) with variance Theta(n), and a central limit theorem holds; on uniform spherical point sets E[S_n] = 2n log n + c_n n + O(log n), where c_n converges to gamma + 1/2 (gamma the Euler constant) convolved with the single-point spherical measure constant. (incremental hull conflict CLT)

**中文。** 定义：随机增量凸包的冲突图：插入第 i 点时的冲突数 C_i（新点可见的面数）的总和 S_n=ΣC_i。猜想：E[S_n] = Θ(n log n)，且方差为 Θ(n)，中心极限定理成立；在均匀球面点集上 E[S_n] = 2n log n + c_n·n+O(log n)，常数 c_n 收敛到 γ+1/2（γ 为 Euler 常数）与球面单点测度的卷积常数。
