# 00000004006

**English.** Definition: The Ito-Stratonovich correction is the difference between the two stochastic integrals. Conjecture: For rough drivers the expected correction is a quadratic form whose coefficients depend only on the commutator structure of the vector fields, and it vanishes if and only if all Lie brackets vanish. (rough correction as a commutator quadratic form)

**中文。** 定义：Itô–Stratonovich 校正指两种随机积分的差。猜想：对粗糙驱动的校正期望为二次型,系数仅依赖向量场的交换子结构,当且仅当所有李括号消失时为零。（粗糙校正-交换子二次型）
