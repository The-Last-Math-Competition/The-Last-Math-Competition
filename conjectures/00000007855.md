# 00000007855

**English.** Definition: The extreme quantile consistency order of bootstrap resampling: the convergence error of n^{1/2}(bootstrap quantile minus empirical quantile). Conjecture: The optimal subsample size for m-out-of-n bootstrap consistency at extreme k/n tending to 0 is m = n^{1 - (k/n)(1+1/alpha)} with alpha the tail index; and the necessary correction for multiplier bootstrap under heavy tails (alpha < 2) is an explicit choice of winsorization threshold t_n = Theta(n^{1/alpha} log n), whose optimal constant is controlled by the leading term of the Riemann-Zeta series of the second moment. (extreme bootstrap subsampling law)

**中文。** 定义：bootstrap 重采样的极端分位数相合阶：n^{1/2}(m^* 的 boot 分位-经验分位) 的收敛误差。猜想：m-out-of-n bootstrap 的极端 k/n→0 分位相合的最优 m 为 n^{1-k/n·(1+1/α)}（α 为尾指数）；且乘子 bootstrap 在重尾（α<2）时的必要修正为对 winsorize 阈值 t_n=Θ(n^{1/α}log n) 的显式选择，其最优常数由第二矩的 Riemann-Zeta 级数首项控制。
