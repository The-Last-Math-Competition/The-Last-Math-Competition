# 00000000218

**English.** Definition: The value of the generating function of the Euler numbers at a point. Conjecture: h(1/π) is transcendental; and the transcendence is settled through the window where the algebraic-base argument fails. (Euler algebraic-base failure window transcendence)

**中文。** 定义：Euler 数的母函数在一点的值。猜想：h(1/π) 为超越数；且超越的核为代数底论证失效窗。（Euler 代数底失效窗超越）
