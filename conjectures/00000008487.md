# 00000008487

**English.** Definition: The fractal structure of the set of locked functions: the codimension of the space of all locked functions on interval maps. Conjecture: The set of locked functions is Baire-large, i.e. dense G_delta, but Lebesgue measure zero (a coexistence law); its complement is a dense open set (a dense open complement law); the conjectured box dimension of the complement is 1/2 (a half-dimension conjecture law); and the current gap between upper and lower dimension bounds is a logarithmic factor (a logarithmic gap law). (locked function half-dimension logarithmic gap)

**中文。** 定义：锁定函数集的分形结构：区间映射上一切锁定函数组成的空间的余维数。猜想：锁定函数集为 Baire 意义巨大即稠密 G_delta 但 Lebesgue 零测（并存律）；其补集为稠密开集（稠密开补律）；补集的 box 维数的猜测值为 1/2（半维猜测律）；维数的上下界的当前间隙为对数因子（对数间隙律）。
