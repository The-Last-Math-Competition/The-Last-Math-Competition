# 00000000220

**English.** Definition: p is a Wieferich prime to base q if and only if q^{p−1} ≡ 1 (mod p²). Conjecture: There are infinitely many Wieferich primes to base 2; and for every prime p, there are infinitely many q-Wieferich primes for each base pair (p, q).

**中文。** 定义：p 为 Wieferich 素数(基 q)⟺ q^{p−1} ≡ 1 (mod p²)。猜想：基 2 的 Wieferich 素数无穷多;且对每对 (p, q) 素数对,存在无穷多 q-Wieferich 素数。
