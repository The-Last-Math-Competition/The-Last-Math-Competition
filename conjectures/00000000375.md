# 00000000375

**English.** Definition: The set L of Littlewood pairs consists of pairs for which the product-approximation lower bound is positive. Conjecture: dim_H(L) does not exceed one half; and the dimension compression of the inhomogeneous Littlewood set is controlled by spectral rigidity. (Littlewood set dimension compression)

**中文。** 定义：Littlewood 数对集合 L 为使乘积逼近下界为正的对。猜想：dim_H(L) 不超过二分之一；且非齐次 Littlewood 集的维数压缩由谱刚性控制。（Littlewood 集维数压缩）
