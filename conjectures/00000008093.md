# 00000008093

**FUS-13 ★** — source: 255_有限群与融合系统.md

**English.** Definition: The Lefschetz number of a fusion system: the integrality criterion for the Lefschetz number Lambda_p(f) of self-maps of |L|_p-hat. Conjecture: Lambda_p(f) is an integer with Lambda_p congruent to the local fixed count of f modulo p (a congruence criterion); the vanishing of Lambda_p is equivalent to p-divisibility of the local fixed count (a divisibility-vanishing equivalence); and the complexity of verifying the vanishing (local checking) is polynomial in the number of F-closed subgroups (a local polynomial verification law). (fusion Lefschetz congruence local verification)

**中文。** 定义：融合系统的 Lefschetz 数：|L|_p^ 的自映射的 Lefschetz 数 Λ_p(f) 的整数性判据。猜想：Λ_p(f) 为整数且 Λ_p ≡ (f 的局部不动计数 mod p)（同余判据）；且 Λ_p 的消没的充要条件为局部不动计数的 p-整除（整除-消没等价）；消没的可验证性（局部检查）的复杂度为 F-闭子群数的多项式（局部多项式验证律）。
