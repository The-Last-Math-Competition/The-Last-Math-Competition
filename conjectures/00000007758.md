# 00000007758

**ADY-08 △** — source: 244_算术动力系统.md

**English.** Definition: bounded: integer sequence a_0∈Z, a_{n+1}=f(a_n), f∈Z[x] -fold number ≥2 of integral point orbit. Conjecture: if f without real fixed point interval (namely real Julia set completely not connected), then integral point orbit is finite set, and and set O_f of body orbit satisfies density of orbit image set in [1,H] in of counting #{O_f∩[-H,H]} = O(H^{1/2+ε}); in particular x^2+1 is O(H^{-1/2}log H).

**中文。** 定义：整点轨道的有界性：整数序列 a_0∈Z, a_{n+1}=f(a_n)，f∈Z[x] 次数 ≥2。猜想：若 f 无实不动点吸引区间（即实 Julia 集完全不连通），则整点轨道为有限集，且全体整轨道的并集 O_f 满足计数 #{O_f∩[-H,H]} = O(H^{1/2+ε})；特别地 x^2+1 的整轨道像集在 [1,H] 内的密度为 O(H^{-1/2}log H)。
