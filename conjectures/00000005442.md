# 00000005442

**English.** Definition: Modular multiplication is multiplication with a modulus. Conjecture: Its conversion constant is an explicit linear combination of the complexity of integer multiplication, with constant two, attained by representation transforms. (representation-transform linear conversion of modular multiplication)

**中文。** 定义：模乘指带模数的乘法。猜想：其换算常数为整数乘法复杂度的显式线性组合,常数为二且由表示变换达到。（模乘表示变换线性换算）
