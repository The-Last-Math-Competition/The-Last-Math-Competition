# 00000003855

**English.** Definition: The cumulants κ_k(S_f) of linear eigenvalue statistics S_f = Σf(λ_i). Conjecture: For analytic f, the third cumulant satisfies κ₃ = K₃(f)/β² + O(β^{−3}), where K₃(f) is a β-independent explicit functional, nonnegative for convex f. (beta linear statistic third cumulant)

**中文。** 定义：线性特征值统计 S_f = Σf(λ_i) 的累积量 κ_k(S_f)。猜想：对解析 f,三阶累积量满足 κ₃ = K₃(f)/β² + O(β^{−3}),其中 K₃(f) 为与 β 无关的显式泛函且对凸 f 非负。（β-线性统计三阶累积）
