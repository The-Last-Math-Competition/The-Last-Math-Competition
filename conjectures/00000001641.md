# 00000001641

**English.** Definition: The Balmer spectrum of DM_gc(k) is its tensor-triangular prime-ideal spectrum. Conjecture: The topology of this spectrum is a stratified closure structure of p-adic points: the point set is {(p,n) : p prime, n ∈ Z}, with closure order (p,n) ⇝ (p,m) when n ≥ m, and (q,n) ⇝ (p,m) at p = q; the compatibility relations of the stratification are explicit.
