# 00000004392

**GL2-02 ◆** — source: 132_图极限与网络数学.md

**English.** Definition: A quasirandom graph is a graph whose subgraph densities reach the random values, and a test set is a family of properties giving an equivalent characterization. Conjecture: The minimal test set contains exactly the two properties of triangle density and signed four-point density; removing either one leaves a graph satisfying the remaining properties but not quasirandom. (minimal two-element quasirandom test set)

**中文。** 定义：拟随机图指子图密度达随机值的图,测试集指等价刻画的性质族。猜想：极小测试集恰含三角形密度与符号四点密度两条,删去任何一条均存在满足剩余性质的图但非拟随机。（拟随机极小二元测试集）
