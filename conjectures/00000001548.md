# 00000001548

**GM-08 ★** — source: 37_组合几何.md

**English.** Definition: Ordinary circles are circles passing through exactly 3 points. Conjecture: An n-point set that is not collinear or concyclic determines at least (1/4)n² − O(n) ordinary circles, with the extremal configuration of Böröczky type (a Dirac–Motzkin theorem for circles).

**中文。** 定义：ordinary circles(恰过 3 点的圆)。猜想：非共线非共圆 n 点集的 ordinary circles 至少 (1/4)n² − O(n) 且极值构型为 Böröczky 型(圆的 Dirac–Motzkin)。
