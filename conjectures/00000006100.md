# 00000006100

**NC3-30 △** — source: 188_非凸数值优化.md

**English.** Definition: The tangent-kernel spectrum and generalization behavior are two layers. Conjecture: There exist two network families with the same kernel spectrum but different generalization behavior, and the separation is realized by an explicit basis change with the same spectrum but different eigenfunctions. (same kernel spectrum-different generalization basis separation)

**中文。** 定义：切线核谱与泛化行为指两层。猜想：存在两网络族的核谱相同而泛化行为不同,分离由同谱异特征函数的显式基变换实现。（核谱同-泛化异基变换分离）
