**English.** Definition: Tensor rank decomposition: minimal sum decompositions of symmetric tensors. Conjecture: The value set of typical ranks: the typical rank set of random real symmetric tensors is a consecutive interval with endpoints given by dimension counts of Segre–Veronese varieties; positivity of the probability within the interval is decided by the existence of real points. (tensor typical rank interval)

**中文。** 定义：张量秩分解：对称张量的最少和分解。猜想：典型秩的取值集：随机实对称张量的典型秩集合为连续区间且区间端点由 Segre-Veronese 簇的维数计数给出；区间内取值概率为正的判据为实点的存在。（张量典型秩区间）
