# 00000003914

**English.** Definition: A manifold is monotone when the first Chern class is proportional to the symplectic class on H^2, and a monotonization deformation is a deformation making it monotone. Conjecture: A monotonization deformation exists if and only if the proportionality holds on H^2(pi_1); moreover in dimension four the monotonization deformation is unique up to symplectic isotopy. (monotonization deformation criterion)

**中文。** 定义：单调指第一 Chern 类与辛类在 H² 上成比例,单调化形变指化为单调的形变。猜想：单调化形变存在当且仅当该比例在 H²(π₁) 上成立;且四维时单调化形变在辛同痕意义下唯一。（单调化形变判据）
