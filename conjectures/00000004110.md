# 00000004110

**CG4-20 △** — source: 122_组合几何II_配置空间.md

**English.** Definition: Subdivision is the operation of inserting vertices on edges. Conjecture: There exist a graph and its proper subdivision whose configuration homologies are isomorphic for all n yet which are not homotopy equivalent already at n = 2, and the smallest example is the four-claw graph. (minimal subdivision-homotopy separation example)

**中文。** 定义：细分指在边上插入顶点的操作。猜想：存在图与其真细分使一切 n 的配置同调同构但 n = 2 时已不同伦等价,最小例为四爪图。（细分-同伦分离最小例）
