# 00000003888

**CA3-08 ★** — source: 115_交换代数III_正特征.md

**English.** Definition: The Hilbert–Kunz density function is the limit of relative eHK as a function of parameter x. Conjecture: The HK density function of a fixed ideal is piecewise linear with finitely many breakpoints; conversely, there exist explicit one-parameter ideal families whose breakpoint counts grow unboundedly. (HK breakpoint count double bound)

**中文。** 定义：Hilbert–Kunz 密度函数指相对 eHK 随参数 x 的极限函数。猜想：固定理想的 HK 密度函数分段线性且折点数有限;反之存在显式单参数理想族使折点数随参数无界增长。（HK 折点数的双界）
