# 00000006330

**English.** Definition: The determinant, permanent, and integrality type are three data layers. Conjecture: There exist two matrices with the same determinant and permanent but different integrality types, and the separation is realized by an explicit pair with the same values but different unimodular row transformations. (same determinant-permanent-different integrality separation)

**中文。** 定义：行列式永久与整型指三层数据。猜想：存在两矩阵的行列式与永久均相同而整型不同,分离由同值异幺模行变换的显式对实现。（行列式永久同-整型异分离）
