# 00000009543

**QIC-23 ★** — source: 303_量子信道容量.md

**English.** Definition: For arbitrarily varying channels AVC the state s is chosen by an adversary each use; when symmetrizable (there is a state distribution degenerating everything to symmetric noise) the deterministic capacity is zero, otherwise by Ahlswede's dichotomy it equals the random capacity. Conjecture: The symmetrizability criterion for quantum AVC is that the linear span of the state operator set contains the identity map; when not symmetrizable, deterministic capacity equals random capacity and equals the minimax coherent information formula, with symmetrization detonation cost quadratic in the state count, O(|S|^2). (AVC symmetrizability criterion)

**中文。** 定义：任意变化信道 AVC 的状态 s 由敌手每次选取；可对称化（存在状态分布使整体退化为对称噪声）时确定编码容量为零，否则由 Ahlswede 二分律等于随机容量。猜想：量子 AVC 的可对称化判据为状态算子集合的线性张成含恒等映射；不可对称化时确定容量与随机容量相等且等于极小极大相干信息公式，对称化引信代价为状态数平方 O(|S|²)。（AVC 对称化判据）
