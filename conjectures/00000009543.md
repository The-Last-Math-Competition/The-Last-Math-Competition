**QIC-23 ★** — source: 303_量子信道容量.md

**English.** Definition: state s of arbitrary changes channel AVC by every takes; can symmetrization (exists state distribution such that global degenerate is symmetric noise) when deterministic coding capacity is zero, otherwise by Ahlswede two equals random capacity. Conjecture: can symmetrization of quantity AVC is linear of state operator set is spanned contains identical map; not can symmetrization when deterministic capacity and random capacity are equal and equals minimax formula, symmetrization cost is state number square O(|S|²). (AVC symmetrization)

**中文。** 定义：任意变化信道 AVC 的状态 s 由敌手每次选取；可对称化（存在状态分布使整体退化为对称噪声）时确定编码容量为零，否则由 Ahlswede 二分律等于随机容量。猜想：量子 AVC 的可对称化判据为状态算子集合的线性张成含恒等映射；不可对称化时确定容量与随机容量相等且等于极小极大相干信息公式，对称化引信代价为状态数平方 O(|S|²)。（AVC 对称化判据）
