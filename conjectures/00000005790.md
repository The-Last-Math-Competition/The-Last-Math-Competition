# 00000005790

**English.** Definition: Divergence equivalence and generated geometry are two layers. Conjecture: There exist two divergences with the same equivalence class but non-isomorphic dual geometries, and the separation is realized by an explicit affine pair with the same divergence but different potentials. (same divergence-different geometry affine separation)
