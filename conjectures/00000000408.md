# 00000000408

**SA-08 ★** — source: 20_代数组合与对称函数.md

**English.** Definition: Decomposition numbers g(λ,μ,ν) (Kronecker coefficients of s_λ * s_μ). Conjecture: For λ = μ = ν of staircase shape, g is odd if and only if n is a triangular number (verifiable for n ≤ 20).

**中文。** 定义：分解数 g(λ,μ,ν)(Kronecker 系数 s_λ * s_μ)。猜想：对 λ = μ = ν =(阶梯形),g 为奇数当且仅当 n 为三角形数(已 n ≤ 20 可验证)。
