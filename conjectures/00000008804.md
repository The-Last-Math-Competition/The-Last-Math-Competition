# 00000008804

**English.** Definition: Conditional gradient (Frank-Wolfe): a projection-free method using linearized subproblems. Conjecture: The FW convergence rate is O(1/t) (a reciprocal law); the duality gap is explicit from subproblems (a subproblem law); the pairwise variant improves to O(1/t^2) (an improvement law); and the improvement domain is polytopal cases (a sufficiency law). (Frank-Wolfe reciprocal pairwise polytopal improvement)

**中文。** 定义：条件梯度（Frank–Wolfe）：线性化子问题的免投影方法。猜想：FW 的收敛率 O(1/t) 的（倒数律）；且间隙函数（duality gap）的显式的子问题的（子问题律）；加权的（pairwise 的）的 O(1/t²) 的改进（改进律）；改进的域（polytopal 的）的充分（充分律）。
