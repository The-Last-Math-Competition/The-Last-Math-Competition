**English.** Definition: Carleson embedding: measure satisfies Carleson when embedding bounded (quantity exact); matrix this open. Conjecture: matrix Carleson embedding bounded if and only if inequality family bounded; constant of matrix measure is constant and linear product of dimension and dimension factor not. (matrix Carleson characteristic)
