# 00000001367

**DS-07 ★** — source: 31_描述集合论与递归论.md

**English.** Definition: The Borel chromatic number of a Borel graph on a standard Borel space is the least number of colors in a Borel-measurable proper coloring. Conjecture: The Borel chromatic number of the Cayley graph of Z² (generators ±e₁, ±e₂) is exactly 5; the classical chromatic number is 4, but the Borel constraint forces one extra color.

**中文。** 定义：标准 Borel 空间上 Borel 图的 Borel 色数指 Borel 可测正常染色所需的最少色数。猜想：ℤ² 的 Cayley 图(生成元 ±e₁,±e₂)的 Borel 色数恰为 5;经典色数为 4,但 Borel 约束强制多一色。
