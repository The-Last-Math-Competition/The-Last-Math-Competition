# 00000005049

**FM2-29 ★** — source: 153_有限模型论.md

**English.** Definition: The minimal definitional extension adds the fewest new symbols to make the relations of the original structure definable. Conjecture: The minimal single-symbol extension is given by an explicit enumeration of rank-one invariants; the extension size is linear in the original structure with constant factor 2; and the extension is unique up to isomorphism if and only if the original structure is rigid. (enumeration of single-symbol minimal definitional extensions)

**中文。** 定义：最小可定义扩张：添加最少新符号使原结构关系可定义的覆盖。猜想：单符号情形的最小扩张由秩一不变量的显式枚举给出；扩张尺寸为原结构的线性且常数因子为 2；扩张在同构意义下唯一当且仅当原结构为刚性的。（单符号最小定义扩张枚举）
