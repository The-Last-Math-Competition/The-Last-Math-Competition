# 00000000498

**SA-98 ★** — source: 20_代数组合与对称函数.md

**English.** Definition: Watermelon paths are n nonintersecting lattice paths departing near a common start, sharing the endpoint structure; their count is W_n. Conjecture: W_n ~ c·4^{n²}·Γ(n/2+1)^{-2}·n^{1/4}, where c = 2^{1/12}·e^{3ζ'(−1)} is a MacMahon-type constant; this asymptotic follows from a tau-function saddle point.

**中文。** 定义：watermelon 路径指 n 条从同一起点附近出发、共用终点结构且互不相交的格路径,其计数记 W_n。猜想：W_n ~ c·4^{n²}·Γ(n/2+1)^{-2}·n^{1/4},其中 c = 2^{1/12}·e^{3ζ'(-1)} 为 MacMahon 型常数;该渐近由 τ-函数鞍点给出。
