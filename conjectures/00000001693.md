# 00000001693

**EG-03 ★** — source: 42_遍历论II.md

**English.** Definition: A nil-Bohr set B_{s,ε} is the recurrence set of a nilsequence of order ≤ s. Conjecture: Its Haar measure satisfies the lower bound m(B_{s,ε}) ≥ c_s·ε^{s(s+1)/2}; the polynomial decay exponent is exactly the triangular number T_s, given explicitly by a Lévka–Mozes type constant of the s-step nilflow.

**中文。** 定义：nil-Bohr 集 B_{s,ε} 指阶 ≤s 的 nil-序列的递归集。猜想：其 Haar 测度下界满足 m(B_{s,ε}) ≥ c_s·ε^{s(s+1)/2};多项式衰减指数恰为三角数 T_s,且由 s 步 nil-流的 Lévka–Mozes 型常数显式。
