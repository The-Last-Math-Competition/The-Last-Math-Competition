# 00000009536

**English.** Definition: Single-shot information-spectrum capacity uses the Han-Verdu information spectrum: the one-shot optimum code is characterized by smooth max-entropy, and the smoothing converges to the regularized capacity over n uses. Conjecture: The finite-n correction of the smooth information-spectrum capacity to the regularized capacity is Theta(1/sqrt n), with the correction constant explicitly given by the channel spectral gap; and the ratio of one-shot to asymptotic capacity on random d-dimensional channels concentrates on an explicit limit c(d) inside (1/2, 1). (single-shot information-spectrum correction)

**中文。** 定义：单次信息谱容量以 Han–Verdú 信息谱定义：一次使用时最优码由平滑最大熵刻画，n 次使用的平滑量收敛到正则化容量。猜想：平滑信息谱容量对正则化容量的有限 n 修正为 Θ(1/√n)，修正常数由信道谱间隙显式给出；n=1 单次容量与 n→∞ 容量之比在随机 d 维信道上集中于 (1/2,1) 内的显式极限 c(d)。（单次信息谱修正）
