# 00000009923

**PHT-13 ★** — source: 316_持久同调II_统计与稳定性.md

**English.** Definition: Kernel embeddings of persistence diagrams: the characterization of kernel methods. Conjecture: A persistence diagram kernel is universal if and only if its feature map separates orbits of persistence diagrams, with orbit separation realized by measure separation on the birth-death plane; the minimal feature width of universal kernels is one-dimensional. (persistence kernel universality criterion)

**中文。** 定义：持久图核嵌入：核方法的特征刻画。猜想：持久图核为普适当且仅当其特征映射分离持久图的轨道且轨道分离由出生-死亡平面的测度分离实现；普适核的最小特征宽度为一维。（持久核普适判据）
