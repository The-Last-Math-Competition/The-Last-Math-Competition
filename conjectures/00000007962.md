# 00000007962

**CD3-02 ★** — source: 251_编码理论III_列表解码与局部译码.md

**English.** Definition: A (k,delta)-LDC (locally decodable code) is an encoding map where each bit can be recovered with probability 1/2 + delta by querying k positions. Conjecture: The length lower bound n >= 2^{Omega(m)} (m the message length) for 2-query LDCs is asymptotically attained by Hadamard-type constructions (exponential optimality); and for k at least 3 the optimal length lies between m^{1+o(1)} and 2^{m^{Omega(1)}}, with the separation realized by Reed-Muller powers matching lower bounds: the optimal exponent at k = 3 is 1/2 (a dichotomy matching the m^2 upper bound of Reed-Muller type). (LDC length exponent separation)

**中文。** 定义：局部可译码（LDR）(k,δ)-LDC 为每比特可通过查询 k 个位置以概率 1/2+δ 恢复的编码映射。猜想：2-查询 LDC 的长度下界 n ≥ 2^{Ω(m)}（m 为消息长）由 Hadamard 型构造渐近取得（指数最优）；且 k≥3 时的最优长度为 m^{1+o(1)} 与 2^{m^{Ω(1)}} 之间的分离由匹配下界的 Reed–Muller 次方实现：k=3 的最优指数为 1/2（Reed–Muller 型匹配 m² 上界的二分法）。
