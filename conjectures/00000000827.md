# 00000000827

**English.** Definition: The stability constant of the Sobolev inequality is the optimal c in ||u − u*||² ≥ c·inf. Conjecture: This optimal constant equals an explicit ratio λ₂/λ₁ of the second eigenvalue of the linearized operator on the Sobolev extremal manifold, in closed form c of the type 2^{-2/n}·n/(n+2); the Bianchi–Egnell bound is attained at this value.

**中文。** 定义：Sobolev 不等式稳定性常数指 ||u−u*||² ≥ c·inf 的最优 c。猜想：该最优常数为 Sobolev 极值流形上线性化算子的第二特征值 λ₂/λ₁ 的显式比,数值上 c = 2^{-2/n}·n/(n+2) 型闭式;Bianchi–Egnell 的界在该值处达到。
