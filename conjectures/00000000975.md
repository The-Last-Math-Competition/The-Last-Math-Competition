# 00000000975

**English.** Conjecture: For any polynomial p on n × n matrices, the ratio C(p) of the sup norm to the matrix sup equals 1 if and only if deg p ≤ 2 (the threshold of matrix hyper-reflexivity; deg ≤ 2 is trivially known).

**中文。** 猜想：n × n 矩阵上任意多项式 p 的 sup/矩阵 sup 比值 C(p) = 1 当且仅当 deg p ≤ 2(矩阵超反射的阈值,已知 deg ≤ 2 平凡)。
