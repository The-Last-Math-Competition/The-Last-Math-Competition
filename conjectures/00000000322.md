# 00000000322

**DA-22 ★** — source: 19_丢番图逼近与度量数论.md

**English.** Definition: L(α) is the Lagrange constant of α. Conjecture: For every c > 0, the set {α : L(α) = c} is either empty or consists entirely of a finite union of SL₂(Z) orbits.

**中文。** 定义：L(α) 为 α 的 Lagrange 常数。猜想：对每个 c > 0,集合 {α : L(α) = c} 要么空,要么完全由某个 SL₂(ℤ) 轨道的有限并组成。
