# 00000008822

**CVX-22 ★** — source: 279_凸优化的迭代复杂度.md

**English.** Definition: The Pataki rank bound for extreme points of SDP feasible regions: the upper bound structure of the rank r of extreme points of {X positive semidefinite: tr(A_i X) = b_i} with m equality constraints. Conjecture: Extreme point ranks satisfy r(r+1)/2 <= m, i.e. r does not exceed ceil((sqrt(8m+1)-1)/2); the bound is tight — explicit instances exist where some extreme point has rank exactly that value; minimal-rank solutions always exist in the solution set of any feasible SDP; and the Frank-Wolfe trajectory from a feasible point reaches an epsilon-accurate decomposition of rank not exceeding the bound within O(1/epsilon) steps. (Pataki rank tightness Frank-Wolfe decomposition)

**中文。** 定义：半定规划可行域极值点的 Pataki 秩界：m 个等式约束 {X⪰0: tr(A_i X)=b_i} 下极值点秩 r 的上界结构。猜想：极值点秩满足 r(r+1)/2 ≤ m，即 r 不超过 ⌈(√(8m+1)-1)/2⌉；该界为紧——存在显式实例使某极值点秩恰等于该值；任何可行 SDP 的解集中最小秩解恒存在；从可行点出发的 Frank–Wolfe 轨迹在 O(1/ε) 步内到达 ε 精度的秩不超过该界的分解。
