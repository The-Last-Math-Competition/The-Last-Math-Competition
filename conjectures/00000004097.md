**English.** Definition: A weighted configuration is a deformed configuration with a weight-potential function. Conjecture: The weighted Poincare polynomial is a piecewise linear function of the weight parameters, with breakpoint coordinates an explicit finite set of ratios of adjacent weights. (breakpoint set of the weighted Poincare polynomial)
