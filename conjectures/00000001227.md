# 00000001227

**English.** Definition: Undirected vertex geography is the game of moving a token on a graph while deleting visited vertices. Conjecture: Its outcome (whether the first player wins) is characterized by the perfect matchings of the graph and the matching-covered property of the start vertex: the first player wins if and only if the start belongs to every maximum matching; this criterion extends Fraenkel's edge version to the vertex version.

**中文。** 定义：无向点地理指在图上移动棋子并删除已访问顶点的博弈。猜想：其胜负(先手胜否)由图的完美匹配与起点的匹配覆盖性刻画:先手胜当且仅当起点属于一切最大匹配;该判据把 Fraenkel 的边版推广到点版。
