# 00000001210

**English.** Definition: The graph of an SG sequence g(n) is the planar point set {(n, g(n))}, whose box dimension is defined under scale oscillation. Conjecture: There exists an octal game for which the renormalized limit of the graph of g in windows [N,2N]×[0,N^{1/2}] has dimension strictly between 0 and 1; specifically, the graph of game 4.7 has dimension 1/2.

**中文。** 定义：SG 序列 g(n) 的图指平面点集 {(n, g(n))},其盒维数在尺度振荡下定义。猜想：存在 octal 博弈使 g 的图在窗 [N, 2N]×[0, N^{1/2}] 的重整极限具有严格介于 0 与 1 的维数;具体地,博弈 4.7 的图维数为 1/2。
