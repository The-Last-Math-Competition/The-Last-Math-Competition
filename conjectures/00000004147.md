# 00000004147

**English.** Definition: A normal iteration tree is a tree-shaped iteration keeping the iteration strategy normal. Conjecture: The height upper bound of a normal iteration tree is an explicit function of the base cardinal, and the bound is attained at the smallest non-normal tree counterexample. (height bound of normal iteration trees)

**中文。** 定义：正常迭代树指保迭代战略正常的树形迭代。猜想：正常迭代树的高度上限为底基数的显式函数,上限在最小非正常树反例处达到。（正常迭代树高度上限）
