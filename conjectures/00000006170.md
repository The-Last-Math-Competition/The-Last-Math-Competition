# 00000006170

**English.** Definition: The asymptotic main order and sub-leading term are two layers. Conjecture: There exist two counting classes with the same main order but different sub-leading terms, and the separation is realized by an explicit class pair with the same main order but different singularity neighborhoods. (same main order-different singular-neighborhood separation)

**中文。** 定义：渐近主阶与次首项指两层。猜想：存在两类计数的主阶相同而次首项不同,分离由同主阶异奇点邻域的显式组合类对实现。（主阶同-次首项异奇点邻域分离）
