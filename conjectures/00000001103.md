# 00000001103

**LT-03 ◆** — source: 27_李理论与代数群.md

**English.** Definition: Brenti's combinatorial formula for KL polynomials expresses P_{x,w} as a weighted sum over BR-sequences (sequences satisfying the bounce condition). Conjecture: The number of nonzero terms of this sum is exactly half the number of BR-sequences satisfying the bounce-path count, and each term's denominator divides q−1; this yields a cancellation-free combinatorial model for KL polynomials.

**中文。** 定义：Brenti 的 KL 组合公式把 P_{x,w} 表为 BR-序列(满足反弹条件的序列)上的带权和。猜想：该和式的非零项个数恰为满足 bounce 路径计数的 BR-序列数的一半,且每一项的分母整除 q−1;这给出 KL 多项式的一个无消去组合模型。
