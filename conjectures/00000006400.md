# 00000006400

**English.** Definition: The a priori order and a posteriori spectrum are two layers. Conjecture: There exist two mixed elements with the same a priori order but different a posteriori spectra, and the separation is realized by an explicit pair with the same order but different jump quantities. (same a priori order-different jump separation)

**中文。** 定义：先验阶与后验谱指两层。猜想：存在两混合元的先验阶相同而后验谱不同,分离由同阶异跳量的显式对实现。（先验阶同-后验谱异跳量分离）
