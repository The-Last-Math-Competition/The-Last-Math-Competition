# 00000002870

**English.** Definition: The index in noncommutative geometry: local index formulae for spectral triples. Conjecture: The cobordism of local indices: the Connes–Chern character is a cyclic cocycle whose coboundary is the analytic correction; the correction vanishes if and only if the triple is summable. (local index cobordism)

**中文。** 定义：非交换几何的指标：谱三元组的局部指标公式。猜想：局部指标的余边缘性：Connes–Chern 特征为循环上闭链且闭链的余边缘为解析修正项；修正项的消没当且仅当三元组为可和的。（局部指标余边缘）
