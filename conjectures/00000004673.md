# 00000004673

**English.** Definition: A minimal resolution is one whose exceptional intersection matrix is negative definite. Conjecture: The attainable values of the discriminant of the matrix are exactly the perfect squares, and the set is given explicitly by the type classification of graphs and is closed. (perfect-square set of resolution discriminants)

**中文。** 定义：极小分解指例外相交矩阵负定的极小分辨率。猜想：矩阵判别式的可达值为完全平方的集合,集合由图的型分类显式给出且封闭。（极小分解判别式平方集）
