# 00000000976

**English.** Definition: Spectral multiplicativity sets. Conjecture: A compact set K ⊂ C is a spectral multiplicativity set for all separable Hilbert spaces if and only if K has the connected-spectrum property (a direction toward the complete characterization of S-sets).

**中文。** 定义：谱子乘法集。猜想：ℂ 中紧集 K 为所有可分 Hilbert 空间的谱子乘法集 ⟺ K 连通谱性质(S-集合完全刻画方向)。
