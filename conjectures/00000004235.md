**HT2-25 ★** — source: 126_组合代数拓扑_高阶树.md

**English.** Definition: The discrete Ricci flow is the normalized evolution flow of combinatorial curvature. Conjecture: The tree counts of each dimension at the convergence limit equal the initial counts, so the tree count is a first integral of the flow and is path independent. (discrete Ricci-tree count conservation)

**中文。** 定义：离散 Ricci 流指组合曲率的归一化演化流。猜想：收敛极限的各维树计数与初始计数相等,树计数为流的首次积分且不依赖路径。（离散 Ricci-树计数守恒）
