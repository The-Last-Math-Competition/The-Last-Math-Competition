# 00000008132

**NAG-22 ★** — source: 256_非交换代数几何.md

**English.** Definition: The spectrum of Gorenstein parameters of Yekutieli-Zhang duality for noncommutative varieties: gpl(A), the set of translation parameters of the dualizing complex. Conjecture: gpl is a singleton (parameter uniqueness); the Gorenstein parameter d agrees with the AS-regular dimension (a parameter-dimension agreement); and the exception to integral parameters (fractional parameters of graded Gorenstein) is the half-integer parameter of weighted smash products (a half-integer exception law), the denominator of the half-integers being always 2 (a denominator-2 rigidity). (Yekutieli-Zhang Gorenstein half-integer exception)

**中文。** 定义：非交换簇的 Yekutieli–Zhang 对偶的 Gorenstein 参数的谱：gpl(A)（对偶化复形的平移参数集）。猜想：gpl 为单点集（参数唯一性）；且 Gorenstein 参数 d 与 AS 正则维数一致（参数-维数一致）；参数的非整数（分次 Gorenstein 的分数参数）的例外为 weighted smash 积的半整数参数（半整数例外律），半整数的分母恒为 2（二分母刚性）。
