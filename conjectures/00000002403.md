# 00000002403

**English.** Definition: Eremenko's conjecture states that the escaping set of the exponential map has nonempty components. Conjecture: The conjecture holds; moreover, the critical values (the asymptotic values 0 and ∞ of e^z) are dense on the boundary of every component of the escaping set.

**中文。** 定义：Eremenko 猜想指指数映射的 escaping 集具有非空分支。猜想：该猜想成立;且 escaping 集的每个分支的边界上临界值(即 e^z 的渐近值 0 与 ∞)稠密。
