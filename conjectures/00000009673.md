# 00000009673

**TAG-03 ★** — source: 308_算术超越.md

**English.** Definition: Mahler's method treats values at algebraic points of functions satisfying f(z^p) = R(z, f(z)); the single-prime case is known. Conjecture: Mahler functions in all composite integer-coefficient cases take transcendental values at nonzero algebraic points within the convergence radius, with exceptions only an explicit list where the functional equation degenerates to a rational function; and Mahler values for different primes p are algebraically independent. (complete criterion for Mahler values)

**中文。** 定义：Mahler 方法处理满足 f(z^p)=R(z,f(z)) 的函数在代数点的取值；已知单素数 p 情形。猜想：一切复合整系数情形的 Mahler 函数在收敛半径内的非零代数点取超越值，例外仅为其函数方程退化为有理函数的显式列表；不同素数 p 的 Mahler 值之间代数无关。（Mahler 值完备判据）
