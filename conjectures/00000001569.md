# 00000001569

**English.** Definition: The angle set of a point set is the set of all angles it determines. Conjecture: An n-point set determines at least n² − O(n) distinct angles; and the lower bound is attained by the equidistribution of arguments of lattice families. (angle set n-squared lower bound attained by lattices)

**中文。** 定义：角集指点集确定的所有角度的集合。猜想：n 点集确定至少 n² 减 O(n) 个不同角度；且下界由格点族的辐角等分布达到。（角度集 n 方下界格点达到）
