# 00000001799

**English.** Definition: The Godbillon–Vey class GV is the third-order cohomology class of a foliation. Conjecture: The realizable set of GV values of holomorphic CP² foliations is [0, c_d] (c_d an explicit supremum, attained by rigid foliations of degree d); the interval endpoints cannot be exceeded.

**中文。** 定义：Godbillon–Vey 类 GV 指叶状结构的三阶上同调类。猜想：全纯 CP² 叶状结构的 GV 值的实现集为 [0,c_d](c_d 为显式上确界,由度 d 的刚性叶状结构达到);区间的端点值不可越。
