# 00000001216

**English.** Definition: The 2-angel is a token on Z² that may jump distance ≤ 2 each turn, playing against a devil that blocks squares. Conjecture: On the cylinder Z×[0,2] the 2-angel has an explicit winning strategy, and an oblivious version (depending only on local 7×7 information) exists; the half-plane case likewise holds.

**中文。** 定义：2-angel 指在 Z² 上每次可跳距离 ≤2 的棋子,与封锁格子的魔鬼博弈。猜想：在柱面 Z×[0,2] 上 2-angel 有显式必胜策略,且策略的遗忘式(仅依赖局部 7×7 信息)版本存在;半平面情形同样成立。
