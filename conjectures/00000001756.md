# 00000001756

**English.** Definition: A unimodular submatrix of the character table of S_n is a square submatrix with determinant ±1. Conjecture: Its maximal order d(n) is characterized by the hook-coprimality condition: d(n) = #{λ ⊢ n : hook(λ) pairwise coprime}, an explicit formula; a submatrix of that order can be selected from irreducible-character rows (sorted by dimension).

**中文。** 定义：S_n 特征标表的幺模子方阵指其行列式为 ±1 的方子阵。猜想：其最大阶 d(n) 由钩长互素条件刻画:d(n)=#\{λ⊢n:hook(λ) 互素\} 的显式公式;阶为该数的子方阵可由不可约特征标行列(按维数排序)选取。
